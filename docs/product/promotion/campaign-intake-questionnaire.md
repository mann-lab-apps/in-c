# 공연홍보 파일럿 신청 폼 스펙

작성일: 2026-08-13

## 사용 방식

이 문서는 공연자에게 웹페이지로 입력받을 무료 파일럿 신청 폼의 초안이다.

사용자는 자동화된 서비스처럼 공연 정보를 제출하지만, 첫 MVP에서는 김재만이 뒤에서
수작업으로 공연을 이해하고 홍보 계획을 정리한다. 거짓으로 자동 분석을 약속하지
않고, "검토 후 직접 연락드린다"는 경험으로 설계한다.

## 화면 약속

```text
공연 정보를 보내주시면,
in C가 공연의 관객 타깃과 홍보 채널을 검토해
무료 파일럿 가능 여부와 1차 홍보 방향을 직접 정리해드립니다.
```

CTA:

```text
공연 홍보 파일럿 신청하기
```

제출 후 안내:

```text
신청이 접수되었습니다.
공연 정보와 일정을 확인한 뒤 직접 연락드릴게요.
```

## 필수 입력

| 필드 | 입력 방식 | 메모 |
| --- | --- |
| 신청자 이름 | text | 연락 가능한 실제 이름 |
| 연락처 | text | 전화, 카카오톡 ID, 이메일 중 하나 |
| 공연명 | text | 공개 표기 기준 |
| 공연 일시 | datetime 또는 text | 날짜만 확정된 경우 text 허용 |
| 공연 장소/지역 | text | 공연장명, 지역 |
| 예매 또는 상세 링크 | url | 없으면 공식 안내 링크 |
| 주최/주관/출연자 표기 | text | 포스터 표기와 다를 수 있음 |
| 공연 소개 한 줄 | textarea | 길게 쓰지 않아도 됨 |

## 포스터와 디자인

포스터 이미지는 파일 업로드를 바로 받기보다, 첫 버전에서는 상태를 체크박스로 받는다.

| 필드 | 입력 방식 | 메모 |
| --- | --- | --- |
| 포스터 디자인 상태 | checkbox/radio | 아래 옵션 중 선택 |

옵션:

- 포스터 디자인을 이미 맡겼고, 홍보에 사용할 이미지가 있다.
- 포스터 디자인은 아직 없고, 디자인 의뢰가 필요하다.
- 포스터 디자인은 필요 없고, 텍스트 중심 홍보만 원한다.

디자인이 없는 경우:

- in C가 연결 가능한 디자이너에게 맡길 수 있다.
- 홍보 파일럿은 무료로 진행하되, 디자인비는 별도로 받는다.
- 디자인비 범위와 일정은 접수 후 별도 안내한다.

인쇄가 필요한 경우:

- 인쇄는 기본 범위에 포함하지 않는다.
- 필요한 경우 별도 요청으로 받고, 비용과 수량을 확인한 뒤 진행한다.

## 선택 입력

| 필드 | 입력 방식 | 메모 |
| --- | --- | --- |
| 프로그램/곡 목록 | textarea | 확정 전이면 아는 범위만 |
| 티켓 가격 | text | 무료 공연이면 무료로 표기 |
| 사용할 수 있는 이미지/자료 링크 | url/text | 드라이브, 인스타, 홈페이지 등 |
| 기존 홍보 채널 | textarea | 이미 올린 곳이 있으면 적음 |
| 홍보 시작 희망일 | text/date | 급하면 비고에 적음 |
| 추가 요청사항/비고 | textarea | 어려운 점, 주의 문구, 요청사항을 자유롭게 작성 |

## 제외하는 질문

첫 폼에서는 다음 질문을 빼둔다.

- 홍보 예산 여부
- 가장 오면 좋겠는 관객
- 지금 가장 어려운 홍보 문제

이 질문들은 추상적이고 사용자가 답하기 어려울 수 있다. 필요한 내용은
`추가 요청사항/비고`나 후속 대화에서 자연스럽게 받는다.

## 내부 후속 확인

폼 제출 후 김재만이 직접 확인할 항목:

- 공연일이 너무 임박하지 않은가?
- 예매/상세 링크가 정상 동작하는가?
- 포스터 디자인 상태가 명확한가?
- 디자인비가 필요한 경우 상대가 비용을 이해했는가?
- 인쇄 요청이 있는 경우 수량, 일정, 비용을 별도로 확인했는가?
- 홍보에 쓰면 안 되는 이미지/문구/정보가 있는가?
- 공연자가 결과 리포트를 받을 수 있는 연락처를 남겼는가?

## 데이터 저장 방식

첫 버전에서는 다음 중 가장 빠른 경로를 택한다.

1. 정적 웹 폼 + Formspree/Google Forms/Google Sheet 연동
2. 정적 웹 폼 + Supabase insert
3. 정적 웹 폼 + 이메일 전송 서비스

로그인, 공연 등록 CRUD, 관리자 페이지는 만들지 않는다.

## 대화로 보완할 질문

폼 제출 후 필요하면 아래를 후속 대화에서 확인한다.

- 이번 공연에서 가장 기대하는 장면은 무엇인가?
- 비전공자가 붙잡아도 좋은 포인트가 있는가?
- 이미 홍보한 채널이 있는가?
- 공연 종료 후 결과를 언제 공유하면 좋은가?
