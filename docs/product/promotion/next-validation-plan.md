# 다음 검증 계획

작성일: 2026-08-18

## 목적

이번 검증의 목적은 in C가 풀려는 문제가 이미 충분히 해결된 문제인지 먼저 확인하는
것이다. 특히 소규모 클래식 공연 홍보의 기본값이 Instagram이라면, 다음 질문을 먼저
검증한다.

```text
Instagram은 이미 충분한 해결책인가,
아니면 연주자가 어쩔 수 없이 쓰는 최선의 기본값인가?
```

이미 충분히 해결된 문제라면 in C가 굳이 풀지 않는다. 반대로 Instagram, 예매처,
KOPIS, Club Balcony, 범용 광고 도구가 있음에도 소규모 공연자에게 반복되는 빈칸이
남는다면 그때만 in C의 가설로 올린다.

## 검증 순서

```text
강자/대체재 확인 -> Instagram 현실 확인 -> 공연자 인터뷰 -> Insights 수집 ->
작은 수동 노출 -> 결과 리포트 -> 유료 제안
```

제품은 이 순서를 지나기 전까지 만들지 않는다.

## 핵심 판별

### 버릴 문제

다음이 확인되면 공연홍보 가설은 우선순위를 낮춘다.

- 연주자들이 Instagram, 예매처, Club Balcony, 광고 도구를 이미 잘 쓰고 있다.
- 기존 도구의 결과를 이해하고 다음 홍보 판단에 활용하고 있다.
- non-follower reach와 link click이 충분하다고 느낀다.
- 추가 홍보 대행이나 in C식 노출에 돈을 낼 이유가 약하다.
- 문제는 홍보가 아니라 작품성, 일정, 가격, 장소, 인지도에 더 가깝다.

### 남는 문제

다음이 반복되면 in C가 더 검증할 만하다.

- Instagram이 사실상 최선이지만 기존 팔로워/지인 반응에 갇힌다.
- 홍보를 더 하고 싶지만 알아보고 비교하고 실행할 attention이 없다.
- 광고 도구는 존재하지만 직접 세팅하기 귀찮거나 불안하다.
- reach는 보여도 누가 봤고 다음에 뭘 해야 하는지 모르겠다.
- 작은 금액이라도 관련 관객에게 더 닿고 결과를 정리받고 싶다.

## Phase 1. Instagram 사용 현실 확인

### 대상

- 최근 6개월 안에 독주회, 실내악, 학생 공연, 작은 기획 공연을 홍보한 연주자 5명
- 가능하면 전공/악기/공연 규모가 겹치지 않게 고른다.

### 질문

```text
최근 공연 홍보에서 Instagram이 사실상 최선의 방법이었나요?
```

이어 묻는다.

- 홍보는 언제부터 시작했는가?
- Instagram 외에 실제로 한 홍보는 무엇인가?
- 더 해보고 싶었지만 못 한 홍보가 있었는가?
- 못 한 이유는 시간, 비용, 방법 모름, 효과 불신, 귀찮음 중 무엇인가?
- 유료 광고를 고려했는가?
- Meta/Instagram 광고를 직접 세팅할 수 있다고 느꼈는가?
- 공연 이후 무엇이 효과 있었는지 알 수 있었는가?

### 기록 기준

| 항목 | 기록 |
| --- | --- |
| 공연 유형 | 독주회 / 실내악 / 학생 공연 / 기획 공연 |
| 홍보 시작 시점 | D-몇 주 |
| 기본 홍보 채널 | Instagram / 카톡 / 포스터 / 예매처 / 기타 |
| 추가 홍보 포기 이유 | 시간 / 비용 / 효과 불신 / 방법 모름 / 기타 |
| 유료 광고 경험 | 있음 / 없음 / 고려만 함 |
| Instagram 만족도 | 충분 / 아쉬움 / 모르겠음 |
| 다음 공연에서 맡길 의향 | 있음 / 조건부 / 없음 |

## Phase 2. Instagram Insights 수집

### 대상

Phase 1 중 동의한 3명 이상.

### 수집할 지표

가능하면 최근 공연 홍보 게시물 1-3개의 캡처를 익명으로 받는다.

- accounts reached
- follower reach
- non-follower reach
- profile visits
- link clicks 또는 profile link taps
- saves
- shares
- comments
- DMs/inquiries

### 해석

| 관찰 | 해석 |
| --- | --- |
| follower reach 비중이 높고 non-follower reach가 낮다 | 관계망 안쪽 홍보에 머물 가능성 |
| reach는 높지만 link click/save/share가 낮다 | 노출은 됐지만 공연 행동으로 이어지지 않았을 가능성 |
| save/share가 있다 | relevant audience가 있을 수 있는 약한 신호 |
| DM/문의가 있다 | 예매 전환에 가까운 강한 정성 신호 |
| 게시물별 반응 차이가 크다 | 카피/작품 맥락/이미지 개선 여지가 있음 |

### 주의

Instagram 지표는 추정치이고, 실제 관객 증가를 직접 증명하지 않는다. 따라서 이 단계의
목표는 성과 판정이 아니라 `기존 홍보의 reach 구조`를 보는 것이다.

## Phase 3. 강자/대체재 플로우 확인

### 확인할 제품

- Instagram promotion / Meta Boost
- 당근 피드광고
- 네이버 지역소상공인/플레이스 광고
- 카카오톡 채널 메시지
- KOPIS/예매처/Club Balcony 노출 경로

### 기록할 것

| 제품 | 공급자가 해야 하는 결정 | 최소 비용 | 결과 지표 | 클래식 소규모 공연 적합도 | 메모 |
| --- | --- | --- | --- | --- | --- |
| Instagram promotion | 대상, 예산, 기간, 목적 | 확인 필요 | reach, click, engagement | 확인 필요 |  |
| 당근 피드광고 | 지역, 예산, 소재 | 확인 필요 | 노출, 클릭 등 | 확인 필요 |  |
| 네이버 지역 광고 | 업체/장소 연동, 지역, 예산 | 확인 필요 | 노출, 클릭 등 | 낮을 수 있음 | 공연장이 아니라 개인 공연자일 때 확인 |
| 카카오 채널 메시지 | 채널 친구, 메시지, 발송수 | 확인 필요 | 발송/클릭 등 | 기존 친구 기반 | 신규 관객 확장에는 한계 가능 |

### 판별 질문

```text
이 제품들이 이미 소규모 클래식 공연자의 문제를 충분히 해결하는가?
```

충분히 해결한다면 in C는 이 영역을 버린다. 충분히 해결하지 못한다면 이유를 고객의
언어로 기록한다.

## Phase 4. 관객 missed discovery 확인

### 대상

- 클래식에 약간 관심 있는 사람 10명
- 전공자 3명, 취미 음악인 3명, 라이트 관객 4명 정도로 섞는다.

### 방법

최근 종료된 실제 소규모 공연 4개를 보여준다.

- 무료 또는 1만원대 학생/청년 공연
- 소극장/살롱 공연
- 실내악 또는 독주회
- 작품이나 출연진 맥락이 설명 가능한 공연

### 질문

- 이 공연을 공연 전에 알고 있었는가?
- 몰랐다면, 공연 전에 봤으면 관심이 생겼을까?
- 실제로 갈지 고민했을 가능성은 어느 정도인가?
- 가지 않았을 이유는 가격, 시간, 거리, 동행자, 작품 정보 부족, 예매 번거로움 중 무엇인가?
- 이런 공연을 어디서 알려주면 덜 부담스럽게 볼 것 같은가?

### 성공 신호

10명 중 4명 이상이 `몰랐지만 미리 알았다면 관심은 있었을 것`이라고 답하면 latent
audience 가설을 계속 본다. 단, 관심과 실제 관람은 다르므로 바로 수요로 단정하지 않는다.

## Phase 5. 작은 수동 노출

### 조건

공연자 1명에게 허락을 받고, 공연 1건을 수동으로 홍보한다.

### 실행

- 공연 포스터와 공식 링크 확보
- 작품/연주자/장소/가격 맥락 정리
- 타깃 2-3개 정의
- Instagram, 개인 네트워크, 커뮤니티, 블로그/Columns 중 2개 이하 채널에서 작게 배포
- 추적 가능한 링크 또는 채널별 링크를 사용

### 기록

- 배포 채널
- 카피/이미지
- 노출 가능한 경우
- 클릭
- 저장/공유
- 문의/DM
- 공식 링크 이동
- 공연자 피드백

### 성공 신호

초기 성공은 관객 증가가 아니다. 다음 중 2개 이상이면 다음 사이클로 간다.

- 클릭/저장/공유/문의 중 하나 이상이 발생
- 공연자가 결과 리포트를 이해하고 유용하다고 말함
- 다음 공연에서도 다시 이야기해보고 싶다고 말함
- 무료가 아니라면 얼마까지 가능한지 구체적인 금액 또는 조건이 나옴

## Phase 6. 유료 제안

무료 PoC가 끝난 뒤 반드시 묻는다.

```text
다음 공연에서 같은 방식으로 진행한다면, 무료가 아니라 얼마까지는 맡길 수 있을까요?
```

금액보다 이유를 더 중요하게 기록한다.

| 답변 | 해석 |
| --- | --- |
| 0원 | 고마운 도움일 뿐 구매가치 약함 |
| 1만원 이하 | 작은 편의 가치는 있으나 사업성 약함 |
| 1만-3만원 | 소규모 깃발 가격 실험 후보 |
| 5만-10만원 | Concierge MVP 유료 전환 후보 |
| 10만원 이상 | 명확한 결과/대행 가치가 있을 가능성 |

## 이번 검증의 최종 판단

2주 뒤 다음 중 하나로 결론낸다.

1. `이미 해결됨`: Instagram/기존 광고/예매처로 충분하다. 공연홍보 우선순위를 낮춘다.
2. `문제는 있으나 구매 약함`: 불편은 있지만 돈을 낼 정도는 아니다. 콘텐츠/커뮤니티 쪽으로 돌린다.
3. `작은 유료 가능성`: 소규모 공연자에게 zero-decision distribution을 1만-10만원 범위로 더 검증한다.
4. `강한 Concierge 가능성`: 반복 의뢰와 10만원 이상 WTP가 보인다. 수동 대행을 더 한다.
