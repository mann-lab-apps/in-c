# 공연홍보 캠페인 기록과 결과 리포트 템플릿

작성일: 2026-08-13

## 사용 방식

이 템플릿은 첫 공연홍보 Concierge MVP를 끝까지 완주하기 위한 기록지다. 처음에는
Notion, Google Docs, Google Sheet 중 아무 곳에나 옮겨 써도 된다.

중요한 것은 예쁜 대시보드가 아니라, 어떤 가설로 어디에 홍보했고 어떤 반응을 얻었는지
공연자에게 설명할 수 있는 기록을 남기는 것이다.

## 2. 캠페인 목표

이번 캠페인의 목표는 무엇인가?

- 공연 인지 늘리기
- 예매 링크 클릭 만들기
- 특정 지역 관객에게 알리기
- 특정 악기/장르 관심층에게 알리기
- 공연자/단체의 다음 홍보 방식을 배우기

한 문장 목표:

```text
이번 캠페인은 _______에게 _______ 공연을 알리고, _______ 반응을 확인한다.
```

## 10. 피드백 질문

공연자에게 결과 전달 후 물어볼 질문:

1. 이번 홍보 과정에서 가장 도움이 된 부분은 무엇이었나요?
2. 별로 도움이 안 됐거나 기대와 달랐던 부분은 무엇이었나요?
3. 결과 리포트에서 더 보고 싶은 정보가 있었나요?
4. 다음 공연에도 이런 방식으로 한 번 더 해볼 의향이 있나요?
5. 돈을 낸다면 어떤 부분에 돈을 낼 수 있을 것 같나요?
