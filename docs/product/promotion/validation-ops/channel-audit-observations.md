# 공개 채널/대체재 표본 관찰 메모

작성일: 2026-08-19

## 목적

`channel-audit.csv`의 30건 공개 표본을 해석하기 위한 메모다. 이 표본은 시장 대표성을
증명하지 않는다. 목적은 기존 대체재가 이미 충분히 해결한 영역을 먼저 버리고, 아직 직접
검증할 가치가 있는 빈칸만 남기는 것이다.

## 현재 집계

`npm run validation:ops` 기준:

| 지표 | 값 | 해석 |
| --- | ---: | --- |
| 공개 채널 관찰 표본 | 30/30 | 목표 표본 수 충족 |
| 대체재 빈칸 관찰 | 23/30 | 일부 빈칸이 반복되지만, 이는 수동 검증 전 보조 신호다 |
| 수동 매칭용 공급 정보 후보 | 9/9 | 공개 링크 기반 후보를 확보했지만, 일부는 종료 표본이라 missed discovery 질문용이다 |

## 관찰한 대체재

| 대체재 | 관찰 | in C에 주는 의미 |
| --- | --- | --- |
| 서울문화포털/세종문화회관/예술의전당/롯데콘서트홀 | 공연 상세, 일정, 장소, 티켓 정보는 잘 노출된다 | 단순 공연 DB나 공연장 캘린더는 만들 이유가 약하다 |
| 티켓링크 등 예매처 | 대형/기획 공연의 예매 전환 경로는 강하다 | in C는 예매 직전 플랫폼이 아니라 예매 전 발견/맥락/알림으로 봐야 한다 |
| Contest 계열 콩쿠르 목록 | 콩쿠르와 대회 정보는 목록형으로 꽤 모인다 | 콩쿠르 DB 자체보다 개인 조건에 맞는 마감 알림이 남는 질문이다 |
| Obri | 구인, 레슨, 반주, 종교음악, 포트폴리오, 오디션/콩쿠르를 직접 다룬다 | 구인/레슨 게시판 문제는 이미 강한 대체재가 있다 |
| 숨고/레슨 플랫폼 | 범용 레슨 매칭과 견적 요청 흐름이 있다 | 일반 레슨 매칭은 직접 경쟁하면 불리하고, 클래식 맥락/전공자 조건이 핵심이어야 한다 |
| 음악예술인 프로필 플랫폼 | 프로필, 메시지, 팔로우, 레슨 소개 흐름이 있다 | 프로필 자체보다 프로필이 기회 정보와 연결되는 순간을 봐야 한다 |

## 이미 해결된 것으로 낮춰야 할 영역

- 일반 공연 일정 목록
- 대형 공연 예매 경로
- 단순 음악인 구인구직 게시판
- 피아노/바이올린 레슨 구인 목록
- 범용 레슨 매칭
- 콩쿠르 목록 자체

## 아직 남는 질문

공개 표본만으로는 아래 질문이 풀리지 않았다.

- 소규모 공연자가 기존 공연장/예매처 노출만으로 relevant audience에 닿는가?
- 수요자는 검색하지 않아도 자기 조건에 맞는 공연/레슨/구인/공고를 받을 때 유용하게
  느끼는가?
- 공급자는 조회수보다 더 구체적인 저장, 공유, 문의, 클릭, 재등록 의향 같은 반응을
  원하고 돈을 낼 수 있는가?
- Obri가 있어도 구인/레슨/공연/공고가 같은 관심 그래프 위에서 흐를 여지가 있는가?
- 알림이 단순 광고가 아니라 허락 기반 정보 흐름으로 받아들여지는가?

## 현재 해석

공개 채널 관찰만 놓고 보면 in C의 초기 문제정의는 더 좁아져야 한다.

```text
클래식/음악 정보가 온라인에 없다
```

는 약하다. 대신 남는 가설은 다음에 가깝다.

```text
정보와 대체재는 있지만, 수요자가 검색하기 전에는 놓치고 공급자는 적절한 사람에게
닿았는지 이해하기 어렵다.
```

따라서 다음 검증은 제품이 아니라 사람 반응이어야 한다.

1. 공급자에게 기존 대체재를 알고도 안 쓰는지, 써도 아쉬운지 묻는다.
2. 수요자에게 정말 핏이 맞는 정보라면 알림이 유용한지 묻는다.
3. 실제 2주 수동 매칭에서 클릭, 저장, 공유, 문의, 계속 수신 요청이 생기는지 본다.

수동 매칭용 공개 후보 9개는 `opportunity-inventory.csv`에 따로 옮겼다. 공연 2건과 대타
공고 1건은 이미 종료된 표본이라 실제 홍보 발송보다는 `미리 알았다면 관심이 있었는가`
질문에 사용한다.

## 1차 판단

공개 채널 관찰 단계만 기준으로는:

```text
대체재가 충분히 있는 영역이 확인됐고, 동시에 맞춤 알림/반응 리포트의 빈칸은 아직 열려 있다.
```

따라서 현재 판단은 `알림/매칭 구조 가능성 있음`이 아니라 `데이터 부족`이다. 다만
이후 인터뷰에서 Obri, 공연장, 예매처, Instagram으로 충분하다는 답이 많으면
`이미 해결됨` 또는 `문제는 있으나 플랫폼 구조 약함`으로 내려야 한다.
