# 대체재 대비 in C 포지셔닝 메모

작성일: 2026-08-19

## 목적

이 문서는 `final-judgement.md`의 `대체재 대비 판단` 섹션에 옮길 1차 정리다. 목적은
in C가 이길 수 있는 이야기를 만드는 것이 아니라, 이미 충분히 해결된 문제를 먼저 버리고
사람 데이터로만 검증할 수 있는 빈칸을 남기는 것이다.

현재 결론은 다음이다.

```text
홍보, 검색, 공고, 레슨, 프로필은 이미 여러 대체재가 상당 부분 해결한다.
in C에 남는 질문은 정보 자체가 아니라, 클래식 맥락의 relevant audience에게
검색 전, 허락 기반으로, 이해 가능한 반응과 함께 흐를 수 있는가다.
```

## 대체재별 판단

| 대체재 | 이미 해결한 것 | 아직 증명되지 않은 빈칸 | in C 판단 |
| --- | --- | --- | --- |
| Instagram | 연주자가 자기 관계망에 포스터를 가장 쉽게 올리는 기본 채널 | 관계망 밖의 맞는 관객에게 충분히 닿는지, 관심 없는 지인에게 과노출되는 문제가 있는지, 공연자가 반응을 해석할 수 있는지 | 인스타를 대체하지 않는다. 인스타가 놓치는 `관계망 밖 relevant reach`만 검증한다. |
| 당근 | 지역 기반 소상공인/생활권 노출, 간편 광고, 검색 광고, 비즈프로필 | 클래식 관심, 악기, 작품, 전공/취미 수준 같은 음악 맥락으로 충분히 나뉘는지 | 지역 광고로 해결되는 공연/레슨은 낮춘다. 음악 맥락 타게팅이 필요한 long-tail만 본다. |
| 네이버 | 업체 정보 관리, 지역소상공인 광고, 검색/플레이스 기반 발견 | 이미 찾고 있는 사람이 아니라 아직 모르는 relevant audience에게 닿는지 | 검색 수요가 분명한 레슨/업체형 공급은 낮춘다. 검색 전 알림 가설만 남긴다. |
| 카카오톡 채널 | 이미 친구가 된 고객에게 메시지를 보내는 운영 채널 | 아직 관계가 없는 수요자를 발견하는 데 충분한지 | 기존 고객 관리 문제는 낮춘다. 신규 relevant audience 발견은 별도 검증한다. |
| 예매처/공연장/문화포털 | 공연 상세, 일정, 장소, 예매 경로, 대형 공연 발견 | 소규모/무료/학생 공연이 충분히 발견되는지, 관심자에게 검색 전 도달하는지 | 공연 DB나 티켓팅은 낮춘다. `발견 전 단계`만 남긴다. |
| Obri | 클래식 음악인 구인, 레슨, 반주, 종교음악, 공고, 포트폴리오 | 수요자가 검색하지 않아도 맞는 공고를 받는지, 공급자가 반응 리포트와 재등록 가치를 느끼는지 | 구인/레슨/프로필 게시판은 낮춘다. 알림/반응/관심 그래프만 검증한다. |
| 숨고/레슨 플랫폼 | 범용 레슨 매칭, 견적 요청, 서비스 탐색 | 클래식 전공/입시/악기/작품 맥락까지 충분히 설명되는지 | 범용 레슨 매칭은 낮춘다. 전문 조건 기반 레슨 발견만 본다. |

## 인스타 관찰의 정확한 위치

사용자 관찰은 `인스타에서 연주회 홍보가 너무 많이 보여 불편하다` 자체가 핵심 문제가
아니다. 이는 음대 출신 관계망 때문에 생긴 특수한 경험일 수 있다.

더 중요한 신호는 다음이다.

```text
공급자는 가장 쉬운 관계망 채널에 반복적으로 올리지만,
그 노출이 정말 맞는 사람에게 충분히 닿았는지는 불확실하다.
```

따라서 인터뷰 질문은 `인스타 홍보가 불편한가`가 아니라 아래처럼 가야 한다.

- 최근 공연/레슨/구인 정보를 인스타에 올렸는가?
- 인스타에 올린 이유는 쉬워서인가, 효과가 좋아서인가, 다른 대안이 없어서인가?
- 관계망 밖의 사람에게 더 닿고 싶었는가?
- 누가 봤고 어떤 반응이 있었는지 충분히 이해했는가?
- 지인에게 반복 노출되는 것에 부담이 있었는가?
- 인스타 외에 돈을 쓰거나 다른 채널을 알아볼 여유가 있었는가?

## 당근 판단의 정확한 위치

당근은 in C의 좋은 비교 대상이지만, 동일한 제품은 아니다. 당근은 동네 기반 공급과 간편
광고가 강하다. 그러므로 in C는 `당근보다 싼 광고`가 아니라 아래 빈칸만 검증해야 한다.

```text
같은 지역 안에서도 클래식 관심, 악기, 수준, 작품, 목적 기준으로 나눴을 때
알림 효용과 반응률이 유의미하게 달라지는가?
```

수동 매칭에서 이 차이가 안 보이면 당근식 지역 홍보로 충분하다고 보고 공연 홍보 범위를
낮춰야 한다.

## Obri 판단의 정확한 위치

Obri는 단순 참고 대상이 아니라 구인/레슨/프로필 영역의 강한 선행 시도다. 따라서 아래
답변이 반복되면 in C는 해당 영역을 낮춰야 한다.

- `Obri면 충분하다.`
- `공고는 올리면 알아서 연락이 온다.`
- `조회수 정도면 충분하다.`
- `따로 푸시나 매칭까지는 필요 없다.`
- `프로필은 Obri나 인스타 링크면 된다.`

반대로 아래 답변이 반복될 때만 in C의 남는 영역이 생긴다.

- `올렸지만 맞는 사람이 봤는지 모르겠다.`
- `검색해서 들어오는 사람만으로는 부족하다.`
- `내 악기/지역/수준에 맞는 사람에게 직접 알려지면 좋겠다.`
- `조회수보다 저장, 공유, 문의, 지원자 질, 재등록 의향을 알고 싶다.`
- `공연, 레슨, 구인 이력이 한 사람의 활동 맥락으로 이어지면 좋겠다.`

## 버릴 영역 후보

지금 상태에서 아래는 in C MVP에서 낮추는 것이 맞다.

- 일반 공연 캘린더
- 대형 공연 예매/티켓팅
- 공연장/예매처 상세 페이지 복제
- 콩쿠르 전체 목록
- 음악인 구인구직 게시판
- 일반 피아노/바이올린 레슨 공고 목록
- 범용 레슨 매칭
- 단순 음악인 프로필 페이지
- 광고관리자형 캠페인 생성 UI

## 남길 영역 후보

사람 데이터로 계속 볼 영역은 아래뿐이다.

- 검색하지 않아도 받는 맞춤 공연/레슨/구인/공고 알림
- 악기, 지역, 수준, 목적, 작품/장르 기반의 설명 가능한 관심 조건
- 공급자가 `어디에 올릴지` 결정하지 않아도 되는 zero-decision distribution
- 수요자가 허락한 빈도 안에서 받는 relevant opportunity feed
- 조회수보다 이해 쉬운 반응 리포트: 클릭, 저장, 공유, 문의, 지원, 계속 수신 요청
- 공연/레슨/구인/공고가 같은 관심 그래프 위에서 흐르는지에 대한 수동 검증

## 인터뷰에서 바로 확인할 반증 질문

공급자에게:

- 인스타, Obri, 예매처, 카톡방 중 현재 제일 충분한 채널은 무엇인가?
- 충분하다면 왜 추가 채널이 필요 없는가?
- 충분하지 않다면 부족한 것은 노출량, 맞는 사람, 신뢰, 피드백, 비용, 시간 중 무엇인가?
- 같은 결과라면 직접 광고를 세팅하는 것과 맡기는 것 중 무엇이 나은가?
- `조회수 300`과 `관심 조건이 맞는 사람 20명 중 저장 4명/문의 1명` 중 어느 쪽이 더 유용한가?

수요자에게:

- 지금도 인스타, 예매처, Obri, 네이버 검색으로 충분한가?
- 놓친 적이 있다면 정보가 없어서였나, 찾아볼 생각을 못 해서였나?
- 어떤 조건이 맞으면 알림이 광고가 아니라 정보로 느껴지는가?
- 한 달에 몇 번부터 부담스러운가?
- 공연에 가지 않아도 저장, 공유, 나중에 보기, 지인에게 전달할 가치가 있는가?

## 수동 매칭에서 봐야 할 차이

아래 차이가 관찰되어야 in C의 남는 영역이 강해진다.

| 비교 | in C에 유리한 신호 | in C에 불리한 신호 |
| --- | --- | --- |
| 지역만 맞춘 발송 vs 악기/수준/목적까지 맞춘 발송 | 후자에서 저장/답장/공유가 더 잘 생김 | 지역만 맞아도 반응 차이가 거의 없음 |
| 공연만 발송 vs 공연/레슨/구인 혼합 발송 | 같은 사람이 여러 유형에 관심 조건을 설명할 수 있음 | 유형마다 완전히 다른 참여자와 조건이 필요함 |
| 조회수 리포트 vs 약한 행동 리포트 | 공급자가 약한 행동 리포트를 더 신뢰함 | 조회수나 감으로 충분하다고 답함 |
| 검색 링크 제공 vs 직접 DM 알림 | 직접 알림을 계속 받아도 된다는 반응이 있음 | 검색하면 되니 알림은 싫다는 반응이 우세 |
