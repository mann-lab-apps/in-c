# Q3 공연홍보 후보 목록

작성일: 2026-08-13

## 목적

Q3 공연홍보 Concierge MVP의 첫 공연 1건을 확보하기 위한 연락 후보 목록이다.
이 목록은 CRM이 아니라, 실제로 연락하고 반응을 기록하기 위한 가벼운 운영 문서다.

## 상태 값

| 상태 | 의미 |
| --- | --- |
| 후보 | 아직 연락하지 않음 |
| 연락 예정 | 연락 문구와 타이밍을 정함 |
| 연락함 | 첫 메시지를 보냄 |
| 관심 있음 | 공연 정보 공유 가능성이 있음 |
| 보류 | 지금은 어렵거나 일정 미정 |
| 진행 | 캠페인 후보 공연이 정해짐 |
| 완료 | 캠페인 1사이클 완료 |

## 연락 후 기록할 것

- 연락일
- 어떤 관계 맥락으로 이야기했는지
- 공연 일정이 있는지
- 무료 파일럿에 관심을 보였는지
- 바로 받을 수 있는 공연 정보가 있는지
- 다음 연락 날짜
- 거절/보류 이유

## 제안 원칙

제안문은 후보마다 관계가 다르므로 고정 템플릿을 쓰지 않는다. 다만 핵심 제안은
다음 범위를 벗어나지 않는다.

```text
공연 하나를 무료로 홍보해보고,
어디에 어떻게 알렸고 어떤 반응이 있었는지 결과까지 정리해서 보여주겠다.
```

첫 연락의 목표는 설득이 아니라, 실제로 홍보할 공연 1건을 받을 수 있는지 확인하는 것이다.
