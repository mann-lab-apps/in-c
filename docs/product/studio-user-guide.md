# 띠로리 Studio 사용 안내와 단축키

앱의 도움말 → 단축키 도움말에서 같은 안내를 볼 수 있습니다. 이 문서는 현재 Studio 구현 기준이며 MuseScore 전체 단축키와 동일하지 않습니다.

먼저 음표를 선택합니다. N으로 입력 모드에 들어가면 숫자는 다음 입력 음가를 정하고 A–G는 새 음을 넣습니다. Esc로 나온 선택 모드에서는 숫자와 A–G가 선택한 표기를 수정합니다. 입력창에 커서가 있으면 텍스트 편집이 우선입니다.

Mac의 Option은 Alt, ⌘는 Command입니다. Windows/Linux에서는 Ctrl과 Alt를 사용합니다. 옥타브 이동은 **Mac ⌘+↑/↓ / Windows·Linux Ctrl+↑/↓**입니다. 단순 ↑/↓는 반음 이동이며 Alt+↑/↓는 보표 선택 이동입니다.

## 음높이·옥타브 이동

| 작업 | 키 / 조작 | 적용 대상과 주의점 |
| --- | --- | --- |
| 한 옥타브 올리기/내리기 | Mac: ⌘+↑/↓ · Windows/Linux: Ctrl+↑/↓ | 음표 또는 동일 화음 전체를 선택한 상태에서 사용합니다. |
| 조성에 맞춰 한 음 이동 | Option/Alt+Shift+↑/↓ | 온음계 순서로 이동합니다. |
| 반음 올리기/내리기 | ↑ / ↓ | 반음 단위로 이동합니다. |
| 음 이름 변경 | A–G | 선택 모드에서는 선택 음표를 변경하고, 입력 모드에서는 다음 음표를 넣습니다. |
| 화음 구성음 추가 | Shift+A–G | 입력 모드를 끝내고 단일 음표/화음을 선택한 뒤 사용합니다. |
| 이명동음 표기 바꾸기 | J | 실제 음높이를 유지하며 표기를 바꿉니다. |

## 음표 입력·음가

| 작업 | 키 / 조작 | 적용 대상과 주의점 |
| --- | --- | --- |
| 음표 입력 시작/종료 | N · Esc | N으로 입력 모드를 전환하고 Esc로 선택 모드로 돌아옵니다. |
| 음가 선택 | 1=64분 · 2=32분 · 3=16분 · 4=8분 · 5=4분 · 6=2분 · 7=온음표 | 선택 모드에서는 선택 음가를 바꾸고, 입력 모드에서는 다음 입력 음가를 정합니다. |
| 쉼표 입력/변환 | 0 또는 R | 입력 모드에서는 쉼표를 넣고, 선택 모드에서는 선택 음표를 쉼표로 바꿉니다. |
| 점 추가/제거 | . / , | 선택 음표 또는 다음 입력의 점 개수를 바꿉니다. |
| 셋잇단음표 | ⌘/Ctrl+3 | 선택 리듬에 적용하거나 셋잇단음표 입력을 준비합니다. Esc로 입력을 취소합니다. |
| 타이 추가/해제 | T | 현재 지원하는 같은 음높이의 단음/동일 화음을 연결합니다. |
| 슬러 시작/끝 지정 | S | 시작 음표를 고르고 S, 끝 음표를 고르고 다시 S를 누릅니다. |

## 꾸밈음

| 작업 | 키 / 조작 | 적용 대상과 주의점 |
| --- | --- | --- |
| 선택 음표 앞에 붙이기/제거 | Option/Alt+G | 상단 꾸밈음 버튼과 같습니다. 본음의 음가는 변하지 않습니다. |
| 기존 음표를 꾸밈음으로 변환 | Option/Alt+Shift+G | 같은 마디의 다음 음표에 붙이고 뒤 음표를 당긴 뒤 끝을 쉼표로 채웁니다. 한 번의 실행 취소로 복원합니다. |
| 현재 지원 범위 | 8분음표 모양의 빗금 꾸밈음 | 변환은 부착 표기가 없는 단음부터 지원합니다. 타이·잇단음표·범위 기호 경계 등 불가능한 조건은 버튼 설명으로 확인하세요. |

## 선택·보표·성부

| 작업 | 키 / 조작 | 적용 대상과 주의점 |
| --- | --- | --- |
| 앞/뒤 음표로 이동 | ← / → | 선택을 옮깁니다. Shift를 함께 누르면 범위를 확장합니다. |
| 위/아래 보표로 이동 | Option/Alt+↑/↓ | 같은 시점에 가까운 표기로 선택을 옮깁니다. 화음 내부 구성음별 선택은 지원하지 않습니다. |
| 범위 선택 | Shift+클릭 · Shift+←/→ | 시작과 끝 사이를 선택합니다. |
| 다음/이전 성부 | V / Shift+V | 현재 보표에서 성부를 순환합니다. |
| 성부 직접 선택 | ⌘/Ctrl+Alt+1–4 | 1–4성부 중 선택합니다. 입력/선택 상태에 따른 기존 제한을 따릅니다. |
| 악보와 도구 사이 이동 | F6 | 악보·도크·입력 도구의 현재 위치에 따라 포커스를 옮깁니다. |
| 현재 입력/선택 취소 | Esc | 잇단음표·슬러의 미완결 입력을 끝내고 선택 모드로 돌아옵니다. |

## 박자표·변박자

| 작업 | 키 / 조작 | 적용 대상과 주의점 |
| --- | --- | --- |
| 선택 마디 박자 변경 | 마디 우클릭 → 박자표 변경… | 열린 박자표 목록에서 3/4, 6/8 등 필요한 값을 고릅니다. |
| 적용 범위 | 선택 보표의 선택 마디만 | 이후 마디와 다른 보표는 그대로입니다. 총보의 공통 변박자는 각 보표의 같은 마디를 변경해야 합니다. |
| 다른 진입 경로 | 팔레트 → 음자리표·조표·박자표 → 박자표 설정 열기 | 마디 길이에 맞지 않는 기존 음표가 있으면 변경이 거부됩니다. 실행 취소로 복원할 수 있습니다. |

## 재생

| 작업 | 키 / 조작 | 적용 대상과 주의점 |
| --- | --- | --- |
| 재생/일시정지 | Space | 선택 음표/쉼표가 있으면 그 위치를 우선합니다. 입력창·버튼·메뉴 안에서는 해당 조작이 우선합니다. |
| 정지·처음으로·따라가기 | 상단 재생 컨트롤 | 화면에 표시된 버튼을 사용합니다. 구현되지 않은 전역 단축키는 안내하지 않습니다. |
| 수동 스크롤 후 따라가기 복귀 | 따라가기 버튼 | 스크롤바를 누르거나 직접 스크롤하면 자동 추적을 중단합니다. 버튼으로 다시 시작합니다. |

## 파일·실행 취소·입력 확정

| 작업 | 키 / 조작 | 적용 대상과 주의점 |
| --- | --- | --- |
| 현재 형식으로 저장 | ⌘/Ctrl+S | 프로젝트 또는 MusicXML의 현재 저장 상태를 따릅니다. 프로젝트 파일을 새로 만들려면 파일 메뉴의 프로젝트 저장을 사용하세요. |
| 프로젝트 다른 이름 저장 | ⌘/Ctrl+Shift+S | 프로젝트 문서에서 사용합니다. |
| 실행 취소 | ⌘/Ctrl+Z | 마지막 편집 한 번을 되돌립니다. |
| 다시 실행 | ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y | 실행 취소한 편집을 다시 적용합니다. |
| 복사/붙여넣기 | ⌘/Ctrl+C / ⌘/Ctrl+V | 입력창에서는 텍스트 편집이 우선입니다. 악보에서는 지원하는 선택 객체를 복사합니다. |
| 삭제 | Delete / Backspace | 선택한 객체에 맞는 삭제를 실행합니다. 음표 삭제는 리듬을 보존합니다. |
| 속성 입력 확정/취소 | Enter·포커스 이동 / Esc | 숫자·텍스트 draft를 확정하거나 취소합니다. 범위 밖 값은 자동 보정하지 않는 필드의 안내를 확인하세요. |
| 빠르기 입력 | 40–240 bpm의 정수 | 새 악보 입력 중에는 숫자를 자동 보정하지 않습니다. 오류를 수정해야 만들 수 있고 Esc는 마지막 유효값을 복원합니다. |

## 메뉴·주의할 점

| 작업 | 키 / 조작 | 적용 대상과 주의점 |
| --- | --- | --- |
| 메뉴 이동 | ←/→ · ↑/↓ · Home/End · Enter/Space · Esc | 메뉴 제목 사이 이동, 항목 선택/실행, 닫기 순서로 사용합니다. |
| 메뉴 명령 찾기 | 도구 → 명령 검색 | 메뉴에서 찾기 어려운 작업을 검색합니다. 사용 가능한 실제 명령만 표시합니다. |
| 텍스트·한글 조합 중 | 입력창의 편집 우선 | 한글 조합 중에는 전역 음악 명령을 실행하지 않습니다. 미확정 입력은 먼저 확정한 뒤 저장하세요. |
| MuseScore와 다른 지원 범위 | 화음 구성음별 선택·Shift+↑/↓ 보표 범위 확장 미지원 | 음높이 이동은 MuseScore 방식입니다. 기존 ⌘/Ctrl+Alt+↑/↓는 옥타브를 바꾸지 않습니다. |

## 음가 확대와 덮어쓰기

선택한 음표의 음가를 늘릴 때 뒤 음표와 겹치면 확인창이 열립니다. 취소하면 악보는 바뀌지 않습니다. 적용하면 겹치는 뒤 음표 전체와 그 음표의 부착 표기가 대체되고 남는 공간은 쉼표가 됩니다. 겹치지 않는 음표의 위치와 다른 마디·성부는 유지하며 실행 취소 한 번으로 복원할 수 있습니다. 타이·잇단음표·범위 기호 경계나 마디를 넘는 확대는 제한될 수 있습니다.

이 확인 단계는 현재 Studio의 보호 장치입니다. MuseScore의 기본 덮어쓰기와 완전히 같은 조작이라고 설명하지 않습니다. 근거: [공식 음표 편집 설명](https://handbook.musescore.org/basics/editing-notes-and-rests).

## 저장과 사본 출력

프로젝트(.chromatics), MusicXML 사본, PDF/PNG/MIDI는 서로 다른 결과입니다. 사본 출력 성공은 프로젝트 저장 완료가 아닙니다. 저장 취소·실패 때는 악보와 변경 사항을 유지합니다. 빠르기 등 미확정 입력이 있으면 먼저 입력을 확정하거나 Esc로 취소한 뒤 저장하세요.

꾸밈음은 현재 8분음표 모양의 빗금 표기이며 본음의 박자를 차지하지 않습니다. 개별 꾸밈음 음가 편집이나 미지원 부분 화음 타이를 지원한 것으로 읽지 않습니다.

현재 꾸밈음은 표기와 프로젝트/MusicXML 보존을 지원합니다. 내부 재생/MIDI의 꾸밈음 별도 발음은 이번 변경에 추가하지 않았습니다.
