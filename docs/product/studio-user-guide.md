# 띠로리 Studio 사용 안내와 단축키

기능 기준 alpha.40의 빠른 진입 안내입니다. 전체 정본은 [사용설명서 목차](studio-manual/README.md), [기능 색인](studio-manual/feature-index.md), [단축키 전체 참고](studio-manual/10-shortcuts.md)입니다.

**도움말 → 사용설명서** 메뉴에서 alpha.40의 전체 설명서를 열 수 있습니다. 단축키만 확인하려면 **도움말 → 단축키 도움말**을 선택하세요.

## 음높이·옥타브 이동

[반음·온음계·옥타브·보표 이동의 차이](studio-manual/03-notes.md#pitch)를 확인하세요. 음표 선택 상태와 가사/입력창 상태를 구분합니다.

## 음표 입력·음가

[입력/선택 모드](studio-manual/03-notes.md#input-mode), [음가·점·쉼표](studio-manual/03-notes.md#duration), [셋잇단음표](studio-manual/03-notes.md#tuplet)를 확인하세요.

## 꾸밈음

[붙이기와 기존 음표 변환](studio-manual/03-notes.md#grace)은 다른 명령입니다. 내부 재생/MIDI의 별도 꾸밈음 발음은 지원 범위와 구분합니다.

## 선택·보표·성부

[선택](studio-manual/02-workspace.md#selection), [성부](studio-manual/03-notes.md#voices), [필터](studio-manual/02-workspace.md#filters)를 확인하세요.

## 박자표·변박자

[마디 우클릭 → 박자표 변경…](studio-manual/04-structure.md#meter)에서 선택 보표의 한 마디만 바뀝니다. 총보/이후 마디 자동 전파와 사용자 지정 박자는 미지원입니다.

## 재생

[재생 컨트롤](studio-manual/07-playback.md#transport), [따라가기](studio-manual/07-playback.md#follow), [믹서](studio-manual/07-playback.md#mixer)를 확인하세요.

## 파일·실행 취소·입력 확정

[프로젝트 저장](studio-manual/09-files.md#project), [undo/redo](studio-manual/03-notes.md#history), [draft 확정/취소](studio-manual/06-properties.md#drafts)를 구분합니다.

## 메뉴·주의할 점

[메뉴·명령 검색](studio-manual/02-workspace.md#menus), [문제 해결](studio-manual/11-troubleshooting.md), [지원 범위](studio-manual/12-reference.md#limits)를 참고하세요.

## 음가 확대와 덮어쓰기

[뒤 음표와 겹치는 음가 확대](studio-manual/03-notes.md#overwrite)의 확인/취소와 보호 조건을 읽고 진행하세요. MuseScore의 확인 없는 기본 덮어쓰기와 완전히 같은 동작은 아닙니다.

## 저장과 사본 출력

[프로젝트](studio-manual/09-files.md#project), [XML](studio-manual/09-files.md#xml-save), [MIDI](studio-manual/09-files.md#midi), [PDF](studio-manual/09-files.md#pdf), [PNG](studio-manual/09-files.md#png)는 서로 다른 결과입니다.

직접 따라 하려면 [연습 악보](studio-manual/examples/README.md)와 [사용자 확인표](studio-manual/13-checklist.md)를 사용하세요. 사용자 확인란은 비워 두었습니다.
