# 직접 확인하기

사용자 확인란은 비워 두었습니다. 에이전트 자동/프로그램 검증과 사용자가 직접 확인한 결과는 별도입니다.

예제는 [manual-practice.musicxml](examples/manual-practice.musicxml)로 시작할 수 있습니다. native 파일이 필요하면 가져온 뒤 프로젝트로 저장하세요. 시작/wizard 과제는 새 악보로 진행합니다.

<a id="focus"></a>
## 악보·도구·도크 사이 포커스

- [ ] 설명 읽음
- [ ] 직접 동작 확인
- [ ] 막힌 점 기록

[설명과 단계](02-workspace.md#focus)

**준비:** 예제 또는 새 악보. 기능에 맞는 단음/마디/범위를 선택합니다.

1. 악보로 이동 버튼이나 F6을 사용합니다
2. Tab으로 도구와 입력 필드를 이동합니다
3. 일반 선택 모드에서 음표에 Tab으로 초점을 옮긴 뒤 Enter로 선택합니다
4. 슬러·헤어핀의 연결 조각에 초점을 옮겨 Enter 또는 Space로 선택합니다
5. 음표에 초점이 있을 때 Space는 현재 선택 기준의 재생·일시정지인지 확인합니다
6. 작업이 끝나면 도크의 악보 복귀 또는 F6으로 돌아옵니다

**기대 결과:** Tab의 초점 이동만으로 기존 선택을 바꾸지 않습니다. 음표·쉼표는 Enter로 선택하고, Space는 현재 선택 기준의 재생·일시정지입니다. 슬러·헤어핀 조각에서는 Enter·Space 모두 표기를 선택하며 재생을 시작하지 않습니다. 입력창·열린 선택 목록·대화상자는 해당 컨트롤의 키 동작이 우선입니다.

4. Escape 또는 닫기로 이전 control에 복귀합니다

**기대 결과:** 본문은 앱에 번들되며 외부 참고 링크를 제외한 읽기에 인터넷이 필요 없습니다. 단축키 표는 기존 도움말과 같은 원본입니다.

**확인자·앱 버전·날짜·막힌 점:** 직접 작성하세요.

<a id="practice-loop"></a>
## 선택 구간 연습 루프

- [ ] 설명 읽음
- [ ] 직접 동작 확인
- [ ] 막힌 점 기록

[설명과 단계](07-playback.md#practice-loop)

**준비:** 반복·볼타와 경계 타이가 없는 정렬된 총보.

1. 같은 보표·성부의 연속 구간을 선택하고 연습 루프를 켭니다.
2. 마지막 음의 끝과 다음 회차의 시작, 빠르기·메트로놈을 확인합니다.
3. 일시정지·처음으로·정지·해제와 악보 수정 후 구간 해제를 확인합니다.
4. 프로젝트·출력에는 연습 루프가 포함되지 않는지 비교합니다.

**기대 결과:** 확정한 구간을 총보로 반복하며, 원본 음악과 실행 취소 기록은 바뀌지 않습니다. 지원하지 않는 조건은 이유를 안내합니다.

<a id="print-profiles"></a>
## 이름 있는 출력 설정 프리셋

- [ ] 설명 읽음
- [ ] 직접 동작 확인
- [ ] 막힌 점 기록

[설명과 단계](08-layout.md#print-profiles)

**준비:** 두 파트가 있는 임시 악보. 현재 총보/선택 파트를 확인합니다.

1. 현재 설정을 새 이름으로 저장한 뒤 다른 설정으로 바꿉니다.
2. 목록 선택만으로 악보가 바뀌지 않는지 확인하고, 명시적으로 적용합니다.
3. 한 번의 undo/redo, 파트 독립성, 같은 설정 재적용의 no-op를 확인합니다.
4. 창과 앱을 재열어 목록을 확인하고 프로젝트 저장/재열기의 적용값과 구분합니다.

**기대 결과:** 목록 관리는 기기 로컬 상태이며 적용만 악보를 바꿉니다. 설정 적용 범위와 소수 반올림을 안내합니다.

<a id="editing-shortcuts"></a>
## 편집 단축키 재지정·해제·복원

- [ ] 설명 읽음
- [ ] 직접 동작 확인
- [ ] 막힌 점 기록

[설명과 단계](02-workspace.md#editing-shortcuts)

**준비:** 사용자 원본이 아닌 임시 악보. 음표·선택한 선·마디의 삭제 의미를 먼저 확인합니다.

1. 편집의 단축키 설정에서 삭제를 선택해 예약되지 않은 키를 지정합니다.
2. 옛 Delete/Backspace가 해제되고 새 키만 기존 삭제를 실행하는지, 한 undo로 복원되는지 확인합니다.
3. 속성 도크 버튼에서도 같은 키가 적용되는지, 입력창·Select·IME에 값이 새지 않는지 확인합니다.
4. 선택 명령 해제·기본값 복원·앱 재열기와 다른 5명령 설정 보존을 확인합니다.

**기대 결과:** 키 설정은 프로젝트·dirty·undo를 바꾸지 않습니다. 마디 선택의 삭제는 현재 마디를 제거하며 별도의 표기 지우기 메뉴와 다릅니다.


<a id="voice-move"></a>
## 선택 음표를 빈 성부로 옮기기

- [ ] 설명 읽음
- [ ] 직접 동작 확인
- [ ] 막힌 점 기록

[설명과 단계](03-notes.md#voice-move)

**준비:** 한 마디의 일반 단음 하나와 다른 빈 성부.

1. 기존 상단 성부 버튼이 입력 위치만 바꾸는지 확인합니다.
2. 원래 음표를 다시 선택하고 별도 성부 이동에서 대상을 고릅니다.
3. 이동 후 원래 자리의 쉼표·같은 박의 새 성부 음표·실제 발음을 확인합니다.
4. undo/redo와 프로젝트 저장·재열기로 음표와 이웃 내용을 비교합니다.

**기대 결과:** 기존 내용을 덮어쓰지 않고 단일 일반 음표만 이동합니다. 미지원 대상은 이유를 안내하며 수정하지 않습니다.

헤어핀 적용 범위를 바꾸는 성부 이동은 중간 음표에서도 거부되어야 합니다. 거부 뒤 원본·선택·수정 이력이 유지되는지 확인하세요.
