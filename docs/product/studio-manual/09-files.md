# 파일과 출력

기능 기준: alpha.40. 메뉴 이름과 아래 적용 범위를 함께 확인하세요.

이 버전은 별도로 지정된 파트 이름·약칭의 표시 설정을 보존하지 못하면 한국어로 안내합니다. 악보단마다 표시를 바꾸는 설정도 이 안내에 포함됩니다. 이름·약칭에 직접 지정된 숨김·글꼴·위치 서식도 보존되지 않으면 안내합니다. 정식 파트 이름·약칭과 재생 의미는 유지하지만, 별도 표시의 글자·임시표·서식을 복원하지는 않습니다. 원본 MusicXML을 보관하고 표시와 다시 내보낸 파일을 비교하세요. 원래 주소와 표시 설정 값은 **기술 정보**에서 확인할 수 있습니다.

이 버전의 읽기 글자 선택: 경고·기술 정보·파일 결과의 보이는 글자를 선택한 동안 Delete/Backspace와 사용자 지정 삭제 키는 뒤의 악보를 지우지 않습니다. 화살표·PageUp/PageDown·Home/End도 선택한 안내 글자의 탐색에 남아 뒤의 음표·선택을 바꾸지 않습니다. 문서 저장과 실행 취소는 기존 단축키를 유지합니다. 악보를 편집하려면 **보기 → 악보로 이동**으로 돌아가세요. 글자 선택이 없거나 명시적으로 악보에 초점을 옮긴 경우에는 기존 악보 삭제가 적용됩니다.

이 버전의 저장 취소: 파일 오류의 기술 정보를 읽다가 프로젝트 또는 MusicXML 저장을 취소하면 같은 안내의 접힌 **기술 정보** 버튼으로 초점을 돌려줍니다. 다른 입력·열기 작업이나 수동 스크롤로 이동했다면 그 새 작업을 우선합니다. 취소는 편집 내용과 실행 취소 기록을 바꾸지 않습니다.

이 버전의 경고 읽기: **기술 정보**와 접힌 경고 목록에서는 화살표·Page Up/Down·Home/End가 악보 음높이·선택을 바꾸지 않도록 분리했습니다. 펼치기는 Enter/Space로 조작하고 긴 진단은 기본 스크롤로 읽습니다. 악보를 수정하려면 **보기 → 악보로 이동**으로 돌아가세요. 저장 단축키는 문서 종류에 따릅니다. MusicXML 문서의 ⌘/Ctrl+S와 프로젝트 파일 저장은 서로 다른 결과입니다.

## 최근 파일에서 다시 열기

시작 화면의 **최근 악보**에서 파일명을 선택합니다. 이 버전은 MusicXML을 읽는 동안 해당 행에 **불러오는 중**을 표시합니다. Native 프로젝트를 열 때는 **프로젝트 열기**의 **처리 중** 표시를 확인할 수 있습니다.

다른 최근 항목을 선택하면 나중에 선택한 파일이 우선합니다. 앞선 읽기가 늦게 끝나도 새 항목의 진행 표시를 지우거나 앞선 파일을 다시 열지 않습니다. 새 악보 만들기나 다른 열기 작업을 시작한 경우에도 새 작업을 우선합니다.

**파일을 찾을 수 없음**이 표시되면 파일 위치를 확인하고 원래 위치로 복원한 뒤 같은 항목을 다시 선택하세요. 재시도 중에는 **불러오는 중**으로 바뀌고, 다시 실패하면 파일 없음 표시로 돌아갑니다. **목록에서 지우기**로 최근 항목을 정리할 수 있습니다. 목록 정리는 진행 중인 읽기를 취소하지 않습니다. 읽던 MusicXML 항목이 목록에서 사라져도 최근 악보 영역에 파일명과 **불러오는 중** 안내가 남습니다. 읽기가 끝나면 파일이 열리고 최근 목록에 다시 기록됩니다.

## 프로젝트 열기·저장·다른 이름 저장

**찾는 곳:** 파일 → 프로젝트 열기/저장/다른 이름으로 저장

1. 프로젝트 파일을 엽니다
2. 편집 후 프로젝트 저장을 실행합니다
3. 새 이름을 원하면 프로젝트 다른 이름으로 저장을 고릅니다
4. 파일을 다시 열어 선택한 형식과 내용을 확인합니다

- **결과·적용 범위:** native .chromatics는 배치와 편집 상태를 보존하는 프로젝트입니다. ⌘/Ctrl+S는 현재 문서 형식에 맞춰 저장합니다.
- **단축키:** ⌘/Ctrl+S, 프로젝트에서 ⌘/Ctrl+Shift+S
- **안 되거나 다른 결과가 나오면:** 저장 중·해당 파일 기능을 사용할 수 없음·미확정 draft에서는 비활성/안내가 나옵니다. 저장 실패/취소는 문서·dirty·선택·undo를 유지합니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#project)에서 예제·기대 결과와 대조하세요.

이 버전의 외부 변경 보호: 프로젝트 파일이 앱 밖에서 바뀌면 현재 편집으로 덮어쓰지 않고 저장을 거부합니다. 현재 편집 내용과 실행 취소는 유지됩니다. **파일 → 프로젝트 다른 이름으로 저장**을 선택해 새 파일로 먼저 보관하세요. 원래 파일의 외부 변경을 확인하려면 편집 내용을 보관한 뒤 프로젝트 열기로 다시 여세요. 이 안내는 파일 쓰기 전에 확인된 외부 변경에 적용됩니다. 파일 쓰기 뒤 최근 목록·복구 정리를 마무리하지 못한 오류는 구분하며, 원래 진단은 **기술 정보**에서 확인할 수 있습니다.

이 버전의 MusicXML/MXL 외부 변경 보호: 열거나 성공적으로 저장한 XML 본문이 앱 밖에서 바뀌거나 파일이 없어지면 **MusicXML로 저장**은 덮어쓰지 않고 오류를 안내합니다. 현재 편집·선택·실행 취소는 유지됩니다. **파일 → 내보내기 설정 → MusicXML 내보내기**에서 다른 새 파일로 먼저 보관하고 원래 파일의 외부 변경을 확인하세요. 사본 출력 성공은 프로젝트 저장 완료와 다릅니다. 원래 파일을 다시 가져오면 그때 읽은 내용을 기준으로 저장할 수 있지만, 먼저 현재 편집을 보관해야 합니다. MXL 압축 포장만 바뀌고 XML 본문이 같으면 같은 내용으로 처리합니다. 이 검사는 동시 편집의 자동 병합이나 다중 창·외부 경합의 원자적 보호를 뜻하지 않습니다.

이 버전의 읽기 전용 대상 보호: 기존 프로젝트 또는 MusicXML/MXL 파일에 쓰기 권한이 없으면 파일을 교체하지 않고 오류를 안내합니다. **기술 정보**의 경로·진단을 확인하고, 프로젝트는 **프로젝트 다른 이름으로 저장**, MusicXML은 **내보내기 설정 → MusicXML 내보내기**에서 쓰기 가능한 새 위치를 선택하세요. 해당 파일·위치의 쓰기 권한을 소유자에게 허용된 범위에서 수정한 뒤 같은 작업을 재시도할 수도 있습니다. 실패 시 현재 문서·미저장 변경·선택·실행 취소를 유지하며, 사본 출력 성공은 프로젝트 저장 완료와 다릅니다. [저장 오류 해결 절차](11-troubleshooting.md#save-errors)를 참고하세요.

이 버전의 파트 식별자: 프로젝트에서 사용하는 ID가 MusicXML 식별자 형식에 맞지 않으면 **MusicXML 출력에만** 유효한 ID를 부여합니다. 총보·파트보 사본, 반복 펼치기와 MusicXML 저장에 적용하며 원본 프로젝트의 파트 ID·파트 설정은 바꾸지 않습니다. 유효한 영문·한글 ID는 유지하고 충돌을 피합니다. 내보내기 경고의 **기술 정보**에서 변환 전후 ID를 확인하세요. 외부 파일의 내부 식별자를 이용하는 별도 도구는 새 ID를 확인해야 합니다. 이 변환이 원본 음색·이조·모든 외부 앱 호환성까지 보증하지는 않습니다.

**MusicXML/MXL의 원본과 백업:** MusicXML로 저장은 열어 둔 파일의 경로를 사용할 수 있습니다. 이전 파일이 있으면 백업한 뒤 임시 파일로 교체하며, 백업에 실패하면 원본을 바꾸지 않습니다. 자동 백업은 앱 사용자 데이터 폴더의 `musicxml-backups`에 보관되며 프로젝트 백업 목록과 별개입니다. 현재 지원 모델에 없는 머리 글자 등은 새 저장본에 복원되지 않습니다. 백업만 의존하지 말고 원본을 별도로 보관하며, 다른 파일을 만들려면 MusicXML 사본 내보내기를 사용하세요.

이 버전의 심볼릭 링크 경로: 파일 시스템의 심볼릭 링크로 연 MusicXML/MXL은 링크를 유지하고 실제 연결 대상 파일에 저장합니다. 새 저장·사본의 대상으로 선택한 링크에 아직 대상 파일이 없으면, 저장할 폴더가 존재하고 쓰기 가능한 경우 대상 파일을 새로 만듭니다. 사본 내보내기에서 선택한 링크도 같은 방식으로 처리하지만, 열거나 저장한 원본을 가리키는 링크에는 사본을 덮어쓰지 않습니다. 연결 대상의 쓰기 권한과 백업을 확인하며, 권한 오류 시 링크와 원본 내용을 유지합니다. 일반 Finder 별칭이나 다른 운영체제의 바로가기를 모두 지원한다는 뜻은 아닙니다.

native 파일의 입력 방식: 이 버전은 ‘음높이를 먼저 선택하는 입력 방식’ 설정을 읽었을 때 아직 적용되지 않는다고 안내합니다. 현재는 음가를 고른 뒤 A–G로 음을 넣습니다. 파일의 원래 입력 설정값은 그대로 저장합니다. 백업·native 자동저장 복구에서도 같은 범위를 안내하며, 이 안내가 새 입력 모드의 지원을 뜻하지는 않습니다.

## MusicXML·MXL 가져오기와 원본 보호

이 버전은 제목·작곡가·파트 이름·약칭의 일반 글자와 CDATA·처리 지시문이 만나는 곳에서도 단어 사이 공백을 유지합니다. 바깥 공백 정리, 빈 작품 제목의 우선순위, 작곡가 역할은 기존 정책을 따릅니다. 내부 DTD 선언값의 참조를 모두 복원하는 지원과는 다른 범위입니다. 원본과 다르게 `&word;` 같은 이름이 제목·가사에 남으면 내부 선언값의 참조가 해석되지 않은 것일 수 있습니다. 이 버전은 확인된 내부 선언 참조가 이름으로 남으면 원래 주소·참조 이름·건수를 기술 정보에 안내합니다. CDATA나 이스케이프된 실제 글자를 참조로 오인하지 않도록 구분합니다. 이는 내부 선언값의 글자 복원이 아니며 모든 DTD·XML 규칙 검증도 아닙니다. 원본 MusicXML을 보관하고 글자와 다시 내보낸 파일을 비교해 주세요.

이 버전은 XML 1.0 원문과 직접 숫자 문자 참조에 허용되지 않는 문자가 있으면 가져오기를 중단합니다. 글자를 조용히 지우지 않고 현재 악보·선택·실행 취소를 유지합니다. 이스케이프된 리터럴과 CDATA 안의 문자 참조 모양 글자는 그대로 읽습니다. 기존 Native 프로젝트의 글자를 자동으로 고치는 기능이나 모든 XML 버전·DTD 규칙 검증은 아닙니다.

이 버전은 닫는 태그 누락·잘못된 태그 중첩·중복 속성·여러 최상위 요소·최상위 요소 밖의 글자 등 확인된 XML 문법 오류를 가져오기 실패로 처리합니다. 현재 문서·선택·실행 취소 이력은 유지됩니다. 원본을 보관하고 만든 앱에서 파일을 다시 내보낸 뒤 재시도하세요. 이는 모든 MusicXML 스키마·DTD 규칙이나 외부 앱 호환성의 검증을 뜻하지 않습니다.

장조·단조 이외의 선법이나 비전통 조표가 있는 MusicXML은 현재 가져오기에서 지원하지 않습니다. 이 경우 원본 파일을 보관하고 지원되는 조표를 사용한 사본을 확인하세요. 가져오기가 실패하면 현재 악보·선택·실행 취소 이력은 유지됩니다. 파일이 잘못됐다는 뜻으로만 해석하지 말고 기술 정보의 원래 진단도 확인하세요. 조표를 자동으로 장조·단조로 바꿔 읽는 기능은 아닙니다.

이 버전의 구조 지원 범위: 현재 가져오기는 **파트 우선(score-partwise)** 구조를 지원합니다. **마디 우선(score-timewise)** 구조는 유효한 MusicXML일 수 있지만 현재 가져오기에서는 지원하지 않습니다. 원본을 보관하고 파트 우선 구조로 저장한 사본을 확인하세요. 파일 확장자나 최상위 태그 이름만 바꾸는 것은 구조 변환이 아닙니다. 자동 변환이나 모든 MusicXML 기능 지원을 뜻하지 않습니다.

**찾는 곳:** 파일 → MusicXML 가져오기

1. MusicXML 또는 MXL 파일을 선택합니다
2. 가져오기 결과와 손실 안내를 확인합니다
3. 프로젝트로 저장하거나 사본 내보내기를 선택합니다

- **결과·적용 범위:** 외부 교환 형식과 native 프로젝트는 다릅니다. 읽은 데이터의 보존만 가능한 항목과 직접 편집 가능한 항목을 구분합니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 미지원 내용은 원문·코드·경로를 기술 정보에서 확인합니다. 새 악보를 시작하면 앞선 열기의 늦은 응답을 적용하지 않습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#import)에서 예제·기대 결과와 대조하세요.

원본 마디선 모양: 이 버전은 가져온 이중선·점선·특수 끝선 등 현재 모델에 없는 마디선 스타일을 경고합니다. 경고의 파트·마디를 확인하고 **기술 정보**에서 원래 스타일과 XML 위치를 볼 수 있습니다. 원본 MusicXML을 함께 보관하세요. 일반·기본 반복/볼타 표시와 임의 마디선 스타일 편집은 다른 범위이며, native나 재저장 MusicXML이 원본의 모든 마디선 모양을 보존하는 것은 아닙니다.

온마디 쉼표는 이 버전에서 MusicXML의 그래픽 음가 `type`이 생략돼도 가져옵니다. 현재 마디의 실제 길이와 못갖춘마디를 따릅니다. 일반 음표·쉼표의 음가 누락이나, 여러 마디 쉼표 묶음·교차보표 빔 지원으로 해석하지 마세요.

여러 마디 쉼표의 묶음 지시(`multiple-rest`)는 현재 프로젝트에 보존하지 못합니다. 이 버전은 가져올 때 원래 마디 위치와 손실을 안내하며 각 마디의 쉼표로 표시합니다. 묶음 생성이나 빈 보표 숨김 기능이 추가된 것은 아니므로 원본 MusicXML을 보관하세요.

온마디 쉼표의 원본 길이가 현재 마디 길이와 다르면, 현재 길이로 표시·재생되는 변환을 경고합니다. 원본 길이가 프로젝트나 재저장 XML에 그대로 보존된다는 뜻은 아닙니다. 원본 MusicXML을 별도 보관하고 박자표·실제 마디 길이·재생을 비교하세요. 원래 길이와 XML 경로는 기술 정보에서 확인합니다.

특수 음표 머리의 모양·채움·괄호·SMuFL 지정은 현재 프로젝트 모델에 보존하지 못합니다. 이 버전은 해당 손실을 가져올 때 안내합니다. 원본 MusicXML을 보관하고 음표 모양과 재출력을 비교하세요. 기본 음표 머리의 직접 편집이나 특수 모양 지원이 추가된 것은 아닙니다.

이 버전은 **음표 머리 안의 글자·임시표**도 별도 손실로 안내합니다. 모양이 기본값인 음표나 꾸밈음·화음 구성음에도 원본의 글자는 남지 않을 수 있습니다. 경고의 파트·마디를 확인하고 기술 정보에서 원본 음표 경로를 확인하세요. 현재 모델의 프로젝트 저장이나 사본 내보내기가 원래 글자·서식을 복원하지는 않으므로 원본 MusicXML을 함께 보관하세요. 이 글자를 가사나 일반 표현 글자로 자동 변환하지 않습니다.

기존 native 프로젝트의 TAB 보표 값이 있더라도 **TAB MusicXML 가져오기·저장은 현재 지원하지 않습니다**. 화면과 PDF의 기존 일반 오선 대체 표시는 현·프렛을 가진 TAB 기보가 아닙니다. PDF 파일이 생성됐더라도 원래 TAB 표기가 보존됐다는 뜻이 아니므로 TAB 출력물로 사용하기 전에 원본과 비교하세요. 이 버전은 가져오기 실패 시 기존 문서를 유지하고 원본 MusicXML을 보관하도록 안내합니다. 저장·사본 내보내기가 차단되면 프로젝트 파일로 보관하세요. 원래 clef 진단은 기술 정보에 있습니다. TAB이 없는 파트를 명시적으로 선택한 파트보 사본은 해당 지원 범위에서 별도로 내보낼 수 있으며, 전체 TAB 악보를 지원 형식으로 자동 바꾸지는 않습니다.



아르페지오·동시화음 괄호·글리산도·슬라이드 지시도 현재 프로젝트에 보존하지 못합니다. 이 버전은 가져올 때 원본 위치와 손실을 안내합니다. 일반 화음·타이·슬러로 해당 지시가 복원되는 것은 아니므로 원본 MusicXML을 따로 보관하세요.

### 음표별 악기 지정

이 버전은 MusicXML 음표의 `instrument` 참조를 별도로 보존하지 못하면 원본 위치와 악기 ID를 안내합니다. 현재 파트의 재생 방식은 유지되지만 원본의 악기 전환이나 공유 음표의 여러 악기가 복원되는 것은 아닙니다. 원본 MusicXML을 보관하고 음색과 다시 내보낸 파일을 비교하세요. 한국어 요약을 먼저 읽고 **기술 정보**에서 원래 참조를 확인합니다. 파트 이름·보표 글자를 바꾸는 것과 음표별 악기 지정을 지원하는 것은 다릅니다. 같은 종류의 악기 지정 경고가 여러 개면 요약을 먼저 표시합니다. **악기 지정별 경고 상세 N개**를 펼친 뒤 각 **기술 정보**에서 모든 원래 위치·ID를 확인하세요. 단일 경고나 다른 종류가 섞인 목록은 그대로 표시합니다.

### 무음정 음표와 타악기 가져오기

이 버전은 MusicXML의 무음정 음표(`unpitched`, 타악기·말소리 등)를 아직 가져오지 못합니다. 이 경우 파일이 잘못됐다고 판단하지 않고 현재 지원 범위를 안내합니다. **현재 악보·선택·실행 취소 기록은 유지되므로 원본 MusicXML을 보관하세요.** 원래 진단은 **기술 정보**에서 확인할 수 있습니다.

타악기 음자리표가 보이는 것과 드럼 킷의 악기·음색·음표 머리를 지원하는 것은 다른 범위입니다. 표시 위치를 일반 음높이로 바꿔 읽지 않습니다. 타악기 음자리표만 가진 쉼표 악보의 기존 처리와 MIDI 출력에서 해당 보표를 건너뛰는 정책도 무음정 타악기 연주 지원을 뜻하지 않습니다.

### 원본 마디 폭과 재배치

MusicXML의 마디별 `width` 지정은 현재 프로젝트와 다시 저장한 MusicXML에 보존되지 않습니다. Studio의 현재 배치로 다시 그리므로 원본과 마디 폭·줄바꿈이 같다는 보장이 없습니다. 이 폭 지정만을 위한 별도 가져오기 경고도 현재는 없습니다. 원본 MusicXML을 별도로 보관하고 화면과 출력 결과를 비교하세요. 마디별 고정 폭이나 늘이기 편집을 지원한다는 뜻은 아닙니다.

### 원본 줄기 숨김 지정

이 버전에서는 줄기가 있는 음가에 원본 MusicXML의 줄기 숨김(`stem=none`)이 지정됐지만 보존되지 않는 경우 한국어 손실 요약을 보여줍니다. 원본 MusicXML을 보관하고 가져온 표기·재출력을 비교하세요. 원래 part/measure/note 위치와 영문 진단은 **기술 정보**에서 확인합니다. 이 안내가 줄기 숨김 편집이나 원본 모양 보존을 구현했다는 뜻은 아닙니다. 온음표·쉼표의 기본 무줄기 모양은 이 가시적 손실 검사에서 제외하며, 수동 줄기 방향·길이·쉼표 stemlet·빔 override는 별도 미지원 범위입니다.

숫자저음 가져오기 경계: 원본의 숫자저음 숫자·임시표·연장선·숨김/빈 자리 데이터는 현재 모델에 보존하지 못하며 경고 상세에서 원본 위치를 안내합니다. 기본 화면은 한국어 안내이고 원래 진단과 경로는 기술 정보에 있습니다. 일반 코드(harmony)나 일반 글자와 같은 지원으로 계산하지 마세요. 정규화 사본/프로젝트 저장은 원본 숫자저음 보존이 아닙니다. [지원 경계](12-reference.md#limits)를 확인하세요.

프렛보드 그림 가져오기 경계: 코드 심벌의 근음·종류·베이스와 코드 글자는 현재 지원 범위를 따르지만, 그에 딸린 지판 그림의 현·프렛·바레·손가락 표시는 보존하지 못합니다. 숨긴 그림 데이터도 포함합니다. 경고에서 파트·마디를 확인하고 원본 MusicXML을 함께 보관하세요. 기술 정보에는 원본 데이터 경로가 있습니다. 프로젝트/사본 저장으로 그림이 복원되거나 프렛보드 편집 기능이 추가되는 것은 아닙니다.

페이지 이미지 가져오기 경계: MusicXML의 마디 밖 `credit-image`는 현재 악보에 보존하지 못합니다. 경고에서 원본의 쪽과 데이터 위치를 확인하고 MusicXML과 이미지 파일을 함께 보관하세요. 이미지 URI는 이 안내를 위해 조회하지 않습니다. 마디 안 이미지의 기존 지시 기호 경고와 구분하며, 프로젝트나 사본을 저장했다고 원본 이미지가 복원되는 것은 아닙니다.

가져오기 보호: 결과가 현재 프로젝트의 구조·참조 규칙에 맞지 않으면 기존 문서를 교체하지 않고 오류를 안내합니다. 현재 악보·선택·실행 취소와 프로젝트 경로를 확인한 뒤 원본을 수정하거나 지원되는 사본으로 다시 시도하세요. 유효한 MusicXML이라는 사실과 현재 모델의 지원 범위는 다릅니다. 이 검사는 임의 마디 번호·새 표기 모델의 지원이나 이후 모든 저장의 성공을 보장하지 않습니다.

마디 번호 가져오기 경계: 원본 마디 번호 문구가 내부 번호와 다르거나 명시적인 번호 표시설정이 있으면, 보존하지 못한 내용을 경고 상세에서 안내합니다. 원본 파트·마디와 기술 정보를 확인하세요. 원본 MusicXML을 보관하고 번호 표시와 재내보내기를 비교하세요. 내부 번호와 같은 문구에는 이 손실 경고가 없으며, 프로젝트·사본 저장은 원본 표시설정 복원이 아닙니다.

마디 식별자 정규화: 문자·0·중복 등 내부 주소로 쓸 수 없는 마디 번호가 있으면, 해당 파트 전체를 원본 순서의 1부터 읽습니다. 다른 파트와 고유한 양의 정수 번호는 유지합니다. 원본 표시번호는 그대로 보존되지 않으므로 원본 MusicXML을 보관하세요. 가져오기 후 경고 상세의 한국어 안내를 확인하고, 기술 정보에서 원본 번호와 내부 순서의 대응을 확인할 수 있습니다. 이는 임의 번호를 편집하거나 표시하는 기능이 아닙니다. 이 버전은 조표·음자리표·반복/볼타·없는 성부를 추가하는 편집에서도 이 유효 번호를 유지합니다. 마디를 추가하거나 삭제할 때의 번호 정책은 별개입니다.

저작권 고지 안내: 원본 MusicXML의 권리 메타데이터와 명시적인 저작권 크레디트는 현재 악보·프로젝트·사본에 보존하지 못합니다. 가져오기 경고 상세에서 파일 메타데이터와 해당 페이지 크레디트를 구분해 확인하세요. 기술 정보에는 원본 발생 위치와 종류가 표시됩니다. 원본 MusicXML을 보관하고 고지 내용과 재내보낸 사본을 비교하세요. 프로젝트 저장과 이 안내는 저작권 정보 복원이나 머리말·꼬리말 편집 기능이 아닙니다.

여러 글자 조각 가져오기 경계: 같은 MusicXML `direction-type` 안에서 여러 `words`로 나눈 보표·빠르기 글자는 현재 단일 문자열 모델로 가져오지 못합니다. 서식뿐 아니라 글자 내용이 빠질 수 있으므로 경고의 파트·마디를 확인하고 원본 MusicXML을 보관해 화면과 다시 내보낸 파일을 비교하세요. 기술 정보에는 원본 조각 수와 경로가 있습니다. 임의로 공백을 넣어 합치거나 서식을 복원하지 않습니다. 단일 `words`와 서로 다른 `direction-type`에 있는 기존 글자 읽기는 유지합니다. 프로젝트 저장이나 사본 내보내기로 원본 조각이 복원되는 것은 아니며 고급 글자 서식 편집을 지원한다는 뜻도 아닙니다.

연습표 글자 조각도 같은 경계를 가집니다. 같은 `direction-type`의 여러 `rehearsal`은 글자·서식을 나눈 원본 구성요소일 수 있으며 현재 단일 문자열 모델에 포함되지 않습니다. 손실 경고에서 파트·마디와 기술 정보의 조각 수·경로를 확인하세요. 단일 연습표와 별도 `direction-type`의 기존 읽기는 유지하고, 여러 조각을 임의로 합치거나 여러 새 연습표로 바꾸지 않습니다. 원본을 보관하고 다시 내보낸 표기와 비교하세요.

단일 보표 글자의 굵게 서식 안내: 일반 보표 글자의 `font-weight="bold"`는 현재 보존하지 못하지만 글자 내용은 유지됩니다. 경고에서 파트·마디를 확인하고 원본 MusicXML의 서식과 다시 내보낸 파일을 비교하세요. 시스템 글자의 기존 굵게 표시, 표현 글자의 기울임과 빠르기 글자는 별도 처리합니다. 이 안내는 글꼴·크기·색 등 모든 서식의 손실을 검사하거나 고급 서식 편집을 지원한다는 뜻이 아닙니다.

기울임 서식 안내: 단일 `words`의 명시적인 `font-style="italic"`가 일반·시스템·빠르기·리듬감 글자의 현재 모델과 사본에 남지 않는 경우 경고합니다. 아래쪽 표현 글자의 기존 기울임은 보존합니다. 화면의 기본 모양과 원본 서식 override를 저장하는 것은 다른 범위이므로 원본 MusicXML을 보관하고 재내보내기를 비교하세요. 색 등 모든 서식의 검사나 고급 서식 편집을 추가한 것은 아닙니다.


파트 묶음 가져오기 경계: MusicXML의 `part-group` 지정은 현재 프로젝트와 사본에 별도로 보존하지 못합니다. 원본을 보관하고 묶음·괄호와 다시 내보낸 파일을 비교하세요. 기술 정보에는 원본 시작 지정의 위치·묶음 번호와 이름·기호 등의 값이 있습니다. 중첩 그룹은 각각 안내하며 끝 지정의 자식값을 새 그룹으로 복원하지 않습니다. 한 악기의 다중 보표와 파트 간 묶음은 별개이고, 이 경고가 괄호를 그리거나 `part-symbol`을 포함한 모든 괄호 정보를 보존·편집하는 기능은 아닙니다.

다중 보표 묶음 가져오기 경계: 한 악기의 `part-symbol`이 기본 중괄호와 다른 모양을 지정하거나 일부 보표만 묶으면, 현재 프로젝트와 사본에 별도 보존하지 못하는 것을 안내합니다. 파트 간 `part-group`과 구분하세요. 원본 MusicXML을 보관하고 괄호·포함 보표와 마디선을 비교합니다. 기본 중괄호와 전체 보표 범위를 읽는 것, 지정한 모양과 배치를 그대로 저장하는 것은 다릅니다. 색·임의 위치를 포함한 모든 외형을 검사하거나 복원하는 기능은 아닙니다.

### 코드 심벌의 추가·변경·생략 구성음

이 버전은 MusicXML 코드 심벌의 `degree` 정보를 보존하지 못할 때 안내합니다. 예를 들어 기본 코드에 추가한 음, 변경한 음, 생략한 음의 구조는 현재 코드 글자와 별개입니다. 글자에 이미 표현되어 숨겨진 구성음 정보도 프로젝트나 사본에서 사라질 수 있습니다.

**원본 MusicXML을 따로 보관하고**, 경고의 파트·마디와 **기술 정보**의 원래 값·XML 위치를 확인하세요. 현재 코드 글자가 같다고 구성음 구조까지 보존됐다는 뜻은 아닙니다. 프로젝트 저장·재열기와 사본 내보내기는 잃은 원본 정보를 복원하지 않습니다. 이 안내로 확장 코드 입력·화음 연주 지원이 추가된 것은 아닙니다.

### 숨김으로 지정된 코드 심벌

이 버전에서는 MusicXML에서 숨김(`harmony print-object="no"`)으로 지정한 코드 심벌의 표시 설정을 보존하지 못하면 한국어로 안내합니다. 코드 글자와 현재 모델은 남아도 숨김 상태는 사라져 Studio 화면과 PDF·MusicXML 사본에 나타날 수 있습니다. 원본 MusicXML을 보관하고 경고의 파트·마디와 기술 정보의 원래 값·경로를 확인해 사본을 비교하세요. 기본 표시 또는 명시적 표시(`yes`)는 이 손실로 경고하지 않습니다.

프로젝트 저장·재열기는 현재 모델을 보존하며 잃은 숨김 속성을 복원하지 않습니다. 가져오기 경고가 프로젝트의 숨김 설정으로 저장되는 것도 아닙니다. 이 안내는 코드 숨김 편집이나 코드 실현 연주를 지원한다는 뜻이 아닙니다. 구성음 `degree` 자체의 표시와 프렛보드 그림의 표시는 각각 별도 속성입니다.

### 한 코드 심벌 안에 쌓은 여러 화음

이 버전은 MusicXML의 한 `harmony` 안에 여러 화음 그룹을 쌓은 표기를 보존하지 못하면 안내합니다. 여러 독립 코드 심벌과는 다른 구조이며, 현재 읽은 악보에서 코드 글자도 빠질 수 있습니다. **원본 MusicXML을 별도로 보관하고**, 경고의 파트·마디와 기술 정보의 화음 수·근음·임시표·종류·배치와 다시 내보낸 파일을 비교하세요.

프로젝트 저장·재열기와 사본 출력은 잃은 복수 화음 구조를 복원하지 않습니다. 이 안내는 복수 화음을 독립 코드로 바꾸거나 새 겹친 화음 편집·연주를 추가하는 기능이 아닙니다. 정상 단일 코드와 여러 독립 `harmony`의 기존 읽기는 유지합니다.

### 상대 화성: 로마 숫자와 숫자 코드

이 버전은 MusicXML의 상대 화성(`function`, `numeral`) 정보를 보존하지 못할 때 가져오기 경고를 보여줍니다. 일부 표시 글자를 읽을 수 있어도 원래의 상대 관계나 별도 기준 조성을 지원한다는 뜻은 아닙니다. 경고의 **기술 정보**에서 원래 값과 위치를 확인하고 원본 MusicXML을 함께 보관하세요.

읽은 글자에서 절대 코드 구조를 확인할 수 없으면 MusicXML 저장·사본 내보내기는 기존 오류로 거부됩니다. 음표를 임의로 바꿔 출력하지 않습니다. 현재 읽은 악보는 프로젝트 파일로 보관할 수 있지만, 프로젝트를 다시 열어도 가져오지 못한 상대 화성 정보가 복원되지는 않습니다. 전용 로마 숫자·Nashville 코드 편집이나 연주는 추가하지 않았습니다.

## MusicXML 저장과 사본 내보내기

**찾는 곳:** 파일 → MusicXML로 저장 / 내보내기 → MusicXML

1. 현재 보기(총보/파트보)를 확인합니다
2. MusicXML로 저장 또는 사본 내보내기를 구분해 실행합니다
3. 원본과 다른 경로의 사본을 저장합니다
4. 경고와 파일명을 확인합니다

- **결과·적용 범위:** 사본은 원본 프로젝트를 clean 처리하지 않습니다. 작업 시작 후 추가 편집/보기 변경은 해당 사본에 포함되지 않을 수 있습니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 원본 경로 사본 덮어쓰기는 차단됩니다. 파트 독립 배치 등 손실 안내를 확인하고 native도 보관하세요.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#xml-save)에서 예제·기대 결과와 대조하세요.

숫자 빠르기 왕복: 기존 프로젝트 모델에서 유효한 숫자 빠르기는 MusicXML 왕복에서 반올림하거나40/240으로 바꾸지 않습니다. 새로 편집하는 값의40–240정수 범위와 구분하세요. 모델 밖 수치까지 모두 지원한다는 뜻은 아닙니다. 아래의 문구형 표기 지원 범위를 구분하세요.

기존 빠르기가 새 값 입력 범위 밖이면 보존 안내가 나타납니다. 수정하지 않으면 기존 값이 유지되며, 새로 입력할 때에는40–240 사이의 정수를 사용합니다. 위치별 입력에서 Escape는 원래 값을 복원합니다. 보존 안내 자체는 수정 명령이나 실행 취소 항목을 만들지 않습니다.

## MIDI 내보내기와 손실 정보

**찾는 곳:** 내보내기 → MIDI

2. MIDI를 누르고 저장 위치를 선택합니다
3. 한국어 손실 요약을 읽고 필요하면 기술 정보를 펼칩니다

- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.

- **직접 확인:** [사용자 확인표](13-checklist.md#midi)에서 예제·기대 결과와 대조하세요.

꾸밈음 MIDI 안내: 꾸밈음의 별도 발음은 MIDI에 포함되지 않고 본음은 유지됩니다. 성공 후 경고 상세에서 원래 파트·보표·마디와 기술 정보의 개수를 확인하세요. 표기는 프로젝트 또는 MusicXML로 보관하세요. 꾸밈음 없는 파트에서 새로 성공한 사본에는 이 경고가 없습니다. 취소·실패만으로 이전 파일의 보고서가 바뀌지는 않습니다.

트릴·트레몰로 MIDI 안내: 내부 재생의 트릴 교대 음열과 단음 트레몰로 반복 음열은 MIDI 사본에 확장되지 않습니다. 본음은 유지됩니다. 경고 상세에서 원래 파트·보표·마디, 기호 종류와 트레몰로 획 수를 확인하고 프로젝트 또는 MusicXML을 보관하세요. 꾸밈음과 함께 있으면 각 손실을 별도로 안내합니다. 표시·내부 재생·MIDI의 지원 범위는 서로 다릅니다.

## PNG 전체/선택 페이지와 해상도

**찾는 곳:** 파일 → PNG 출력 설정

1. PNG 페이지에서 전체 페이지 또는 페이지 선택을 고릅니다
2. 선택이면 페이지 번호를 입력합니다
3. 150/300 dpi를 고릅니다
4. PNG 내보내기로 파일 또는 새 폴더에 저장합니다

- **결과·적용 범위:** PDF 페이지 설정의 용지·방향·여백을 사용합니다. 여러 페이지는 선택 위치의 새 폴더에 저장합니다. 한 페이지를 기존 파일에 저장할 때 기존 파일의 POSIX 권한을 유지합니다. 심볼릭 링크를 선택하면 링크는 남고 연결 대상에 저장됩니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 위험한 선택 페이지·전체 출력은 각각 검사합니다. 상태줄에 다른 결과가 표시되면 **PNG 출력 설정**의 **기술 정보**에서 앞선 PNG 오류를 확인할 수 있습니다. SVG 출력은 지원하지 않습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#png)에서 예제·기대 결과와 대조하세요.

개별 보표 줄 수 가져오기 경계: MusicXML의1선·6선 등 비5선 지시는 현재 보존하지 못하며 현재 악보는5선 보표로 표시합니다. 가져오기 경고의 파트·마디와 기술 정보의 보표 번호를 확인하고 원본 MusicXML의 보표 및 다시 내보낸 파일을 비교하세요. 생략되거나 명시적으로5선인 기본 지정은 이 손실로 안내하지 않습니다. 이 안내는 줄 수 편집·개별 보표 크기·보표 유형 변경을 지원한다는 뜻이 아니며, PDF 전체 보표 크기 설정과도 다릅니다.


개별 보표 크기 가져오기 경계: 개별 보표 공간 크기나 그 위 기보 배율이100%가 아닌 원본 지정은 현재 보존하지 못합니다. 원본 MusicXML을 보관하고 경고의 파트·마디/기술 정보의 보표 번호·원래 값을 확인해 보표와 재출력 파일을 비교하세요. 두 비율은 서로 다를 수 있고 PDF 전체 보표 크기와도 다릅니다. 생략되거나 명시적으로100%인 기본 지정은 이 손실로 안내하지 않습니다. 하단 상태줄은 짧게 알리며 상세 보고서와 원문 값은 그대로 남습니다. 이 안내는 개별 보표/기보 배율 편집이나 원본 배치를 지원한다는 뜻이 아닙니다.


지정 글꼴·크기 안내: 단일 `words`에 지정된 `font-family`와 `font-size`는 현재 모델과 사본에 원래 값으로 보존되지 않아 경고합니다. 일반·시스템·빠르기·리듬·표현 글자의 내용과 재생 의미는 유지하며, 원래 값과 파트·마디 경로는 기술 정보에서 확인할 수 있습니다. 글꼴·크기를 실제 편집하거나 복원하는 기능은 아닙니다. 여러 글자 조각은 기존 구성요소 손실 안내를 확인하고 원본 MusicXML을 함께 보관하세요.

지정 글자색 안내: 단일 `words`의 `color` 값이 현재 모델과 사본에 보존되지 않으면 한국어로 안내합니다. 글자 내용과 재생 의미는 유지하며 원래 색 값과 파트·마디 경로는 기술 정보에서 확인할 수 있습니다. 색을 편집하거나 복원하는 기능은 아닙니다. 기존 숨김 빠르기처럼 투명한 표시 의미를 보존하는 경우에는 이 색 손실 경고를 추가하지 않습니다. 원본 MusicXML을 함께 보관하고 글자 색과 다시 내보낸 파일을 비교하세요.


보표 숨김 설정 안내: MusicXML에서 숨김으로 지정한 보표의 표시 설정은 현재 프로젝트 모델에 보존되지 않습니다. 가져오기 경고에서 원본의 파트·마디를 확인하고, 기술 정보에서 보표 번호와 명시된 표시·간격 지정값을 확인하세요. 화면과 출력에 보표가 나타날 수 있으므로 원본 MusicXML을 보관하고 사본을 비교합니다. 이 안내가 빈 보표 자동 숨김, 보표 표시 설정 편집 또는 원래 숨김 배치의 복원을 제공하는 것은 아닙니다.

동일한 보표 숨김 경고만 여러 개라면 손실 내용·확인 방법·전체 경고 수를 요약으로 먼저 보여줍니다. `마디별 경고 상세`를 펼치면 각 원본 위치와 `기술 정보`를 확인할 수 있습니다. 단일 경고나 다른 종류가 함께 있는 경우는 기존 안내를 그대로 표시합니다. 같은 파일을 다시 가져오면 상세 목록은 접힌 상태로 새로 시작합니다.

### 보표의 대체·큐·편집 용도

이 버전은 MusicXML의 대체 보표(`alternate`), 다른 파트의 큐 보표(`cue`), 편집상 대안(`editorial`), 다른 연주 대안(`ossia`)의 용도를 보존하지 못하면 안내합니다. 일반 보표로 처리되어 재생과 출력이 원본과 다를 수 있습니다. 특히 `alternate`의 원래 재생 제외 의미를 구현한 것은 아닙니다. **원본 MusicXML을 보관하고 재생·보표·다시 내보낸 파일을 비교하세요.** 기술 정보에는 원래 용도와 보표/마디 위치가 남습니다. 프로젝트 저장이나 이 경고가 해당 용도를 복원·편집하거나 자동 음소거하는 기능은 아닙니다. 기본 일반 보표와 용도 생략은 이 손실로 경고하지 않습니다.


### 경고·기술 정보의 글자 복사

이 버전: 보이는 경고, 펼친 기술 정보 또는 파일 작업 결과의 글자를 선택한 동안에는 ⌘/Ctrl+C·X·V를 악보 복사·잘라내기·붙여넣기로 실행하지 않습니다. 읽기 전용 안내의 글자 선택은 브라우저의 기본 클립보드 동작을 따릅니다. **악보를 복사하거나 편집하려면 먼저 악보에 초점을 옮기세요.** 이전 진단 글자 선택이 남아 있어도 악보로 명시적으로 이동한 뒤에는 기존 악보 명령을 사용합니다.

이 동작은 경고를 편집 가능한 입력란으로 바꾸지 않습니다. 악보용 내부 클립보드, 저장 단축키와 사용자 지정 명령은 유지합니다. 접힌 기술 정보나 화면에서 제거된 옛 글자의 선택은 이 읽기 동작의 대상이 아닙니다. 실제 OS 클립보드 전달과 물리 키보드·스크린리더 검수는 별도입니다.


### 개별 음표·쉼표의 숨김 설정

이 버전: MusicXML에서 숨김으로 지정한 개별 음표·쉼표의 표시 설정은 현재 프로젝트 모델에 보존되지 않습니다. 화면과 출력에 나타날 수 있으므로 **원본 MusicXML을 보관하고 표기와 다시 내보낸 파일을 비교하세요.** 가져오기 경고에서 파트·마디를 확인하고, `기술 정보`를 펼쳐 원래 음표 위치와 표시 속성을 확인할 수 있습니다. 같은 숨김 손실이 반복되면 요약과 전체 수를 먼저 표시하며, `마디별 경고 상세`에서 각각의 안내를 확인합니다.

이 안내는 개별 음표 숨김 편집이나 원래의 비표시 출력을 복원하는 기능이 아닙니다. 프로젝트로 저장해도 원래 숨김 설정이 복원되지 않습니다. 보표 전체 숨김·음표 머리 모양 설정과도 구분합니다. 현재의 음높이·리듬·재생 내용은 이 안내 때문에 바뀌지 않습니다.


### 가사 숨김 설정

이 버전은 MusicXML에서 숨김으로 지정한 가사의 표시 설정을 보존하지 못하면 안내합니다. 원본 MusicXML을 보관하고, 절별 가사와 화면·다시 내보낸 파일을 비교하세요. 음표 전체의 숨김과 가사 숨김은 다른 설정입니다. 개별 가사를 표시하도록 지정한 경우에는 상위 숨김보다 우선합니다. 같은 가사 손실이 반복되면 요약 아래 **마디별 경고 상세**를 펼쳐 모든 원문을 확인할 수 있습니다. **기술 정보**에는 원래 파트·마디·음표·가사 순서와 숨김을 지정한 속성 경로가 있습니다.

이 안내는 원래 가사의 비표시를 복원하는 기능이 아닙니다. 가사 숨김의 개별 편집은 지원하지 않으며, 프로젝트로 저장해도 원본의 잃어버린 표시 설정이 복구되지 않습니다.


### 여러 조각으로 저장된 한 가사 음절

이 버전은 MusicXML에서 같은 음절을 여러 `text` 조각으로 저장했을 때 조각 사이에 없는 공백을 넣지 않습니다. 예를 들어 `사`와 `랑` 조각은 `사랑`으로 읽습니다. 조각 경계에 원래 들어 있던 내부 공백은 유지하며, 가사 문자열의 양끝 공백 정리는 기존과 같습니다. 기존 `elision`의 기본 구분 처리도 유지합니다.

조각별 굵게·기울임 등 서식을 복원하는 기능은 아닙니다. 일반 가사 문자열로 편집·저장하므로 원래 서식이 필요하면 원본 MusicXML도 함께 보관하세요.


### 가사 글자의 굵게·기울임 지정

이 버전은 MusicXML 가사 글자의 굵게 또는 기울임 지정을 보존하지 못하면 한국어로 안내합니다. 원본 MusicXML을 보관하고 가사 내용·서식과 다시 내보낸 파일을 비교하세요. 같은 서식 손실이 반복되면 **마디별 경고 상세**에서 모두 확인할 수 있고, 다른 경고와 섞인 경우에도 각각의 안내를 유지합니다. **기술 정보**에는 원본 파트·마디·음표·절·글자 조각·속성의 위치와 값이 있습니다.

이 안내는 가사 서식을 복원하거나 편집하는 기능이 아닙니다. 글꼴 종류·크기·색과 전체 rich text 지원도 별도 범위입니다.


### 긴 경고 목록 읽기

이 버전의 긴 경고 목록은 본문 안에서 스크롤됩니다. 서로 다른 경고가 섞여 있어도 기존 안내와 **기술 정보**를 유지합니다. Tab으로 목록 읽기 영역에 초점을 옮겨 방향키·PageUp/PageDown·Home/End로 탐색할 수 있습니다. 같은 경고의 요약이 접혀 있다면 먼저 **마디별 경고 상세**를 펼치세요. 짧은 목록은 불필요한 고정 높이를 사용하지 않습니다.

목록을 읽는 탐색 키는 뒤의 음표 이동이나 재생 명령으로 보내지 않습니다. 원본 경고와 위치 정보는 각 항목의 기술 정보에서 확인하세요.


### 가사 연결 기호의 손실 안내

이 버전은 MusicXML의 명시적 가사 연결 문자나 SMuFL 연결 기호를 평문 가사로 보존하지 못하면 원본 보관과 다시 내보낸 파일 비교를 안내합니다. 원래 절·기호 위치와 값은 기술 정보에서 확인합니다. 기호가 지정되지 않은 기본 연결의 기존 공백 처리는 유지합니다. 원래 기호·서식을 편집하거나 복원하는 기능은 아닙니다.


### MusicXML의 숫자 문자 참조

이 버전은 악보 본문의 숫자 문자 참조(예: `caf&#233;` → `café`)를 문자로 읽습니다. CDATA나 이스케이프된 참조의 문자 표기는 다시 해석하지 않습니다. 기존 프로젝트에 이미 저장된 참조 모양의 문자열을 자동 고치지는 않습니다. 원본을 보관하고 가사·절 번호와 다시 내보낸 파일을 비교하세요. 압축 파일의 container 경로는 아래 압축 MusicXML 안내를 참고하세요.


### 압축 MusicXML의 악보 경로

이 버전은 `.mxl` 안의 첫 악보 경로와 파일 형식에 사용된 XML 문자 참조를 한 번 해석합니다. 잘못된 참조, 허용하지 않는 경로 또는 없는 악보는 열지 않습니다. 이스케이프된 참조 모양의 실제 파일명은 다시 해석하지 않습니다. 압축 파일의 DTD 확장은 활성화하지 않으며 원본 파일을 자동으로 고치거나 다른 악보로 대신 열지 않습니다.


### 음표 덧줄의 숨김 설정

이 버전은 MusicXML 음표에 지정된 덧줄 숨김 설정을 보존하지 못하면 안내합니다. **원본 MusicXML을 보관하고 덧줄과 다시 내보낸 표기를 비교하세요.** 원래 파트·마디·음표와 속성 값은 기술 정보에 있습니다. 같은 손실이 반복되면 마디별 경고 상세를 펼쳐 모두 확인할 수 있습니다.

이 안내는 원래 덧줄 숨김을 복원하거나 편집하는 기능이 아닙니다. 프로젝트로 저장해도 원래 표시 설정이 복구되지 않습니다. 쉼표에는 이 덧줄 경고를 표시하지 않으며, 음표 전체의 숨김 손실과 함께 발생하면 기존 통합 안내를 유지합니다. 현재 음높이·음가·재생 의미는 바꾸지 않습니다.


### 음가 점의 숨김 설정

이 버전은 일반 음표·화음·쉼표의 점 음가는 유지하면서, 원본의 점 숨김 설정을 보존하지 못하면 안내합니다. **원본 MusicXML을 보관하고 점 표시와 다시 내보낸 표기를 비교하세요.** 원래 속성 값과 음표 위치는 기술 정보에 있습니다. 같은 손실이 반복되면 마디별 경고 상세를 펼쳐 모두 확인할 수 있습니다.

음표 전체 숨김과 함께 지정됐다면 기존 통합 안내의 기술 정보에서 점 표시 값을 확인합니다. 이 안내는 점 숨김을 복원·편집하거나 음표의 리듬을 바꾸는 기능이 아닙니다. 점이 없는 음표와 기본 표시에는 이 점 숨김 경고를 추가하지 않습니다. 꾸밈음의 원래 음가·점 표기는 별도 지원 범위입니다.


### 개별 큐 표기의 구분

이 버전은 MusicXML의 개별 큐 표기 구분을 보존하지 못하면 안내합니다. **원본 MusicXML을 보관하고 재생에 포함되는 음과 표기 크기·다시 내보낸 파일을 비교하세요.** 화음 구성음 등 무음 큐로 지정된 음이 현재 일반 음표로 재생될 수 있습니다. 원래 파트·마디·음표의 cue/grace/rest/chord 구분과 명시된 크기는 기술 정보에서 확인합니다.

이 안내는 무음 큐 입력·편집이나 원래 크기를 복원하는 기능이 아닙니다. 프로젝트로 저장해도 원래 큐 구분이 복구되지 않습니다. 크기만 `cue`로 지정한 일반 음표는 무음 큐와 다르며, 이 값만 보고 자동 음소거하지 않습니다. 보표 전체의 큐 용도와 개별 음표의 큐 지정도 서로 다릅니다.


### 꾸밈음의 기보 음가·점

이 버전은 꾸밈음의 원래 기보 음가나 점 표기를 보존하지 못하면 안내합니다. 현재는 기본 8분 모양으로 표시되므로 **원본 MusicXML을 보관하고 꾸밈음 모양과 다시 내보낸 표기를 비교하세요.** 원래 type·점 개수와 명시된 점 숨김 값은 기술 정보에서 확인할 수 있습니다. pitch와 slash 상태는 유지되지만 프로젝트 저장이 원래 모양을 복원하지는 않습니다. 기보상의 음가와 실제 꾸밈음 발음·시간 배분은 서로 다른 지원 범위입니다.


### 꾸밈음의 원래 연주 시간 지정

이 버전은 꾸밈음이 앞뒤 음에서 차용하거나 추가하도록 지정한 시간을 보존하지 못하면 안내합니다. **원본 MusicXML을 보관하고 꾸밈음 재생과 다시 내보낸 파일을 비교하세요.** 원래 백분율과 make-time의 divisions 값, 명시적 0과 원래 위치는 기술 정보에서 확인합니다. 이 안내는 꾸밈음의 별도 발음·시간 배분을 구현하거나 원래 값을 프로젝트에 복원하는 기능이 아닙니다. 기보 음가·점 모양과 MIDI 발음 누락의 안내는 서로 다른 범위입니다.


### 임시표의 괄호·크기·주의/편집 지정

이 버전은 임시표의 원래 비기본 괄호·대괄호·크기·주의/편집 지정을 보존하지 못하면 안내합니다. **원본 MusicXML을 보관하고 임시표 표시와 다시 내보낸 표기를 비교하세요.** 원래 값과 지정·음표 위치는 기술 정보에서 확인합니다. 현재 음높이 해석은 유지되며 이 안내가 원래 모양을 복원하거나 강제로 표시하는 편집 기능은 아닙니다. 기본값과 명시적 no/full에는 이 경고를 추가하지 않습니다. 큐 크기 지정도 무음 큐나 재생 제외를 의미하지 않습니다.

문구형 빠르기 가져오기: `90–100`, `90 circa`처럼 선행 숫자가 있는 표기는 원래 문구를 표시하고 기존 숫자를 사용합니다. 유효한 `sound tempo`가 함께 있으면 그 재생값을 기준 음가·점에 맞춰 사용합니다. `ca. 90`처럼 선행 숫자가 없어도 명시된 재생값이 있으면 문구와 재생값을 함께 보존합니다. 빠르기를 임의로 추측하지 않으므로 둘 다 없으면 원본 파일을 보관하고 숫자·재생 빠르기가 지정된 사본으로 다시 시도하세요. 별도의 명시 글자가 원래 메트로놈 문구보다 우선하는 경우에는 그 글자를 유지하고 문구 손실을 안내합니다. 다른 파트의 독립 빠르기와 별도 재생 위치는 총보 공통 빠르기 지원과 구분합니다.

모델 범위 밖 수치 안내: 메트로놈의 원래 값이 현재 프로젝트 숫자 범위 `(0, 1000]` 밖이면 기존 가져오기 변환 결과를 유지하면서 원래 값·실제 적용값·기준 음가·점과 원래 위치를 경고합니다. 예를 들어 원래 1001은 기존 규칙상 240으로 적용됩니다. 원래 값을 모두 저장할 수 있게 된 것은 아니므로 원본 MusicXML을 보관하고 빠르기·재생·재내보내기를 비교하세요. 새 값 입력의 40–240 정수 범위와 가져오기 보존 범위는 별개입니다.

페이지 추가 내용 안내: MusicXML의 `credit-words`·`credit-symbol`에 있는 별도 글자와 음악 기호가 현재 악보에 남지 않으면 원래 페이지를 안내합니다. 이미 가져온 제목·작곡가와 대응하는 같은 내용의 credit은 중복 경고하지 않으며, 기존 저작권·이미지 경고는 유지합니다. 반복된 추가 내용은 ‘페이지별 경고 상세’에서 각 원문과 경로를 볼 수 있습니다. 이는 원래 페이지의 글꼴·기호·프레임·배치가 복원됐다는 뜻이 아닙니다. 원본 MusicXML을 보관하고 페이지별 내용과 다시 내보낸 파일을 비교하세요.


추가 저자 안내: MusicXML의 편곡자·작사가·번역자나 두 번째 작곡가 등 현재 악보에 보존하지 못한 이름·역할은 가져오기 경고에서 확인할 수 있습니다. 반복된 항목은 ‘저자별 경고 상세’로 묶이며 기술 정보에 원래 역할·이름과 `identification.creator[n]` 경로를 유지합니다. 기존 첫 작곡가 선택 정책은 유지하며 여러 저자를 자동으로 합치지 않습니다. 원본 파일을 보관하고 저자 목록과 다시 내보낸 파일을 비교하세요. 범용 저자 목록 편집이나 페이지 크레디트 복원 기능은 아닙니다.


원본의 악기별 음량·공간 배치: 이 버전은 MusicXML의 `midi-instrument`에 지정된 `volume`·`pan`·`elevation`이 프로젝트와 사본에 보존되지 않는다는 안내를 표시합니다. 초기 파트 정의와 중간 재생 지시를 구분해 기술 정보의 원래 값·악기 ID·위치를 확인하세요. 기존 로컬 믹서 설정이나 현재 음악을 자동 변환하지 않습니다.


### MusicXML에 표현할 수 없는 문자

이 버전은 제목·작곡가·파트 이름·가사·글자에 MusicXML로 표현할 수 없는 문자가 있으면 **파일을 쓰기 전에 중단**합니다. 안내된 항목을 수정하거나 문구를 다시 입력한 뒤 저장·내보내기를 다시 시도하세요. 자세한 문자 코드와 출력 위치는 ‘기술 정보’에서 확인할 수 있습니다. 파트·마디의 위치 번호는 내보낼 문서에 포함되는 순서 기준입니다.

원문을 자동 삭제하거나 대체하지 않습니다. **Native 프로젝트 저장과 재열기는 원문을 유지**합니다. 유효한 한글·이모지·탭·줄바꿈과 문자 참조 모양의 실제 문구는 이 제한과 구분합니다. XML 출력용 파트 ID 변환도 기존대로 원본 ID를 유지합니다. 선택 파트 사본에서는 실제 포함되는 글자만 검사하며, 전체 MusicXML 저장에는 다른 파트도 포함됩니다.


일반 음표에 특정 반복 회차만 연주하도록 지정한 MusicXML 조건은 현재 가져온 악보에 저장되지 않습니다. 가져오기 경고가 나타나면 원본 MusicXML을 보관하고 반복 재생과 다시 내보낸 사본을 비교하세요. 이는 타이의 반복 회차 조건과 별개입니다. 기본 안내에서 파트·마디를, 경고의 기술 정보에서 원래 조건값과 경로를 확인하세요.

음표별 연주 시작·종료 시점의 추가 조정은 현재 가져온 악보에 저장되지 않습니다. 비영 값이 있으면 시작과 종료 조정의 손실을 각각 안내합니다. 음가 자체는 유지되며 현재 재생과 사본에는 이 추가 조정이 적용되지 않습니다. 원본 MusicXML을 보관하고 음의 시작·끝과 재출력을 비교하세요. 기본 안내에서 파트·마디를, 기술 정보에서 원래 값과 경로를 확인하세요.

피치카토·아르코의 MusicXML 원본 지시도 현재 연주 모델에 저장되지 않습니다. 이 버전은 이 음표만의 지정과 이후 음표에 적용할 지시를 구분하고, 명시적인 끄기/아르코 지정도 안내합니다. 기본 안내에서 파트·마디를, 가져오기 경고의 기술 정보에서 원래 값과 위치를 확인하세요. 악보의 `pizz.`/`arco` 글자와 실제 연주 방식은 별개입니다. 현재 재생과 사본에는 이 주법 지시가 적용되지 않으므로 원본 MusicXML을 별도로 보관하세요. 프로젝트 재열기로 원본 속성이 복구되는 기능은 아닙니다.

### 보표·시스템 글자의 마디 안 위치

이 버전은 MusicXML의 보표·시스템 글자가 마디 중간에 붙어 있지만 현재 마디 단위 모델로 가져오는 경우 위치 손실을 안내합니다. 글자 내용은 유지되며 원본의 정확한 박별 위치를 복원하는 기능은 아닙니다. 기본 안내에서 파트·마디를, 기술 정보에서 원래 위치와 경로·명시된 offset을 확인하세요. 원본 MusicXML을 보관하고 글자가 붙는 음표와 다시 내보낸 파일을 비교하세요. 지원하는 표현 글자·빠르기·리듬 표기와 수동 좌표는 별도 계약입니다.

### 표현 글자의 MusicXML 위치

이 버전은 현재 지원하는 표현 글자(아래에 기울임으로 지정된 단일 글자)의 원본 박별 위치를 MusicXML의 현재 음악 위치와 divisions 단위에 맞게 읽습니다. 앞선 음표·backup/forward·상대 offset을 반영하며, 유효한 음수·소수 offset도 기존 내부 tick으로 변환합니다. 가져온 글자를 선택하면 속성의 대상 목록에서 4분음표 기준 위치를 확인할 수 있습니다. 글자 내용·음악과 기존 프로젝트 형식은 유지됩니다.

이미 저장된 Native 프로젝트의 위치를 자동으로 고치는 기능은 아닙니다. 원본 시점으로 다시 읽으려면 원본 MusicXML을 새로 가져와 비교하세요. 보표·시스템 글자의 마디 단위 배치 및 원본 서식·수동 좌표 보존과는 별개입니다.
