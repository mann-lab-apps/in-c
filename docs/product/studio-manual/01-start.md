# 시작하기

기능 기준: alpha.43. 메뉴 이름과 아래 적용 범위를 함께 확인하세요.

<a id="install"></a>
## 설치와 이전 in-C에서 옮겨 오기

**찾는 곳:** 다운로드한 DMG 또는 플랫폼 설치본

1. 기존 in-C를 종료합니다
2. macOS에서는 띠로리 Studio를 Applications로 복사하고 새 이름의 앱을 실행합니다
3. 창 이름과 버전을 확인하고 프로젝트 파일을 엽니다

- **결과·적용 범위:** 기존 com.mannlab.inc ID·.chromatics 형식·설정·최근 파일·복구 경로를 유지합니다. 이름이 달라 이전 앱이 남아 있을 수 있습니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 사용자 데이터 삭제·캐시 초기화는 이행 절차가 아닙니다. Windows는 미서명 안내가 나올 수 있습니다.
- **되돌리기·취소:** 설치를 취소하면 기존 앱과 파일을 유지합니다. 이번 문서의 새 사용설명서 메뉴는 아직 배포 전입니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#install)에서 예제·기대 결과와 대조하세요.

<a id="first-score"></a>
## 새 악보·내장 템플릿 만들기

**찾는 곳:** 시작 화면 또는 파일 → 새 악보 만들기

1. 새 악보 만들기를 엽니다
2. 템플릿 또는 악보 구성을 고르고 제목·작곡가·조표·박자표·마디 수·빠르기를 설정합니다
3. 만들기를 눌러 빈 악보를 엽니다

- **결과·적용 범위:** 선택한 템플릿 구성의 새 문서입니다. 마디 수는 1–64입니다. 기본 박자표 2/4·3/4·4/4·6/8 또는 사용자 지정 분자1–128과 분모1/2/4/8/16/32/64를 고릅니다. 새 문서의 모든 보표·마디에 적용하며 기존 악보를 전파·재분할하는 기능은 아닙니다. 이 버전은 마디 수를 지우거나 범위 밖 값을 입력해도 자동으로 바꾸지 않습니다. 빈 값·범위 밖·소수는 수정한 뒤 생성하며 취소하면 이전 문서를 유지합니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 미저장 변경을 교체할 때 확인이 필요합니다. 취소하면 이전 문서를 유지합니다.
- **되돌리기·취소:** wizard 취소는 이전 악보와 편집 이력을 유지합니다. 문서 생성/교체는 일반 음표 편집 undo와 구분합니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#first-score)에서 예제·기대 결과와 대조하세요.

<a id="first-tempo"></a>
## 새 악보의 빠르기 입력

**찾는 곳:** 새 악보 만들기 → 빠르기

1. 빠르기에 80을 입력합니다
2. 40–240 bpm의 정수인지 확인합니다
3. 잘못된 값은 수정하거나 Escape로 마지막 유효값을 복원한 뒤 만듭니다

- **결과·적용 범위:** 새 문서의 기본 빠르기입니다. 입력 도중 40/240으로 자동 보정하지 않습니다.
- **단축키:** Escape: 마지막 유효값 복원
- **안 되거나 다른 결과가 나오면:** 빈 값·범위 밖·소수는 오류 안내 후 수정해야 합니다. 이 계약은 새 악보 입력기에 해당합니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#first-tempo)에서 예제·기대 결과와 대조하세요.

<a id="first-note"></a>
## 첫 실제 음표와 첫 프로젝트 저장

**찾는 곳:** 빈 악보 → 음표 입력 도구

1. 첫 마디를 선택합니다
2. N으로 입력 모드에 들어가 5로 4분음표를 고르고 C를 입력합니다
3. Esc로 선택 모드로 돌아와 ⌘/Ctrl+Z로 되돌리고 다시 실행합니다
4. 파일 → 프로젝트 저장으로 .chromatics를 저장하고 다시 엽니다

- **결과·적용 범위:** N 중 숫자는 다음 입력 음가, A–G는 실제 음표 입력입니다. 프로젝트 저장 성공과 사본 출력 성공은 다릅니다.
- **단축키:** N, 5, C, Esc, ⌘/Ctrl+S
- **안 되거나 다른 결과가 나오면:** 입력 커서·남은 마디 길이·성부 조건을 확인합니다. 저장 취소/실패는 성공 알림이나 clean 상태가 아닙니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#first-note)에서 예제·기대 결과와 대조하세요.

<a id="recent"></a>
## 최근 악보와 없는 파일 정리

**찾는 곳:** 시작 화면 → 최근 악보

1. 최근 파일 이름을 누릅니다
2. 없는 파일 안내가 나오면 목록에서 지우기를 선택합니다
3. 다른 파일을 선택해 재시도합니다

- **결과·적용 범위:** 목록 제거는 실제 악보 파일 삭제가 아닙니다. 연속 선택은 나중에 선택한 파일이 우선합니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 이동·삭제된 파일은 열 수 없습니다. 최근 목록이 비면 파일/가져오기를 사용합니다.
- **되돌리기·취소:** 파일 선택 취소는 현재 문서를 유지합니다. 이전 요청의 늦은 응답을 새 선택에 적용하지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#recent)에서 예제·기대 결과와 대조하세요.

<a id="recovery"></a>
## 자동저장 복구본 열기

**찾는 곳:** 시작 화면 → 복구본 열기

1. 복구본 제목과 시각을 확인합니다
2. 복구본 열기를 누르면 별도 취소 대화상자 없이 복구본이 열립니다
3. 내용을 검토한 뒤 프로젝트 파일로 저장합니다

- **결과·적용 범위:** 자동저장 snapshot 복구이며 원본 파일에 대한 저장 성공을 뜻하지 않습니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 복구본 없음은 비활성입니다. 복구 파일 오류를 실제 저장 완료로 해석하지 않습니다.
- **되돌리기·취소:** 복구본 열기를 누르기 전에는 다른 시작 작업을 선택할 수 있습니다. 복구본 열기 자체는 실행 취소할 수 없으며, 복구 후 실제 파일 저장은 별도입니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#recovery)에서 예제·기대 결과와 대조하세요.

<a id="backups"></a>
## 프로젝트 백업에서 복구

**찾는 곳:** 파일 → 프로젝트 백업

1. 백업 목록에서 제목·파일명·시각을 확인합니다
2. 원하는 백업의 복구 버튼을 누릅니다
3. 변경 교체 확인 후 내용을 확인하고 파일로 저장합니다

- **결과·적용 범위:** 프로젝트 백업을 새 현재 문서로 복구합니다. 자동저장 복구와 별도 경로입니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 프로젝트 파일 기능이나 백업이 없으면 사용할 수 없습니다. 목록의 상태·오류를 확인합니다.
- **되돌리기·취소:** 닫기/취소는 현재 문서와 실제 프로젝트 파일을 바꾸지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#backups)에서 예제·기대 결과와 대조하세요.
