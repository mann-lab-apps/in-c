# 매뉴얼 연습 악보

새로 생성한 2파트·8마디·다장조(1–7마디 4/4, 8마디 2/4) 예제입니다. 원본 사용자 악보가 아닙니다.

1. MusicXML 가져오기로 manual-practice.musicxml을 엽니다.
2. Melody 1마디 첫 C를 선택합니다. 5→6으로 바꾸면 뒤 D와 겹치는 음가 확대 확인을 연습할 수 있습니다. 취소/적용 후 undo로 비교하세요.
3. Melody 2마디 첫 C는 부착 표기가 없는 단음입니다. Alt+G 붙이기와 undo, Alt+Shift+G 변환과 undo를 각각 연습합니다.
4. Melody 3마디 첫 C와 다음 C는 같은 음높이입니다. 첫 C에서 T로 타이를 만들고 undo합니다.
5. Melody 4마디 첫 음에서 S, 끝 음을 선택하고 S로 슬러를 만들고 속성을 확인합니다.
6. 5–6마디에는 단순 반복이 있습니다. 반복/믹서 재생 과제를 사용할 수 있습니다. 볼타는 설명서 단계로 별도 적용합니다.
7. Melody 8마디는 두 4분음표의 2/4입니다. 우클릭 → 박자표 변경…에서 3/4로 바꾸면 선택 보표의 이 마디만 바뀌고 다른 보표/마디는 유지됩니다. undo로 복원하세요.
8. 프로젝트로 저장한 뒤 재열기, XML/MIDI/PDF/PNG 사본을 별도 출력합니다. 출력 성공을 프로젝트 저장 성공과 혼동하지 마세요.

위 단계의 사용자 체크는 자동으로 채우지 않습니다. 앱 내 매뉴얼에서 예제 링크를 누르면 정적 MusicXML 사본을 다운로드합니다. 실제 가져오기는 사용자가 별도로 실행합니다.
