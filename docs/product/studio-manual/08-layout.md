# 조판과 페이지

기능 기준: alpha.42. 메뉴 이름과 아래 적용 범위를 함께 확인하세요.

<a id="breaks"></a>
## 시스템·페이지 나누기

**찾는 곳:** 형식 → 악보 설정 / 마디 구조

1. 대상 마디를 선택합니다
2. 시스템 나누기 또는 페이지 나누기를 켭니다
3. 총보/파트보와 출력 미리보기를 비교합니다
4. 같은 버튼으로 해제합니다

- **결과·적용 범위:** 나누기는 현재 적용 범위와 파트보 독립 설정을 따릅니다. 화면의 스크롤 줄과 출력 페이지를 구분합니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 대상이 없거나 지원하지 않는 범위에서는 비활성입니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#breaks)에서 예제·기대 결과와 대조하세요.

## 용지·방향·여백·보표 크기·시스템 간격

**찾는 곳:** 형식 → PDF 페이지 설정 또는 파일 → 내보내기 설정

1. 프리셋/용지/방향을 선택합니다
2. 여백은 3–30mm 정수로 입력합니다
3. 보표 크기75–125%와 시스템 간격80–140%를 조절합니다
4. 보기 → 페이지 여백 가이드로 확인합니다

- **결과·적용 범위:** 현재 총보 또는 선택 파트보에 적용하는지 작업창에 표시됩니다. 보표 크기 step5%, 간격 step5%입니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** schema의 더 넓은 숫자 범위를 공개 UI 지원 범위로 해석하지 않습니다. 긴 제목과 실제 잉크 경계를 함께 확인합니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#page)에서 예제·기대 결과와 대조하세요.

## 파트보 조판 초기화

**찾는 곳:** 파트보 선택 → PDF 페이지 설정 → 파트보 조판 초기화

1. 원하는 파트보를 선택합니다
2. 독립 설정이 있는지 확인합니다
3. 파트보 조판 초기화를 누르고 총보와 비교합니다

- **결과·적용 범위:** 버튼이 설명하는 파트 조판 범위의 override를 복원합니다. 팔레트/도크 로컬 초기화와 구분합니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 이미 상속/기본 상태면 비활성입니다. 이웃 파트 설정을 함께 초기화하지 않습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#part-reset)에서 예제·기대 결과와 대조하세요.

## 제목·작곡가·파트보 제목 직접 편집

**찾는 곳:** 상단 악보 정보 또는 형식 → 악보 정보 편집

1. 악보 제목 편집·작곡가 편집 또는 파트보 제목 편집을 고릅니다
2. 실제 지면의 입력창에서 수정합니다
3. Enter/blur로 확정하고 Escape로 취소합니다

- **결과·적용 범위:** 총보 제목과 독립 파트보 제목의 범위가 다릅니다. 종이 표시는 유지하고 별도 공통 편집 버튼으로 접근합니다.
- **단축키:** Enter/blur, Escape
- **안 되거나 다른 결과가 나오면:** 짧은 지면 글자의 클릭 영역을 확대해 주변 표기를 덮지 않습니다. 긴 글자는 출력 페이지 제약을 확인합니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#metadata)에서 예제·기대 결과와 대조하세요.

## 기호 잘림·과대 악보단 출력 차단

**찾는 곳:** PDF/PNG 출력 전 검사

1. 페이지/크기/여백 설정과 출력 대상 페이지를 확인합니다
2. 차단되면 안내의 시작 마디·보표·기호를 찾습니다
3. 보표 크기·용지 방향·파트보·텍스트/수동 배치를 조정합니다
4. 동일 출력을 다시 시도합니다

- **결과·적용 범위:** 실제 잉크가 물리 페이지를 넘거나 한 악보단이 용지에 들어가지 않으면 저장 대화상자 전에 차단합니다. 수동 geometry를 임의 이동하지 않습니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 전체 출력이 막혀도 안전한 선택 PNG 페이지는 별도 검사합니다. 단순 SVG 내부 containment만으로 안전을 판단하지 않습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#page-guard)에서 예제·기대 결과와 대조하세요.

## 이름 있는 출력 설정 프리셋

**이 버전. 찾는 곳:** 형식 → PDF 페이지 설정 → 출력 설정 프리셋 관리

1. 확정된 현재 총보 또는 선택 파트보 설정을 확인하고 관리 창을 엽니다.
2. 이름을 1–40자로 입력해 현재 출력 설정을 저장합니다. 최대20개이며 같은 이름은 거부합니다.
3. 목록을 선택하고 저장한 값과 적용할 값을 확인합니다. 용지·방향·여백·보표 크기·시스템 간격5개만 취급합니다.
4. ‘선택 프리셋 적용’은 현재 총보/선택 파트에 적용하고 창을 닫습니다. 선택만으로 적용하지 않습니다.
5. ‘선택 프리셋 갱신’은 현재 설정으로 해당 목록만 갱신합니다. 삭제도 현재 악보 설정을 바꾸지 않습니다.

- **소수값:** 유효한 원본 소수는 목록에서 보존합니다. 실제 적용은 기존 출력 설정과 같이 정수 반올림하며 적용할 값을 먼저 보여줍니다.
- **저장 경계:** 이 기기의 로컬 목록이며 악보 템플릿·전체 스타일·.mss 가져오기/내보내기가 아닙니다. 적용한 설정만 기존 프로젝트 저장에 포함됩니다. 목록은 자동 갱신되지 않습니다.
- **undo:** 적용은 기존 명령1회/실행 취소1회이며, 같은 유효 설정은 no-op입니다. 목록 저장·갱신·삭제·창 닫기는 악보·dirty·선택·undo를 바꾸지 않습니다.
- **입력:** 미확정 숫자는 확정/취소 후 관리 창을 엽니다. 이름 조합 중에는 Enter로 저장하거나 Escape로 닫지 않습니다. 조합이 끝난 뒤 Escape로 창만 닫을 수 있습니다. 창 안의 ⌘/Ctrl+S는 프로젝트를 저장하지 않습니다.
- **오류:** 목록이 손상되면 그대로 두고 안내합니다. 새 저장은 목록을 새로 씁니다. 기기 쓰기 실패 시 현재 창의 세션에서만 사용할 수 있음을 안내합니다.
- **지원 범위:** 내장4개 프리셋은 그대로 유지합니다. 다른 파트·음표·수동 기호 배치를 바꾸지 않습니다. 실제 검증 범위는 반환 자료와 구분합니다.
- **직접 확인:** [사용자 확인표](13-checklist.md#print-profiles)
