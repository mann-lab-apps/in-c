# MuseScore와의 차이

현재 지원과 앞으로의 작업을 구분합니다. 기준은 띠로리 Studio alpha.40입니다. 아래 목록은 출시 일정이나 지원 약속이 아닙니다. 목록에 없는 기능도 모든 세부 동작까지 동일하다는 뜻은 아닙니다.

지원 중인 작업은 [기능 색인](feature-index.md)과 [단축키](10-shortcuts.md)를 확인하세요. 예를 들어 일반 타이·슬러, 꾸밈음 붙이기/변환, 도돌이표·볼타, MIDI·MusicXML·PDF·PNG 출력은 이미 제공하며 아래의 추가 범위와 다릅니다.

<a id="gaps-1"></a>
## 입력·표기

- **사용자 지정 박자표 · 일부 지원**: 선택 한 마디와 새 악보의 사용자 지정 박자표 입력은 이 버전에서 지원합니다. 실제 박자와 다른 표시문구·합산 박자 표기·사용자 빔 그룹은 아직 지원하지 않습니다.
- **박자표의 총보·이후 구간 적용 범위 · 일부 지원**: 박자표 변경은 선택 보표의 한 마디에 적용됩니다. 총보의 모든 보표나 이후 마디에 함께 적용하는 기능은 아직 없습니다.
- **못갖춘마디·실제 마디 길이 편집 · 일부 지원**: 새 악보에서 못갖춘 길이를 지정하고, 이 버전의 형식 → 첫 마디 길이…에서 모든 보표의 빈 첫 마디만 함께 변환·복원합니다. 기존 음표가 있는 마디·끝마디 보상·번호 제외는 별도 범위입니다.
- **음표 앞 음자리표 직접 입력 · 별도 제품 범위 결정**: 한 마디와 보표 전체 음자리표는 바꿀 수 있습니다. 음표 앞 음자리표 위치는 가져와도 보존하지 못하며 이 버전은 이를 안내합니다. 직접 편집은 위치별 모델 설계가 필요한 후속 범위입니다.
- **셋잇단음표 외 비율·중첩 잇단음표 · 일부 지원**: 기존3:2와alpha.40의 고정2:3/5:4/7:4입력이있습니다. 임의비율·중첩·전용속성편집은아직없습니다.
- **화음 구성음 선택과 부분 화음 타이 · 일부 지원**: 화음 전체를 선택·편집하며 새 타이는 동일한 화음 전체에만 연결합니다. 구성음 하나만 선택하거나 서로 다른 화음의 일부 음만 잇는 직접 입력은 지원하지 않습니다.
- **박·성부별 셈여림 · 일부 지원**: 현재 셈여림은 마디 단위로 적용됩니다. 같은 마디의 보관 값을 정리할 수 있지만 박이나 성부마다 별도로 재생하는 기능은 아닙니다.
- **실음·기보음 화면 전환 · 별도 제품 범위 결정**: 이조 악기의 기보음과 재생음은 처리하지만, 악보 화면 전체를 실음 보기로 바꾸는 스위치는 아직 없습니다.
- **음높이를 먼저 고르는 입력 모드 · 직접 UI 없음**: 음높이를 먼저 고르고 음가로 확정하는 별도 입력 모드는 아직 없습니다. 이 버전에서는 해당 native 설정의 현재 미지원과 보존 범위를 안내합니다.
- **추가 음가 범위 · 일부 지원**: 현재 음가는 온음표부터64분음표까지7종입니다. 이보다 길거나 짧은 음가를 직접 입력하는 기능은 지원하지 않습니다.
- **특수 마디선 스타일·범위 편집 · 일부 지원**: 일반·반복/볼타 마디선은 사용할 수 있습니다. 이중선·점선 등 임의 스타일 직접 편집은 없으며, 원본 스타일의 손실은 가져오기 경고로 안내합니다.
- **기존 음표의 성부 이동·성부 교환 · 일부 지원**: 성부 버튼은 입력 위치를 전환합니다. 이 버전의 별도 성부 이동은 단일 일반 음표와 같은 마디의 빈 성부부터 검증 중입니다. 범위 이동·성부 교환은 아직 별도 설계가 필요합니다.
- **보표·악기 괄호와 파트 묶음 편집 · 직접 UI 없음**: 사용자 지정 파트 묶음·괄호 편집기는 없습니다. 이 버전은 가져온 part-group의 손실을 안내합니다. 안내가 괄호·중괄호를 복원하거나 원본 구조를 보존하는 것은 아닙니다.
- **조표의 총보 범위·가시성·비전통 조성 · 일부 지원**: 현재 장조·단조 조표 타일은 선택 보표의 해당 마디부터 적용됩니다. 총보 일괄 적용·조표 표시 스타일·무조성/비전통 조표 편집은 제공하지 않습니다.
- **임시표의 괄호·크기·주의/편집 지정 가져오기 손실 안내 · 일부 지원**: 이 버전은 임시표의 비기본 괄호·크기·주의/편집 지정을 보존하지 못하면 원본 보관과 표시·재출력 비교를 안내합니다. 기본/no/full은 이 손실로 경고하지 않습니다. 원래 표시를 복원·편집하거나 음높이를 바꾸는 기능은 아닙니다.
- **페달 기호·선의 표기와 속성 편집 · 일부 지원**: 수동 서스테인과 가져온 악보의 페달 재생은 가능합니다. 페달 기호·선을 악보에 표시하고 속성에서 편집하는 기능은 별도 설계가 필요합니다. 원본 MusicXML을 함께 보관하세요.
- **범위 이명동음 정리와 실음·기보음 분리 전환 · 일부 지원**: 단음과 화음 전체의 J 전환은 지원합니다. 범위 자동 최적화와 실음·기보음의 분리 전환은 별도 설계가 필요합니다.

<a id="gaps-2"></a>
## 속성·작업 공간

- **파트·구간별 span 속성 편집 · 별도 제품 범위 결정**: 현재 슬러·헤어핀 속성은 총보와 해당 파트보에 공통 적용됩니다. 파트별·줄별 독립 배치의 저장과 직접 편집은 현재 형식에서 지원하지 않습니다.
- **악보 위 직접 배치·핸들 조절 · 일부 지원**: 이 버전은 수동 배치된 슬러·헤어핀의 공통 위치를 키보드와 기본 마우스 드래그로 옮깁니다. 곡선·끝점 모양 핸들, 자동 배치 전환과 독립 구간 편집 전체는 아직 지원하지 않습니다.
- **팔레트 드래그 적용·사용자 팔레트 · 일부 지원**: 이 버전은 음자리표·조표·박자표·셈여림의 지정된 마디 범위와 표현 기호·장식음의 음표 드래그, 정지 기호의 음표·쉼표 드래그를 제공합니다. 가족 순서·접힘 저장도 제공하며 사용자 가족 편집과 모든 타일의 드래그는 아직 없습니다.
- **단축키 사용자 재지정 · 일부 지원**: 이 버전은 편집6명령의 단축키를 이 기기에서 바꿀 수 있습니다. 다른 음악/파일 명령과 설정 파일 교환은 아직 지원하지 않습니다.
- **사용자 템플릿·악보 스타일 저장 · 일부 지원**: 이름 있는 출력 설정 프리셋을 기기에 저장하고 현재 총보/파트에 적용할 수 있습니다. 사용자 악보 템플릿·전체 스타일/.mss는 아직 없습니다.
- **이름 있는 작업 공간·자유 도킹 · 일부 지원**: 이 버전에서 도크 폭·표시·열린 탭을 이름으로 저장합니다. 팔레트 내용·자유 도킹·전체 작업 공간 프로필과는 다릅니다.
- **옥타브 선의 선택 속성·모양 편집 · 일부 지원**: 옥타브 선 네 종류의 범위 적용·해제는 지원합니다. 숫자만 표시·선 숨김·대각선·선/텍스트 스타일이나 슬러·헤어핀과 같은 상세 속성 편집기는 없습니다.
- **보표 유형·줄 수·개별 크기 설정 · 직접 UI 없음**: 개별 보표의 줄 수·크기와 마디별 보표 유형 변경은 아직 지원 범위를 설계해야 합니다. PDF 전체 보표 크기와 다른 설정입니다.
- **마디별 가로 간격·고정 폭 설정 · 별도 제품 범위 결정**: 개별 마디 폭을 직접 고정하는 편집은 현재 지원하지 않습니다. 기존 자동 배치와 줄·페이지 나누기는 별도 기능입니다.
- **PDF 완료 전후 OS 활성·native 입력 초점 소유권 조사 · 일부 지원**: PDF 출력 전후 앱의 초점과 다음 작업 입력이 유지되는지 추가 조사 중입니다. 확인되지 않은 OS 활성 변화를 제품 수정 완료로 표시하지 않습니다.
- **MusicXML 대체·큐 보표 용도 손실 안내 · 직접 UI 없음**: 이 버전은 대체·큐·편집/다른 연주 보표의 용도 손실을 안내합니다. 일반 보표로 처리되어 재생과 출력이 다를 수 있으므로 원본을 보관하고 비교하세요. 해당 용도 전용 편집·재생 제외는 지원하지 않습니다.
- **파일 작업 완료 순서·초점·진단 소유권 · 일부 지원**: 이 버전은 나중에 시작한 파일·출력 작업의 초점을 이전 완료 응답이 덮어쓰지 않도록 보완합니다. 수락한 열기와 확인 거절을 구분하며 문서·현재 입력·수동 스크롤은 유지합니다. 실제 OS 입력 검증은 별도입니다. 최근 파일 A의 늦은 목록 삭제 결과가 다른 파일 B의 열기 실패 안내와 정리 대상을 지우지 않도록 보완했습니다. 새로 수락한 MIDI 결과의 기술 정보는 다시 접고, 대기·취소나 문서 편집 중에는 기존 결과의 펼침을 유지하도록 보완했습니다.

<a id="gaps-3"></a>
## 재생과 파일 교환

- **꾸밈음 발음과 연주 시간 배분 · 일부 지원**: 꾸밈음 붙이기·기존 음표 변환과 표기 저장은 가능합니다. 현재 내부 재생과 MIDI에는 꾸밈음의 별도 발음이 반영되지 않습니다.
- **메트로놈 · 일부 지원**: 이 버전에 파트 음소거와 독립인 연습 메트로놈을 추가했습니다. 기본은 꺼짐이며 같은 박자·마디 길이인 보표에서 사용합니다. 프로젝트·MIDI·MusicXML·PDF에는 포함되지 않습니다.
- **선택 구간 루프 재생 · 일부 지원**: 이 버전은 총보에서 음표·쉼표 또는 연속 구간을 세션 연습 루프로 반복합니다. 반복·볼타/경계 타이/정렬되지 않은 보표는 적용 불가로 안내하며 파일에는 저장하지 않습니다.
- **MIDI 키보드 입력 · 직접 UI 없음**: MIDI 파일 내보내기는 가능합니다. 연결한 MIDI 키보드로 악보에 음표를 입력하는 기능은 아직 없습니다.
- **SVG 제품 내보내기 · 직접 UI 없음**: PDF와PNG는 내보낼 수 있습니다. 편집 가능한SVG 파일 내보내기는 아직 제공하지 않습니다.
- **오디오 파일 내보내기 · 직접 UI 없음**: 피아노 재생과 MIDI 저장은 가능합니다. WAV/MP3처럼 소리가 담긴 오디오 파일 내보내기는 아직 없습니다.
- **외부 음원·SoundFont·VST · 직접 UI 없음**: 내장 피아노와 파트 믹서는 사용할 수 있습니다. 외부SoundFont·VST 음원을 설치해 쓰는 기능은 아직 없습니다.
- **외부 MusicXML 이조·중첩 반복 호환성 · 외부 검증 미완**: MusicXML 기본/반복 펼치기 사본은 내보낼 수 있습니다. 외부 앱에서 중첩 반복이나 이조가 다르게 처리되는 과거 관찰은 별도 검증 과제로 남아 있습니다.
- **스윙 재생의 비율·구간·보표 범위 · 일부 지원**: 이 버전은 표기와 별도로 전역 스윙 재생 8분·16분, 2:1·3:2를 선택합니다. 기본은 꺼짐입니다. 표기와 재생이 다르거나 현재 악보에 적용되지 않을 때 안내하며, 적용 불가 MIDI는 직선 리듬임을 경고합니다. 구간·보표별 변경과 임의 비율은 지원하지 않습니다.
- **표기와 분리한 전역 스윙 재생의 첫 범위 · 일부 지원**: 이 버전은 표기와 별도로 전역 스윙 재생 8분·16분, 2:1·3:2를 선택합니다. 기본은 꺼짐입니다. 표기와 재생이 다르거나 현재 악보에 적용되지 않을 때 안내하며, 적용 불가 MIDI는 직선 리듬임을 경고합니다. 구간·보표별 변경과 임의 비율은 지원하지 않습니다.
- **꾸밈음 원래 연주 시간 지정의 가져오기 손실 안내 · 일부 지원**: 이 버전은 꾸밈음의 원래 시간 차용·추가 지정을 보존하지 못하면 원본 보관과 재생·재출력 비교를 안내합니다. 명시적 0과 원래 단위·값을 기술 정보에서 확인할 수 있습니다. 실제 꾸밈음 발음·시간 배분이나 원본 지정을 복원하는 기능은 아닙니다.
- **참고용 편집층의 표시·재생 구분 보존 설계 · 별도 제품 범위 결정**: 참고용 편집층의 원래 표시·재생 구분을 보존하는 기능은 아직 설계가 필요합니다. 현재 가져온 표기와 재생은 원본과 다를 수 있으므로 원본 MusicXML을 보관하고 비교하세요.

## 추가 조사 대상

다음은 정확한 범위를 더 확인할 항목입니다. 아직 미구현이라고 확정한 목록이 아닙니다.

XML 1.0 원문과 직접 숫자 참조가 허용되지 않는 문자를 나타내면 가져오기를 중단해 현재 문서를 유지합니다. 정상 리터럴과 CDATA, 기존 Native 글자를 자동 변경하지 않습니다. 제목·작곡가의 CDATA·처리 지시문 경계에서 단어 사이 공백을 보존합니다. 내부 선언값에 참조가 포함된 글자는 아직 이름으로 남을 수 있으며 원본과 비교가 필요합니다. 파트 이름과 약칭의 CDATA·처리 지시문 경계 공백도 보존합니다. 확인된 내부 선언 참조가 이름으로 남으면 원래 주소·참조 이름·건수를 기술 정보에 안내합니다. 이는 원문 글자를 복원하는 기능이 아닙니다.

## 이 버전에서 보완한 범위

- **위치별 빠르기의 범위 밖 입력 처리**: 이 버전에서는 위치별 빠르기도40–240 정수만 확정합니다. 잘못된 값은 오류로 남고 Enter 후에도 수정·Escape 취소가 가능합니다. 배포된alpha.39의 자동 보정과 구분하세요.

- **음 이름 변경의 이웃음 보존**: A–G는 선택한 음표를 바꾸고, 화음은 단음으로 바꿉니다. 이웃음의 원래 소리를 보존하는 보완이며, 다음 음표 입력과 쉼표 변환의 기존 동작은 유지합니다.
- **선택 임시표의 이웃음 보존**: 선택 모드의 임시표 버튼은 선택한 음표·화음에 적용합니다. 이웃음의 원래 소리를 보존하는 보완이며, 입력 모드에서 다음 음표에 적용하는 설정과 구분합니다.
- **화음 구성음 편집의 이웃음 보존**: 3도·5도 추가, Shift+A–G와 제거 가능한 구성음 편집은 선택한 음표에 적용합니다. 이웃음의 원래 소리를 보존하며, 기준음 제거와 부분 타이의 지원 범위는 확장하지 않습니다.
- **화음 추가의 저장 가능 음역 보호**: 프로젝트가 저장할 수 있는 음역(-1~9옥타브)을 벗어나는 구성음 추가는 안내와 함께 거부합니다. 기존 화음·선택·실행 취소 기록은 유지하며, 다른 출력 형식의 음역과는 구분합니다.
- **MIDI 음높이 표현 범위의 손실 없는 출력 정책**: 이 버전은 MIDI가 표현할 수 없는 음높이를 저장 전에 안내합니다. 원본 음높이를 임의로 보정하지 않으며, 음높이·이조·옥타브선을 확인한 뒤 다시 내보낼 수 있습니다. 프로젝트와 내부 재생은 유지합니다.
- **MIDI 음역 오류의 읽을 수 있는 원인 위치**: MIDI 음역 오류는 내보내기 요청 시점의 원인 파트 이름·보표·마디 번호를 기본 안내에 표시합니다. 같은 이름의 파트는 원래 목록 번호로 구분하며, 원본과 선택은 유지합니다.
- **MIDI 빠르기 오류의 기본·위치별 수정 범위 안내**: MIDI 빠르기 오류는 악보 기본 빠르기와 특정 마디의 위치별 빠르기를 구분해 안내합니다. 위치별 빠르기는 총보 공통이며, 원본값을 임의로 보정하지 않습니다.
- **파트 사본의 총보 공통 빠르기 전달 범위**: 이 버전은 마디 시작과 실제 길이가 같은 총보의 파트 사본에서 공통 빠르기를 유지합니다. MIDI와 구조 유지·반복 펼치기 MusicXML에 적용하며 원본 프로젝트와 파트보 화면·PDF는 바꾸지 않습니다. 시간 구조가 다른 보표의 빠르기 대응은 이 지원 범위에 포함하지 않습니다.
- **소프트·소스테누토 페달 재생 지시의 손실 안내**: 이 버전은 MusicXML의 소프트·소스테누토 페달 재생 지시를 보존하지 못하면 원본 보관과 페달 연주 비교를 안내합니다. 지원하는 댐퍼 페달 재생은 유지하며 새 페달 발음을 추가한 것은 아닙니다.
- **같은 문서의 선택 대상 변경과 표기 속성 후보 소유권**: 이 버전은 선택 대상을 바꾸면 트레몰로·표기 배치·조표와 박자표·선택 마디와 현재 보표의 음자리표·현재 파트 이조·가사 음절의 미확정 후보를 폐기합니다. 각 속성의 적용 대상이 같으면 후보와 명시적 편집·실행 취소를 유지합니다. 가사 절 탐색과 다음에 추가할 악기는 별도 설정으로 유지합니다. 물리 입력과 스크린리더 검수는 별도입니다.
- **MusicXML 음표 반복 회차 조건의 가져오기 손실 안내**: 이 버전은 MusicXML 음표의 반복 회차 조건을 가져오지 못하면 파트·마디와 함께 안내합니다. 현재 재생과 사본에는 이 조건이 적용되지 않습니다. 원본을 보관하고 반복 재생과 다시 내보낸 파일을 비교하세요. 조건부 음표 재생 지원과는 별개입니다.
- **MusicXML 음표 연주 시작·종료 시점 조정 손실 안내**: 이 버전은 MusicXML 음표의 연주 시작·종료 시점 조정을 가져오지 못하면 파트·마디와 함께 각각 안내합니다. 현재 재생과 사본에는 이 추가 조정이 적용되지 않습니다. 원본을 보관하고 음의 시작·끝과 다시 내보낸 파일을 비교하세요. 음가 변경이나 실제 연주offset 지원과는 별개입니다.
- **MusicXML 피치카토·아르코 연주 지시 손실 안내**: 이 버전은 음표별 피치카토 켜기/끄기와 이후 음표의 피치카토·아르코 지시가 보존되지 않으면 파트·마디와 함께 안내합니다. 가져오기 경고의 기술 정보에서 원래 값과 위치를 확인할 수 있습니다. 현재 재생과 사본에는 이 지시가 적용되지 않습니다. 원본 MusicXML을 별도로 보관하세요. 새 주법·음색 재생 지원은 아닙니다.
- **MusicXML 보표·시스템 글자의 마디 안 위치 손실 안내**: 이 버전은 MusicXML 보표·시스템 글자의 마디 안 위치를 가져오지 못하면 파트·마디와 함께 안내합니다. 글자 내용은 유지하지만 현재 표기와 사본은 마디 단위로 배치합니다. 원본을 보관하고 글자가 붙는 음표와 다시 내보낸 파일을 비교하세요. 정확한 박별 위치 보존 기능은 아닙니다.
- **MusicXML 표현 글자의 원본 박별 위치와 divisions 읽기**: 이 버전은 지원하는 표현 글자의 원본 박별 위치를 MusicXML의 현재 위치와 divisions에 맞게 읽습니다. 유효한 음수·소수 offset도 기존 tick으로 변환하며 글자 내용과 음악은 유지합니다. 이미 저장된 Native 위치는 자동 수정하지 않습니다. 보표·시스템 글자의 마디 단위 배치와는 별개입니다.
- **MusicXML MIDI 뱅크 지정의 손실 안내**: 이 버전은 MusicXML의 MIDI 뱅크 지정이 보존되지 않을 때 한국어로 안내합니다. 기술 정보에서 원래 값·악기 참조·파트와 마디·원본 경로를 확인하세요. 기존 음색·로컬 믹서와 음악은 유지하며 원본 뱅크의 재생·음색 복원을 추가한 것은 아닙니다.
- **MusicXML 원본 MIDI 채널 지정의 손실 안내**: 이 버전은 MusicXML의 MIDI 채널 지정이 보존되지 않을 때 한국어로 안내합니다. 기술 정보에서 원래 값·악기 참조·파트와 마디·원본 경로를 확인하세요. MIDI 사본은 현재 파트 순서에 따라 채널을 배정하며 원본 채널 라우팅을 복원한 것은 아닙니다. 기존 음색·로컬 믹서와 음악은 유지합니다.
- **MusicXML 원본 MIDI 악기 이름·장치 지정의 손실 안내**: 이 버전은 MusicXML의 원본 MIDI 악기 이름·장치 지정을 보존하지 못할 때 한국어로 안내합니다. 기술 정보에서 원래 이름·장치·포트·악기 참조와 원본 위치·경로를 확인하세요. 원문의 공백도 유지합니다. 현재 음악·재생·믹서는 유지하며 원본 장치 라우팅을 복원한 것은 아닙니다.
- **원본 MIDI 타악기 음 번호 지정의 가져오기 손실 안내**: 이 버전은 MusicXML의 원본 MIDI 타악기 음 번호 지정을 보존하지 못할 때 한국어로 안내합니다. 원래 값·악기 식별자·위치는 기술 정보에서 확인할 수 있습니다. 현재 재생과 믹서는 유지하며, 무음정 음표 가져오기나 타악기 음 번호 적용을 추가한 것은 아닙니다.
- **독립 임시표·사용자 확장 표기의 가져오기 손실 안내**: 이 버전은 MusicXML의 독립 임시표와 사용자 확장 표기를 보존하지 못할 때 한국어로 안내합니다. 원래 값과 위치는 기술 정보에서 확인할 수 있습니다. 원본 MusicXML을 보관하세요. 해당 기호의 표시·편집 기능을 추가한 것은 아닙니다.
- **MusicXML 원본 재생 연주법 지정의 손실 안내**: 이 버전은 MusicXML 원본의 재생 연주법 지시를 보존하지 못할 때 한국어로 안내합니다. 원래 지시와 대상·위치는 기술 정보에서 확인하세요. 현재 믹서 음소거와는 다른 설정입니다. 원본 파일을 보관하고 악기 소리와 사본을 비교하세요. 원래 연주법을 적용하는 재생 기능을 추가한 것은 아닙니다.
- **MusicXML 마디 우선 구조의 미지원 안내**: 이 버전은 마디 우선(score-timewise) MusicXML을 현재 지원하지 않는 구조로 안내합니다. 원본을 보관하고 파트 우선(score-partwise) 구조의 사본을 확인하세요. 자동 변환 기능은 아닙니다.
- **긴 최근 목록의 시작 화면 오류 노출**: 이 버전은 시작 화면의 새 파일 오류를 화면에 보여주고 키보드 초점은 유지합니다. 최근 목록이 늦게 표시될 때도 현재 안내를 확인합니다. 요청 뒤 스크롤·초점 이동·글자 읽기·새 악보 작업을 시작했다면 그 작업을 우선하며, 읽기 선택을 해제해도 이전 안내로 화면을 되돌리지 않습니다. 새 파일을 여는 동안에는 이전 안내 때문에 화면을 이동하지 않습니다.
- **최근 MusicXML 읽기의 진행 상태**: 이 버전은 최근 MusicXML을 읽는 동안 해당 행에 ‘불러오는 중’을 표시합니다. 다른 항목을 선택할 수 있으며 나중에 선택한 파일이 우선합니다. 파일 없음 후 재시도 중에도 읽는 중을 표시하고, 다시 실패하면 파일 없음 표시로 돌아갑니다. 읽는 중인 항목을 목록에서 지워도 최근 악보 영역에 파일명과 진행 안내가 남습니다. 목록 정리는 읽기 취소가 아니며 완료되면 파일이 열립니다.
