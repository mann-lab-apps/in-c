# 선택 객체 속성과 배치

기능 기준: alpha.41. 메뉴 이름과 아래 적용 범위를 함께 확인하세요.

<a id="inspector"></a>
## 선택 객체 속성 읽기·수정

**찾는 곳:** 보기 → 속성 / 도구 → 선택 속성 열기

1. 단음·쉼표·마디·글자·슬러/헤어핀을 선택합니다
2. 선택한 표기와 작업 마디의 구분을 읽습니다
3. 해당 카드의 편집기를 사용합니다

- **결과·적용 범위:** 대상·파트·보표·성부·마디와 입력 커서 위치를 구분합니다. 선택 없음/범위의 항목은 현재 지원 정책대로 제한됩니다.
- **복수 선택의 경계:** 서로 다른 객체를 한꺼번에 바꾸는 mixed 속성 편집은 지원하지 않습니다. 범위를 선택했다고 마디/위치의 글자·코드·셈여림 속성이 범위 전체에 적용되는 것은 아닙니다. 활성화된 필드의 대상과 적용 범위를 먼저 확인하세요. [선택과 복사](03-notes.md#delete)는 별도의 지원 범위를 따릅니다.
- **단축키:** F6으로 도구/악보 이동
- **안 되거나 다른 결과가 나오면:** 지원되지 않는 mixed 편집 UI를 완성한 것으로 표시하지 않습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#inspector)에서 예제·기대 결과와 대조하세요.

이 버전은 선택 대상을 바꾸면 트레몰로·표기 배치 목록의 미확정 후보를 폐기합니다. 새 대상의 값을 바꾸려면 목록을 다시 열어 선택하고 Enter 또는 Tab으로 확정하세요. Escape는 후보만 취소합니다. 같은 대상의 화면 갱신은 탐색 중인 후보를 유지합니다.

<a id="span-find"></a>
## 범위 표기 찾기·선택·끝점·삭제

**찾는 곳:** 도구 → 범위 표기 찾기

1. 표기 객체 선택에서 슬러/헤어핀을 고릅니다
2. 파트·보표·성부·범위를 확인합니다
3. 시작점/끝점 목록에서 유효한 위치를 선택합니다
4. 필요하면 선택 표기 삭제 또는 선택 해제를 누릅니다

- **결과·적용 범위:** 현재 picker는 슬러/헤어핀을 대상으로 합니다. 시작은 끝보다 앞이어야 하고 지원하는 같은 파트·보표 범위를 따릅니다.
- **단축키:** 버튼 focus에서 Delete/Backspace: 삭제, Escape: 선택 해제
- **안 되거나 다른 결과가 나오면:** 미지원 끝점은 그대로 표시하되 선택할 수 없고 오류 안내가 나옵니다. 타이/옥타브에 같은 geometry 편집기가 있다고 설명하지 않습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#span-find)에서 예제·기대 결과와 대조하세요.

<a id="geometry"></a>
## 배치·형상: 자동값과 명시적 0

**찾는 곳:** 범위 표기 속성 → 배치 · 형상

1. 슬러/헤어핀을 선택하고 배치 · 형상을 펼칩니다
2. 자동/보표 위/보표 아래와 가로·세로·높이를 조절합니다
3. Enter 또는 포커스 이동으로 확정합니다
4. 초기화 아이콘으로 수동값을 자동으로 복원합니다

- **결과·적용 범위:** 빈 값은 자동, offset 0은 명시한 위치입니다. sp는 오선 간격 단위입니다. offset -8–8, 높이 0.5–8, step0.25 sp입니다.
- **단축키:** Enter/blur: 한 명령, Escape: 초안 취소
- **안 되거나 다른 결과가 나오면:** 범위 밖 값은 오류와 원래 값 복원을 따릅니다. 수동 geometry를 자동 충돌 보정이 임의 이동하지 않습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#geometry)에서 예제·기대 결과와 대조하세요.

<a id="part-geometry"></a>
## 총보·파트보 배치의 공통 범위와 보존

**찾는 곳:** 총보·파트보 전환 → 선택 span 속성

1. 총보와 파트보를 전환합니다
2. 범위 속성에 표시된 총보·해당 파트보 공통 범위를 확인합니다
3. 파트보의 용지/보표 크기는 PDF 페이지 설정에서 별도로 바꿉니다
4. 공통 속성 변경이 총보와 해당 파트보에 함께 적용됨을 확인합니다

- **결과·적용 범위:** 현재 범위 속성은 총보·해당 파트보 공통 geometry를 편집합니다. 파트·시스템 구간별 독립 geometry는 현재 모델과 native 형식에서 지원하지 않습니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 파트별 span/임의 segment 편집기를 현재 UI에 있다고 안내하지 않습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 공통 편집 지원; 파트·구간별 독립 배치는 별도 설계 필요. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#part-geometry)에서 예제·기대 결과와 대조하세요.

<a id="drafts"></a>
## 속성 입력 확정·취소·저장 전 확인

**찾는 곳:** 숫자/글자 속성 필드

1. 값을 수정합니다
2. Enter 또는 blur로 확정합니다
3. Escape로 해당 draft를 취소합니다
4. 미확정 입력 중 저장 안내가 나오면 먼저 확정하거나 취소한 뒤 저장합니다

- **결과·적용 범위:** 한 번 확정은 명령1회·undo1회입니다. 대상 변경 시 이전 draft를 새 객체에 저장하지 않습니다. 필드별 범위/오류 정책은 다릅니다.
- **단축키:** Enter, Escape, ⌘/Ctrl+S
- **안 되거나 다른 결과가 나오면:** IME 조합은 확정과 전역 단축키에서 보호합니다. 필드 일부에 자동 보정/복원 경로가 있으므로 모든 숫자 UX가 같다고 가정하지 않습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#drafts)에서 예제·기대 결과와 대조하세요.
