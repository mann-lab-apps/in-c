# 재생과 믹서

기능 기준: alpha.43. 메뉴 이름과 아래 적용 범위를 함께 확인하세요.

<a id="transport"></a>
## 선택 위치 재생·일시정지·정지·처음으로

MusicXML로 가져온 마디 경계의 D.C.·D.S., Fine, To Coda와 세뇨·코다는 악보의 보표와 마디 길이가 맞고 이동 경로가 하나로 정해지면 재생에 적용합니다. 악보에 표시되는 일반 글자는 원래의 표시로 유지됩니다. 복합 경로, 박 중간 지시나 표시 없는 반복 시작이 적용되지 않으면 가져오기 경고를 확인하세요.

**찾는 곳:** 상단 재생 컨트롤

1. 음표/쉼표를 선택합니다
2. 재생 또는 Space를 누릅니다
3. 일시정지로 멈췄다가 다시 시작합니다
4. 정지와 처음으로를 구분해 사용합니다

- **결과·적용 범위:** 선택 위치가 있는 경우 그 위치를 우선하는 기존 정책입니다. 입력창·버튼·메뉴에서 Space는 해당 control이 우선합니다.
- **단축키:** Space

표시된 오류·경고 안내의 글자를 선택해 읽는 동안에는 Space가 전역 재생·일시정지로 전달되지 않습니다. 브라우저의 기본 읽기 동작을 유지합니다. 글자 선택을 해제하거나 악보로 명시적으로 돌아오면 기존 Space 재생을 사용할 수 있습니다. 기술 정보 버튼 등 컨트롤 위에서는 해당 버튼의 조작이 우선합니다.
- **안 되거나 다른 결과가 나오면:** 음색 준비/지원하지 않는 보표/실패 상태에서 안내와 enablement를 확인합니다.
- **되돌리기·취소:** 재생 중에는 일시정지 또는 정지로 멈춥니다. 준비 중인 소리는 정지로 취소합니다. 재생 조작은 악보 실행 취소 기록을 만들지 않으며, ⌘/Ctrl+Z는 이전 악보 편집에 적용됩니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#transport)에서 예제·기대 결과와 대조하세요.

<a id="metronome"></a>
## 연습 메트로놈

**찾는 곳:** 상단 재생 컨트롤 → 메트로놈. 이 버전의 기능입니다.

1. 메트로놈 버튼을 켭니다. 처음에는 꺼져 있습니다.
2. 재생하면 박마다 짧은 클릭이 나며 마디 첫 박은 다른 높이입니다.
3. 재생 중 끄거나 일시정지·정지를 누르면 예약된 클릭도 취소됩니다.

파트 음소거·솔로·음량0과 독립인 로컬 연습 도구입니다. 설정은 앱에 저장되지만 악보를 수정하거나 undo를 만들지 않습니다. 프로젝트·MusicXML·MIDI·PDF에는 포함되지 않고, 음표 미리듣기에서는 클릭하지 않습니다. 별도 단축키는 없으며 버튼에 Tab으로 이동해 Enter/Space로 조작합니다.

단순박자는 분모 음가를 따릅니다. 6/8처럼 분자가3보다 큰3의 배수인 겹박자는 마디 시작의 큰박 빠르기가 분당60 이상이면3개씩 묶고, 느리면 분모 단위로 클릭합니다. 위치별 빠르기와 반복·페르마타는 기존 재생 시간을 따릅니다. 못갖춘마디는 명목 마디 끝에 맞추므로 아주 짧으면 클릭할 박이 없을 수 있습니다.

모든 보표의 박자표·마디 수·실제 길이가 같을 때 지원합니다. 다른 악보에서는 적용 불가 안내와 함께 버튼이 비활성화되지만 악보 재생은 유지됩니다. 저장된 켜짐 설정은 유지되며 지원되는 악보에서 다시 사용됩니다. count-in·음색 선택·오디오 파일 출력은 이번 범위가 아닙니다. 연속 구간 연습 루프는 아래의 별도 범위를 확인하세요. 실제 청음과 물리 장치 검수는 별도입니다.

클릭 소스를 준비하거나 예약하는 중 오류가 나면 재생을 멈추고 한국어 안내를 표시합니다. 시작 전 실패는 정지, 재생 중 실패는 해당 위치에서 일시정지 상태로 남습니다. 원래 진단은 피아노 영역의 **기술 정보**를 펼쳐 확인합니다. **재생**을 눌러 다시 시도하며, 실패 때문에 악보 내용이나 실행 취소 기록이 바뀌지는 않습니다.

## 선택 구간 연습 루프

**찾는 곳:** 총보 보기 → 음표·쉼표 또는 연속 범위 선택 → 상단 **연습 루프**. 이 버전의 기능입니다.

1. 한 음표·쉼표를 선택하거나 Shift+클릭/Shift+방향키로 같은 보표·성부의 연속 구간을 선택합니다.
2. 연습 루프를 켜고 표시된 시작·끝과 **총보** 적용 범위를 확인합니다.
3. 재생을 누릅니다. 첫 음의 시작부터 마지막 음의 끝까지 반복하며 바로 다음 음의 attack은 포함하지 않습니다.
4. 일시정지는 구간 안의 위치를 유지하고, 처음으로는 구간 시작으로 돌아갑니다. 정지는 기존처럼 0으로 돌아가며 다음 재생은 구간 안에서 시작합니다.
5. 루프를 끄면 현재 위치에서 일반 재생으로 돌아갑니다. 다른 구간을 설정하려면 끈 뒤 새 구간을 선택해 켭니다.

선택한 보표만 solo하는 기능이 아닙니다. 같은 시간의 총보 모든 파트를 기존 음소거·솔로·음량에 따라 재생합니다. 빠르기 변경·페르마타·메트로놈은 기존 오디오 시계를 사용합니다. 재생 중 따라가기 때문에 선택이 바뀌어도 확정한 구간은 유지됩니다.

반복·볼타가 있는 악보나 실제 재생 이동이 있는 악보, 보표의 박자·마디 수·길이가 다른 악보, 어느 파트에서든 구간 경계를 가로지르는 타이는 첫 지원 범위에서 적용 불가로 안내합니다. 타이를 구간 안에 모두 포함하면 지원합니다. 원본 기호를 삭제하거나 반복 의미를 바꾸지 않으며 일반 재생은 계속 사용할 수 있습니다.

루프는 **세션 전용**입니다. 악보를 수정하거나 총보에서 파트보로 바꾸면 해제됩니다. 실행 취소로 이전 루프를 되살리지 않습니다. 프로젝트·MusicXML·MIDI·PDF에 저장되지 않고 문서를 clean으로 바꾸거나 undo를 만들지 않습니다. 별도 단축키는 없으며 Tab으로 버튼에 이동해 Enter/Space로 조작합니다. 입력 모드는 완료하거나 취소한 뒤 설정하세요.

## 재생 위치 따라가기와 수동 스크롤

**찾는 곳:** 상단 재생 위치 따라가기

1. 따라가기를 켜고 재생합니다
2. wheel/touch/스크롤바로 직접 이동합니다
3. 자동 추적이 중단된 뒤 따라가기 버튼을 다시 눌러 복귀합니다

- **결과·적용 범위:** 일반/오버레이 스크롤바는 손잡이·트랙을 누르는 즉시 추적을 중단합니다. 음악 재생 자체는 별도입니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 도구/입력 focus와 수동 이동의 소유권을 구분합니다. 오래된 예약 스크롤이 새 수동 이동을 취소하면 결함 후보입니다.
- **되돌리기·취소:** 추적을 다시 켜려면 재생 위치 따라가기를 누릅니다. 따라가기 설정은 보기 상태이며 악보 실행 취소로 켜거나 끄지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#follow)에서 예제·기대 결과와 대조하세요.

## 파트 믹서·뮤트·솔로·음량·활동 표시

**찾는 곳:** 보기 → 믹서 / 재생 도구 / 믹서 표시

1. 믹서를 엽니다
2. 각 파트의 뮤트·솔로와 음량을 바꿉니다
3. 재생 중/대기 표시와 실제 선택 파트를 구분합니다
4. 믹서 필드에서 F6으로 선택한 음표에 돌아갑니다. 다시 F6을 누르면 악보 이동 도구로 갑니다. 상단 재생 도구로 돌아갈 때는 휠로 직접 이동한 뒤 믹서를 닫을 수 있습니다.

- **결과·적용 범위:** 로컬 믹서 설정과 악보 기호를 구분합니다. 활동 표시는 timeline/gain 기준이며 실제 음향 에너지 meter가 아닙니다.

재생 중 믹서를 바꾸면 계속 들리는 피아노 음은 울리던 샘플 위치에서 이어집니다. 볼륨·음소거·솔로 설정은 이어지는 재생과 다음 음에 반영됩니다.

이 버전은 가져온 MusicXML의 악기별 음량(`volume`)·좌우 배치(`pan`)·상하 배치(`elevation`)를 현재 프로젝트에 보존하지 못하면 경고합니다. 음량 0이나 공간 배치 0도 원본에 명시된 값이면 안내합니다. **기술 정보**에서 원래 값·악기 참조·XML 위치를 확인하세요. 이 안내는 현재 로컬 믹서의 뮤트·솔로·음량을 자동 변경하지 않으며, 원본 공간 배치를 재생하거나 사본에 복원하는 기능은 아닙니다. 원본을 보관하고 재생과 교환 결과를 비교하세요.
- **단축키:** F6은 믹서 필드 → 선택한 악보 위치 → 악보 이동 도구로 이동합니다. IME 조합 중에는 실행하지 않습니다.
- **안 되거나 다른 결과가 나오면:** 쉼표·뮤트·solo 배제·volume0·pause/stop은 표시가 달라집니다. 여러 파트가 동시에 재생 중일 수 있습니다.
- **되돌리기·취소:** 믹서 값을 되돌리거나 닫을 수 있습니다. 악보 내용의 undo와 별도 로컬 상태입니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#mixer)에서 예제·기대 결과와 대조하세요.

## 그랜드 피아노·미리 듣기·준비 오류 재시도

**찾는 곳:** 피아노 음색

1. 들어보기 버튼으로 음색을 준비합니다
2. 준비 중 진행과 오류를 확인합니다
3. 실패 시 재생을 눌러 재시도합니다
4. 음원 정보를 펼쳐 원본·크레딧을 확인합니다

- **결과·적용 범위:** 내장 sample/worker를 사용하는 실제 앱 재생입니다. 준비 중/재생 중에는 들어보기 버튼이 제한됩니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 음소거 검증을 청음으로 대신하지 않습니다. 모든 악기를 독립적인 실제 악기 음원으로 제공한다는 뜻이 아닙니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#piano)에서 예제·기대 결과와 대조하세요.

<a id="pedal"></a>
## 수동 서스테인과 자연스러운 연주(시험)

**찾는 곳:** 피아노 음색의 체크 항목

1. 수동 서스테인 페달을 켜거나 끕니다
2. 자연스러운 연주(시험)를 켜고 표현 준비가 끝날 때까지 기다립니다
3. 같은 악보의 연주와 기보 내용이 구분되는지 확인합니다

- **결과·적용 범위:** 수동 페달은 악보 페달 재생에 더하는 앱 연주 상태입니다. 페달을 밟은 동안 건반을 뗀 음은 자연스럽게 감쇠하며 이어집니다. 악보 페달과 수동 페달이 겹치면 해당 파트에 적용되는 두 페달이 모두 해제될 때 음이 풀립니다. 아직 건반을 떼지 않은 음은 원래 음 길이까지 재생됩니다. 같은 위치에서 일시정지 후 재생을 계속하면 수동 페달로 울리던 음도 이어집니다. 일시정지 중 수동 페달을 해제하면 그 페달로 유지하던 소리는 정리됩니다. 시험 기능은 악보 입력과 다른 표현 모델입니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 이 옵션이 MusicXML/MIDI에 그대로 bake되거나 모든 외부 앱이 같은 소리를 낸다고 보장하지 않습니다.

MusicXML의 소프트·소스테누토 페달 재생 지시는 현재 보존하지 못합니다. 가져오기 경고에서 원래 지시와 값을 확인하고 원본 파일을 보관하세요. 지원하는 댐퍼 페달 재생과 수동 서스테인은 유지되며, 새 페달 발음이 추가되는 것은 아닙니다.
- **되돌리기·취소:** 체크를 해제해 이전 연주 설정으로 돌아옵니다. 악보 음표를 변경하는 undo 명령이 아닙니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#pedal)에서 예제·기대 결과와 대조하세요.

<a id="leading-grace-playback"></a>
## 앞꾸밈음 발음

**형식 → 악보 설정 → 앞꾸밈음 발음**을 켜면 일반 단음 앞의 꾸밈음 하나를 재생과 MIDI 사본에서 들을 수 있습니다. 기존 프로젝트의 기본값은 꺼짐입니다. 설정을 유지하려면 프로젝트 파일로 저장하세요. 설정을 켜서 저장한 프로젝트를 열려면 앞꾸밈음 발음을 지원하는 빌드가 필요합니다.

꾸밈음은 본음 시작에서 길이를 가져옵니다. 4분음표 한 박을 기준으로 사선이 있으면 최대 1/16박, 사선이 없으면 최대 1/2박을 사용하며 본음 길이의 절반을 넘지 않습니다. 본음의 끝과 다음 음의 시작은 유지됩니다. 뒤꾸밈음, 여러 꾸밈음, 화음·타이·잇단음표·페르마타·장식음·트레몰로가 있는 본음의 꾸밈음은 이전처럼 표기로 남습니다. MusicXML에는 표기를 내보내며, 실제로 발음하지 않은 꾸밈음은 MIDI 내보내기 경고에서 확인할 수 있습니다.

<a id="repeat-play"></a>
## 반복·볼타·빠르기·타이·헤어핀 재생 범위

**찾는 곳:** 반복 악보 → 재생 / MIDI 내보내기

1. 단순 반복과 볼타를 만든 뒤 재생합니다
2. 반복 복귀 위치의 빠르기를 확인합니다
3. 헤어핀과 타이가 반복을 가로지르는 조건에서는 표기와 실제 음 이벤트를 구분합니다

- **결과·적용 범위:** 복귀 위치의 유효 빠르기를 복원하고 미완결 헤어핀 적용은 반복 복귀에서 중단합니다. 원본 표기는 보존합니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 외부 MuseScore의 중첩 반복/볼타·중간 이조 차이는 미해결입니다. 가져온 미지원 타이/기호는 경고를 확인합니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#repeat-play)에서 예제·기대 결과와 대조하세요.


바깥과 안쪽의 시작·끝이 모두 명시되고 볼타가 없는 중첩 반복은 바깥으로 돌아올 때 안쪽도 다시 시작합니다. 이 순서는 내부 재생·MIDI·반복 펼치기에 함께 적용됩니다. 원본과 기본 MusicXML은 반복 마디선을 보존합니다. 다른 구간의 1·2번 볼타는 해당 구간에서 기존과 같이 재생됩니다. 단순 반복의 MusicXML에서 가져온 `1,2`와 `3`은 각 회차에서만 재생됩니다. 몇 번째 회차인지 없는 볼타는 괄호만 표시하고 해당 마디를 거르는 재생 조건으로 쓰지 않습니다. 이 경우 가져오기 경고를 확인하세요. 볼타가 중첩 구간과 겹치거나, 끝점이 모호하거나, 펼친 마디 수가 원래 마디 수의 100배를 넘는 경우에는 기존 재생 규칙을 따릅니다.

명시적인 시작 도돌이표 하나에 여러 끝이 붙을 수 있습니다. 각 끝에서 되돌아가는 회차와 최종 볼타의 회차가 겹치거나 빠지지 않게 지정하면, 매 회차에 같은 시작으로 돌아가 해당 볼타를 연주합니다. 예를 들어 첫째·둘째 볼타에서 각각 돌아오고 셋째 볼타에서 진행하면 1–2–1–3–1–4 순서가 됩니다. 회차가 겹치거나 마지막 회차가 빠지면 가져오기 경고의 기술 정보에서 해당 끝 도돌이표를 확인하세요.

타이로 이어지는 음에 헤어핀을 연결해도 그 음의 박에서 재생 세기 범위를 계산합니다. 타이는 한 번 눌러 이어 재생합니다. 샘플 피아노와 MIDI는 새로 시작하는 음의 타건 세기에 변화를 적용합니다. MusicXML에서 가져온 독립 종료 박의 헤어핀은 샘플 피아노에서 이미 울리는 음의 세기에도 적용됩니다. 중간에서 재생을 계속하면 해당 위치의 세기에서 이어집니다. MIDI 사본에는 음이 시작할 때의 타건 세기가 기록됩니다.

### D.C.·D.S.와 이동 표지 편집

- 세뇨와 코다는 마디 시작에, D.C.·D.S.·Fine과 To Coda는 마디 끝에 표시합니다. MusicXML에 재생 지시와 함께 기호·글자가 있으면 둘을 함께 읽습니다. 원본의 위치·꾸밈이 자동 배치로 바뀌면 가져오기 경고를 확인하세요.
- 재생, MIDI, 반복 펼치기 MusicXML은 같은 마디 순서를 따릅니다. 원본 프로젝트와 구조 유지 MusicXML 사본에는 지원하는 이동 지시가 남습니다. 점프 뒤 도돌이표를 수행하는지 MusicXML에서 명시하면 그 설정을 적용합니다.
- 명시적인 시작·끝 도돌이표 하나에 연속된 두 볼타를 붙이고, 앞 볼타에는 마지막 전 회차 전부를, 뒤 볼타에는 마지막 회차만 지정할 수 있습니다. 예를 들어 세 번 반복할 때 앞 볼타에 `1, 2`, 뒤 볼타에 `3`을 적용합니다. D.C. 또는 D.S.로 돌아오면 기본 설정에서 마지막 볼타를 연주합니다. 이어지는 Fine 정지점 또는 점프보다 뒤쪽의 Coda로 연결할 수 있습니다. 하나의 시작과 여러 끝을 공유하는 볼타의 회차가 모두 확정된다면, D.S. al Fine 또는 D.S. al Coda로 돌아올 때 마지막 볼타를 연주합니다. 마지막 볼타의 To Coda에 도달하면 연결한 뒤쪽 코다로 이동합니다. 이 볼타 구간 앞에 서로 겹치지 않는 일반 도돌이표가 있으면, 돌아오는 길에 만나는 각 구간의 설정을 따릅니다. MusicXML에서 점프 뒤 반복을 명시한 구간은 다시 반복하고, 설정이 없거나 반복 생략을 명시한 구간은 한 번 지나갑니다. 여러 도돌이표가 겹치거나 도착 지점이 모호하면 가져오기 경고나 반복 이동 편집의 안내를 확인하세요.

1. 마디 또는 그 안의 표기를 선택합니다.
2. **추가 → 반복·볼타 팔레트 → 반복·볼타 설정 열기**에서 **반복 이동**을 펼칩니다.
3. 세뇨, 코다, D.C., D.S., Fine, To Coda 중 종류를 고릅니다. D.S.와 세뇨, To Coda와 코다에는 각각 동일한 연결 이름을 입력합니다. D.S. al Fine처럼 악보에서 볼 문구는 따로 입력합니다.
4. **이동 표지 적용**을 누릅니다. 새 표지는 총보의 대응 마디 첫 보표에 표시합니다. 여러 보표의 마디 개수와 길이가 같아야 추가할 수 있습니다.
5. 이미 붙은 표지를 바꾸려면 **편집할 이동 표지**에서 소유 파트·보표를 확인합니다. **이동 표지 삭제**는 그 표지만 삭제합니다. 적용과 삭제는 각각 한 번 실행 취소할 수 있습니다.

재생 경로가 완성될 때까지 프로젝트로 저장할 수 있습니다. 연결 이름이 맞지 않으면 표지가 남고 재생은 일반 반복 순서를 사용합니다. 여러 점프, 중첩 볼타, 표지 드래그는 후속 범위입니다.

MuseScore Studio 4.7.5는 Studio의 구조 유지 XML에서 D.S.를 생략하고 도돌이표만 수행한 사례가 있습니다. 다른 앱에서 재생 순서가 우선이면 **반복 펼치기 MusicXML 사본**을 사용해 재생을 확인하세요. 편집에 쓸 악보는 프로젝트 파일과 구조 유지 사본으로 보관하세요.

이 버전의 파트 사본은 마디 시작과 실제 길이가 같은 총보의 공통 빠르기를 유지합니다. 다른 파트의 마디에 연결된 빠르기도 MIDI와 구조 유지·반복 펼치기 MusicXML 사본에 포함합니다. 원본 프로젝트와 파트보 화면·PDF는 변경하지 않습니다. 시간 구조가 다른 보표의 빠르기 대응은 이 지원 범위에 포함하지 않습니다.
