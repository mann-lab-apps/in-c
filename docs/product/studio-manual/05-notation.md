# 표기와 표현

기능 기준: alpha.43. 메뉴 이름과 아래 적용 범위를 함께 확인하세요.

<a id="tie"></a>
## 타이: 같은 소리를 이어 연주

T는 수식키 없이 사용합니다. Shift+T도 같은 동작이며, Control/Command/Option(Alt)와 함께 누른 T는 Studio의 타이 편집을 실행하지 않습니다. 사용자 키 재지정이나 새 글자 단축키가 추가된 것은 아닙니다.

**찾는 곳:** 음표 선택 → 타이 버튼

1. 같은 소리로 이어질 앞 음표를 선택합니다
2. T 또는 타이 버튼으로 연결/해제합니다
3. 줄바꿈과 재생에서 이어지는지 확인합니다

- **결과·적용 범위:** 현재 지원하는 동일 음높이 단음 또는 동일 화음 전체 연결입니다. 옥타브 선을 반영한 실제 음높이 조건을 따릅니다.
- **단축키:** T
- **안 되거나 다른 결과가 나오면:** 서로 다른 화음의 일부 음만 잇는 새 타이는 만들 수 없습니다. 기존 파일의 미지원 타이는 안내와 제거 경로를 사용합니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#tie)에서 예제·기대 결과와 대조하세요.

MusicXML에서 F♯와 G♭처럼 소리가 같고 음이름이 다른 두 단음의 타이를 가져올 수 있습니다. 같은 보표·성부에서 두 음이 바로 이어지고 악기 이조가 같아야 합니다. 악보의 음이름과 필요한 임시표를 유지하고 한 음으로 이어 재생합니다. 이미 연결된 단음의 한쪽을 J로 같은 소리의 다른 음이름으로 바꿀 때도 타이를 유지합니다. 이 타이는 Native 프로젝트와 MusicXML 사본에 보존되며, 편집 화면에서 제거할 수 있습니다.

<a id="slur"></a>
## 슬러: 프레이즈를 묶는 곡선

**찾는 곳:** 추가 → 범위 기호 팔레트 → 범위 기호 설정 열기

1. 시작 음표를 선택하고 S를 누릅니다
2. 끝 음표를 선택하고 다시 S를 누릅니다
3. 슬러를 선택해 속성에서 시작/끝·배치·높이를 수정합니다
4. 이 버전에서는 수동 배치된 슬러·헤어핀의 선에 포커스를 두고 방향키로 0.25 sp 격자, ⌘/Ctrl+방향키로 1 sp 격자 이동합니다. 모든 구간의 공통 배치이며 ±8 sp 범위를 벗어나면 현재 위치를 유지합니다. 자동 배치·타이·포인터 모양 핸들·파트별 독립 편집은 이 경로에 포함되지 않습니다.

- **결과·적용 범위:** 슬러는 프레이즈 표기이며 타이처럼 음가를 합쳐 동일 음으로 재생하는 명령이 아닙니다. 끝이 가늘고 줄바꿈에서 이어집니다.
- **단축키:** S, S / Esc
- **안 되거나 다른 결과가 나오면:** 지원하는 같은 파트·보표·시간 순서의 끝점이 필요합니다. 미완결 입력은 Esc로 취소합니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#slur)에서 예제·기대 결과와 대조하세요.

슬러 조각에 키보드 초점을 둔 채 줄·페이지 나누기를 되돌리면, 같은 마디를 포함하는 조각으로 초점이 돌아옵니다. 조각이 합쳐졌다가 다시 나뉘는 경우에도 처음 초점을 둔 마디를 따라갑니다.

## 셈여림 적용과 원본 보관 값

**찾는 곳:** 추가 → 셈여림 팔레트 / 선택 위치 속성

1. 음표나 마디를 선택합니다
2. ppp·pp·p·mp·mf·f·ff·fff·sfz 중 타일을 적용합니다
3. 속성의 셈여림 대상에서 개별 값을 확인·수정·제거합니다
4. 이 버전에서는 타일을 음표·쉼표로 끌어 다른 보표의 마디에 적용할 수도 있습니다. 목적지에 셈여림이 없거나 하나일 때만 적용하며, 여러 값이 있으면 속성에서 개별 값을 먼저 정리합니다. 선택한 원본 보관 값과 끌어 놓는 목적지는 서로 구분됩니다.

- **결과·적용 범위:** 현재 모델은 마디 단위입니다. 한 마디의 첫 값이 표시·재생되고 이후 값은 원본 보관으로 구분해 개별 정리할 수 있습니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 박·성부별 자유로운 셈여림 모델이라고 설명하지 않습니다. 범위 선택에서는 현재 지원되는 적용 범위를 확인합니다.

MusicXML에서 가져온 셈여림의 마디 안 위치나 성부 지정은 현재 마디 단위 값에 남지 않을 수 있습니다. 이 버전은 이 손실을 경고하며, 원래 offset·성부와 주소는 기술 정보에서 확인할 수 있습니다. 원본 파일을 보관하고 적용 범위와 다시 내보낸 파일을 비교하세요.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#dynamics)에서 예제·기대 결과와 대조하세요.

복합·미지원 기호나 음표·쉼표에 직접 붙은 셈여림은 일부만 남거나 빠질 수 있습니다. 이 버전은 이 기호 손실과 음표의 별도 재생 세기 지정을 구분해 안내합니다. 원본 파일을 보관하고 기술 정보와 재출력을 비교하세요. 이 안내가 원래 복합 표기나 음표 단위 셈여림을 복원하는 것은 아닙니다.

<a id="hairpin"></a>
## 크레셴도·디미누엔도 헤어핀

**찾는 곳:** 범위 선택 → 범위 기호 설정

1. 시작/끝의 범위를 선택합니다
2. 크레셴도 또는 디미누엔도를 누릅니다
3. 생성한 선을 선택해 속성에서 범위와 배치를 확인합니다

- **결과·적용 범위:** 표기와 재생 세기 변화는 별도 계약입니다. 반복 복귀를 가로지르는 미완결 재생 적용은 중단하고 원본 선은 보존합니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 끝점 범위와 선택 조건이 맞아야 합니다. 다른 보표/성부의 선을 같은 대상으로 취급하지 않습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#hairpin)에서 예제·기대 결과와 대조하세요.

같은 보표에서 헤어핀이 겹치면 자동 배치 선에 세로 간격을 둡니다. 수동 배치 선은 지정한 위치를 우선합니다.

가져온 헤어핀이 음표나 쉼표 사이에서 닫히면 **속성 → 표기 끝점**에 마디·성부·마디 시작 기준 위치를 표시합니다. 선을 선택해 수동 배치하거나 삭제하고, 실행 취소로 복원할 수 있습니다. 시간 끝점은 가져오기에서만 만들어집니다. 배치 조정 후에도 저장된 종료 박을 유지합니다.

MusicXML에서 줄바꿈을 넘는 헤어핀의 이어지는 조각은 자동으로 배치합니다. 원본이 조각의 벌어짐·좌표·점선 같은 서식을 지정하면 가져오기에서 안내합니다. 시작·끝은 가져오며 원래 서식과 위치는 경고 상세의 **기술 정보**에서 확인할 수 있습니다.

같은 박에서 시작한 다른 성부의 음이 타이 없이 마디 끝에서 끝나면, 그 끝에 연결한 MusicXML 헤어핀을 마디 끝까지 표시하고 다시 내보냅니다. 해당 음과 성부는 유지됩니다. 속성의 표기 끝점은 그 음의 길이 끝에 연결된다고 안내합니다.

이 마디를 [반복 펼치기 MusicXML](09-files.md#xml-expanded)으로 내보내면, 복제된 각 마디에서도 같은 성부의 음 길이 끝에 헤어핀이 닫힙니다.

MusicXML에서 끝 음의 길이 끝을 정확히 찾거나 다른 성부에 있는 끝 음의 시작을 찾으면, Studio가 종료 위치를 보존합니다. 위치는 악보·PDF·재생·MusicXML 사본에 적용됩니다. 같은 성부에서 음의 시작과 앞 음의 길이 끝이 같은 위치이면 음의 시작에 연결합니다. 속성에서 끝 음을 그대로 두고 배치를 조절하면 종료 위치가 유지됩니다. 끝 음을 바꾸면 새 음의 시작에 표기를 연결합니다.

종료 위치가 기록된 끝 음을 같은 길이의 쉼표로 변환하면 연결 위치가 유지됩니다. 속성의 **표기 끝점**에서 쉼표의 시작 또는 길이 끝을 확인할 수 있습니다.

시작점을 같은 성부로 옮기거나 음 길이를 줄여 두 종료 후보가 겹치면, Studio가 MusicXML 사본에 종료 역할을 기록합니다. 해당 사본을 Studio로 다시 열면 편집한 종료 위치와 재생 범위가 유지됩니다. 다른 앱이 이 정보를 지울 수 있으므로 앱 사이에서 재저장할 때는 Native 프로젝트와 비교용 MIDI도 보관하세요.

종료 위치를 새로 기록한 프로젝트는 업데이트된 Studio에서 열 수 있습니다. 이전 버전과 악보를 주고받을 때는 [MusicXML 사본](09-files.md#xml-save)으로 기보를 전달하고, 재생을 비교하려면 MIDI도 함께 내보내세요. 종료 위치 정보가 없는 기존 프로젝트에는 기존 재생 방식이 적용됩니다.

음이나 쉼표의 길이 끝에 닫힌 헤어핀의 위치를 보존할 수 없으면 가져오기 경고를 표시합니다. 화면에서 끝 표기의 시작에 연결된 위치와 경고의 **기술 정보**에 있는 원본·적용 위치를 비교하세요.

## 8va·8vb·15ma·15mb 옥타브 선

**찾는 곳:** 범위 선택 → 범위 기호 → 옥타브

1. 범위를 선택합니다
2. 8va/8vb/15ma/15mb를 누릅니다
3. 위/아래 방향·줄바꿈 연결과 같은 보표의 다른 성부 음높이를 확인합니다
4. 같은 범위를 유지하고 같은 종류를 다시 누르면 해제됩니다. 다른 종류를 누르면 교체됩니다

- **결과·적용 범위:** 선택한 시작 음부터 끝 음의 종료 전까지, 같은 보표의 구간 안에서 시작하는 모든 성부 음에 적용합니다. 구간 앞에서 시작해 이어지는 음과 다른 보표·파트는 그대로입니다. 기보 음높이와 임시표는 유지하며 15mb는 아래 방향입니다. MIDI와 MusicXML은 선의 옥타브 변화와 기보된 임시표를 함께 반영합니다. 같은 범위에서 같은 종류를 다시 누르면 해제하고 다른 종류를 누르면 교체합니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 음표로 시작하고 끝나는 지원 범위를 선택해야 합니다. 숫자만 표시·선 숨김·대각선·선과 글자 스타일 편집기는 없습니다. 슬러/헤어핀 전용 속성 항목을 옥타브 선에도 있다고 가정하지 않습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#octave)에서 예제·기대 결과와 대조하세요.

<a id="articulation"></a>
## 스타카토·악센트·테누토·마르카토

**찾는 곳:** 팔레트 → 표현 기호 / 선택 음표 속성

1. 음표를 선택합니다
2. 표현 기호 묶음을 펼칩니다
3. 원하는 기호를 눌러 선택 음표에 적용하거나 같은 기호로 해제합니다
4. 다른 음표에 추가하려면 타일을 그 주 음표로 끌어 놓습니다. 놓을 대상의 강조와 안내를 확인합니다. 같은 기호를 다시 놓으면 그대로 유지합니다.

- **결과·적용 범위:** 클릭은 선택 음표의 적용/해제입니다. 음표를 하나 선택하고 타일을 다른 주 음표로 끌면 그 이벤트 전체에 추가합니다. 같은 기호는 유지하며 빈 실행 취소를 만들지 않습니다. 기존 꾸밈음·타이·다른 기호는 보존합니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 쉼표·개별 꾸밈음·화음 구성음·여러 대상·입력/범위/구간 선택에는 끌어 적용하지 않습니다. 표기·재생·출력의 지원 범위는 별도로 확인합니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#articulation)에서 예제·기대 결과와 대조하세요.

## 트릴·모르덴트·턴과 트레몰로

**찾는 곳:** 팔레트 → 장식음 / 선택 음표 속성 → 음표 장식

1. 음표를 선택합니다
2. 트릴·모르덴트·프랄트릴러·턴 중 타일을 적용합니다
3. 트레몰로는 선택 음표 속성에서 없음/1줄/2줄/3줄을 고릅니다

이 버전의 단음 트레몰로는 원음의 꼬리·빔과 획 수를 함께 반영해 내부 연주 간격을 계산합니다. 예를 들어 한 획의 8분음표는 16분음표 간격으로, 점8분음표는 같은 간격의 세 번으로 연주합니다. 점은 반복 횟수, 잇단음표 비율은 간격에 반영합니다. 원래 음가와 프로젝트·MusicXML·MIDI 사본은 바뀌지 않습니다. MIDI에는 이 내부 반복 음열이 아직 반영되지 않습니다. 이 버전의 [MIDI 손실 안내](09-files.md#midi)에서 표기와 파일 재생의 차이를 확인하세요.

현재 네 장식음의 지원 범위는 다음과 같습니다. 표기·파일 보존과 실제 장식 연주는 별개입니다.

| 기호 | 표기·프로젝트/MusicXML | 앱 내부 연주 | MIDI 사본 |
| --- | --- | --- | --- |
| 트릴 | 표기·저장 지원 | 본음이 보조음과 교대 | 본음만 유지·이 버전은 누락 안내 |
| 모르덴트 | 표기·저장 지원 | 별도 음열 없음·본음 유지 | 본음만 유지 |
| 프랄트릴러 | 표기·저장 지원 | 별도 음열 없음·본음 유지 | 본음만 유지 |
| 턴 | 표기·저장 지원 | 별도 음열 없음·본음 유지 | 본음만 유지 |

모르덴트·프랄트릴러·턴을 실제 장식 음열로 연주하는 기능은 아직 없습니다. 원본 표기를 지우거나 자동 변환하지 않으며 프로젝트·MusicXML에 보관할 수 있습니다.

- **결과·적용 범위:** 꾸밈음 붙이기와 장식 기호는 다른 기능입니다. 기호가 보인다고 모든 장식을 실제 음열로 재생하는 것은 아닙니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 선택 음표가 없으면 해당 속성이 나오지 않습니다. 구체적 음원 재생은 지원 범위/내보내기 경고를 확인합니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#ornaments)에서 예제·기대 결과와 대조하세요.

## 페르마타·숨표·중지표

**찾는 곳:** 팔레트 → 정지 기호 / 선택 표기의 연주 기호

1. 적용할 음표/지원 쉼표를 선택합니다
2. 페르마타 또는 숨표·중지표 타일을 누릅니다
3. 선택 기호와 속성 상태를 확인합니다

입력을 마친 상태에서는 타일을 다른 음표·쉼표로 끌어 추가할 수도 있습니다. 같은 기호를 다시 놓으면 제거하지 않습니다. 숨표·중지표는 서로 교체하고, 페르마타와 이웃 표기는 유지합니다. 개별 꾸밈음에는 놓을 수 없습니다.

- **결과·적용 범위:** 선택한 음표 또는 쉼표 하나에 기호를 붙이거나 해제합니다. 다른 보표의 같은 위치에 기호를 자동으로 복제하지 않습니다.

| 확인할 항목 | 현재 동작 |
| --- | --- |
| 기본 페르마타 | 내부 재생과 MIDI는 해당 음가의 절반만큼 시간을 추가합니다. 예를 들어 1박 음표는 기본 재생 시간 1.5박이 됩니다. 기보된 음가와 마디 길이는 유지됩니다. |
| 합주 시간 | 같은 끝 위치의 페르마타가 여럿이면 가장 긴 추가 시간을 한 번 반영하며, 총보의 다음 재생 위치를 함께 늦춥니다. |
| 숨표·중지표 | 선택한 음표·쉼표의 기호로 표시하고 저장합니다. 기호별 멈춤 시간을 지정하거나 별도 재생 지연을 추가하는 기능은 없습니다. |
| 개별 설정 | 페르마타의 위/아래 위치, 변형 모양, 개별 시간 배율과 전체 기호 스타일을 편집하는 기능은 없습니다. |

페르마타가 만드는 재생 연장과 기호를 여러 보표에 표시하는 작업은 별개입니다. 실제 소리의 길이는 음원과 다른 연주 기호의 영향도 받으므로 재생으로 확인하세요. MuseScore의 개별 멈춤 길이·위치 설정과 같은 지원 범위로 해석하지 마세요.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 기호별 지원 대상이 다릅니다. 비활성 툴팁과 실제 대상 설명을 확인합니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#pauses)에서 예제·기대 결과와 대조하세요.

## 1번·2번 볼타

**찾는 곳:** 반복·볼타 설정 / 마디 우클릭

1. 해당 마디 또는 지원 범위를 선택합니다
2. 1번/2번 볼타를 선택합니다
3. 반복 끝과 선의 범위·재생 순서를 확인합니다

- **결과·적용 범위:** 괄호가 있는 마디를 선택하면 그 괄호 전체의 번호를 바꿀 수 있습니다. 같은 번호를 한 번 더 누르면 해당 괄호를 지웁니다. 새 괄호는 선택한 마디부터 다음 도돌이표 끝까지 적용하며, 새 반복이 먼저 시작되면 선택한 마디에 적용합니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 적용하려는 범위에 다른 괄호가 있으면 위치 확인을 안내합니다. 기존 괄호를 편집하려면 괄호 안의 마디를 선택하세요.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#volta)에서 예제·기대 결과와 대조하세요.

단순 반복의 MusicXML에서 가져온 `1,2`나 `3` 같은 회차 목록을 괄호에 표시합니다. 괄호 안의 마디를 선택하면 **볼타 회차**에 목록을 표시합니다. Native 프로젝트와 기본 MusicXML에 회차를 보존합니다. 단순 반복의 횟수보다 큰 회차는 재생하지 않습니다. 가져오기 경고의 기술 정보에서 해당 괄호와 반복 횟수를 확인하세요.

경계가 분명한 단순 반복의 기존 괄호를 선택하면 **볼타 회차 편집**을 열 수 있습니다. 첫 도돌이표 시작을 생략해 악보 처음으로 돌아오는 경우에도 적용됩니다. 괄호가 덮는 마디, 도돌이표 끝과 총 반복 횟수를 확인한 뒤 `1, 2` 또는 `3`처럼 입력하세요. **회차 적용** 또는 Enter로 확정하고 Escape로 입력을 취소합니다. 끝 도돌이표 뒤의 괄호에는 마지막 회차를 포함합니다. 세 번 이상 반복에서 두 번째 회차만 지정한 MusicXML은 가져올 수 있습니다. 끝 표시 없이 한 마디에 붙은 경우도 해당합니다. **재생 회차** 설명에서 실제로 연주할 회차를 확인하세요. 회차 편집기에서 두 번째 회차만 입력하는 동작은 후속 범위입니다. 재생 예제는 [반복·볼타 재생](07-playback.md#repeat-play)을 확인하세요.

- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.

## 가사 글자·절·음절·멜리스마

이 버전은 한 가사 안의 연속 공백을 화면과 PDF에서도 구분해 표시합니다. MusicXML의 여러 text 조각을 읽을 때 없는 공백을 추가하지 않으며, 원래 조각별 서식이나 elision 기호 복원과는 구분합니다.

**찾는 곳:** 음표 선택 → 추가 → 가사 및 코드 → 가사 글자 입력

1. 음표를 선택하고 가사 글자 입력을 엽니다
2. 악보 위 입력창에 글자를 적습니다
3. Enter로 확정 후 다음 음표, ↑/↓로 절을 이동합니다
4. 가사 속성에서 절·음절·멜리스마를 조절합니다

- **결과·적용 범위:** 가사는 선택 음표에 연결됩니다. _는 멜리스마를 적용하고 다음 음표로 이동합니다. 한글 조합 중에는 확정/전역 명령을 실행하지 않습니다.
- **단축키:** Enter, ↑/↓, _, Esc
- **안 되거나 다른 결과가 나오면:** 중복/모호한 원본 가사가 있어 편집이 막히면 안내를 확인합니다. 음표가 아니면 입력 항목이 없습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#lyrics)에서 예제·기대 결과와 대조하세요.

### Studio의 가사 입력 키

현재 Studio는 MuseScore의 가사 입력 키와 다릅니다. 기존 글자와 단축키 동작을 유지하므로, 아래 기준으로 입력하세요.

| 입력 | Studio에서 하는 일 |
| --- | --- |
| Space와 하이픈은 글자 입력 | 현재 음표의 가사 안에 공백·하이픈을 적습니다. 다음 음표로 이동하지 않습니다. |
| Enter는 다음 음표 | 현재 가사를 확정하고 다음 입력 가능한 음표로 이동합니다. 다음 절로 바꾸지 않습니다. |
| ↑ / ↓ | 현재 글자를 확정하고 이전 / 다음 절 입력으로 바꿉니다. |
| _ | 현재 음절을 단일 음절·멜리스마로 확정하고 다음 음표로 이동합니다. |
| Esc | 미확정 글자를 버리고 악보로 돌아갑니다. 한글 조합 중에는 조합 처리를 우선합니다. |

음절의 시작·중간·끝은 **가사 속성 → 가사 음절**에서 지정하세요. 쉼표를 골라 직접 가사를 입력하거나, 외부 가사를 음절별로 붙여넣는 전용 흐름은 현재 지원하지 않습니다. 멜리스마는 현재 저장·표시 범위를 따르며 MuseScore의 반복 키 입력과 같은 결과를 보장하지 않습니다.

참고로 [MuseScore 가사 핸드북](https://handbook.musescore.org/text/lyrics)은 Space·하이픈으로 다음 음표, Shift+Space로 이전 음절, Enter로 다음 절에 이동하는 흐름을 설명합니다. 이 키 배치를 Studio에 적용한 것으로 해석하지 마세요.

## 코드 심벌 입력·수정

이 버전의 MusicXML 가져오기: 기존 지원 어휘와 일치하는 코드 종류 접미사(`m`, `7`, `maj7`, `m7`, `dim`, `sus4`, 빈 장조 표기)는 근음·베이스와 함께 표시합니다. 예를 들어 근음 D와 접미사 m은 Dm, 근음 Bb·접미사 7·베이스 F#은 Bb7/F#로 읽습니다. 기존 전체 코드명과 사용자 지정 글자는 유지하며, 이 보완이 새 코드 문법이나 자동 화음 연주를 추가하는 것은 아닙니다.

**찾는 곳:** 추가 → 가사 및 코드 → 코드 심벌 편집

1. 음표/마디의 위치를 선택합니다
2. 코드 심벌 편집을 눌러 선택 위치의 코드 필드로 갑니다
3. 코드 글자를 입력하고 확정합니다
4. 동일 위치의 여러 원본 값은 대상 목록에서 구분합니다

- **결과·적용 범위:** 표시용 코드 심벌과 실제 화음 음표 추가는 다릅니다. 적용 위치와 원본 표기 보존 지원을 확인합니다.
- **단축키:** Enter/blur 확정, Esc 초안 취소
- **안 되거나 다른 결과가 나오면:** 코드를 적었다고 반주 음표를 자동 생성하거나 재생한다고 설명하지 않습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#harmony)에서 예제·기대 결과와 대조하세요.

## 전역 빠르기·리듬 표기·스윙 재생

**찾는 곳:** 형식 → 악보 설정 → 전역 빠르기

1. 빠르기 slider를 40–240 BPM에서 조절합니다
2. 빠르기 기준 음가를 선택합니다
3. 악보에 빠르기말 표기와 리듬 해석 표기를 필요에 맞게 정합니다
4. 이 버전에서 실제 스윙을 들으려면 별도 **전역 스윙 재생**을 8분/16분·2:1/3:2 중에서 선택합니다. 꺼짐으로 되돌리면 직선 리듬입니다. 표기만 켜서는 재생이 바뀌지 않습니다.
5. 선택기 아래에서 표기와 실제 재생의 차이를 확인합니다. 기본 표기의 비율은 2:1이며, 다른 음가/비율을 선택해도 자동으로 맞추지 않습니다. 직접 입력한 문구의 비율은 추론하지 않습니다.
6. 보표별 박자·마디 길이가 달라 적용할 수 없으면 설정은 보관하고 직선으로 재생합니다. MIDI 내보내기도 직선 리듬임을 경고 상세에서 안내하며, 원래 진단은 기술 정보에서 확인할 수 있습니다.
7. 이 버전에서 총보에 적용할 수 없는 스윙은 파트 MIDI/MusicXML 사본에도 포함하지 않고 직선 리듬으로 출력합니다. 경고 상세에서 사본의 적용 범위를 확인하세요. 원본 프로젝트와 총보 MusicXML에는 보관된 설정이 유지됩니다. 정상 적용 가능한 전역 스윙과 꺼짐 설정은 그대로 내보냅니다.

- **결과·적용 범위:** 악보 전체의 기본 빠르기입니다. 기준 음가/점과 위치별 변경을 구분합니다. 표시 문구만 바꾸는 것과 실제 BPM 적용은 다릅니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** ‘리듬 해석 표기’는 표기 전용입니다. 별도 전역 스윙을 켜면 재생/MIDI 발음 시점과 길이가 바뀌며, 음표의 기보 음가와 tick은 유지됩니다. 기본 악보대로 재생/연주 표현 꺼짐 기준, 120 BPM의 연속 8분음표에서 두 번째 음은 직선 0.25초, 3:2는 0.30초, 2:1은 약 0.333초에 시작합니다. 자연스러운 연주를 켜면 기존의 미세한 시점 변화가 추가됩니다. 기본 꺼짐이며 예전 프로젝트를 열어도 자동으로 켜지지 않습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#tempo)에서 예제·기대 결과와 대조하세요.
- **첫 지원 범위:** 모든 보표의 마디 길이·박자가 같은 악보에 전역 적용합니다. 잇단음표나 더 짧은 음가가 겹친 두 음 묶음은 해당 성부에서 직선으로 유지합니다. 다른 성부·파트의 정상 음가를 직선으로 바꾸지 않습니다. 못갖춘마디는 정규 마디의 끝에 맞춰 계산하며 시작에 짧은 대기가 생길 수 있습니다. 마디 끝의 불완전한 묶음은 늘리지 않습니다. 꾸밈음의 별도 발음 지원을 추가한 기능은 아닙니다.
- **저장·교환:** 프로젝트와 MIDI에 반영하며, MusicXML은 모든 파트의 시작에 같은 sound/swing 설정이 있을 때 가져옵니다. 구간·파트·보표별 변경과 다른 비율은 원본 보관을 안내합니다. 새 스윙 필드를 저장한 프로젝트는 이전 strict reader에서 열리지 않을 수 있습니다. PDF·PNG 표기와 프로젝트 dirty 상태의 경계는 기존과 같습니다. 단축키는 새로 추가하지 않았습니다.

이 버전은 불러온 32·64분 기준 음가나 점3개 값을 선택기에 **기존값**으로 표시합니다. 값을 고르지 않고 펼쳐보기만 한 뒤 Tab으로 닫거나 Escape로 취소해도 악보·재생 빠르기·실행 취소 이력은 바뀌지 않습니다. 다른 기준 음가를 직접 고르면 변경되며 실행 취소로 돌아갈 수 있습니다. 새로 고르는 기본 목록을 늘리거나 지원하지 않는 음가를 추가한 기능은 아닙니다. 위치별 빠르기 목록과 적용 범위의 점 개수도 실제 저장값으로 안내합니다.

### 수동 슬러·헤어핀을 마우스로 옮기기

범위 표기를 선택하고 속성의 **배치 · 형상**에서 수동값을 설정합니다. 이미 수동인 선을 다시 기본 마우스 버튼으로 누른 채 끌면 줄바꿈된 조각도 함께 미리보기로 움직입니다. 다른 표기를 처음 클릭하면 기존 선택을 먼저 수행합니다. 기존 키보드 이동과 같은 공통 offset을 편집하며, 모양 핸들·끝점·파트/구간 독립 배치를 만드는 기능은 아닙니다.

- 이동량은 0.25 sp 격자이고 가져온 원점의 소수값·명시적 0·나머지 형상은 유지합니다.
- 놓을 때 한 명령으로 확정하며 한 번의 실행 취소로 복원합니다. 끄는 중에는 악보·저장 상태·undo 기록을 바꾸지 않습니다.
- Escape는 미리보기만 취소합니다. 다른 입력/선택·문서 변경, IME·포커스 상실, 스크롤/창 크기 변경도 취소합니다. 이후 명령은 기존 동작을 따릅니다.
- 각 offset의 −8~8 sp 범위를 벗어난 채 놓으면 저장하지 않고 안내합니다. 임의로 경계값으로 보정하거나 마지막 유효 위치를 대신 저장하지 않습니다.
- 자동 배치·수식키 드래그·터치/펜 드래그는 이 경로에서 변경하지 않습니다. 터치에서는 기존 스크롤과 공통 속성 컨트롤/키보드 대안을 사용하세요.

이는 이 버전입니다. 실제 포인터·화면/PDF 검증의 수행 범위는 인계 자료와 함께 확인하며, 물리 터치나 모든 MuseScore 모양 핸들 지원으로 해석하지 않습니다.

수치가 −8~8 sp 안에 있어도 수동 배치된 선이 물리 페이지를 넘으면 PDF를 차단할 수 있습니다. 원래 위치를 임의로 보정하지 않으므로 가로 이동을 줄이는 등 속성에서 직접 조정한 뒤 다시 출력하세요. PDF 성공은 프로젝트 저장과 별개입니다.
