# 지원 범위와 용어

기능 기준: alpha.43. 메뉴 이름과 아래 적용 범위를 함께 확인하세요.

<a id="limits"></a>
## 직접 지원·제한·보존만 가능한 데이터

**찾는 곳:** 각 장의 지원 범위와 손실 안내

1. 직접 편집할 UI가 있는지 확인합니다
2. 화면·재생·native·교환 형식의 지원을 각각 읽습니다
3. 미지원 항목은 원본을 보관합니다

- **결과·적용 범위:** 부분 화음 타이·구성음별 선택·임의 박자표 표시문구·총보 박자 일괄 전파·꾸밈음 별도 발음·SVG 제품 출력·범용 mixed 편집은 완성된 기능으로 안내하지 않습니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 모델에 필드가 있거나 외부 파일을 읽는다고 모든 값을 직접 생성/편집할 수 있는 것은 아닙니다.
- **되돌리기·취소:** 안내 열람 자체는 악보를 변경하지 않습니다.
- **지원 경계:** 지원 경계 안내. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#limits)에서 예제·기대 결과와 대조하세요.

## 용어

- 음가: 음표/쉼표의 길이입니다.
- 성부: 같은 보표의 독립적인 리듬 줄입니다.
- caret: 다음 입력 위치를 표시하는 커서입니다. 선택한 음표와 다를 수 있습니다.
- sp: 오선 두 선 사이의 간격을 기준으로 한 배치 단위입니다.
- draft: 아직 명령으로 확정하지 않은 필드의 입력값입니다.
- native 프로젝트: .chromatics 편집 파일입니다.
- 사본 출력: 원본 프로젝트 저장과 구분되는 XML/MIDI/PDF/PNG 결과입니다.
- override/상속: 파트의 독립 설정 또는 총보 설정을 따르는 상태입니다.

## 수동 미검증

물리 IME·OS dialog·스크린리더·청음·실기기·외부 앱의 실제 동작은 프로그램 검증과 구분합니다. 사용자 확인란은 아직 사용자가 수행한 것으로 표시하지 않았습니다. Commercial V1/RC 또는 MuseScore 전체 parity 완료가 아닙니다.

## 현재 제공하는 목록과 전용 UI가 없는 항목

- 내장 악보 구성: 솔로 멜로디, 피아노 grand staff, 2파트 앙상블, 현악 4중주.
- 추가 악기: 피아노, 바이올린, 비올라, 첼로, 더블베이스, 플루트, 클라리넷, 알토 색소폰(E♭), 호른(F), 성악, 멜로디.
- 음자리표 preset: 높은음자리표, 낮은음자리표, 가온음자리표, 테너음자리표. 타악기와 TAB은 일반 음자리표 preset 지원과 구분합니다. 기존 native 프로젝트의 TAB 값은 보존하지만, TAB MusicXML 가져오기·저장과 현/프렛 표시는 지원하지 않습니다. 현재 TAB 마디는 일반 높은음자리표 경로로 표시되며 MIDI에서 건너뜁니다. 원본 native 파일을 보관하세요. 타악기·말소리 등에 쓰는 무음정 음표의 MusicXML 가져오기는 아직 지원하지 않습니다. [가져오기 지원 범위](09-files.md#import)를 확인하세요.
- 조표: 조표 없음과 ♯/♭1–7개의 장조/단조. 마장조는 ♯4개입니다.
- 박자표 preset: 2/4, 3/4, 4/4, 6/8. 이 버전의 선택 마디 입력은 분자1–128·분모1/2/4/8/16/32/64를 지원합니다. 새 악보 만들기에서도 같은 범위의 사용자 지정을 제공합니다.
- 표현 기호: 스타카토, 악센트, 테누토, 마르카토.
- 장식음: 트릴, 모르덴트, 프랄트릴러, 턴. 트레몰로는 0/1/2/3줄.
- 정지 기호: 페르마타, 숨표, 중지표.
- 셈여림: ppp, pp, p, mp, mf, f, ff, fff, sfz. 마디의 첫 값 표시/재생과 원본 보관 값을 구분합니다.
- 옥타브: 8va, 8vb, 15ma, 15mb. 볼타 직접 진입은 1번/2번입니다.
- 가사 절: 1–4절. 한 음절/첫/가운데/마지막 음절과 멜리스마를 설정합니다.
- 악보 pedal, note velocity, MIDI program/channel, 숨김 표기처럼 원본에서 보존/재생하는 일부 필드는 공개 UI에서 직접 새로 만드는 편집기가 없을 수 있습니다. 파서 필드 존재를 사용 가능 UI로 계산하지 않습니다.
- 가져온 못갖춘마디 길이는 보존하며 새 악보의 첫 마디에서도 설정할 수 있습니다. 파트별/구간별 span geometry의 저장·직접 편집은 현재 형식에서 지원하지 않습니다. 음표 앞 inline clef 위치는 현재 보존하지 못하며 원본 MusicXML과 비교해야 합니다. 현재 span geometry 카드에는 총보·해당 파트보 공통이라고 표시됩니다.
- 자유 drag docking, 외부 MIDI keyboard 녹음, 범용 VST/음원 설치, 계정/cloud 공유, 반복·볼타를 포함한 범용 연습 loop 등 MuseScore 목차의 기능을 이 설명서만으로 Studio가 지원한다고 읽지 않습니다.

가져오기 경계: 별도의 bar-style 필드가 없는 이중선·점선·특수 끝선은 손실을 안내합니다. 원본을 보관하고 파트/마디 및 기술 정보의 XML 경로로 비교하세요. 경고 추가가 해당 모양의 편집·native 보존 지원을 뜻하지는 않습니다.

### 자동 줄기·빔과 수동 편집

현재 줄기 방향과 빔은 성부·박자·음가에 따라 자동으로 그립니다. 개별 줄기 방향·길이·숨김이나 빔 분할/합치기/각도를 수동으로 지정하는 편집기는 없습니다. MuseScore의 X 방향 뒤집기나 리듬 재묶음 명령이 Studio에도 있다고 가정하지 마세요. 원본 줄기 숨김 손실 안내는 가져오기 진단이며 편집·native/XML 보존 기능은 아닙니다.

입력 방식과 native 보존: 현재 일반 입력은 음가를 고른 뒤 음을 넣습니다. 파일에 보관된 음높이 먼저 입력 설정은 적용되지 않으며, 이 버전은 열기·복구 시 이 제한을 안내합니다. 설정값 보존과 실제 입력 모드의 지원은 다릅니다.

### 숫자저음과 운지의 지원 경계

숫자저음은 일반 코드·글자와 다른 객체이며 전용 입력·편집·반주 생성은 아직 없습니다. 이 버전은 MusicXML의 숫자저음 데이터가 현재 모델에 포함되지 않는 것을 안내합니다. 숨긴 숫자·연장선·빈 figure 자리도 원본 데이터와 구분해 확인합니다. 안내가 항상 보이는 글리프의 잘림을 뜻하지는 않습니다. 원본 MusicXML을 보관하고 표기와 사본을 비교하세요.

기술 정보에는 원본 파트/마디/발생 번호와 일부 원본 속성이 있습니다. 정규화한 프로젝트를 저장하거나 XML/MIDI/PDF를 만들었다고 원본 숫자저음까지 보존한 것은 아닙니다. native 재열기나 사본에서는 원본 숫자저음 자체가 없으므로 같은 가져오기 경고가 다시 나오지 않을 수 있습니다. 운지 등 technical 지시의 기존 손실 안내와도 구분합니다.

연습 루프의 일부 범위는 이미 지원합니다. 반복·볼타와 경계 타이가 없는 [연속 구간·총보 세션 루프](07-playback.md#practice-loop)의 지원 조건을 확인하세요. 범용 loop가 미지원이라는 설명을 이 범위까지 불가능하다는 뜻으로 읽지 마세요.


### 페이지 이미지와 프레임의 지원 경계

페이지 이미지·임의 프레임의 삽입·크기/위치 편집은 아직 없습니다. 이 버전은 MusicXML의 마디 밖 페이지 이미지(`credit-image`) 손실을 쪽과 원본 데이터 위치로 안내합니다. 마디 안 이미지의 기존 경고와 구분하세요. 제목/작곡가 입력이나 페이지 설정을 프레임·이미지 편집과 같은 기능으로 계산하지 않습니다.

이미지 URI를 가져오거나 경고에 그대로 표시하지 않습니다. 원본 MusicXML과 이미지 파일을 함께 보관하고 실제 표기와 재내보내기를 비교하세요. 정규화한 native 재열기에 경고가 없는 것은 원본 이미지 데이터 자체가 없는 상태일 수 있으며 보존 성공을 뜻하지 않습니다.

### 마디 번호 문구와 표시설정의 지원 경계

임의 마디 번호 문구와 번호 표시 빈도·숨김 설정의 편집은 아직 없습니다. 이 버전은 다른 표시 문구와 MusicXML의 명시적인 번호 표시설정 손실을 안내합니다. 내부 번호/ID 정규화 정책이나 페이지 번호 편집과는 별개입니다. 기술 정보의 원본 설정과 원본 파일을 보관하세요. 정규화한 프로젝트 재열기에서 경고가 사라져도 원본 설정이 보존됐다는 뜻은 아닙니다.


### 입력 성부 전환과 음표의 성부 이동

[입력 보표·성부 전환](03-notes.md#voices)은 기존처럼 입력할 위치를 선택합니다. 이 버전의 별도 [선택 음표 성부 이동](03-notes.md#voice-move)은 일반 단음 하나를 같은 마디·보표의 빈 성부로 옮깁니다. 원래 자리는 쉼표로 남습니다. 화음·범위 이동·기존 내용 병합·성부 교환은 지원하지 않습니다. 없는 성부를 선택해 온마디 쉼표를 추가하는 탐색과 선택 음표를 옮기는 명령을 구분하세요.


### 옥타브 선의 보표 범위와 상세 속성

[옥타브 선](05-notation.md#octave)은 선택한 성부만의 효과가 아닙니다. 같은 보표의 해당 시간 구간 안에서 시작하는 다른 성부 음도 적용됩니다. 앞에서 시작해 이어지는 음과 다른 보표·파트는 구분해 확인하세요. 같은 범위에서 같은 종류를 다시 누르면 해제하고 다른 종류로 교체할 수 있습니다. 숫자만·선 숨김·대각선·임의 선/글자 스타일과 slur/hairpin의 상세 배치 속성을 옥타브의 지원 기능으로 읽지 않습니다.
