# 문제 해결

기능 기준: alpha.41. 메뉴 이름과 아래 적용 범위를 함께 확인하세요.

이 버전의 시작 화면 오류 안내: 파일 열기나 최근 파일 읽기에 실패하면 현재 요청의 새 오류 안내를 화면 안에 보여줍니다. 키보드 초점은 옮기지 않습니다. 요청 뒤 다른 항목으로 초점을 옮기거나 스크롤·안내 글자 선택·새 악보 작업을 시작했다면 그 작업을 우선하므로, 오류와 기술 정보는 최근 목록 아래에서 확인하세요. 안내 글자를 선택해 읽은 뒤 선택을 해제해도 이전 안내로 갑자기 화면을 되돌리지 않습니다. 새 파일을 여는 동안에는 이전 안내 때문에 화면을 이동하지 않습니다. 최근 목록이 늦게 표시되더라도 새 안내를 확인할 수 있으며, 다시 열기를 실행하면 새 결과를 안내합니다. 파일을 고친 뒤 같은 항목을 다시 열 수 있으며 실패 자체는 악보 편집이나 실행 취소를 만들지 않습니다.

이 버전의 최근 MusicXML 읽기 상태: 현재 항목의 **불러오는 중**은 해당 파일을 읽고 있음을 뜻합니다. 다른 항목을 선택하면 새 항목의 상태를 표시합니다. 파일을 찾을 수 없었던 항목도 재시도 중에는 읽는 중으로 표시하며, 다시 실패하면 파일 없음 표시로 돌아갑니다. 파일이 복원됐으면 같은 항목을 다시 선택하세요.

<a id="disabled"></a>
## 버튼이 회색이거나 기호가 안 바뀔 때

**찾는 곳:** 해당 도구의 설명과 상태 표시

1. 선택한 표기가 음표/쉼표/마디/범위 중 무엇인지 확인합니다
2. 입력 모드와 선택 모드, 보표·성부를 확인합니다
3. 현재 도구의 툴팁과 적용 범위를 읽습니다
4. Esc 후 올바른 대상을 다시 선택합니다

- **결과·적용 범위:** 비활성은 선택 없음·지원하지 않는 대상·저장 중·모델 제약일 수 있습니다. 오류를 무시하려고 원본을 임의 변경하지 않습니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 예: 꾸밈음 변환에 다음 음표가 없거나 타이 경계가 있으면 먼저 조건을 확인합니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#disabled)에서 예제·기대 결과와 대조하세요.

<a id="save-errors"></a>
## 저장 완료인데 입력한 값이 없거나 저장이 실패할 때

**찾는 곳:** 문서 상태·숫자/글자 입력·저장 결과

1. 미확정 draft를 Enter/blur로 확정하거나 Escape로 취소합니다
2. 프로젝트 저장인지 사본 출력인지 확인합니다
3. 현재 문서/파일명과 저장 시작 이후 추가 편집을 확인합니다
4. 저장 결과의 **기술 정보**를 펼쳐 파일 경로와 오류를 확인합니다
5. 쓰기 가능한 위치에 새 파일로 보관하거나, 본인 파일의 쓰기 권한을 확인한 뒤 다시 시도합니다

**읽기 전용 파일·쓰기 권한 오류:** 이 버전은 쓰기 권한이 없는 기존 파일을 저장으로 교체하지 않습니다. 확인된 읽기 전용 대상 오류에서는 원본 파일과 현재 편집·선택·실행 취소 이력이 유지됩니다. 저장을 취소하거나 실패한 것은 저장 완료가 아닙니다. 오류 코드·경로는 **기술 정보**에서 확인하세요. 소유자에게 허용된 범위에서 해당 파일과 저장 위치의 쓰기 권한을 확인한 뒤 같은 작업을 다시 시도할 수 있습니다. 원본 삭제, 모든 파일의 권한 확대, 앱 설정 초기화는 필요하지 않습니다.

**다른 위치에 보관하기:** 프로젝트 내용과 편집 정보를 보관하려면 **파일 → 프로젝트 다른 이름으로 저장**에서 쓰기 가능한 위치를 고릅니다. MusicXML은 **파일 → 내보내기 설정 → MusicXML 내보내기**로 별도 사본을 만들 수 있습니다. PDF·MIDI·PNG는 같은 내보내기 설정에서 필요한 출력 형식을 선택합니다. 이 사본들은 편집 프로젝트 저장을 대신하지 않으며, 사본 출력 성공만으로 프로젝트가 ‘변경 없음’이 되지는 않습니다. [파일별 저장·출력](09-files.md#project)도 함께 확인하세요.

- **결과·적용 범위:** 저장 중 새 편집이 있으면 저장한 snapshot과 현재 문서는 다릅니다. 사본 출력으로 프로젝트를 clean 처리하지 않습니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 쓰기 권한 오류와 파일이 앱 밖에서 변경된 오류를 구분합니다. 외부에서 바뀐 파일은 새 파일로 먼저 보관한 뒤 원래 파일을 확인하세요. 숫자 입력 오류는 해당 필드의 안내에 따라 확정하거나 취소합니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#save-errors)에서 예제·기대 결과와 대조하세요.

## 외부 앱에서 반복·이조·음표 모양이 다를 때

**찾는 곳:** 가져오기/내보내기 손실 안내 → 기술 정보

1. 원본 native를 보관합니다
2. 구조 유지와 반복 펼치기 사본을 구분합니다
3. 외부 앱에서 정상 완료한 결과만 비교합니다
4. 문제가 난 파일·앱 버전·단계를 기록합니다

- **결과·적용 범위:** 원본 보존·XSD 검사·내부 MIDI 비교와 외부 앱 동일 동작은 다른 검증입니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 기존 MuseScore 중첩 반복/볼타·중간 이조 차이와 CLI/GUI 종료 문제는 미해결입니다. 기대값 약화나 설정 초기화를 해결 절차로 쓰지 않습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#external)에서 예제·기대 결과와 대조하세요.
