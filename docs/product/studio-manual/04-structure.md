# 악보 구성

기능 기준: alpha.42. 메뉴 이름과 아래 적용 범위를 함께 확인하세요.

<a id="parts"></a>
## 파트·보표 추가·삭제·순서

**찾는 곳:** 형식 → 악보 설정 → 파트와 보표 구성

1. 현재 파트를 선택합니다
2. 추가할 악기를 고른 뒤 파트 추가를 누릅니다
3. 보표 추가/삭제와 파트 위로/아래로 이동을 사용합니다
4. 총보와 파트보에서 결과를 확인합니다

- **결과·적용 범위:** 추가할 악기는 다음 추가용 preset이며 기존 파트를 자동 교체하지 않습니다. 삭제·이동은 현재 대상에 적용됩니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 마지막 파트/마지막 보표 삭제 등 구성 보호 조건은 비활성입니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#parts)에서 예제·기대 결과와 대조하세요.

## 파트 이름·약어·기본 음자리표·이조

선택기 보완: 기존 음자리표와 사용자 지정·혼합 이조는 확인하려고 펼쳤다가 Tab/Escape로 닫아도 그대로 유지합니다. 방향키로 다른 항목을 고르고 Tab을 누르거나 프리셋을 클릭하면 원래 범위에 적용합니다. ‘사용자 지정 / 혼합’ 표시는 새 이조 입력 양식이나 실음 보기 전환 기능이 아닙니다.

**찾는 곳:** 형식 → 악보 설정

1. 현재 파트 이름과 약어를 수정하고 Enter/blur로 확정합니다
2. 현재 보표 음자리표를 선택합니다
3. 현재 파트 이조 preset을 선택하고 기보/재생을 확인합니다

- **결과·적용 범위:** 파트 이름은 첫 악보단, 약어는 이후 표시에 쓰입니다. 보표 음자리표는 현재 보표 전체, 이조는 현재 파트 전체에 적용하며 기보음은 유지합니다.
- **단축키:** Enter/blur 확정, Esc 초안 취소
- **안 되거나 다른 결과가 나오면:** 혼합/사용자 지정 이조는 원본 상태를 표시할 수 있으나 모든 값을 직접 편집하는 것은 아닙니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#part-labels)에서 예제·기대 결과와 대조하세요.

## 마디 추가·삭제·우클릭

**찾는 곳:** 마디 우클릭 → 앞/뒤에 마디 추가·마디 제거·마디 속성…

1. 대상 마디의 빈 공간(음표·가사 밖)을 우클릭합니다
2. 앞/뒤 추가 또는 제거를 선택합니다
3. 총보의 각 보표와 다시 매긴 번호·주변 연결 표기를 확인합니다

- **결과·적용 범위:** 모든 파트·보표의 같은 위치에 한 마디씩 추가하거나 제거합니다. 구조를 바꾸면 마디 번호를 1부터 순서대로 다시 매깁니다. 조표·음자리표 같은 비구조 편집의 원본 번호 보존과 다릅니다.
- **단축키:** 우클릭, 메뉴 ↑/↓/Home/End/Enter/Esc
- **안 되거나 다른 결과가 나오면:** 보표별 마디 수가 다르거나 마지막 마디를 제거하려면 거부합니다. 삭제한 마디의 음표와 연결 표기도 함께 바뀔 수 있으므로 실행 취소로 비교하세요.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#measures)에서 예제·기대 결과와 대조하세요.

이 버전의 **마디 속성…**은 우클릭한 마디의 기존 구조·조표·박자표 작업대를 열고 **조표** 필드에 초점을 둡니다. 여는 것만으로 악보나 실행 취소 기록을 바꾸지 않습니다. **박자표 변경…**은 같은 작업대의 박자표 필드로 바로 갑니다. 조표는 선택 보표의 해당 마디부터, 박자표는 선택 보표의 그 마디만 바꾸므로 표시된 적용 범위를 확인하세요.

파트보에서는 **형식 → 악보 설정 → 악보 보기/파트보 선택**으로 파트를 고르고 **악보로 이동**한 뒤 해당 마디를 우클릭합니다. 적용 범위에 표시된 파트·보표·마디를 확인하세요. 파트보에서 다른 파트까지 한꺼번에 박자표를 바꾸는 명령은 아닙니다.

이 진입점은 [MuseScore의 마디 속성](https://handbook.musescore.org/notation/rhythm-meter-and-measures/measure-properties) 전체 항목과 같지 않습니다. 임의의 마디 실제 길이, 마디별 보표 숨김·줄기 없음·번호·폭 설정 대화상자는 추가하지 않았습니다. 못갖춘마디는 현재 지원하는 **모든 보표의 빈 첫 마디** 범위를 따릅니다.

마디 선택의 Delete도 마디 자체를 제거합니다. 음표·범위 선택에서 리듬을 남기며 지우는 동작과 다르므로 삭제 전에 선택 대상을 확인하세요. 입력창에서는 텍스트 편집이 우선합니다. 마디 내용 지우기와 별도 마디 제거 키의 MuseScore식 구분은 아직 적용하지 않았습니다.

<a id="key"></a>
## 조표와 조성 변경

선택기 보완: ‘장·단조 미지정 (현재)’ 조표는 목록을 열고 Tab/Escape로 닫는 것만으로 장조 프리셋으로 바뀌지 않습니다. 실제 변경은 다른 프리셋을 명시적으로 고를 때 적용합니다.

**찾는 곳:** 추가 → 음자리표·조표·박자표 팔레트 → 조표 타일 또는 조표 설정 열기

1. 마디를 선택합니다
2. 조표 타일의 팔레트 조표 보기에서 장조/단조를 골라 기존 30프리셋을 15개씩 봅니다. 기존 조표 설정 열기도 유지합니다
3. 예를 들어 마장조(♯4개) 타일을 클릭하거나 Tab으로 이동해 Enter를 누르고 이후 조표/음표를 확인합니다. 기호 썸네일의 숫자는 부호 개수이며 실제 악보의 조표 배치를 축소한 그림은 아닙니다

- **결과·적용 범위:** 선택 보표의 선택 마디부터 이후 모든 마디에 적용합니다. 다른 보표는 바꾸지 않고 기존 소리나는 음높이를 유지하며 필요한 임시표를 조정합니다. 장·단조와 조표 부호 개수를 함께 확인하세요.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 조표 타일은 범위/span/미완성 잇단음표에 적용하지 않습니다. 검색 중에는 장조·단조 결과를 함께 보여주며 보기 선택만으로 악보가 바뀌지 않습니다. 원본의 장·단조 미지정 상태는 명시적 preset 적용 전까지 보존합니다. 이 버전에서는 입력을 마친 뒤 조표 타일을 음표·쉼표로 끌어 놓을 수도 있습니다. 놓은 보표의 그 마디부터 이후 마디에 적용하고 실제 음높이는 유지합니다. 놓기 전 안내와 마디 강조를 확인하고, 취소하면 악보를 바꾸지 않습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#key)에서 예제·기대 결과와 대조하세요.

## 마디 박자표와 변박자

선택기 보완: 이미 저장한 사용자 지정 박자표는 ‘현재’ 값으로 표시합니다. 목록을 펼쳤다가 Tab/Escape로 닫기만 하면 박자표·음표·실행 취소 이력이 바뀌지 않습니다. 다른 프리셋을 명시적으로 고르거나 사용자 지정 대화상자에서 적용해야 변경됩니다.

**찾는 곳:** 추가 → 음자리표·조표·박자표 팔레트 → 박자표 타일 / 마디 우클릭 → 박자표 변경…

1. 변경할 마디를 선택하고 음표·가사가 없는 마디의 빈 공간을 우클릭합니다
2. 박자표 변경…을 선택합니다
3. 기본 목록에서 2/4·3/4·4/4·6/8을 고릅니다. 이 버전은 같은 네 **박자표 타일**을 팔레트에서 클릭하거나 Tab/Enter로 적용할 수도 있습니다. 사용자 지정은 기존 **박자표 설정 열기 → 사용자 지정 박자표…**를 사용합니다
4. 분자 5·분모 4 또는 분자 7·분모 8을 입력하고 적용합니다. 분자는 1–128 정수, 분모는 1/2/4/8/16/32/64입니다
5. 다른 마디와 보표가 유지되는지 확인하고 실행 취소/다시 실행을 시험합니다. 잘못된 입력은 오류로 남으며 취소는 악보를 바꾸지 않습니다

- **결과·적용 범위:** 선택 보표의 선택 마디만 변경합니다. 이후 마디나 총보 모든 보표에 자동 전파하지 않습니다. 같은 박자표·빠르기 설정의 재적용은 이미 적용된 값임을 안내하며 추가 실행 취소를 만들지 않습니다. 이 버전에서 박자표를 바꾸어도 유효한 원본 마디 번호는 유지됩니다. 마디를 삽입하거나 삭제하는 작업과는 구분됩니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 기존 음표가 새 마디 길이를 초과하거나 쉼표의 부착 기호·범위 끝점을 잃으면 변경을 거부합니다. 통마디 쉼표의 페르마타·숨표는 유지합니다. 이 버전은 새 마디 끝을 넘게 되는 빠르기·코드·표현 글자의 위치도 보호해 축소를 거부합니다. 표기를 임의로 옮기거나 삭제하지 않습니다. 총보 공통 적용은 미지원입니다. 이 버전에서는 입력을 마친 뒤 박자표 타일을 음표·쉼표로 끌어 놓아 놓은 보표의 그 한 마디에 적용할 수도 있습니다. 마디 강조와 범위를 확인하고 취소하면 악보는 바뀌지 않습니다. 타일은 입력·미완성 잇단음표·범위/span 편집 중에는 사용할 수 없습니다. 6/8 선택 시 기본 빠르기 음가를 점4분으로 바꾸는 기존 박자표 명령도 함께 적용될 수 있습니다. 새 악보 만들기에서도 사용자 지정 분자·분모를 정할 수 있습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#meter)에서 예제·기대 결과와 대조하세요.

<a id="clef"></a>
## 한 마디 음자리표와 보표 전체 음자리표

**찾는 곳:** 팔레트 → 음자리표·조표·박자표 / 선택 음표 속성

1. 마디를 선택하고 음자리표 타일 또는 설정 열기를 사용합니다. 이 버전에서는 입력을 마친 뒤 음자리표 타일을 음표·쉼표로 끌어 놓은 대상의 한 마디에 적용할 수 있습니다
2. 한 마디에 적용할지 형식 → 악보 설정에서 현재 보표 전체를 바꿀지 구분합니다
3. 높은/낮은/가온/테너 중 현재 목록을 선택합니다

- **결과·적용 범위:** 마디 팔레트는 한 마디, 현재 보표 음자리표는 보표 전체에 적용합니다. 음표 앞 inline clef의 위치는 보존하지 못합니다. 이 버전은 가져오기 손실을 안내하며 원본 MusicXML을 함께 보관해야 합니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 현재 공개 UI에는 음표 앞 inline clef 전용 편집기가 없습니다. 타악기/TAB 원본 상태는 표시/지원 경계를 따릅니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#clef)에서 예제·기대 결과와 대조하세요.

<a id="pickup"></a>
## 못갖춘마디 만들기·가져오기

**찾는 곳:** 파일 → 새 악보 만들기 → 첫 마디를 못갖춘마디로 만들기 / 형식 → 첫 마디 길이…

1. 새 악보 설정에서 **첫 마디를 못갖춘마디로 만들기**를 켭니다
2. 개수와 음가를 지정합니다. 예를 들어 8분음표 1개로 시작할 수 있습니다
3. 만들기를 누르고 첫 마디에 실제 음표를 입력합니다
4. 프로젝트 저장/재열기와 MusicXML/PDF 출력을 구분해 확인합니다

- **결과·적용 범위:** 이 버전에서 모든 보표의 첫 마디를 같은 짧은 길이로 만듭니다. 설정한 총 마디 수에 포함하며 마디 번호와 마지막 마디 길이는 바꾸지 않습니다. 가져온 implicit/timing 길이도 보존합니다.
- **단축키:** 전용 없음. 창의 키보드 이동과 취소를 사용합니다.
- **안 되거나 다른 결과가 나오면:** 개수는1–128 정수이고 전체 길이는 현재 박자표의 한 마디보다 짧아야 합니다. 범위 밖 값은 임의 보정하지 않습니다. 기존 악보에서는 모든 보표의 첫 마디 박자·실제 길이가 같고 각 성부가 한 개의 온마디 쉼표여야 합니다. 음표·분할 쉼표·잇단음표가 있거나 줄어든 길이 밖에 빠르기·코드·표현 글자·페달 위치가 있으면 변경하지 않습니다.
- **되돌리기·취소:** 만들기 전 취소하면 기존 문서를 유지합니다. 생성 후 음표 편집은 기존 실행 취소/다시 실행을 사용합니다. 새 문서 만들기는 이전 문서로 돌아가는 undo가 아닙니다.
기존 빈 첫 마디 변환: **형식 → 첫 마디 길이…**를 열고 **첫 마디를 못갖춘마디로**를 켭니다. 개수·음가를 지정한 뒤 **적용**합니다. 선택한 보표 하나가 아닌 모든 보표의 첫 마디에 함께 적용하며, 마디 번호·끝마디·쉼표 기호는 그대로입니다. 같은 값은 적용하지 않으며 체크를 끄고 적용하면 정상 길이로 복원합니다. 적용은 한 번의 ⌘/Ctrl+Z로 되돌립니다. 초안에서 저장하려면 적용하거나 취소하라는 안내를 확인하세요. 가져온 길이가 이 입력기로 표현되지 않아 빈 개수로 보이면, 취소로 원본을 유지하거나 명시적으로 유효 길이를 지정합니다. 소리 없이 기본값으로 바뀌지 않습니다.

- **지원 경계:** 새 악보 생성과 빈 첫 마디 변환은 이 버전의 기능입니다. 배포된alpha.39의 원본 보존 범위와 구분하세요. 외부 앱의 실제 읽기/재생 검증은 별도입니다.
- **직접 확인:** [사용자 확인표](13-checklist.md#pickup)에서 직접 확인하세요.

## 총보·파트보 전환

**찾는 곳:** 보기 → 총보·파트보 보기

1. 악보 보기를 총보 또는 파트보로 고릅니다
2. 파트보에서는 파트보 선택에서 대상을 고릅니다
3. 상태 표시와 출력 대상을 확인합니다

- **결과·적용 범위:** 파트보는 선택 파트 표시와 독립 배치/출력 설정을 사용합니다. 같은 악보 내용의 다른 보기입니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 총보 모드에서는 파트보 선택이 비활성입니다. 파트가 없거나 제거된 경우 실제 표시 대상을 확인합니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#part-view)에서 예제·기대 결과와 대조하세요.
