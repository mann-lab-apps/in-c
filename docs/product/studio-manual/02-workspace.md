# 화면과 악보 탐색

기능 기준: alpha.41. 메뉴 이름과 아래 적용 범위를 함께 확인하세요.

<a id="menus"></a>
## 전역 메뉴와 명령 검색

**찾는 곳:** 파일·편집·보기·추가·형식·도구·도움말 / 도구 → 명령 검색

1. 메뉴 제목을 열고 원하는 항목을 선택합니다
2. 모르면 명령 검색에 실제 이름이나 메뉴 이름을 입력합니다
3. 비활성 항목은 필요한 선택/문서/작업 상태를 먼저 준비합니다

- **결과·적용 범위:** 명령 검색은 실제 메뉴 항목을 검색합니다. 모든 악보 기호의 별도 명령 검색기는 아닙니다.
- **단축키:** 방향키, Home/End, Enter/Space, Esc
- **안 되거나 다른 결과가 나오면:** 저장 중/선택 없음/해당 파일 기능을 사용할 수 없음 등 원래 명령의 비활성 조건이 유지됩니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#menus)에서 예제·기대 결과와 대조하세요.

## 음표·쉼표·마디·범위 선택

이 버전에서 음표·쉼표를 포인터로 선택하면 선택한 음악 기호로 대상을 확인합니다. Tab으로 이동한 키보드 초점은 기존 작은 대상 테두리로 구분합니다. 큰 글꼴 상자 전체를 감싸는 브라우저 기본 테두리는 사용하지 않습니다.

**찾는 곳:** 악보의 음표/쉼표 또는 마디

1. 음표/쉼표를 누르거나 ←/→로 옮깁니다
2. Shift+클릭 또는 Shift+←/→로 범위를 만듭니다
3. 상태 표시의 대상·보표·성부·필터를 확인합니다

- **결과·적용 범위:** 클릭한 객체와 범위에 따라 편집 가능한 속성이 달라집니다. 개별 화음 구성음 선택은 지원하지 않습니다.
- **단축키:** ←/→, Shift+클릭, Shift+←/→
- **안 되거나 다른 결과가 나오면:** 범위 끝점·보표/성부 또는 필터 때문에 명령 대상이 줄어들 수 있습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#selection)에서 예제·기대 결과와 대조하세요.

<a id="focus"></a>
## 악보·도구·도크 사이 포커스

**찾는 곳:** 악보로 이동 / 도크 헤더

1. 악보로 이동 버튼이나 F6을 사용합니다
2. Tab으로 도구와 입력 필드를 이동합니다
3. 작업이 끝나면 도크의 악보 복귀 또는 F6으로 돌아옵니다

- **결과·적용 범위:** Tab으로 초점만 옮겨도 현재 선택한 음표나 표기가 바뀌지는 않습니다. 일반 선택 모드에서 아래 표의 키로 초점 대상에 맞는 동작을 실행합니다. 텍스트 입력 중에는 입력창의 편집이 우선입니다.

### 초점 위치에 따른 Enter·Space

이 버전에서는 표시된 오류·경고 안내 글자를 선택해 읽는 동안 Space가 악보 재생·일시정지를 실행하지 않습니다. 글자 선택을 해제하거나 악보로 돌아오면 원래 Space 동작을 사용합니다. 기술 정보 버튼의 펼치기·접기는 해당 컨트롤의 기본 동작을 유지합니다.

이 버전에서는 안내 글자를 선택해 읽는 동안 재생 커서가 읽던 화면을 밀어내지 않도록 보완합니다. 재생 자체와 따라가기 설정은 유지합니다. 글자 선택을 해제하거나 악보로 돌아오면 기존 따라가기를 이어갑니다. 따라가기 버튼을 명시적으로 켠 경우에는 그 명령을 우선합니다.

| 초점 위치 | Enter | Space |
| --- | --- | --- |
| 음표·쉼표 | 해당 음표·쉼표 선택 | 현재 선택 기준으로 재생·일시정지 |
| 슬러·헤어핀 연결 조각 | 해당 표기 선택 | 해당 표기 선택 |
| 일반 버튼·선택 목록 | 현재 컨트롤 실행·선택 | 현재 컨트롤의 기본 동작 |

음표·쉼표에 초점이 있어도 Enter로 선택하기 전에는 기존 선택이 남아 있을 수 있습니다. 예를 들어 슬러를 선택한 뒤 Tab으로 음표에 초점을 옮겼다면, Enter로 음표를 선택한 다음 편집하세요. 슬러·헤어핀의 연결 조각은 Enter 또는 Space로 선택하며, 이때 Space는 재생을 시작하지 않습니다.

이 버전에서는 코드를 수정한 뒤 같은 코드를 다시 선택하고 Tab으로 음표에 초점만 옮겼다면, 실행 취소·다시 실행이 예전 코드 입력창으로 초점을 되돌리지 않습니다. 코드 선택과 내용은 이력에 따라 복원됩니다. 음표를 편집하려면 Enter로 먼저 선택하세요. 코드를 다시 명시적으로 편집하면 코드 입력창으로 이동합니다. 이는 같은 객체·문서·보기에서의 초점 보존이며, 다른 객체의 선택 복원 정책을 바꾸지는 않습니다.

입력창·열린 선택 목록·대화상자에서는 해당 컨트롤의 키 동작을 따릅니다. 위 표는 일반 선택 모드의 안내이며, 음표 입력 모드나 MuseScore의 모든 탐색 단축키를 지원한다는 뜻은 아닙니다. 도움말을 닫은 뒤 실제 악보에서 확인하세요.
- **단축키:** F6, Tab, Shift+Tab
- **안 되거나 다른 결과가 나오면:** IME 조합 중 전역 명령을 실행하지 않습니다. 수동 스크롤 뒤 오래된 예약 포커스로 화면을 되돌리지 않습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#focus)에서 예제·기대 결과와 대조하세요.

## 팔레트·속성 도크 표시와 폭

**찾는 곳:** 보기 → 팔레트/속성 또는 도크 헤더 → 설정

1. 필요한 도크를 표시하고 공유 도크 탭을 선택합니다
2. 설정에서 폭을 200–360px 정수로 입력합니다
3. 보이는 분할선을 드래그하거나 방향키로 조절합니다
4. 헤더 닫기 후 보기 메뉴에서 다시 엽니다

- **결과·적용 범위:** 기본 폭은 280px이며 폭·표시는 로컬 작업 공간 설정입니다. 악보 음높이/출력 geometry를 직접 수정하지 않습니다.
- **단축키:** 분할선 ←/→, 드래그 중 Escape
- **안 되거나 다른 결과가 나오면:** 화면 폭에 따라 도크 배치가 바뀌고 전용 resize control이 숨겨질 수 있습니다. 설정에 실제 표시되는 초기화 범위만 적용합니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#dock)에서 예제·기대 결과와 대조하세요.

## 팔레트 검색·접기·한 가족·순서

**찾는 곳:** 추가 → 표기 팔레트 열기 / 팔레트 헤더 설정

1. 표기 기호 검색에 이름을 입력합니다
2. 원하는 묶음을 펴 기호나 설정 열기를 선택합니다
3. 헤더 설정에서 한 팔레트씩 열기·전체 접기/펼치기·표시 기본값을 사용합니다
4. 순서를 바꿀 팔레트를 고르고 위/아래 이동을 누릅니다. 표시 기본값은 순서와 접힘도 복원하며 도크 폭은 유지합니다

- **결과·적용 범위:** 현재 8개 팔레트 묶음입니다. 일부 타일은 기호를 적용하고 일부는 기존 편집기를 엽니다. 표현 기호 4종은 선택 음표 클릭 적용/해제와 다른 주 음표로 끌어 추가를 구분합니다. 검색은 접힌 결과도 보여줍니다.
- **단축키:** family 제목: ↑/↓, Home/End
- **안 되거나 다른 결과가 나오면:** 한 팔레트씩 열기에서는 모두 펼치기가 비활성입니다. 가족 순서는 선택+이동으로 조절하며 가족 헤더 drag·즐겨찾기·모든 타일 drag는 지원하지 않습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#palette)에서 예제·기대 결과와 대조하세요.

## 폭 맞춤과 고정 확대율

**찾는 곳:** 하단 상태 표시 → 악보 보기 방식

1. 폭 맞춤 또는 고정 배율을 고릅니다
2. 고정 배율에서는 나타나는 확대율 목록을 선택합니다
3. 스크롤로 작업 위치를 확인합니다

- **결과·적용 범위:** 화면 보기와 PDF 보표 크기는 다른 설정입니다. 폭 맞춤은 도크와 창 폭에 따라 달라집니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 화면을 맞추려고 출력 glyph/font 크기를 변경할 필요가 없습니다.
- **되돌리기·취소:** 보기 설정을 되돌리면 화면 배율을 바꿀 수 있습니다. 악보 편집 undo와 다릅니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.

## 선택 필터와 표기 필터

**찾는 곳:** 파일 → 파일 작업 열기 → 선택 편집

1. 마디/범위를 선택합니다
2. 선택 필터에서 전체/음표만/쉼표만을 고릅니다
3. 표기 필터에서 셈여림·코드·보표 글자·시스템 텍스트·연습표·표현 텍스트를 고릅니다
4. 복사·삭제·붙여넣기 대상과 수를 확인합니다

- **결과·적용 범위:** 필터는 선택된 범위에서 명령이 다룰 대상을 제한합니다. 가려진 표기가 삭제됐다는 뜻이 아닙니다.
- **두 필터의 차이:** 선택 필터는 음표/쉼표 범위의 복사·삭제 대상을 제한합니다. 표기 필터는 마디를 선택한 뒤 그 종류의 표기를 복사·삭제할 때 사용합니다. MuseScore의 여러 종류·성부를 동시에 체크하는 Selection Filter와는 다릅니다. 필터 뒤 연속성 등 [실제 복사·붙여넣기 범위](03-notes.md#delete)를 확인하세요.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 시스템 텍스트/연습표 붙여넣기는 총보 첫 보표의 마디만 지원하는 등 종류별 제약이 있습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#filters)에서 예제·기대 결과와 대조하세요.

## 밝은/어두운 작업창과 악보 지면

**찾는 곳:** OS 표시 모드 → 앱 작업창

1. OS의 밝게/어둡게 설정에 따라 작업창을 확인합니다
2. 악보 지면과 음악 잉크는 그대로인지 확인합니다

- **결과·적용 범위:** 현재 앱은 OS 색상 선호를 따릅니다. 앱 내부에 별도 테마 선택 메뉴가 있다고 가정하지 않습니다.
- **단축키:** 없음
- **안 되거나 다른 결과가 나오면:** 어두운 작업창에서도 인쇄 지면을 검게 반전하는 기능이 아닙니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#theme)에서 예제·기대 결과와 대조하세요.

## 오프라인 사용설명서와 단축키 도움말

**찾는 곳:** 도움말 → 사용설명서 / 단축키 도움말

1. 사용설명서를 엽니다
2. 목차 또는 검색으로 항목을 찾습니다
3. 관련 항목으로 이동하고 이전 항목으로 돌아옵니다
4. Escape 또는 닫기로 이전 control에 복귀합니다

- **결과·적용 범위:** 본문은 앱에 번들되며 외부 참고 링크를 제외한 읽기에 인터넷이 필요 없습니다. 단축키 표는 기존 도움말과 같은 원본입니다.
- **단축키:** Escape
- **안 되거나 다른 결과가 나오면:** 전체 설명서는 alpha.41부터 앱에 포함됩니다. 배포된 alpha.39에는 기존 단축키 도움말만 있습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 앱 내 오프라인 설명서. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#manual)에서 예제·기대 결과와 대조하세요.

## 이름 있는 도크 배치 저장·복원

**찾는 곳:** 보기 → 도크 배치… (이 버전)

1. 원하는 도크 폭·표시 여부와 공유 도크의 열린 탭을 먼저 정합니다.
2. 도크 배치를 열어 새 배치 이름을 1–40자로 입력하고 **현재 배치 저장**을 누릅니다. 최대 20개이며 한글 이름을 사용할 수 있습니다.
3. 저장한 도크 배치를 선택해 요약을 확인한 뒤 **선택 배치 복원**을 누릅니다. 이름을 고르는 것만으로 화면이 바뀌지 않습니다.
4. 변경한 현재 배치를 같은 이름에 반영하려면 **선택 배치 갱신**을 사용합니다. 배치는 자동 갱신되지 않습니다.
5. **선택 배치 삭제**는 목록에서만 지우며 현재 화면은 유지합니다. **배치 창 닫기** 또는 Escape로 돌아갑니다.

- **결과·적용 범위:** 이 기기의 폭·표시 설정·열린 탭만 저장합니다. 공유 도크에서 두 표시가 켜져 있어도 한 탭만 열립니다. 모두 숨긴 배치도 저장할 수 있습니다. 악보·팔레트 내용/순서·믹서·확대율·테마는 포함하지 않습니다. 자유 도킹이나 MuseScore의 전체 작업 공간과 같지 않습니다.
- **안 되거나 다른 결과가 나오면:** 미확정 문서 입력은 먼저 확정하거나 취소하세요. 빈 이름·중복 이름·긴 이름은 오류로 안내하며 입력값을 임의로 줄이지 않습니다. 저장 장치를 사용할 수 없으면 현재 세션에서만 유지된다고 안내합니다. 읽을 수 없는 기존 목록을 창을 여는 것만으로 덮어쓰지 않습니다.
- **되돌리기·취소:** 배치 작업은 악보 undo를 만들지 않습니다. 이전 악보 편집의 실행 취소/다시 실행은 유지됩니다. 프로젝트 파일에는 이 목록이 들어가지 않습니다.
- **직접 확인:** [사용자 확인표](13-checklist.md#dock-layouts)

## 편집 단축키 설정

**편집 → 단축키 설정…** 또는 **도움말 → 단축키 도움말 → 단축키 설정 열기**에서 실행 취소·다시 실행·잘라내기·복사·붙여넣기·삭제의 키를 바꿀 수 있습니다. 다른 음악 입력 키와 가져오기/내보내기는 아직 재지정 대상이 아닙니다.

1. 명령을 고르고 현재 키를 확인합니다.
2. ‘새 단축키’ 필드에 포커스를 두고 ⌘/Ctrl+Shift와 영문 글쇠를 누릅니다. 한글 자판에서도 같은 물리 글쇠를 기록합니다. 첫 지원 범위는 이 조합이며 파일·창 관련 예약 키와 이미 쓰는 키는 거부합니다. 원래 복사·붙여넣기·다시 실행의 Shift 변형도 충돌에 포함합니다.
3. ‘단축키 적용’을 누르면 기존 키는 해당 명령에서 해제됩니다. 현재 키는 앱의 단축키 도움말·메뉴의 접근성 정보·파일 도구의 툴팁에도 반영됩니다. 이 설명서의 전체 단축키 표는 **기본값**입니다.
4. ‘선택 명령 단축키 해제’는 키만 해제하며 메뉴 명령은 유지합니다. ‘선택 명령 기본값 복원’은 다른 명령과 충돌하지 않을 때 원래 키를 복구합니다. 다른 명령에 그 키를 옮겼다면 해당 키를 먼저 변경/해제하세요.

Escape는 기록 중인 키를 먼저 취소하고, 기록이 없으면 창을 닫습니다. Tab으로 이동합니다. 한글 조합 중에는 기록·적용·창 닫기를 실행하지 않습니다. 명령을 바꾸면 이전 기록은 취소됩니다. 입력창·가사 등 텍스트 편집의 기존 키, 선택한 선과 닫힌 선택 목록의 기존 명령 범위는 유지합니다.

설정은 `studio.edit-shortcuts.v1`의 로컬 설정이며 악보·실행 취소·프로젝트 파일·도크 폭을 바꾸지 않습니다. 저장 실패 시 이 창에서만 적용된다는 안내를 표시합니다. 손상된 저장값은 원본을 덮어쓰지 않고 기본 키로 시작하며, 명시적 적용/복원 뒤 다시 저장합니다. 다른 기기 전송·설정 파일 가져오기/내보내기는 지원하지 않습니다. 물리 운영체제/IME가 먼저 가로채는 키는 이 설정으로 재정의하지 않습니다.

삭제 설정은 기존 Delete 동작의 키를 바꿉니다. 음표·범위는 리듬을 보존하며 지우고 선택한 선은 제거하지만, 마디를 선택한 상태에서는 마디 자체를 제거합니다. 마디 표기만 지우는 메뉴와는 다릅니다. 삭제키를 해제해도 삭제 버튼은 사용할 수 있으며, 속성 입력창과 선택 목록에서의 기존 키 소유권은 유지합니다. MuseScore가 일반 Delete와 마디 제거용 Cmd/Ctrl+Delete를 구분하는 것과 같다고 보지 마세요. 설정으로 삭제의 음악적 의미를 바꾸지는 않습니다.


### 악보 정보를 열어 확인만 할 때

이 버전은 줄바꿈이 들어 있는 기존 제목·작곡가·파트보 제목을 편집기로 열어 확인만 하고 빠져나와도 원문을 유지합니다. 단일행 입력창의 표시와 저장된 문구가 다를 수 있습니다. 실제 입력이나 Enter 확정은 기존 편집 정책을 따르며, 내용을 바꾼 경우 실행 취소로 되돌릴 수 있습니다. 입력창을 열기만 한 일은 실행 취소 항목을 만들지 않습니다.
