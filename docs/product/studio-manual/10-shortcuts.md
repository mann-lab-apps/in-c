# 단축키 전체 참고

앱의 단축키 도움말과 같은 기본 키 원본입니다. 편집 → 단축키 설정…에서 바꾼 현재 키는 앱의 단축키 도움말에서 확인하세요. 입력 모드·선택 모드·입력창/IME와 문맥에 따라 적용 범위가 다릅니다.

## 음높이·옥타브 이동

| 작업 | macOS | Windows/Linux | 범위·주의 |
| --- | --- | --- | --- |
| 한 옥타브 올리기/내리기 | ⌘+↑/↓ | Ctrl+↑/↓ | 음표 또는 동일 화음 전체를 선택한 상태에서 사용합니다. |
| 조성에 맞춰 한 음 이동 | Option+Shift+↑/↓ | Alt+Shift+↑/↓ | 온음계 순서로 이동합니다. |
| 반음 올리기/내리기 | ↑ / ↓ | ↑ / ↓ | 반음 단위로 이동합니다. |
| 음 이름 변경 | A–G | A–G | 선택 모드에서는 선택 음표를 변경하고, 입력 모드에서는 다음 음표를 넣습니다. |
| 화음 구성음 추가 | Shift+A–G | Shift+A–G | 입력 모드를 끝내고 단일 음표/화음을 선택한 뒤 사용합니다. |
| 이명동음 표기 바꾸기 | J | J | 실제 음높이를 유지하며 표기를 바꿉니다. |

## 음표 입력·음가

| 작업 | macOS | Windows/Linux | 범위·주의 |
| --- | --- | --- | --- |
| 음표 입력 시작/종료 | N · Esc | N · Esc | N으로 입력 모드를 전환하고 Esc로 선택 모드로 돌아옵니다. |
| 음가 선택 | 1=64분 · 2=32분 · 3=16분 · 4=8분 · 5=4분 · 6=2분 · 7=온음표 | 1=64분 · 2=32분 · 3=16분 · 4=8분 · 5=4분 · 6=2분 · 7=온음표 | 선택 모드에서는 선택 음가를 바꾸고, 입력 모드에서는 다음 입력 음가를 정합니다. |
| 쉼표 입력/변환 | 0 또는 R | 0 또는 R | 입력 모드에서는 쉼표를 넣고, 선택 모드에서는 선택 음표를 쉼표로 바꿉니다. |
| 점 추가/제거 | . / , | . / , | 선택 음표 또는 다음 입력의 점 개수를 바꿉니다. |
| 셋잇단음표 | ⌘+3 | Ctrl+3 | 선택 리듬에 적용하거나 셋잇단음표 입력을 준비합니다. Esc로 입력을 취소합니다. |
| 2연음 입력(2:3) | 전용 단축키 없음 | 전용 단축키 없음 | 추가 메뉴에서8분음표2개를3개 길이로 입력합니다. 미완성 취소·선택 그룹 해제는 기존 잇단음표 버튼/⌘/Ctrl+3을 사용합니다. |
| 다섯잇단음표 입력(5:4) | 전용 단축키 없음 | 전용 단축키 없음 | 추가 메뉴에서16분음표5개를4개 길이로 입력합니다. 미완성 입력은 Esc 또는 잇단음표 버튼/Ctrl+3으로 취소합니다. |
| 7연음 입력(7:4) | 전용 단축키 없음 | 전용 단축키 없음 | 추가 메뉴에서16분음표7개를4개 길이로 입력합니다. 미완성 취소·선택 그룹 해제는 기존 잇단음표 버튼/⌘/Ctrl+3을 사용합니다. |
| 타이 추가/해제 | T | T | 현재 지원하는 같은 음높이의 단음/동일 화음을 연결합니다. Control/Command/Option(Alt) 조합은 타이 편집을 실행하지 않습니다. Shift+T는 T와 같습니다. |
| 슬러 시작/끝 지정 | S | S | 시작 음표를 고르고 S, 끝 음표를 고르고 다시 S를 누릅니다. |

## 꾸밈음

| 작업 | macOS | Windows/Linux | 범위·주의 |
| --- | --- | --- | --- |
| 선택 음표 앞에 붙이기/제거 | Option+G | Alt+G | 상단 꾸밈음 버튼과 같습니다. 본음의 음가는 변하지 않습니다. |

| 현재 지원 범위 | 8분음표 모양의 빗금 꾸밈음 | 8분음표 모양의 빗금 꾸밈음 | 변환은 부착 표기가 없는 단음부터 지원합니다. 타이·잇단음표·범위 기호 경계 등 불가능한 조건은 버튼 설명으로 확인하세요. |

## 선택·보표·성부

| 작업 | macOS | Windows/Linux | 범위·주의 |
| --- | --- | --- | --- |
| 앞/뒤 음표로 이동 | ← / → | ← / → | 선택을 옮깁니다. Shift를 함께 누르면 범위를 확장합니다. |
| 위/아래 보표로 이동 | Option+↑/↓ | Alt+↑/↓ | 같은 시점에 가까운 표기로 선택을 옮깁니다. 화음 내부 구성음별 선택은 지원하지 않습니다. |
| 범위 선택 | Shift+클릭 · Shift+←/→ | Shift+클릭 · Shift+←/→ | 시작과 끝 사이를 선택합니다. |
| 다음/이전 성부 | V / Shift+V | V / Shift+V | 현재 보표에서 성부를 순환합니다. |
| 성부 직접 선택 | ⌘+Alt+1–4 | Ctrl+Alt+1–4 | 1–4성부 중 선택합니다. 입력/선택 상태에 따른 기존 제한을 따릅니다. |
| 악보와 도구 사이 이동 | F6 | F6 | 악보·도크·입력 도구의 현재 위치에 따라 포커스를 옮깁니다. |
| 현재 입력/선택 취소 | Esc | Esc | 잇단음표·슬러의 미완결 입력을 끝내고 선택 모드로 돌아옵니다. 열린 툴팁·메뉴가 있으면 먼저 그 표면을 닫고 입력 상태를 확인하세요. |

## 수동 배치 범위 표기

| 작업 | macOS | Windows/Linux | 범위·주의 |
| --- | --- | --- | --- |
| 수동 슬러·헤어핀 끌어 이동 | 선택한 선을 기본 마우스로 드래그 | 선택한 선을 기본 마우스로 드래그 | 이미 수동인 표기만 이동합니다. 이동량은0.25 sp격자이며 놓을 때 한 번의 편집으로 확정합니다. 프로젝트 파일은 별도로 저장하세요. Escape·스크롤·포커스 상실은 미리보기만 취소합니다. 곡선 모양/끝점·touch 드래그는 추가하지 않습니다. |

| 적용 범위와 제한 | 수동 배치된 슬러·헤어핀만 | 수동 배치된 슬러·헤어핀만 | 자동 배치는 속성에서 먼저 수동으로 설정하세요. ±8 sp 밖으로 임의 보정하지 않습니다. 포인터 모양 핸들·타이·파트별/구간별 독립 배치가 추가된 것은 아닙니다. |

## 재생

| 작업 | macOS | Windows/Linux | 범위·주의 |
| --- | --- | --- | --- |
| 재생/일시정지 | Space | Space | 선택 음표/쉼표가 있으면 그 위치를 우선합니다. Control/Command/Option(Alt)/Shift와 함께 누르면 전역 재생을 실행하지 않습니다. 입력창·버튼·메뉴 안에서는 해당 조작이 우선합니다. 표시된 오류·경고 안내 글자를 선택해 읽는 동안에는 Space로 재생하거나 일시정지하지 않습니다. 글자 선택을 해제하거나 악보로 돌아오면 기존 Space 동작을 사용합니다. |
| 정지·처음으로·따라가기 | 상단 재생 컨트롤 | 상단 재생 컨트롤 | 화면에 표시된 버튼을 사용합니다. 구현되지 않은 전역 단축키는 안내하지 않습니다. |
| 수동 스크롤 후 따라가기 복귀 | 따라가기 버튼 | 따라가기 버튼 | 스크롤바를 누르거나 직접 스크롤하면 자동 추적을 중단합니다. 버튼으로 다시 시작합니다. |

## 파일·실행 취소·입력 확정

| 작업 | macOS | Windows/Linux | 범위·주의 |
| --- | --- | --- | --- |
| 현재 형식으로 저장 | ⌘+S | Ctrl+S | 프로젝트 또는 MusicXML의 현재 저장 상태를 따릅니다. 프로젝트 파일을 새로 만들려면 파일 메뉴의 프로젝트 저장을 사용하세요. |
| 프로젝트 다른 이름 저장 | ⌘+Shift+S | Ctrl+Shift+S | 프로젝트 문서에서 사용합니다. |
| 실행 취소 | ⌘+Z | Ctrl+Z | 마지막 편집 한 번을 되돌립니다. |
| 다시 실행 | ⌘+Shift+Z 또는 ⌘+Y | Ctrl+Shift+Z 또는 Ctrl+Y | 실행 취소한 편집을 다시 적용합니다. |
| 음표·쉼표 잘라내기 | ⌘+X | Ctrl+X | 같은 마디·성부에서 기존 복사와 삭제가 모두 가능한 연속 단순 선택만 지원합니다. 원래 자리는 쉼표로 남고 한 번 실행 취소로 복원합니다. 입력 중·선택한 선·마디 표기는 제외하며 입력창에서는 텍스트 편집이 우선입니다. |
| 복사/붙여넣기 | ⌘+C / ⌘+V | Ctrl+C / Ctrl+V | 입력창에서는 텍스트 편집이 우선입니다. 악보에서는 지원하는 선택 객체를 기존 내부 클립보드에 복사합니다. |
| 삭제 | Delete / Backspace | Delete / Backspace | 기존 선택 문맥의 삭제입니다. 음표·범위는 리듬을 보존하며 지우고 선택한 선은 제거합니다. 마디 선택에서는 마디 자체를 제거하므로 대상을 확인하세요. MuseScore의 일반 Delete/마디 제거 키 구분과 다릅니다. |
| 속성 입력 확정/취소 | Enter·포커스 이동 / Esc | Enter·포커스 이동 / Esc | 숫자·텍스트 draft를 확정하거나 취소합니다. 범위 밖 값은 자동 보정하지 않는 필드의 안내를 확인하세요. |
| 빠르기 입력 | 40–240 bpm의 정수 | 40–240 bpm의 정수 | 새 악보 입력 중에는 숫자를 자동 보정하지 않습니다. 오류를 수정해야 만들 수 있고 Esc는 마지막 유효값을 복원합니다. |
