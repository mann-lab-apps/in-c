# 음표와 쉼표 입력·편집

기능 기준: alpha.43. 메뉴 이름과 아래 적용 범위를 함께 확인하세요.

<a id="input-mode"></a>
## 입력 모드와 선택 모드 구분

**찾는 곳:** 상시 음표 입력 도구의 연필 버튼

1. 음표 또는 마디를 선택합니다
2. N을 눌러 입력 모드로 들어갑니다
3. 숫자로 음가를 고른 뒤 A–G를 입력합니다
4. Esc로 끝냅니다

- **결과·적용 범위:** 입력 모드는 다음 음표를 넣고, 선택 모드의 숫자/A–G는 선택한 표기를 수정합니다. 도구 적용 대상과 caret을 확인하세요.
- **단축키:** N, Esc
- **안 되거나 다른 결과가 나오면:** 텍스트 필드가 활성화됐으면 음악 명령 대신 텍스트가 입력됩니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#input-mode)에서 예제·기대 결과와 대조하세요.

## 음가·점·쉼표

**찾는 곳:** 음가 기호·점 ±·쉼표 버튼

1. 1–7 중 음가를 고릅니다
2. . 또는 점 추가로 점을 늘리고 , 또는 점 줄이기로 줄입니다
3. 0/R로 입력 모드에서는 쉼표를 넣고 선택 모드에서는 쉼표로 변환합니다

- **결과·적용 범위:** 1=64분, 2=32분, 3=16분, 4=8분, 5=4분, 6=2분, 7=온음표입니다. 마디 길이와 현재 성부를 보존합니다. 음표나 같은 마디의 범위를 지우거나 쉼표로 바꿔도 뒤의 선택하지 않은 음표·화음·꾸밈음의 음높이는 유지합니다.
- **단축키:** 1–7, . / , , 0 또는 R
- **안 되거나 다른 결과가 나오면:** 잇단음표 입력 중 점 변경이나 보호된 리듬의 편집은 제한됩니다. 8/9 음가와 W/Q는 Studio 기본키로 안내하지 않습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#duration)에서 예제·기대 결과와 대조하세요.

## 음높이·옥타브 이동

**찾는 곳:** 음표 선택 → 방향키 / 속성의 음높이

1. Esc로 선택 모드에 돌아옵니다
2. ↑/↓로 반음, ⌘/Ctrl+↑/↓로 옥타브를 이동합니다
3. Alt+Shift+↑/↓로 온음계를 이동합니다
4. J로 이명동음 표기를 바꿉니다

- **결과·적용 범위:** 선택 단음 또는 화음 전체에 적용합니다. Alt+↑/↓는 보표 선택 이동이며 옥타브 변경이 아닙니다.
- **단축키:** ↑/↓, ⌘/Ctrl+↑/↓, Alt+Shift+↑/↓, J
- **안 되거나 다른 결과가 나오면:** 화음 내부 한 구성음 선택과 Shift+↑/↓ 보표 범위 확장은 미지원입니다. F♯→F𝄪처럼 실제 음높이는 맞지만 철자가 다를 수 있습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#pitch)에서 예제·기대 결과와 대조하세요.

## 임시표와 음 이름 변경

**찾는 곳:** 상시 도구 플랫·제자리표·샤프 / 속성 음높이

1. 입력/선택 모드를 확인합니다
2. 플랫·제자리표·샤프를 선택합니다
3. A–G로 입력하거나 선택 음 이름을 바꿉니다
4. 표기와 재생 음높이를 확인합니다

- **결과·적용 범위:** 입력 모드의 임시표는 다음 입력, 선택 모드는 선택 음표/화음입니다. 조표 및 마디 내 임시표 문맥도 영향을 줍니다. 같은 보표의 다른 성부에서 같은 위치의 음높이가 바뀌면 필요한 임시표를 표시합니다. 줄기가 있는 서로 다른 음높이가 같은 박의 같은 오선 위치에 올 때 음머리를 나눠 표시합니다. 예를 들어 두 성부의 F와 F♯, 세 성부의 F♯·F·F♭를 각각 선택할 수 있습니다. 세 성부에서 화음이나 온음표가 섞인 경우에도 각 성부를 선택할 수 있습니다.
- **단축키:** A–G, J
- **안 되거나 다른 결과가 나오면:** 현재 버튼에 없는 임의 임시표를 직접 입력한다고 설명하지 않습니다. 보관된 원본 표기는 별도 지원 경계를 따릅니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#accidental)에서 예제·기대 결과와 대조하세요.

## 화음 구성음 추가와 전체 편집

**찾는 곳:** 음표 선택 → 속성 → 선택 음표의 화음

1. Esc로 입력을 끝냅니다
2. 단음 또는 화음을 선택합니다
3. Shift+A–G 또는 구성음 추가를 사용합니다
4. 기존 화음의 음 목록과 편집 대상을 확인합니다
5. 3도 추가/5도 추가 또는 기준음 이외 구성음의 제거 버튼도 사용할 수 있습니다

- **결과·적용 범위:** 화음 전체를 하나의 이벤트로 취급합니다. A–G 단음 교체와 Shift+A–G 구성음 추가를 구분합니다.
- **단축키:** Shift+A–G
- **안 되거나 다른 결과가 나오면:** 기준음은 구성음 제거 버튼이 없습니다. 개별 구성음 선택과 서로 다른 화음의 부분 타이는 미지원이지만, 목록의 추가 구성음 제거 버튼은 사용할 수 있습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.

<a id="overwrite"></a>
## 뒤 음표가 있을 때 음가 늘리기

**찾는 곳:** 음표 선택 → 더 긴 음가 버튼/숫자

1. 음표를 선택하고 더 긴 음가를 고릅니다
2. 뒤 음표와 겹치면 덮어쓰기 안내를 읽습니다
3. 취소 또는 덮어쓰고 음가 늘리기를 선택합니다
4. 결과를 확인하고 한 번 실행 취소해 비교합니다

- **결과·적용 범위:** 겹치는 뒤 음표 전체와 부착 표기를 대체하고 남는 꼬리는 쉼표로 채웁니다. 다른 마디/성부와 겹치지 않는 음표 위치는 유지합니다. 범위 밖에 남은 음표와 꾸밈음의 음높이도 유지합니다.
- **단축키:** 1–7
- **안 되거나 다른 결과가 나오면:** 마디를 넘는 확대, 타이·잇단음표·범위 기호 endpoint 보호 조건은 거부될 수 있습니다. 확인 없는 MuseScore 덮어쓰기와 동일하지 않습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#overwrite)에서 예제·기대 결과와 대조하세요.

<a id="voices"></a>
## 입력 보표·성부 전환

**찾는 곳:** 상단 입력 보표·입력 성부

1. 입력 보표와 1–4 성부를 선택합니다
2. V/Shift+V로 성부를 순환합니다
3. 원래 음표가 그대로 남고 입력 대상만 바뀌는지 확인합니다

- **결과·적용 범위:** 입력할 보표·성부와 선택 위치를 전환합니다. 선택한 음표를 다른 성부로 옮기는 명령이 아닙니다. Alt+↑/↓는 가까운 시점의 위/아래 보표 선택입니다.
- **단축키:** V, Shift+V, ⌘/Ctrl+Alt+1–4, Alt+↑/↓
- **안 되거나 다른 결과가 나오면:** 대상 마디를 먼저 선택하세요. 단일 음표를 빈 성부로 옮기기는 아래 별도 명령입니다. 범위 이동·성부 교환은 현재 지원하지 않습니다. 대상 성부에 기존 음표가 있으면 그 성부의 위치로 선택을 전환합니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#voices)에서 예제·기대 결과와 대조하세요.

이미 있는 성부로 전환하면 악보와 실행 취소 이력은 바뀌지 않습니다. 없는 성부를 처음 선택하면 현재 마디에 온마디 쉼표를 가진 성부가 추가되며, 이 악보 변경은 한 번 실행 취소할 수 있습니다.

MuseScore에서는 선택한 음표를 성부 버튼으로 옮기는 편집도 할 수 있지만 Studio의 현재 버튼은 입력 위치 전환입니다. 복사·붙여넣기의 제한된 범위를 음표 이동·성부 교환 기능 전체로 해석하지 마세요.

<a id="tuplet"></a>
## 셋잇단음표·2연음·다섯잇단음표·7연음

**찾는 곳:** 상시 입력 도구 → 셋잇단음표

1. 음표/쉼표 또는 입력 위치를 선택합니다
2. 셋잇단음표 버튼이나 ⌘/Ctrl+3을 누릅니다
3. 입력 중이면 표시되는 진행 상황에 맞춰 입력합니다
4. Esc로 미완결 입력을 취소합니다

- **결과·적용 범위:** 기존3:2 경로를 유지합니다. 이 버전의 추가 → 2연음 입력(2:3)은8분음표2개를3개 길이로, 다섯잇단음표 입력(5:4)과7연음 입력(7:4)은16분음표5개 또는7개를4개 길이로 입력하는 preset입니다. 완성 시 한 번의 실행 취소로 되돌립니다. 임의 비율·중첩·전용 속성은 별도 미지원 범위입니다.
- **단축키:** ⌘/Ctrl+3
- **안 되거나 다른 결과가 나오면:** 그룹 경계·마디 길이·점 변경 제한을 확인합니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#tuplet)에서 예제·기대 결과와 대조하세요.

도구 안내 구분: **입력 모드 밖에서** 잇단음표 구성음을 선택하면 버튼은 해당 그룹의 **해제**를 안내합니다. N으로 일반 입력 모드에 들어가면 같은 버튼은 다음 **셋잇단음표 적용 또는 입력 준비**를 안내하며, 미완성 잇단음표가 있으면 **입력 취소**를 안내합니다. 새 비율 입력과 기존 그룹 해제를 구분하고, 해제할 공간이 부족하거나 보호할 표기가 있으면 기존 오류 안내를 확인하세요.

2:3 입력: 빈 쉼표 또는 입력 위치에서 **추가 → 2연음 입력(2:3)**을 고르고 A–G/R로 두 칸을 채웁니다. 예를 들어3/8에서8분음표 두 개가 마디 전체를 차지합니다. 새 전용 단축키는 없으며 기존 ⌘/Ctrl+Alt+1–4 성부 선택은 바꾸지 않습니다. ⌘/Ctrl+3은 미완성 취소 또는 선택 잇단음표 해제입니다. 해제하며 짧아진 구간은 쉼표로 채우고 뒤 음표의 위치는 유지합니다.

5:4 입력: 빈 쉼표 또는 입력 위치를 선택하고 **추가 → 다섯잇단음표 입력(5:4)**를 사용합니다. A–G와 R로 다섯 개를 채우세요. 미완성 취소는 악보/undo를 바꾸지 않습니다. 프로젝트 저장은 완성/취소 후 진행하며, PDF/MIDI 사본은 확정된 악보만 포함하고 빠진 미완성 입력을 안내합니다. 새5:4 전용 단축키는 없습니다. 실행 취소는 확정 전의 미완성 입력 상태도 복원할 수 있으므로 프로젝트 저장 전에 초안을 마치거나 취소하세요. 툴팁·메뉴가 열려 있으면 첫 Esc는 그 표면을 닫습니다. 입력 상태를 확인하고 다시 Esc로 미완성을 취소하세요.

7:4 입력: **추가 → 7연음 입력(7:4)**에서 A–G/R로 일곱 칸을 채웁니다.16분음표 일곱 개가4분음표 하나의 길이에 들어갑니다. 전용 단축키는 없고 기존 ⌘/Ctrl+3으로 입력 취소/선택 그룹 해제를 합니다. 일반 음가로 해제할 공간과 보호할 표기가 있는지 확인하며, 실행 취소로 원래 그룹을 복원할 수 있습니다.

<a id="grace"></a>
## 꾸밈음 붙이기와 기존 음표 변환

**찾는 곳:** 상시 꾸밈음 / 꾸밈음으로 변환

1. Esc로 선택 모드에서 본음을 선택합니다
2. Alt+G로 본음 앞에 꾸밈음을 붙이거나 제거합니다
3. 기존 음표 자체를 변환하려면 변환 가능한 단음을 선택하고 Alt+Shift+G를 누릅니다
4. 뒤 음표와 마디 끝 쉼표를 확인합니다

- **결과·적용 범위:** 붙이기는 본음 음가 유지, 변환은 다음 음표를 당겨 남는 마디 끝을 쉼표로 채웁니다. 앞으로 당겨진 기존 음표와 꾸밈음의 음높이는 유지합니다. 현재 빗금 8분음표 모양의 부착 꾸밈음입니다. 꾸밈음 뒤 같은 위치의 음이 다른 음높이이면 필요한 임시표를 표시합니다. MusicXML에서 같은 보표·성부의 꾸밈음 화음을 가져오면 동시에 시작하는 관계를 프로젝트와 MusicXML 사본에 보존합니다. 같은 성부의 마디 마지막 음 뒤에 들어 있는 꾸밈음도 본음 오른쪽에 표시합니다. 편집으로 뒤꾸밈음이 마디 중간에 오면 위치를 보존할 수 있도록 프로젝트 파일로 저장하세요.
- **단축키:** Alt+G / Alt+Shift+G
- **안 되거나 다른 결과가 나오면:** 변환은 같은 마디의 다음 음표가 필요하며 타이·잇단음표·부착 표기·구간 경계 등에 제한이 있습니다. 내부 재생/MIDI의 별도 꾸밈음 발음은 미지원입니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#grace)에서 예제·기대 결과와 대조하세요.

<a id="delete"></a>
## 삭제·복사·붙여넣기와 필터

**찾는 곳:** 편집 메뉴 또는 파일 작업 → 선택 편집

1. 단음·범위·표기 객체를 선택합니다
2. 필터와 대상 수를 확인합니다
3. 잘라내기/복사/붙여넣기 또는 삭제를 실행합니다
4. 한 번 실행 취소해 원래 상태와 비교합니다

- **결과·적용 범위:** 음표 삭제는 리듬을 유지하는 쉼표 변환입니다. 표기 객체 삭제는 선택 종류를 따릅니다. 입력창에서는 텍스트 편집이 우선입니다.

### 실제 복사·붙여넣기 범위

| 선택한 대상 | 현재 동작과 제한 |
| --- | --- |
| 음표·쉼표 하나 또는 연속 범위 | 같은 마디·보표·성부 안의 연속된 단순 범위만 복사합니다. 타이·잇단음표와 한 마디 전체를 뜻하는 쉼표는 복사 대상에서 제외됩니다. |
| 연속한 마디 전체 | 같은 보표·성부의 연속 마디에서 첫 이벤트부터 마지막까지 선택해 복사합니다. 여러 마디를 복사할 때 온마디 쉼표도 포함할 수 있습니다. 대상 첫 마디의 맨 앞 음표나 쉼표를 선택하거나, 같은 개수의 마디를 범위로 선택합니다. 대상 마디의 실제 길이는 하나씩 대응해 일치해야 합니다. 마디 정보는 대상에 남고, 가사 등 붙은 표기는 음표와 함께 복사합니다. 타이·잇단음표·구간 표기의 끝점이 있는 범위는 거부합니다. |
| 음표·쉼표 잘라내기 | 기존 복사와 삭제가 모두 가능한 단순 선택에만 적용합니다. 원래 자리는 기존 삭제처럼 리듬을 보존하는 쉼표로 남습니다. 한 번 실행 취소하면 악보를 복원하며, 복사된 내용은 내부 클립보드에 유지됩니다. 입력 중·선택한 선·마디 표기에는 적용하지 않습니다. |
| 음표·쉼표를 붙여넣을 대상 | 복사한 범위와 길이가 같은 단순 범위를 선택합니다. 대상 성부의 잇단음표나 구간 기호의 연결 위치를 보존할 수 없으면 거부합니다. 뒤 음표를 자동으로 밀지 않습니다. 연속 마디를 복사했다면 마디별 길이와 경계를 맞춰 한 번에 붙여넣습니다. 대상이 원본과 겹치거나 조표가 달라도 꾸밈음은 복사한 음높이를 유지합니다. 붙여넣는 범위 밖에 남은 음과 꾸밈음도 원래 음높이를 유지합니다. 필터를 모두 표시로 두세요. |
| 음표만·쉼표만 필터 | 필터 뒤에도 복사 대상이 연속돼야 합니다. 중간 쉼표를 뺀 음표들을 빈틈없이 당겨 복사하는 기능이 아닙니다. |
| 마디 선택과 표기 필터 | 선택한 종류의 마디 표기를 복사합니다. 붙여넣으면 대상 마디의 같은 종류 표기를 교체합니다. 음표·쉼표의 리듬은 그대로이며 시스템 텍스트·연습표는 총보 첫 보표만 대상입니다. |
| 글자·코드 표기 하나 | 선택한 보표/시스템/표현 텍스트·연습표·코드는 기존 개별 복사 경로를 사용합니다. 유효한 대상 마디나 위치에 하나를 추가하며 기존 같은 종류 표기는 유지합니다. |
| 셈여림 하나 | 현재 모델의 마디 전체 설정입니다. 붙여넣으면 대상 보표의 마디 셈여림을 교체합니다. 박·성부별 독립 셈여림으로 추가하는 기능이 아닙니다. |
| 선택한 슬러·헤어핀 | 속성에서 끝점·배치를 바꾸거나 삭제할 수 있습니다. 선택한 선 자체의 복사·붙여넣기는 지원하지 않습니다. |

종료 역할이 기록된 헤어핀의 두 끝을 같은 마디·성부의 복사 범위에 넣으면, 붙여넣은 음표에 헤어핀과 수동 배치도 함께 복제됩니다. 한 끝만 선택하면 선택한 음표·쉼표를 복사합니다. 헤어핀과 음표를 한 번의 실행 취소로 함께 되돌릴 수 있습니다.

여러 보표에 걸친 악구, 서로 떨어진 객체의 목록 복사, 시스템 클립보드와 교환, 반복 복제, 반/두 배 음가 붙여넣기는 아직 지원하지 않습니다. [MuseScore와의 차이](14-musescore-differences.md#gaps-4)도 확인하세요.

- **단축키:** ⌘/Ctrl+X(지원되는 음표·쉼표 잘라내기), ⌘/Ctrl+C, ⌘/Ctrl+V, Delete/Backspace
- **안 되거나 다른 결과가 나오면:** 지원하지 않는 선택·붙여넣기 위치·구간 경계에서는 비활성/안내가 나옵니다. 잘라내기는 복사와 삭제가 모두 가능해야 하며, 거부되면 이전 클립보드와 악보를 유지합니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.
- **지원 경계:** 직접 사용 가능. 표기·재생·native·교환 형식은 동일한 지원 약속이 아닙니다. 해당 기능과 [지원 범위](12-reference.md#limits)를 확인하세요.
- **직접 확인:** [사용자 확인표](13-checklist.md#delete)에서 예제·기대 결과와 대조하세요.

## 실행 취소·다시 실행

**찾는 곳:** 편집 → 실행 취소/다시 실행

1. 한 음표나 확정된 속성을 편집합니다
2. 한 번 실행 취소하고 상태를 비교합니다
3. 다시 실행해 복원합니다

- **안 되거나 다른 결과가 나오면:** 이력이 비면 비활성입니다. 텍스트 입력창에서는 해당 텍스트의 undo가 우선할 수 있습니다.
- **되돌리기·취소:** 악보 변경은 ⌘/Ctrl+Z로 되돌립니다. 다시 실행은 ⌘/Ctrl+Shift+Z 또는 ⌘/Ctrl+Y입니다. 창만 닫은 작업은 실행 취소를 만들지 않습니다.

## 선택 음표를 빈 성부로 옮기기

**찾는 곳:** 도구 → 선택 음표 성부 이동, 또는 선택한 음표의 속성

1. 음표 입력을 마치고 일반 단음 하나를 선택합니다.
2. 옮길 성부를 고릅니다. 선택값만 바꿔서는 악보가 변경되지 않습니다.
3. 선택 음표를 성부로 옮기기를 누릅니다.
4. 음표는 새 성부에 선택된 채 남고, 원래 자리는 같은 음가의 쉼표가 되는지 확인합니다.

- **결과·적용 범위:** 같은 마디·보표의 빈 성부에만 적용합니다. 음표 ID·박 위치·음가·발음은 유지하고 대상의 앞뒤를 쉼표로 채웁니다. 임시표 상속이 달라지면 발음 보존에 필요한 명시값을 사용합니다. 원래 성부에 남은 음표와 꾸밈음의 음높이도 유지합니다. 상단 성부 버튼/V/⌘·Ctrl+Alt+1–4는 기존처럼 입력 위치를 전환합니다.
- **단축키:** 이 이동 명령에는 별도 기본 단축키가 없습니다.
- **안 되거나 다른 결과가 나오면:** 대상은 없거나 부착 표기 없는 온마디 쉼표 하나여야 합니다. 기존 음표나 복잡한 쉼표를 덮어쓰지 않습니다. 화음·꾸밈음·가사/표현 기호·타이·잇단음표·구간 기호 끝점·범위 선택은 현재 지원하지 않습니다. 미확정 입력을 먼저 확정하거나 취소하세요. 성부 교환·교차보표 이동과 구분합니다. 헤어핀 끝점뿐 아니라 이동으로 헤어핀 적용이 달라지는 중간 음표도 재생 세기 보존을 위해 거부합니다. 구간 밖 또는 적용이 같은 다른 빈 성부를 확인하세요.
- **되돌리기·취소:** ⌘/Ctrl+Z 한 번으로 원래 성부·선택을 복원하고 다시 실행으로 이동을 재적용합니다. 성부 선택값 변경만으로 실행 취소를 만들지 않습니다.
- **지원 경계:** 이 버전의 단일 일반 음표/빈 성부 범위입니다. 기존 파일과 교환 형식의 모든 성부 기능을 지원한다는 뜻은 아닙니다.
- **직접 확인:** [사용자 확인표](13-checklist.md#voice-move)와 비교하세요.
