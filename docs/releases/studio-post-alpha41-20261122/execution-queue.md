# Studio alpha.41 이후 실행 큐

| 작업 | 수용 기준 | 검증 |
| --- | --- | --- |
| 선택 없이 PNG 진단 읽기 | 같은 진단이 출력 설정과 상태줄 사이에서 이동해도 읽던 글자가 보인다. 진단 토글의 논리 초점을 유지하고 새로 초점을 받은 필드는 그대로 둔다. | 두 폭의 휠과 1400×750 상태줄의 PageDown, 늦은 PDF 실패·MIDI 성공·MusicXML 취소 12경로 통과 |
| 진단 레이블과 본문을 함께 선택 | 같은 PNG 진단에서 범위의 양끝과 방향을 보존한다. 다른 표면으로 이어지는 선택을 새 진단에 옮기지 않는다. | 양방향 DOM Range와 새 필드 대조 24경로, 실제 Electron Space와 문서 교체 2경로 통과 |
| 도움말에서 재출력 | 문제 해결 설명을 열고 닫은 뒤 파일 위치와 PNG 해상도를 수정해 실제 파일을 저장한다. 원본과 편집 상태를 유지한다. | 두 폭에서 내장 사용설명서·300dpi PNG와 미저장 편집 상태 확인 |
| 실제 OS 대화상자와 스크린리더 | 오류 안내를 읽고 취소·재시도한 뒤 원래 작업으로 복귀한다. | 전면 입력과 낭독을 독점할 수 있는 별도 환경이 필요하다. 이번 검증은 자체 숨김 Electron을 사용한다. |

결과와 재현 조건은 [인계](handoff.md)에 기록한다. 후속 항목은 기존 검증과 겹치지 않는 실패 또는 관측 근거를 확인한 뒤 추가한다.
