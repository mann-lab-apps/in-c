# 띠로리 Studio alpha.39

설치 패키지와 실제 앱의 이름·아이콘을 띠로리 Studio로 정리하고, 음표 편집에서 찾기 어렵거나 불편했던 조작을 개선했습니다.

- DMG, 앱 이름, 창 제목, macOS 앱 메뉴·About·Dock에 새 이름과 파란 연필 아이콘을 적용했습니다. 기존 앱 ID·프로젝트 형식·설정·자동저장·최근 파일 경로는 유지합니다.
- 새 악보의 빠르기를 입력하는 도중 숫자가40/240으로 임의 보정되지 않습니다.40–240 bpm의 정수 범위와 오류를 안내하며, Escape로 마지막 유효값을 복원할 수 있습니다.
- 상시 입력 도구에 꾸밈음 버튼을 표시했습니다. Alt+G로 붙이기/제거, Alt+Shift+G로 기존 단음을 다음 음표의 꾸밈음으로 변환합니다. 변환하면 뒤 음표를 앞당기고 끝을 쉼표로 채우며 한 번의 실행 취소로 복원합니다.
- 음가를 늘릴 때 뒤 음표와 겹치면 확인 후 덮어쓸 수 있습니다. 겹치는 뒤 음표 전체와 부착 표기는 대체되며 남는 부분은 쉼표가 됩니다. 타이·잇단음표·범위 기호 경계 등 보호 조건은 유지합니다.
- 기본 ↑/↓는 반음 이동, Mac ⌘/Windows·Linux Ctrl+↑/↓는 옥타브 이동, Alt+Shift+↑/↓는 온음계 이동으로 정리했습니다. Alt+↑/↓는 보표/성부 선택 이동입니다. 메뉴가 처리한 방향키로 악보가 함께 바뀌는 충돌도 차단했습니다.
- 도움말의 단축키 안내를 확장했습니다. 음표 입력과 선택 편집, 음가·꾸밈음·성부·저장·박자표의 실제 지원 범위를 확인할 수 있습니다.
- 슬러를 끝이 가늘어지는 검은 윤곽선으로 개선했습니다. 줄바꿈 연결부, 수동 배치와 선택 hit 경로를 유지합니다.
- 마디 우클릭에 ‘박자표 변경…’을 추가했습니다. 현재는2/4·3/4·4/4·6/8 중 선택하며, 선택한 보표의 그 마디만 바뀐다는 적용 범위를 표시합니다.

## 알려진 제한

- 꾸밈음은 현재 표기와 프로젝트/MusicXML 보존부터 지원하며, 내부 재생/MIDI의 별도 발음은 추가하지 않았습니다. 기존 음표 변환은 부착 표기가 없는 단음 등 지원 조건을 따릅니다.
- 총보 전체·이후 마디에 박자표를 함께 적용하거나 사용자 지정 박자를 입력하는 기능, 개별 화음 구성음 선택·부분 화음 타이는 이번 범위가 아닙니다.
- 반음 이동의 기존 이명동음 철자는 유지합니다. 필요하면 J로 표기를 변경할 수 있습니다.
- 이전에 기록한 일부 중첩 터치 스크롤, 외부 MuseScore 이조/중첩 반복·볼타 차이와 외부 프로세스 종료 문제는 별도 작업입니다.
- Windows는 코드 서명이 없어 SmartScreen 안내가 표시될 수 있습니다. 물리 IME·스크린리더·OS 파일 대화상자·실제 사용자 악보·청음 검증을 모두 완료한 배포가 아닙니다.

macOS 서명·공증과 플랫폼별 패키지·체크섬은 이 태그의 Release workflow 결과로 확인합니다. Commercial V1/RC 전체 완료를 뜻하지 않습니다.

## macOS 설치 안내

기존 in-C 앱을 종료한 뒤 DMG의 ‘띠로리 Studio’를 Applications로 복사하고 새 이름의 앱을 실행해 주세요. 파일명이 달라 이전 in-C 앱이 남아 있을 수 있습니다. 창 제목에서 실행한 앱을 구분할 수 있으며, 기존 설정·최근 파일·복구 경로와 프로젝트 확장자는 유지합니다.
