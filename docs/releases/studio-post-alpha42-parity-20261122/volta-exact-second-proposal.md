# 세 번 이상 반복하는 MusicXML의 두 번째 볼타

4.0 XSD를 통과한 1/4박자 세 마디를 생성했다. 첫 마디가 반복 시작이고 두 번째 마디에서 `times="3"`으로 돌아간다. 두 번째 마디의 양쪽 볼타 회차는 `number="2"`이며 마지막 마디는 `number="3"`이다.

- Studio는 단일 `2`를 기존 Native의 숫자 필드로 읽어 마디를 **1–1–2–1–2–3** 순서로 재생한다. 두 번째 마디가 마지막 회차에서도 발음한다.
- 회차를 명시한 대조군 `2,2`는 **1–1–2–1–3**으로 재생한다. 이 중복 표기를 일반 출력에 쓰는 해결책은 채택하지 않는다.
- MusicXML과 MuseScore는 명시된 회차에서만 볼타를 재생하는 것으로 정의한다. [MusicXML ending](https://www.w3.org/2021/06/musicxml40/musicxml-reference/elements/ending/) · [MuseScore 볼타](https://handbook.musescore.org/notation/repeats/voltas)

## 승인 판단과 수용 기준

새로 가져오는 단순 반복의 XML `2`는 두 번째 회차만 의미하도록 한다. 기존 Native의 단일 2번 볼타와 직접 편집 명령이 세 번째 이후에도 발음하는 동작은 그대로 둔다. 기존 Native를 구조 유지 XML로 쓸 때 명시적인 회차가 추가로 필요한 경우 파일에서 재생을 유지하는 회차 목록을 출력하고 표시 차이를 안내하는 안이다. 열린 중첩이나 여러 끝 도돌이표의 소유권은 덧붙여 추정하지 않는다.

- 단순 2회 반복, 단순 3회 반복, 4회 반복의 중간/끝 볼타, 이어지는 독립 반복을 분리해 MIDI와 재생 순서를 확인한다.
- 기존 Native와 되돌리기를 보존한다. 기본 및 펼친 XML의 실제 사본을 비교하며, 구조 유지 저장은 호환성 검사를 유지한다.
- 대안은 기존 배열을 새 프로젝트에만 쓰고 구조 유지 XML에서 호환되지 않는 경우를 차단하는 방식이다. 기존 Native 해석을 일괄 변경하면 저장해 놓은 악보의 재생 순서가 달라진다.

관찰 파일은 `out/parity-qa/volta-single-second.musicxml`와 `grace-and-single-volta-studio.log`에 있다. 이 제안은 제품에 미적용 상태다.
