# 띠로리 Studio alpha.43

- **마디 편집** — 같은 위치의 한 마디에 박자표를 총보 전체로 적용할 수 있습니다. 마디 내용을 지우는 동작과 마디 자체를 제거하는 동작을 구분했습니다. 같은 보표·성부 안에서 지원되는 연속 마디 구간을 복사할 수 있습니다.
- **악보 보기와 파트보** — 일정한 이조를 쓰는 단일 파트에서 읽기 전용 실음 보기를 제공합니다. 파트보 출력은 지원되는 연속 빈 마디를 묶습니다.
- **MusicXML·MXL** — 음높이와 여러 성부에 걸친 슬러·셈여림선의 연결을 더 정확히 보존합니다. 표현할 수 없는 마디 중간의 이조는 위치를 안내하고, 현재 열려 있는 악보를 유지합니다.
- **셈여림선** — 지원되는 MusicXML의 음 시작·길이 끝과 음표 사이의 정확한 종료 박을 가져옵니다. 한 보표에서 겹치는 선과 줄·페이지 경계의 표시를 개선했습니다.
- **재생** — 악보 설정에서 지원되는 단일 앞꾸밈음의 발음을 켤 수 있습니다. 기본값은 꺼짐입니다. 같은 위치에서 일시정지 후 재개하거나 재생 중 믹서를 조정할 때 이어지는 피아노 음의 샘플 위치를 보존합니다.

## 프로젝트 호환성

기존 프로젝트를 열 수 있습니다. 독립 종료 박이 있는 셈여림선을 저장하면 프로젝트 형식 v3을 사용합니다. 새 종료 역할이나 앞꾸밈음 재생 설정이 들어간 프로젝트는 파일 형식이 v2여도 이전 버전에서 열리지 않을 수 있습니다. 해당 프로젝트를 편집할 때는 Studio를 업데이트하고, 이전 버전으로 돌아갈 때 사용할 원본 사본을 보관하세요.

다른 앱에는 MusicXML 사본으로 기보를 전달하고 재생을 비교할 때 MIDI를 함께 사용할 수 있습니다. 셈여림선의 정확한 종료 역할은 외부 앱에서 MusicXML을 다시 저장할 때 달라질 수 있습니다.

## 설치

- macOS는 Universal DMG 또는 ZIP을 제공합니다. 배포 파일에 Developer ID 서명과 Apple 공증을 적용합니다.
- Windows는 x64 설치 파일과 포터블 실행 파일을 제공합니다. SmartScreen 안내가 표시될 수 있습니다.
- Linux는 x86_64 AppImage를 제공합니다. 플랫폼별 다운로드 파일은 `SHA256SUMS.txt`로 확인할 수 있습니다.

이 버전은 프리릴리즈입니다.
