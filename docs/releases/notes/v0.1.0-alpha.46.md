# 띠로리 Studio alpha.46

이번 데스크톱 프리릴리즈는 설치 패키지 크기를 줄이고 배포 파일 검증을 보강했습니다.

- 화면에 이미 번들된 라이브러리와 PNG 내보내기에 쓰는 글꼴의 중복 포함을 줄였습니다.
- 배포 전에 macOS·Windows·Linux 패키지의 앱 실행과 필수 모듈·라이선스를 확인합니다.
- 각 플랫폼의 설치 파일을 확인한 뒤 SHA-256 체크섬을 생성합니다.

macOS는 Apple Silicon과 Intel을 지원하는 Universal DMG·ZIP을 제공합니다. Windows는 x64 설치·포터블 EXE, Linux는 x86_64 AppImage를 제공합니다. 체크섬은 릴리즈의 `SHA256SUMS.txt`에 있습니다. [공식 다운로드](https://ddirori.com/studio/#download) · [전체 변경 내역](https://github.com/mann-lab-apps/in-c/compare/v0.1.0-alpha.45...v0.1.0-alpha.46)
