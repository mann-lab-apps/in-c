# 띠로리 Studio alpha.42

- **PNG 출력 오류** — 다른 출력이 완료되어 기술 정보가 상태줄과 내보내기 설정 사이를 옮겨도 읽던 글자나 선택한 텍스트가 유지됩니다. 새 입력란에 초점을 두거나 진단 밖을 스크롤하면 그 작업이 우선합니다.
- **PNG 재시도** — 프로젝트를 바꾸거나 PNG를 다시 내보내면 이전 오류의 읽기 상태를 정리합니다. **도움말 → 사용설명서 → 문제 해결**에서 저장 위치와 출력 설정을 확인하는 방법을 볼 수 있습니다.

## 설치

- macOS는 Universal DMG 또는 ZIP을 사용합니다. Developer ID 서명과 Apple 공증을 적용합니다.
- Windows는 x64 설치 파일과 포터블 실행 파일을 제공합니다. SmartScreen 안내가 표시될 수 있습니다.
- Linux는 x86_64 AppImage를 제공합니다. 플랫폼별 다운로드 파일은 `SHA256SUMS.txt`로 확인할 수 있습니다.

이 버전은 프리릴리즈입니다.
