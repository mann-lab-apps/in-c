# 띠로리 Studio alpha.45

이번 데스크톱 프리릴리즈는 배포 검증을 보강한 업데이트입니다. 악보 편집 기능과 프로젝트 형식은 alpha.44와 같습니다.

## 배포 검증

- macOS 배포 검사에서 MusicXML 저장과 사본 내보내기의 진행 단계를 기록합니다. 검사 시간이 초과되면 어느 단계까지 완료됐는지 확인할 수 있습니다.
- 공유 디자인 시스템의 아이콘, 색상 토큰과 API 명세를 확인하는 자동 검사를 정비했습니다.

## 설치

- macOS는 Apple Silicon과 Intel을 지원하는 Universal DMG·ZIP을 제공합니다.
- Windows는 x64 설치 파일과 포터블 EXE를 제공합니다.
- Linux는 x86_64 AppImage를 제공합니다. 배포 파일의 체크섬은 `SHA256SUMS.txt`에서 확인할 수 있습니다.
