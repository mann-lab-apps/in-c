# 띠로리 Studio alpha.38

편집 작업 공간, 재생, 조판과 파일 교환을 함께 개선한 시험 배포입니다. 설치 파일과 앱 ID는 기존 in-C 배포 체계를 유지합니다.

- MuseScore식 전역 메뉴, 상시 음표 입력·재생 도구, 팔레트와 선택 속성 도크를 디자인 시스템으로 정리했습니다.
- 선택 위치부터 재생, 피아노 음원 캐시·믹서 표시와 재생 커서 노출을 보완했습니다.
- 스크롤바 손잡이·트랙을 누르면 즉시 따라가기가 중단됩니다. 움직이지 않은 클릭도 포함하며, 일반 내용 클릭과 명시적인 따라가기 복귀는 유지합니다.
- 툴팁 잔류와 큰 글자·짧은 창에서 셈여림/코드의 키보드 포커스가 가려지는 문제를 수정했습니다.
- 슬러·타이·헤어핀·옥타브 및 가사 조판, 실제 잉크 기반 페이지 배치와 잘리는 출력의 오류 안내를 보완했습니다.
- MusicXML 반복 펼치기 사본, 내보내기 손실 안내와 프로젝트 저장·재열기의 상태 보존을 개선했습니다.
- 배포 전 점검에서 확인한 Zod 메모리 고갈 취약점은 4.6.7 패치로 수정했습니다. [보안 권고](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5)
- Electron은 같은 42 계열의 42.11.18로 업데이트해 공개 보안 패치를 반영했습니다. [보안 권고](https://github.com/advisories/GHSA-jr5w-w6x2-84p9)

## 알려진 제한

- 1400px에서 일부 중첩 터치 스크롤이 문서를 움직이지 않는 사례는 원인 조사 중입니다. 이번 스크롤바 수정과 별개의 문제입니다.
- 외부 MuseScore의 중간 이조·중첩 반복/볼타 차이와 비정상 종료 사례, 물리 IME·스크린리더·청음·실기기 검증은 완료되지 않았습니다.
- 이 배포는 Commercial V1/RC 전체 완료가 아닙니다. Windows는 코드 서명이 없어 SmartScreen 안내가 표시될 수 있습니다.

macOS 서명·공증과 각 플랫폼 패키지·체크섬은 해당 태그의 Release workflow 결과로 확인합니다. 테스트 자동화·임시 파일/프로필 기반 검증은 실제 OS 파일 대화상자·물리 장치 검사와 구분합니다.

검증된 피아노 음원과 라이선스를 새 checkout에도 포함하고, 패키지 실행 검사의 창 표시·프레임 진단을 보완했습니다. alpha.35·alpha.36·alpha.37 후보는 게시되지 않았습니다.
