# Clef 외부 테스터 체크리스트

작성일: 2026-08-23

## 빌드 정보 확인

앱 첫 화면 오른쪽 위 `테스트 정보`에서 다음을 확인한다.

- 앱 이름: Clef
- 버전/build: `1.0.0+1`
- 설치 방식: TestFlight, debug APK, release APK 중 하나

피드백에는 기기명, OS 버전, PDF 종류, 재현 단계를 같이 적는다.

## 첫 실행/가져오기

1. 빈 라이브러리에서 `악보 추가` 버튼이 보이는지 확인한다.
2. PDF 한 개를 가져와 라이브러리에 등록한다.
3. JPG/PNG 이미지를 PDF 악보로 묶어 등록한다.
4. 지원하지 않는 파일이나 손상 PDF를 시도했을 때 crash 없이 안내되는지 확인한다.

## PDF 뷰어

1. PDF가 blank 없이 열리는지 확인한다.
2. 이전/다음 페이지, 1페이지, 2페이지, 세로 스크롤, 반 페이지 넘김을 확인한다.
3. PDF 파일이 사라진 상태를 만들 수 있으면, viewer가 구체적인 오류 안내를 표시하는지 확인한다.
4. 색상 반전과 어두운 배경 표시 효과를 켜고 다시 열어 복원되는지 확인한다.

## 주석/공유

1. 펜/형광펜 stroke를 남기고 앱을 다시 열어 복원되는지 확인한다.
2. 텍스트 주석을 추가한다.
3. 기존 텍스트 주석을 다시 탭해 수정/삭제한다.
4. 필기 포함 PDF 공유를 실행한다.
5. 한글 텍스트 주석만 있는 경우, 한글 text export 제한 안내와 원본 공유 fallback을 확인한다.
6. stroke 또는 영문 텍스트가 포함된 경우 공유 PDF 사본이 생성되는지 확인한다.

## 연주 보조

1. 메트로놈을 열고 BPM/박자를 바꾼다.
2. `tick 소리`를 켜고 시작/정지한다.
3. 튜너를 열고 Concert/Bb Trumpet 표시 모드를 바꾼다.
4. 튜너 감지 profile을 Chromatic/Bb Trumpet으로 바꾼다.
5. 조용한 방에서 `소리가 작거나 안정적이지 않습니다` 상태가 안정적으로 보이는지 확인한다.
6. 440Hz reference tone에서 Concert A4 근처로 잡히는지 확인한다.
7. Bb Trumpet profile에서 실제 트럼펫 연주음의 written/concert 표시가 이해되는지 확인한다.
8. 마이크 권한 거부, 입력 없음, 재시작 상태가 crash 없이 안내되는지 확인한다.
9. start/stop을 반복하고 bottom sheet를 닫았을 때 microphone indicator가 꺼지는지 확인한다.
10. 자동 스크롤을 시작하고 수동 페이지 이동 시 정지되는지 확인한다.

## 세트리스트/백업

1. 세트리스트를 만들고 악보를 추가/정렬한다.
2. 세트리스트에서 첫 곡을 열고 이전/다음 곡 버튼을 확인한다.
3. metadata 백업과 PDF 포함 전체 백업을 생성한다.
4. 잘못된 JSON/ZIP을 복원하려 할 때 crash 없이 안내되는지 확인한다.

## 기록할 항목

- 기기명과 OS 버전.
- 앱 버전/build.
- PDF 페이지 수와 파일 출처.
- 어떤 버튼/메뉴를 눌렀는지.
- 기대한 결과와 실제 결과.
- 표시된 오류 문구.
