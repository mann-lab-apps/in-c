# 도요 기준 팔레트

2026-10-22 · 사용자 선택: A 코코아·블루그레이 · 브랜드 탐색 기준 · 제품 미적용

![선택한 코코아·블루그레이 팔레트](palettes/a-cocoa-bluegray.png)

앞으로 편 머리와 부리, 들어 올린 배선, 둥근 등선의 v4 실루엣을 유지한다. 새는 한 색으로 그린다. 코코아의 부드러운 인상과 블루그레이의 차분함을 결합해 친근한 음악 서비스와 전문 도구를 함께 묶는다. 색을 음악 용어나 깃털에 억지로 대응시키지 않는다.

## 기준 색과 역할

| 역할 | 색 | HEX |
| --- | --- | --- |
| 새 · 워드마크 · 본문 | 코코아 | `#3E332F` |
| 대표 아이콘 배경 | 블루그레이 | `#A8BECC` |
| 기본 화면 | 종이색 | `#F7F4EF` |
| 보조 배경 | 모래색 | `#DCC5B0` |
| 카드 · 구획 | 밝은 중간색 | `#E8E0D5` |
| 버튼 · 링크 | 짙은 청색 | `#486879` |

대표 앱 아이콘의 우선 조합은 블루그레이 바탕에 코코아 새다. 모래색은 배너·카드에서 쓰는 보조색이며 모든 화면에 함께 넣는 필수 색은 아니다. 대표색과 보조색을 같은 비중으로 사용하지 않는다. 한 화면은 종이색·코코아를 중심으로 두고, 작은 면적의 짙은 청색으로 행동을 표시한다.

## 서비스 적용 원칙

- **도요 Note / Studio:** 탐색·도구막대에는 기준 팔레트를 쓴다. 악보 지면은 `#FFFFFF`, 기보는 `#202020`을 기본으로 제안한다. 브랜드 배경색을 악보 전체에 강제하지 않는다.
- **감상·공연·커뮤니티:** 앨범아트·공연 사진·사용자 콘텐츠 주변에 중립색을 넓게 두고, 블루그레이를 카드·선택 영역에 사용한다.
- **제품군:** 한 색의 새와 공통 타이포그래피를 유지한다. 현재 세 색상 타일은 배경 비교이며 각 앱에 색을 배정한 결과가 아니다. 앱과 상태 구분에는 이름·형태·윤곽도 함께 쓴다.
- **작은 아이콘:** 코코아 새와 블루그레이 바탕의 명도 차이를 확보한다. 부리·다리·눈의 최종 간격은 벡터 정리 후 실제 크기에서 별도 검수한다.

## 다크 모드 제안

| 역할 | HEX |
| --- | --- |
| 바탕 | `#24211F` |
| 본문·역상 로고용 밝은색 | `#F1ECE5` |
| 행동·링크 | `#B4CDDA` |
| 밝은 버튼 위 글자 | `#24211F` |

선택한 밝은 팔레트에서 파생한 검토용 조합이다. 밝은 실루엣 로고 원본은 아직 별도 제작하지 않았다. 다크 모드에서도 악보 지면을 어둡게 바꿀지는 브랜드 색 선택과 분리해 사용자 설정·기보 가독성으로 판단한다.

## 대비 확인

정확한 HEX의 sRGB 상대휘도로 계산했다. 아래는 지정한 전경·배경 쌍에 대한 결과이며 전체 화면의 접근성 통과를 의미하지 않는다.

| 조합 | 대비 |
| --- | --- |
| 기본 본문 / 종이색 (`#3E332F` / `#F7F4EF`) | 11.13:1 |
| 대표 아이콘 / 배경 (`#3E332F` / `#A8BECC`) | 6.34:1 |
| 밝은 버튼 글자 / 행동색 (`#FFFFFF` / `#486879`) | 5.95:1 |
| 행동색 글자 / 종이색 (`#486879` / `#F7F4EF`) | 5.42:1 |
| 다크 본문 / 배경 (`#F1ECE5` / `#24211F`) | 13.62:1 |
| 다크 버튼 글자 / 배경 (`#24211F` / `#B4CDDA`) | 9.67:1 |
| 다크 링크 / 배경 (`#B4CDDA` / `#24211F`) | 9.67:1 |

일반 텍스트는 4.5:1, 큰 텍스트는 3:1을 기준으로 검토한다. 로고에는 이 텍스트 기준의 예외가 있으나 제품 본문에는 그대로 적용한다. [W3C 대비 기준](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

밝은 블루그레이 위에는 코코아 글자를 사용한다. 흰 글자를 얹어야 하는 버튼은 짙은 청색을 사용한다. 선택·오류·재생 상태는 색 외에 윤곽·아이콘·문구를 함께 사용한다. 색각 차이에 대한 시뮬레이션이나 사용자 검증까지 수행한 것은 아니다. [W3C 색상 사용 기준](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)
