# 띠로리 그래픽과 모션

세 음표의 높낮이는 공간 구성으로, 64분·64분·점32분의 1:1:3 비율은 시간과 길이로 옮긴다. 음악 기보의 빔을 장식 막대와 혼동하지 않도록 심벌 원본과 그래픽 패턴을 분리한다.

## 공간과 시간

배너의 세 면은 높음–낮음–높음으로 놓고 폭을 1:1:3으로 잡는다. 간격과 낮아지는 폭은 화면 크기에 맞게 조정하되 콘텐츠의 읽는 순서는 바꾸지 않는다. 모든 카드나 버튼에 세 칸 구조를 강제하지 않는다.

로딩 한 주기는 1200ms다. 첫 머리 120ms, 둘째 120ms, 셋째 360ms를 강조하고 600ms 쉰다. 음표머리의 불투명도만 .55와 1 사이에서 바꾸고 기둥·연결선·점은 그대로 둔다. 배경 전체가 번쩍이거나 로고가 회전·늘어나는 동작은 사용하지 않는다. Flutter·React·SVG가 동일한 순서를 사용한다.

버튼 피드백과 패널 전환은 기존 토큰의 120ms·180ms를 따른다. 브랜드 리듬을 모든 인터랙션의 대기 시간으로 넣지 않는다. 온보딩은 사용자의 다음 행동으로 이동하며 자동 페이지 넘김을 추가하지 않는다. 카탈로그 배너는 정지형을 기본으로 사용한다.

## 상태 계약

| 상태 | 표현 | 접근성 |
| --- | --- | --- |
| 진행률 미상 | 음형의 머리 강조 + 작업 설명 | 백분율 없음, 작업 이름 제공 |
| 진행률 있음 | 실제 값의 진행 막대 + 작업 설명 | 범위와 현재 값 전달 |
| 완료 | 완료 문구, 필요한 경우 기쁜 바흐 | 실제 완료 후 상태 알림 |
| 실패 | 오류 의미 아이콘·원인·복구 행동 | 문자로 상태 설명, 진단 원문은 별도 펼침 |
| reduced motion | 정지 음형 또는 실제 진행 막대 | 반복 애니메이션 제거, 상태 정보 유지 |

진행 중인 작업이 실패했을 때 로더를 계속 돌리지 않는다. 백분율 100으로 완료를 연출하지 않는다. 악보를 읽거나 오디오를 재생하는 동안 작업과 무관한 배너·캐릭터의 반복 모션은 정지한다.

## 소리와 햅틱 확장

기본 브랜드 동작에는 자동 효과음을 넣지 않는다. 사용자가 켜는 소개·완료 경험을 나중에 설계할 때는 1:1:3 리듬과 세 음의 윤곽을 출발점으로 삼되, 기존 연주 음원이나 악보 스캔을 그대로 자산으로 가져오지 않는다. 연습·녹음·재생 중에는 브랜드 소리를 쉬게 하고 무음 설정을 존중한다. 햅틱은 선택 완료·오류 등 실제 플랫폼 의미와 맞춰 검토하며 기기 지원 여부를 확인한 뒤 적용한다.
