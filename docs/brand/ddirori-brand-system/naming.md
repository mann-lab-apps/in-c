# 띠로리 제품군 네이밍

2026-10-23 · 모브랜드 확정 / 하위 제품명 권고안 / 플레이·스코어 로컬 시범 적용

모브랜드는 띠로리, 영문은 Ddirori다. 하위 제품에는 짧은 역할 명사를 붙인다. 듣기·연주·창작을 한 사람이 오가는 제품군이므로, 이름만으로 다음 도구를 예상할 수 있어야 한다.

## 세 체계 비교

| 제품 역할 | A 역할 중심 | B 한국어 중심 | C 작업 중심 |
| --- | --- | --- | --- |
| 로컬 음원·디스커버리 | 띠로리 플레이 | 띠로리 음악 | 띠로리 라이브러리 |
| 악보 열람·연습 | 띠로리 스코어 | 띠로리 악보 | 띠로리 노트 |
| 사보·편집 | 띠로리 스튜디오 | 띠로리 창작 | 띠로리 에디터 |
| 커뮤니티 | 띠로리 톡 | 띠로리 모임 | 띠로리 커뮤니티 |
| 공연 발견·홍보 | 띠로리 스테이지 | 띠로리 무대 | 띠로리 라이브 |
| 메트로놈 | 띠로리 클릭 | 띠로리 박자 | 띠로리 템포 |
| 기준음·드론 | 띠로리 차임 | 띠로리 기준음 | 띠로리 튠 |

**A를 권고한다.** 플레이는 이미 사용하는 이름을 이어가며, 스코어는 악보를, 스튜디오는 만드는 작업 공간을 구분한다. 톡은 대화, 스테이지는 공연을 가리킨다. 클릭·차임은 각각 박자와 지속음을 다루는 도구다. 두 기능을 합친 앱이 실제로 생길 경우 그 제품의 이름을 별도로 검토한다.

B는 즉시 이해하기 쉽지만 ‘음악’이 전체 브랜드와 겹치고 ‘창작’은 앱보다 활동의 이름에 가깝다. C는 노트가 메모 앱으로, 라이브가 실시간 방송으로 읽힐 수 있다. 라이브러리는 스코어의 악보함과도 겹친다.

A의 약점도 남는다. 스코어는 점수, 스튜디오는 녹음 도구, 차임은 알림으로 이해할 수 있다. 처음 만나는 화면·스토어에는 아래 한 줄 설명을 함께 쓴다. 스코어의 사전 지식 없이도 이름에서 악보 열람을 떠올리는지는 사용자 검증 대상이다.

실제 공개 스토어의 이름을 변경한 기록은 없다. 로컬 적용은 공개 출시·상표 검토의 완료를 뜻하지 않는다. 상위 서비스의 공유·협업 지향은 제품군의 방향이며, 플레이·스코어에 계정이나 클라우드 협업이 있다고 설명하지 않는다.

## 표기와 이행

- 공식 표기는 `띠로리 스코어`, `Ddirori Score`처럼 한 칸 띄운다. Ddirori와 제품 명사는 첫 글자를 대문자로 쓴다.
- 좁은 영역에서도 모브랜드와 제품명을 서로 다른 줄로 나눌 수 있지만 글자를 임의로 줄이지 않는다. 제품명 자체를 중간에서 분리하지 않는다.
- 앱 내부에서 맥락이 분명하면 ‘악보함’, ‘라이브러리’, ‘재생’ 등 실제 기능명을 쓴다. 모든 메뉴에 띠로리를 반복하지 않는다.
- ‘띠플’, ‘띠스’ 같은 줄임말은 사용자의 별칭으로 허용하되 공식 내비게이션·접근성 이름·스토어에는 사용하지 않는다.
- 한국어 출시 화면은 한국어 제품명, 영문 소개는 영문 제품명을 쓴다. 영문 UI 전체 번역을 이번 이름 변경으로 간주하지 않는다.
- 기존 이름은 정보·지원 화면의 첫 소개에 병기한다. 화면의 주요 제목에 두 이름을 항상 병렬로 넣지 않는다.
- 번들 ID, 패키지명, 저장 키, 백업 포맷과 기존 지원 URL은 유지한다. 링크가 실제 이전된 뒤에만 새 URL을 쓴다.
- 나머지 앱의 표시명 변경은 해당 앱의 빌드·메타데이터·지원 화면을 함께 검증하는 후속 이행으로 진행한다.
