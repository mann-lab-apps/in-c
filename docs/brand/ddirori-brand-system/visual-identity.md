> 현재 기준: [중립 바탕·여섯 강조색·콘텐츠 12색](../ddirori-design-system/color-system.md). 이전 라임·올리브 배경 시안은 승인된 방향이 아니다. 라임은 임시 강조색으로만 유지하며 대표색은 검토 중이다.

2026-10-23 · 승인된 음형·얼굴형과 현재 시범색을 바탕으로 만든 제작 원본과 제품군 적용안

대표색과 팔레트는 사용자 요청으로 재검토 중이다. 아래 파랑 규칙은 현재 제작 자산의 기준이며 후속 디자인의 색을 제한하지 않는다. [레퍼런스 선정과 비교 기준](reference-direction.md)을 함께 읽는다.

## 심벌과 캐릭터의 역할

음형은 띠로리의 서명이다. 세 음표의 높음–낮음–높음, 64분·64분·점32분을 보존한다. 바흐는 발견과 반응의 표정이다. 주요 조작이나 오류의 원인을 캐릭터 표정만으로 설명하지 않는다.

| 접점 | 기본 자산 | 사용 규칙 |
| --- | --- | --- |
| 모브랜드·웹사이트 | 음형 + 한글 또는 영문 워드마크 | 첫 소개는 조합형, 좁은 반복 영역은 음형 단독 |
| 앱 런처 | 앱별 큰 기능 실루엣 | 기존 제작본의 공통 바탕·여백·단순한 면; 새 후보는 별도 검토 |
| 앱 첫 화면 | 제품 심벌 + 텍스트 제품명 | 실제 글자 크기 설정을 반영하고 줄바꿈 허용 |
| 온보딩·소개 배너 | 음형 서명 + 바흐 또는 리듬 그래픽 | 한 장의 주요 그래픽은 하나를 중심으로 구성 |
| 로딩 | 전체 음형 + 상태 설명 | 기둥·연결선·점은 고정, 음표머리의 명도만 순서대로 변화 |
| 처음 비어 있는 화면 | 차분하거나 놀란 바흐 + 다음 행동 | 앱당 한 화면에 캐릭터 한 번을 기본으로 사용 |
| 검색 결과 없음 | 검색 맥락 아이콘 + 조건 변경 안내 | 캐릭터 반복으로 검색 실패를 과장하지 않음 |
| 완료 | 짧은 문구, 필요한 경우 기쁜 바흐 | 작업 성공을 명시적으로 알림 |
| 오류·삭제 | 의미 아이콘 + 원인·결과·복구 문구 | 놀란 얼굴·웃는 얼굴로 심각도를 표현하지 않음 |
| 악보·사보·재생 작업 영역 | 도구 아이콘·지면·실제 정보 | 장식 캐릭터와 주기적 브랜드 모션을 쉬게 함 |

## 앱 아이콘 체계

| 앱 | 대표 형태 | 색 없이 구분되는 근거 |
| --- | --- | --- |
| 플레이 | 오른쪽으로 향한 큰 재생 삼각형 | 넓고 닫힌 비대칭 면 |
| 스코어 | 펼친 두 페이지 | 중앙 세로 틈과 좌우 대칭 |
| 스튜디오 | 대각선 편집 도구 | 사선으로 긴 실루엣 |
| 톡 | 말풍선 | 아래쪽 돌출과 세 개의 리듬 구멍 |
| 스테이지 | 무대 입구와 낮은 단 | 큰 아치와 분리된 받침 |
| 클릭 | 추를 가진 메트로놈 | 위가 좁은 삼각 외곽과 내부 빈 공간 |
| 차임 | 긴 줄기의 소리굽쇠 | 열린 U자와 아래로 긴 기둥 |

최초 제작 설명은 파랑 #0077C8 바탕·흰색 전경이었다. 현재 자산은 생성 원본의 임시 팔레트를 따르며 대표색은 미확정이다. 전경은 대략 256 단위 캔버스의 40~225 범위 안에 두고 시각적 무게를 비교한다. 기능 실루엣을 음형으로 위장하지 않는다. 음형 고증 규칙은 음형 심벌에 적용한다.

놀란 바흐 런처도 비교 자산으로 제공한다. 친근한 인상은 강하지만 일곱 앱을 표정만으로 구별하기 어렵고 악보·연주보다 캐릭터 콘텐츠로 읽힐 수 있다. 이번 제품군에는 기능 실루엣을 배정하고 바흐 런처는 미배정 대안으로 남긴다. 이는 내부 디자인 판단이며 사용자 식별 시험 결과는 아니다.

## 워드마크와 여백

- 한글·영문은 동봉된 Pretendard Variable의 750 굵기 글리프를 윤곽선으로 변환했다. 타이포그래피를 정돈한 제작 원본이며 독자 서체를 개발한 것으로 표현하지 않는다.
- 워드마크는 화면 높이 24px, 가로 조합형은 높이 32px를 권장 최소로 한다. 인쇄 최소값은 교정쇄를 확인한 후 정한다.
- 여백 단위 x는 워드마크 높이의 1/4이다. 조합 바깥에 최소 x, 다른 로고와 함께 놓을 때 2x를 둔다. SVG의 캔버스 여유와 외부 보호 여백은 별개다.
- 음형 기본형은 48px 이상, 소형 보정형은 24·32px에 쓴다. 24px 아래에서는 최소 크기를 억지로 줄이지 말고 주변 레이아웃을 조정한다.
- 밝은 바탕에는 잉크/파랑, 파랑이나 짙은 바탕에는 흰색 원본을 쓴다. 다크 UI 안의 음형은 기존 action 토큰을 쓸 수 있다. 현재 런처 자산은 보존하며, 새 배경색 적용은 후보 승인 후 별도 이행한다.
- 장평·기울임·임의 선 굵기 변경, 연결선·점 삭제, 음표머리 분리, 자동 그림자와 그라디언트 추가를 금한다.
- 플랫폼에 제출하는 아이콘 PNG에는 둥근 모서리를 미리 넣지 않는다. Android 적응형은 별도의 전경·배경을 사용한다.

## 바흐 벡터

승인된 이미지의 흰 구름 모양 가발, 살구색 얼굴, 두 눈과 작은 입을 면으로 옮겼다. 얼굴 음영·종이 질감은 제거하고 정확한 팔레트로 평면화했다. 가발과 얼굴의 외곽은 세 표정에서 동일하며 입만 바뀐다. 원본과 새 벡터는 검토 화면에서 나란히 비교할 수 있다.

기본 크기는 64px 이상이다. 얼굴을 주요 앱 아이콘으로 검토할 때는 큰 가발 실루엣을 유지한다. 캐릭터를 작게 줄여 정보 아이콘을 대신하지 않는다. 단색 원본은 스티커·인쇄 검토용이고 앱 상태의 유일한 표시는 아니다.

## 자산과 제작 경로

- `assets/wordmark-*`: 한글·영문, 잉크·파랑·흰색 윤곽선 워드마크
- `assets/lockup-*`: 가로·세로 조합형
- `assets/motif*.svg`: 승인된 round-4와 동일한 음형 구조
- `assets/bach-*.svg`: 세 표정과 단색형
- `assets/icon-*.svg`: 전체 제품 아이콘과 모브랜드·바흐 비교형
- `assets/platform/`: 플레이·스코어 iOS 1024와 Google Play 512 PNG
- `assets/banner-template.svg`: 소개 배너 편집 원본
- `assets/store-template.svg`: 실제 캡처 교체 위치를 표시한 스토어 편집 원본
- `assets/manifest.json`: 생성한 자산의 파일 크기와 SHA-256

배너와 스토어 템플릿의 본문은 편집 가능한 글자다. Pretendard가 없는 편집 환경에서는 서체를 설치하거나 내보낼 때 윤곽선으로 바꾼다. 스토어 템플릿은 빈 캡처 자리가 있는 제작 틀이며 제출 이미지가 아니다.

폰트 출처는 기존 [공식 v1.3.9 배포](https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard/dist/web/variable/woff2)와 동봉 `assets/FONT-LICENSE.txt`다. 승인 바흐의 참고 원본은 기존 image_gen 산출물이고 새 SVG와 네이티브 도형은 이 저장소에서 제작했다. 외부 캐릭터·초상화를 가져오지 않았다. 원작 악보 스캔은 로고에 포함하지 않는다.
