DDIRORI · APP ICON REVIEW 08

하나의 음형, 네 개의 자리.

모브랜드는 음형 자체를 크게, 앱은 기능의 외곽 안에 음형을 담습니다. 후보 07의 1안을 기준으로 외곽과 여백을 다듬었습니다.

이전 후보와 직접 비교

현재 08과 이전 07의 음가 유지안을 비교합니다. 모브랜드는 이번에 추가한 후보입니다. 웹 마스크는 실제 OS 효과의 근사입니다.

Studio · 연필 형태 비교

기존의 작은 삼각형 구멍을 큰 목재 여백과 검은 끝으로 바꿨습니다. 새 형태도 실제 사용자에게 쓰기 도구로 읽히는지는 별도 확인이 필요합니다.

실제 크기와 음형 위계

각 줄은 Ddirori / Play / Studio / Score 순서입니다. 모브랜드 음형은 앱 내부보다 크게 보입니다. 16–32px에서 앱 내부의 네 겹 빔·점을 읽기는 여전히 어렵습니다. 음가나 점을 생략한 소형 대체형은 만들지 않았습니다.

아이콘잉크 경계 (256px)잉크 면적음형 경계

면적·경계는 시각 보정을 위한 참고값입니다. 모브랜드의 선 중심 음형과 앱의 큰 면을 같은 면적으로 맞추지 않습니다.

보존한 브랜드 자산

64·64·점32의 빔 연결·기둥·점은 그대로입니다. 음형 원본을 앱별로 변형하지 않고 같은 마스터의 크기와 위치만 조정했습니다. 바흐는 별도 캐릭터 자산으로 유지합니다.

블루(#A5D8FF)는 기존 비교 팔레트입니다. 제품 UI 토큰·기존 런처·메타데이터는 변경하지 않았습니다. Ddirori는 브랜드 진입점용 후보이며 새로운 앱을 만들었다는 뜻이 아닙니다.
