DDIRORI · APP ICON REVIEW 05

세 가지 기능, 하나의 조형 규칙.

큰 단색 면에 기능을 파내고, 넓은 틈과 둥근 끝을 공유합니다. 원형 재생 · 사선 연필 · 펼친 악보는 서로 다른 윤곽으로 남겼습니다.

Play

음반의 홈을 넓히고 재생 삼각형을 중심에.

Studio

한 개의 연필 안에 음악을. 내부 음표는 수직으로.

Score

넓은 두 페이지, 줄 두 개, 크게 파낸 음표.

A · 연필 안의 음악을 추천합니다. 공통 블루를 우선 비교하며 대표색은 미정입니다.

판단·제작·검증 기록 · 조형 규칙 · 레퍼런스

A/B는 같은 Play·Score 옆에서 Studio 두 결합 방식을 비교합니다. Android 모드의 A/B는 108dp 전경을 72dp 뷰포트로 봅니다. 이전 후보는 원형 마스크 근사입니다. OS 효과·실제 설치 화면은 아닙니다.

Studio의 두 가지 결합 방식

A · 연필 안의 음악

연필의 외곽이 먼저 쓰기를 말하고, 내부의 큰 음표가 음악을 설명합니다. Play·Score처럼 큰 면 안의 여백으로 기능을 표현합니다.

연필이 굵어 마커·태그처럼 보일 가능성은 실제 사용자 확인이 필요합니다. 전용 사보 앱이라는 의미까지 아이콘만으로 보장하지 않습니다.

B · 연필이 된 음표

음표의 기둥을 뾰족하게 만들어 쓰기를 암시합니다. 한 몸으로 연결되지만 음악 재생 앱이나 위쪽 화살표로 읽힐 여지가 있습니다.

큰 페이지·음반과 비교하면 면이 적고 아래쪽에 무게가 몰립니다. 이번 추천에서 제외한 탐색안입니다.

공통 규칙을 실제 형태에서 확인하기

점선: 256 좌표계의 40–216 작업 범위. 십자선: 캔버스 중심. 세 심벌을 같은 상자로 억지로 늘리지 않습니다.

심벌실제 경계잉크 면적잉크 중심

측정은 256px, 알파 128 이상 픽셀 기준입니다. 시각 보정을 돕는 수치이며 동일한 면적·무게를 강제하거나 사용성을 증명하는 기준은 아닙니다.

기본형과 소형

16·24px에서는 음반 홈과 연필 끝의 작은 여백을 생략하고, 내부 음표를 키웁니다. 악보 줄은 하나로 줄입니다. 앱별 외곽과 주요 기능 단서는 유지합니다.

16px는 축소 점검용입니다. 작은 목록에는 이름을 병기하고, 음표·연필의 의미가 즉시 읽히는지는 사용자 테스트로 확인합니다.

공통색과 앱별 색 비교

공통 블루를 우선 추천합니다. 세 외곽이 이미 달라 색까지 늘릴 필요가 적고, 같은 제품군이라는 단서가 강해집니다. 앱별 색 배정은 비교안으로 남겼습니다.

음형·바흐는 별도 브랜드 자산입니다. 이번 기능 아이콘에는 넣지 않았습니다. 제품의 UI 토큰과 설치 아이콘은 그대로입니다.
