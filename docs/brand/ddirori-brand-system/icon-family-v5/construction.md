# 앱 아이콘 공통 조형 규칙 · 후보 05

2026-10-24. 제작 전에 256 좌표계·큰 면·넓은 틈·둥근 끝을 기준으로 정했고, 원본과 축소 비교 후 다음처럼 구체화했다. 제품 UI의 일반 아이콘에 일괄 적용하는 규칙은 아니다.

## 공통으로 유지하는 것

| 항목 | 제작 기준 | 적용 |
| --- | --- | --- |
| 캔버스 | 256×256 | SVG·PNG·플랫폼 export의 공통 원본 |
| 작업 범위 | x/y 40–216을 기본 가이드로 사용 | 세 심벌은 이 안에 배치. 같은 사각형을 꽉 채우도록 늘리지 않음 |
| 표현 | 큰 단색 면 + 기능을 나타내는 내부 여백 | Play 재생, Studio 음악, Score 음악·문서 줄 |
| 주요 여백 | 원본 설계에서 약14–18 | Play 홈14, Studio 음표 기둥14, Score 기둥16·페이지 사이16. Score는 전체 .96 보정 후 각각15.36 |
| 둥근 끝 | 6·8·12 정도의 곡선 전이를 출발점으로 사용 | 재생 꼭짓점, 페이지 바깥 끝, 연필 상단 모서리. 모든 곡선을 같은 원호 반지름으로 강제하지 않음 |
| 정보량 | 기본형의 내부 기능/보조 여백은 적게 | Play 홈+재생, Studio 음표+연필 끝, Score 줄2개+음표 |
| 색 | 공통 배경·공통 잉크 우선 | 블루 #A5D8FF / 잉크 #202020. 색은 미확정 |
| 소형 | 16·24px 전용 보정 | 보조 여백 생략, 주요 여백 확대. 32px 이상 기본형 |

최소 틈 수치는 주요 식별 영역의 기준이다. 삼각형 끝이나 물체 외곽이 점으로 모이는 부분까지 같은 폭을 보장한다는 뜻은 아니다. SVG는 stroke가 아닌 채워진 path로 제작한다. “선 굵기 통일”은 stroke 속성을 같게 만드는 작업이 아니라, 검은 면과 빈 부분이 주는 무게를 조정하는 작업이다.

## 앱별로 다르게 유지하는 것

- Play: 원형과 가운데 재생 방향. 바깥 지름166을 유지하고, 기본형의 홈을7→14로 넓혔다. 홈이 원형을 가르므로 검은 면은 두 연결 영역이지만 하나의 음반으로 읽는 구성이다.
- Studio A: 폭92의 연필을35° 기울이고 아래로4 이동. 내부 음표는 회전시키지 않아 Score의 음표처럼 수직으로 읽힌다. 음표와 연필을 별개로 놓던 구성을 하나의 연결된 면으로 바꿨다. 연필 끝의 작은 삼각 여백은 보조 단서다.
- Studio B: 음표 몸체와 연필 기둥을 한 면으로 연결한 탐색안. 음악은 잘 보이나 쓰기 단서가 약하고 여백보다 검은 선에 의존한다. 이번 추천에서 제외했다.
- Score: 펼친 두 페이지 유지. 기본 줄3→2, 소형 줄2→1. 줄의 끝을 둥글게 하고 내부 음표 기둥12→16으로 넓혔다. 넓은 검은 면이 무겁게 보이지 않도록 전체를.96배로 보정했다. 두 페이지의 분리는 의도된 구조다.

## 시각적 중심과 무게

아래는 256px 래스터에서 알파128 이상 픽셀을 측정한 보조 지표다. 최종 값은 [자동 검사](evidence/verification.json)의 metrics에서 다시 확인할 수 있다.

| 추천 심벌 | 경계 x₀,y₀,x₁,y₁ | 캔버스 대비 잉크 면적 | 잉크 중심 |
| --- | --- | --- | --- |
| Play | 45,45,210,210 | 21.87% | 127.21,127.56 |
| Studio A | 68,44,207,209 | 18.09% | 129.47,125.31 |
| Score | 46,64,209,195 | 22.67% | 125.97,125.42 |

Studio의 면적을 다른 앱과 수치상 같게 키우지 않았다. 사선의 길이와 뾰족한 끝이 있어 실제 나란히 비교했을 때 지나치게 크게 보일 수 있기 때문이다. A는 중앙 근처에 무게가 모이고 B는 아래쪽에 몰리는 차이가 있었다. 이 관찰은 제작자 판단이며 사용자 인지 테스트 결과가 아니다.

## 소형 규칙과 권장 사용

| 크기 | 처리 |
| --- | --- |
| 16px | 축소 스트레스 테스트. 이름 병기. 세부 음악/쓰기 의미를 보장하지 않음 |
| 24px | Play 홈·Studio 끝 삼각 여백 생략. Studio 내부 음표 확대. Score 줄1개 |
| 32–64px | 기본형. 넓은 홈·연필 끝·악보 줄2개 유지 |
| 128px 이상 | 같은 기본형 사용. 추가 장식을 넣지 않음 |

앱 이름 없이 용도를 고르는 확인은 32·48·64px에서 우선 진행한다. 소형이 잘 보인다는 제작자 판단과 사용자의 실제 정답률은 별도로 기록한다.

## 원본과 수정 방법

[family.json](family.json)의 directions.a / directions.b → paths / smallPaths가 편집 원본이다. [구조 그림](generated/construction/studio.svg)의 점선은 공통 작업 범위, 십자선은 캔버스 중심이다. 그림은 진단용이며 실제 앱 아이콘에 가이드를 넣지 않는다.

JSON을 수정한 뒤 tools/build.mjs로 재생성한다. 생성 SVG만 수정하면 다음 빌드에서 사라지므로 원본과 함께 수정한다. 모브랜드 음형·바흐는 이번 작업에서 변형하지 않았다.
