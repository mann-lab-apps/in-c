1안 · 음가 유지

머리·기둥·점은 조금 굵게, 빔 사이 간격은 넓게. 네 겹 구조는 그대로입니다.

2안 · 브랜드 심벌

기둥과 빔을 모두 제거했습니다. 음가를 뜻하는 악보 표기가 아닙니다.

작게 놓고 비교하기

1안도 16–32px에서는 음가를 읽기 어렵습니다. 2안은 더 단순하지만 음악·띠로리라는 연상은 학습이 필요하며, 일반 점 무늬로 보일 수 있습니다.

크기별 1안 / 2안

각 크기의 위 줄은 1안, 아래 줄은 2안입니다. 외곽은 후보 06과 동일합니다. 연필 형태·Play 크기 조정은 이번 음형 비교에 섞지 않았습니다.
