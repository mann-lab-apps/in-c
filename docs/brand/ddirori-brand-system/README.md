띠로리는 음악을 듣고 연주하고 만드는 사람의 다음 시도를 돕는다. 현재 시범 적용은 중립 UI와 정확한 음형을 공통 서명으로, 바흐를 발견과 반응의 캐릭터로 사용한다. 제품별 앱 아이콘은 큰 기능 실루엣으로 구분한다. 후속 디자인은 [세 축의 레퍼런스](reference-direction.md)를 따르며, 대표색은 여섯 후보로 검토 중이다. 라임은 기존 임시 강조색으로 유지한다.

[브랜드 검토 화면](index.html)에서 전체 아이콘, 한글·영문 로고, 바흐 원본 비교, 로딩·완료·오류 상태와 실제 앱 위젯 캡처를 확인할 수 있다. 다크 모드·24px·원형 마스크·회색조·움직임 줄이기를 직접 비교할 수 있다. 로컬 서버에서는 `http://127.0.0.1:8064/docs/brand/ddirori-brand-system/`로 연다.

## 원본 재생성

Node·Python·Dart를 사용한다. 도구 의존성은 제품 package.json에 추가하지 않고 별도 위치에 설치한다. 아래 버전은 이번 작업에서 사용한 버전이다.

```sh
mkdir -p /tmp/ddirori-brand-tools
python3 -m venv /tmp/ddirori-brand-tools/venv
/tmp/ddirori-brand-tools/venv/bin/pip install fonttools==4.60.2 brotli==1.2.1 pillow==11.3.0 pyyaml==6.0.3
npm install --prefix /tmp/ddirori-brand-tools @resvg/resvg-js@2.6.2 playwright@1.64.1
node docs/brand/ddirori-design-system/tools/build.mjs
/tmp/ddirori-brand-tools/venv/bin/python docs/brand/ddirori-brand-system/tools/build.py
node docs/brand/ddirori-brand-system/tools/render.mjs
```

`DDIRORI_BRAND_TOOLS`로 도구 위치를 바꿀 수 있다. `build.py`는 기존 round-4 음형과 동봉 폰트에서 제작 원본·공통 네이티브 도형을 생성한다. 가족 심벌과 바흐의 좌표 원본은 `tools/build.py`다. `family.json`과 Dart 좌표는 생성 파일이다. 기본 렌더는 브랜드 자산만 갱신한다. 플레이·스코어의 플랫폼 아이콘을 다시 적용하려면 `render.mjs --apply`를 사용한다.

```sh
python3 -m http.server 8064 --bind 127.0.0.1
# 별도 터미널
node docs/brand/ddirori-brand-system/tools/verify-browser.mjs
```

브라우저가 설치되지 않은 경우 해당 도구 위치에서 Playwright Chromium을 설치한다. 이미 설치한 브라우저는 `DDIRORI_BROWSER_PATH`로 지정할 수 있다. 기본 검증 URL은 위 로컬 주소이며 `DDIRORI_BRAND_URL`로 바꿀 수 있다.

앱 위젯 캡처 재생성은 각 앱 폴더에서 `test/brand_pilot_test.dart`를 실행한다. `DDIRORI_BRAND_CAPTURE=true`, `DDIRORI_BRAND_FONT=<build.py가 만든 Pretendard.ttf>`, `DDIRORI_MATERIAL_FONT=<Flutter SDK의 MaterialIcons-Regular.otf>`를 전달하면 evidence에 기록한다. 캡처는 검토용 Pretendard Variable로 렌더링하고 실제 앱 기본 글꼴은 플랫폼 기본값을 유지한다. 캡처 옵션 없이도 테스트는 실행된다.
