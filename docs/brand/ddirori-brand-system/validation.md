## 실제 렌더링과 관찰

브라우저 검토 화면을 데스크톱·390px에서 렌더링하고 밝은/어두운 화면, 회색조 24px 원형 아이콘을 확인했다. 음형은 24·32·48·64px로 비교한다. 워드마크는 한영 가로·세로·반전형을 제공한다. 배너와 바흐 벡터를 승인 이미지와 비교해 얼굴의 음영을 제거하고 단순한 가발·얼굴·눈·입을 유지했다.

제품 캡처는 실제 Flutter 위젯을 테스트 엔진으로 렌더링했다. 스코어 7장과 플레이 4장을 남기며, 좁은 화면·1024px·다크·긴 제목·큰 글씨와 정상·빈 화면·로딩·오류를 포함한다. 파일 경로는 테스트용 값이고 PDF·오디오 엔진의 실제 출력은 이 캡처로 검증하지 않는다. 글자가 네모로 나오는 테스트 기본 폰트를 대체하기 위해 동봉 Pretendard Variable과 SDK Material Icons를 명시적으로 로드했다. 실제 앱 기본 글꼴은 플랫폼 기본값이다.

저장소의 기존 테스트를 보존하고, 큰 글씨 제품명 기대값만 새 줄바꿈·단일 접근성 이름 계약에 맞췄다. GitHub 이슈 생성·PR·원격 CI는 이번 작업 범위에 포함하지 않았다.

## 검증의 한계와 재현 절차

CSS 원형·둥근 사각 마스크는 형태 검토다. 실제 설치된 iOS/Android 런처 마스크·적응형 움직임·테마 아이콘은 해당 후보 앱을 설치해 확인해야 한다. 플랫폼 PNG 규격과 Android 전경 XML 검사는 실행했다. iOS PNG는 불투명 RGB로 내보내 알파 채널을 제거했다.

회색조에서 기능별 외곽과 빈 공간, 텍스트가 남는지 비교했다. 색각 특성이 다른 실제 사용자의 식별률을 측정한 것은 아니다. 접근성 대비 30쌍은 지정한 토큰 조합의 계산이며 전체 화면의 접근성 인증은 아니다.

물리 기기·VoiceOver·실제 음원 출력·페달·마이크 검증은 수행하지 않았다. 해당 장치·사용자를 포함한 검수 세션을 진행하지 않았으므로 앱별 manual 항목은 pending을 유지한다. 실제 후보를 설치한 후 큰 글씨·다크·VoiceOver에서 제품명·검색 지우기·가져오기·실패 재시도·포커스 순서를 확인하고, 엔진 기능은 각 앱의 기존 기기 검증 절차를 따른다.

스토어 촬영 파이프라인은 pending 소스에서 실행하지 않았다. 실제 제품 checkpoint를 정하고 빌드 버전과 manifest를 대조한 뒤 기존 `deployment/SCREENSHOTS.md` 순서로 촬영·시각 검수를 다시 진행한다. 스코어 YAML에 남긴 이전 1.0.3+30 후보 정보는 현재 pubspec의 1.0.0+14와 다르므로 그대로 출시 입력으로 사용하지 않는다. 이번 작업에서 번호를 임의로 맞추거나 source.commit을 추측하지 않았다.

## 사용자 확인 질문

처음 접하는 사람에게 설명 없이 이름과 아이콘을 보여주고 다음을 확인한다. 응답을 만들거나 내부 판단을 사용자 조사 결과로 기록하지 않는다.

1. 띠로리를 한 번 듣고 다시 말하고 입력할 수 있는가? Ddirori를 보고 같은 브랜드로 연결하는가?
2. 플레이·스코어·스튜디오에서 각각 듣기·악보 열람·악보 편집을 예상하는가?
3. 스튜디오를 녹음 앱으로, 스코어를 점수 앱으로 오해하는가? 한 줄 설명 후에는 해소되는가?
4. 아이콘을 작게 나란히 놓았을 때 같은 제품군으로 보이고 각 앱을 다시 찾을 수 있는가?
5. 바흐가 친근함을 주는가? 전문 도구를 장난스럽거나 클래식 교육 전용으로 오해하게 하는가?
6. 정상 화면과 실패 안내의 말투가 각각 편안하고 신뢰할 만한가?

## 공개 전 남은 확인

- 권고 제품명·아이콘 체계를 실제 사용자 피드백과 함께 최종 결정한다.
- 필요한 상표·도메인·스토어·소셜 이름 확인을 별도로 수행한다. 기존 충돌 후보를 이번 작업에서 새로 조사하거나 ‘사용 가능’으로 판정하지 않았다.
- 실제 스토어 이름 변경과 기존 이름의 검색·지원 연결을 확인한다. 현재 지원 URL을 임의의 새 주소로 바꾸지 않는다.
- 스코어의 checkpoint·버전·빌드·촬영 동선을 대조하고 두 앱의 정확한 후보를 촬영한다.
- 공개 배너·스토어 템플릿의 캡처 자리와 문구를 검증한 실제 제품 화면으로 채운다.
- 사보·커뮤니티·공연·클릭·차임은 각 제품의 실제 동작·메타데이터와 함께 이행한다.
