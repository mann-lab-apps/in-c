식별 확인

마스크와 배경은 비교용 근사입니다. 실제 OS 효과·기기 런처 승인 캡처가 아닙니다. 기존은 현재 자산 그대로, A/B는 같은 팔레트로 비교합니다. Android 모드의 A는 실제 export의 108dp 레이어를 72dp 뷰포트로 확인합니다.

색보다 먼저, 세 가지 형태

플레이는 진행 방향이 보이는 재생 면, 스튜디오는 사선의 편집 도구, 스코어는 가운데가 열린 두 페이지입니다. 같은 둥근 마무리와 틈을 사용하되 형태를 반복하지 않습니다.

16·24px에서는 스코어의 안쪽 줄과 스튜디오의 작은 펜촉 구멍을 덜어냈습니다. 명시적으로 관리하는 소형 원본이며 자동 축소로 지워지는 디테일과 구분합니다.

색은 세 앱이 공유합니다

아이콘 배경은 기존 brand.primary, 내부 UI 주요 행동은 action 역할을 따릅니다. 흰 화면 전체에 이 색을 깔지 않습니다.

음형은 모브랜드 서명, 바흐는 발견과 반응, 앱 아이콘은 서비스 식별을 맡습니다.
