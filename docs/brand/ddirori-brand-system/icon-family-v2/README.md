# 세 앱 아이콘과 디자인 시스템 후속

2026-10-24 · **제작 후보, 제품 런처 미적용**. [인터랙티브 리뷰](index.html) · [감사·처리 범위](audit.md) · [레퍼런스](references.md) · [검증·인계](verification.md).

추천은 **A · 열린 면**, 색은 **바이올렛 우선 / 블루·틸 비교**다. 동일한 바탕·부드러운 모서리·굵은 면·열린 틈을 공유하면서 Play는 오른쪽, Studio는 사선, Score는 좌우로 펼쳐지는 방향으로 구분했다. 사용자 승인이나 실제 식별 시험 통과를 뜻하지 않는다. 제품 기본 라임, 기존 런처와 바흐·음형은 그대로다.

## 무엇을 만들었나

| 앱 | A 추천안 | B 대안 | 판단과 약점 |
| --- | --- | --- | --- |
| Play | 왼쪽에 한 번 열린 부드러운 재생 면 | 원형 흐름 안의 재생 면 | A는 큰 방향성이 남고 일반 삼각형에 고유한 틈을 준다. 화살표·진행으로 읽힐 가능성은 사용자 확인 필요. B는 반복 재생으로 좁혀 읽힐 수 있음 |
| Studio | 길고 굵은 대각 편집 도구, 열린 내부 | 세로의 펜촉과 중심 틈 | A는 작은 크기에서 편집 역할과 기울기가 분명함. 음악보다 일반 편집으로 먼저 읽히는 한계는 앱 이름과 실제 사용 맥락으로 보완. B는 만년필·문구 앱 연상이 강함 |
| Score | 두 면이 펼쳐지고 중앙이 열린 악보책 | 이어진 외곽선의 펼친 책 | A는 두 면이 작은 크기에도 남음. 독서 앱과의 연상은 남아 있으며 모든 음악성을 오선지·음표로 설명하려 하지 않음. B는 작은 선과 교차 부분이 상대적으로 약함 |

B도 세 서비스 전체를 같은 선 중심 체계로 제작했다. 실제 단색·회색조·16~128px 비교에서 A를 권고했다. 단색에서 서비스별 방향과 덩어리가 다르므로 색상에만 의존하지 않는다. 가족성은 동일한 도형 반복이나 코너 배지로 만들지 않았다.

## 조형 계약

정본은 [family.json](family.json). SVG는 생성된 편집·전달 원본이며 수정사항은 정본 path에 반영한 뒤 재생성한다. 기존 `../tools/build.py`의 path→SVG/evenOdd 방식을 활용하고, 기존 render의 Resvg 도구 환경을 재사용했다. 기존 생성기를 실행하면 제품 Dart 좌표/기존 자산도 변할 수 있어 후보 전용 생성기로 분리했다.

- 기준 캔버스 256×256. regular와 small geometry를 명시적으로 관리한다.
- A Play는 오른쪽 질량을 고려한 왼쪽 긴 면과 깊은 틈. Score는 보정 전 중앙18unit 간격을 기준으로 한다. Studio는 넓은 사선 면과 내부 절개.
- 16·24px에서는 Play 틈을 넓히고, Score 안쪽 줄·Studio 작은 펜촉 구멍을 생략한다. 32px 이상은 regular 사용.
- 심벌은 한 가지 전경색. 그림자·외곽선·글자·작은 공통 배지 없음. 모서리의 수학적 반경 하나를 서로 다른 실루엣에 강제하지 않는다.
- 첫 비교에서 Score의 면이 상대적으로 무거워 0.92배, Studio는 1.08배와 x=-5 보정을 적용했다. `family.json.opticalNotes`에 이유를 기록했으며 path에 이미 반영되어 있다. 중복 적용하지 않는다.
- 면적·중심은 [verification.json](evidence/verification.json)의 픽셀 측정으로 기록한다. 같은 면적을 맞추는 대신 실제 시각적 무게를 비교했다. 수치가 식별성을 대신하지 않는다.
- 단색 glyph는 서비스 식별 자산이다. 재생/편집/열기 버튼의 일반 기능 아이콘을 자동 교체하지 않는다. 클릭 가능한 UI에 쓸 때는 기능 이름·포커스·상태의 접근성 계약을 별도로 적용한다.
- 음형은 모브랜드 서명, 바흐는 보조 반응/빈 상태 자산. 64·64·점32분 음형이나 승인된 얼굴은 변경하지 않았다.

16px은 작은 목록의 스트레스 테스트다. 이 크기만으로 처음 보는 사용자가 정확한 서비스명을 맞힌다고 보장하지 않는다. 일반 제품 식별에는 텍스트 이름을 함께 사용한다.

## 색 역할

`family.json.paletteSource` → 기존 palette-candidates → 생성 SVG/PNG·review-data.js 경로다. 리뷰 화면의 색값을 별도로 손으로 관리하지 않는다.

| 후보 | 아이콘 바탕 | 전경 | 권고 |
| --- | --- | --- | --- |
| 바이올렛 | #D0BFFF | #202020 | 부드러운 큰 면과 바흐의 따뜻한 얼굴색이 함께 읽힘. 넓은 제품 UI 배경으로 확대하지 않음 |
| 블루 | #A5D8FF | #202020 | 명료하고 친숙함. 범용 도구처럼 보일 가능성은 고유 형태로 보완 |
| 틸 | #96F2D7 | #202020 | 가볍고 밝은 인상. 내부 UI success와 같은 의미로 사용하지 않음 |

이는 조형 평가와 의미 제안이며 보편적인 색 심리 효과 주장이 아니다. 원래 6색 후보는 보존했다. 런처 바탕은 brand.primary, UI 행동은 별도 action 역할을 쓴다. 다른 앱에 다른 색을 배정하지 않았으므로 회색조 비교에서도 형태로 구분해야 한다.

## 산출물과 사용

- `generated/masters/{a,b}/`: 세 앱 regular/small 단색 SVG.
- `generated/icons/{a,b}/{mono,violet,blue,teal}/`: 배경 포함 벡터.
- `generated/png/`: 16·24·32·48·64·128·256·1024px 비교 PNG.
- `generated/platform/{violet,blue,teal}/{play,score}/`: 현재 Contents.json을 읽어 만든 iOS AppIcon 세트, Google Play512, Android legacy density와 adaptive/monochrome XML·전경.
- `generated/platform/{palette}/studio/desktop/`: 현재 Electron 설정에 대응하는 ICNS·ICO·icon.png·Linux 크기별 PNG·iconset.
- `generated/platform/*/*/layers/`: 마스크 없는 배경·전경 SVG. Icon Composer로 가져갈 수 있는 재료이며 컴파일된 .icon 파일은 아님.
- `generated/manifest.json`: 원본/생성기/파일 SHA-256. 참고한 카카오 이미지는 포함하지 않음.

플랫폼별 범위:
- 기존 Play/Score는 AppIcon catalog와 Android resource를 소비한다. 새 폴더는 동일 경로 구조를 가진 후보이며 실제 앱 폴더에는 쓰지 않았다.
- Android는108dp 두 레이어·monochrome 경로를 제공한다. 0.30배/15.6이동으로 중심66dp 원형 안전 영역 안에 전경을 둔다. 이미지를 108→72로 보는 리뷰는 마스크 근사이며 실제 OEM 검수가 아니다.
- 현행 Studio package.json은 mac ICNS, win/Linux PNG 경로다. ICO도 전달용으로 제공한다. 앱 ID·표시명·패키징 경로는 변경하지 않았다.
- legacy ICNS는 투명 외부 여백과 그려진 프레임이 포함된 자체 완결 bitmap이다. Apple의 새 레이어 원본은 마스크 없이 별도 제공한다. 둘을 혼용하지 않는다.
- iOS PNG는 불투명 RGB, Google Play512는 불투명32-bit RGBA/sRGB, Android 전경·glyph·Apple foreground layer는 투명 배경, ICNS 외부 여백은 투명이다.

## 검토와 다음 단계

리뷰의 마스크·배경·Dock은 실제 파일을 사용한 비교 환경이다. 일반 유틸리티 도형은 맥락 비교용이며 타사 제품 화면을 재현한 것이 아니다. 사진이나 AI 생성 래스터를 벡터라고 표시하지 않았다. 이번 아이콘은 직접 작성한 벡터 path다.

사용자 확인은 ① A/B 조형 ② 색 선택 ③ 역할 식별 순서로 진행한다. 이름 없는 세 아이콘을 보고 음악 감상/사보 편집/악보 읽기를 연결하는 과제와 3초 노출 후 기억하는 과제를 분리한다. 실제 참여자·오답·지연·자유 연상을 기록한 뒤 특히 Play의 화살표, Studio의 일반 편집, Score의 독서 연상을 점검한다. 현재 참여자 데이터는 없다.

선택 이후에만 기존 생성기의 geometry/색 원본으로 승격하고 앱별 아이콘을 적용한다. 그 작업에서 iOS metadata·실제 런처 캡처·Android themed icon·macOS Dock·Windows 작업표시줄을 확인한다. 기존 자산 교체·원격 게시·스토어 제출은 수행하지 않았다.
