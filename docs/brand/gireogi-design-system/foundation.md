# 브랜드 원칙과 레퍼런스

기러기는 음악을 향한 서로 다른 시도가 다음 시도로 이어지는 제품군이다. 사용자가 음악을 좋아하는 방식과 속도를 스스로 정하고, 도구는 그 과정을 돕는다. 장애물이 생겼을 때의 우회는 방법의 유연함으로 표현하고, 전진은 명확한 다음 행동으로 표현한다.

브랜드를 대표하는 장면은 **함께 날아가는 기러기 떼**다. 서로의 시도에 응답하는 관계를 무리의 간격·방향·다른 날갯짓으로 표현한다. 단일 기러기는 작은 식별 표식, 부분에서 파생한 심벌은 제품 구분에 사용한다. 넓은 소개 장면은 [무리와 비행 규칙](flock-and-motion.md)을 따른다.

## 경험과 표현의 관계

| 원칙 | 화면에서의 결정 | 피할 것 |
| --- | --- | --- |
| 솔직함 | 로컬 저장·실패·지원 범위를 정확하게 표시 | 저장되지 않았는데 ‘완료’, 동기화되지 않았는데 구름 배지 |
| 모험과 지속 | 실행 취소·재시도·최근 위치·다음 행동 | 실수를 평가하거나 조급하게 만드는 점수와 연속 사용 압박 |
| 서로의 반응 | 대화·피드백에서는 내용과 맥락을 우선 | 모든 시도에 의무적인 칭찬과 축하 애니메이션 |
| 전문성과 친근함 | 정돈된 작업 도구 + 부드러운 브랜드 형태 | 둥근 음표, 캐릭터가 대신 설명하는 복잡한 작업 |
| 확장성 | 장르 중립적인 이름·형태, 악보 특수 규칙은 전용 계층 | 모든 앱에 오선 배경과 클래식 공연장 이미지 |

기러기의 모티브는 사용자가 언급한 『겅호!』의 격려와 응답이다. 기러기의 울음·비행을 특정 조직 원리의 과학적 근거로 삼지 않는다. 책을 읽지 않았거나 이름의 유래를 몰라도 제품을 이용할 수 있어야 한다.

## Figma에서 가져오는 구조

| 공식 자료 | 관찰한 원리 | 기러기에 적용 | 복제하지 않을 것 |
| --- | --- | --- | --- |
| [Friends of Figma 브랜드 개편, 2026-05-19](https://www.figma.com/blog/friends-of-figma-brand-refresh/) | 공통 브랜드 요소를 지역별 표현으로 재구성 | 같은 기러기에서 파생한 부분을 제품마다 다르게 구성 | Figma 로고 분해 방식의 고유한 배치, 지역 배지 디자인 |
| [제품 아이콘 제작, 2025-07-25](https://www.figma.com/blog/the-making-of-a-product-icon/) | 가족의 규칙과 제품 고유 의미를 함께 검토하고 크기별로 반복 | 두 계열·단색·작은 크기를 나란히 검토 | Figma 아이콘의 외곽선·기호·색상 조합 |

| [UI3 설계 과정, 2024-10-01](https://www.figma.com/blog/our-approach-to-designing-ui3/) | 캔버스 집중, 속성의 위계, 패널 설계를 반복 개선 | 악보 중심의 캔버스, 선택에 반응하는 속성, 패널 접기 | 모든 도구를 아래에 띄우는 배치, 협업·AI 기능 |
| [속성 패널 공식 안내](https://help.figma.com/hc/en-us/articles/360039832014-Design-prototype-and-explore-layer-properties-in-the-right-sidebar) | 작업 대상과 속성 편집의 관계 | Chromatics의 전체 악보/선택 속성 구분 | 최신 Figma 구조가 우리 앱에 그대로 적합하다는 가정 |

Figma의 유쾌한 브랜드 그래픽과 실제 도구의 조용한 배치를 서로 다른 표현 강도로 해석한다. 기러기도 캠페인에는 형태를 크게 쓰고, 편집기에는 작은 브랜드 표시와 상태 규칙만 남긴다.

## 표현 강도

전문 도구는 작은 브랜드 마크, 중립 표면, 8px 컨트롤 곡률을 사용한다. 소비자 서비스는 같은 마크와 글꼴을 쓰면서 카드·여백·보조색 면적을 늘린다. 차이는 친근함의 유무가 아니라 작업 밀도와 그래픽의 노출량이다.

사막·항해·은화는 탐색 과정의 소재로 남긴다. 이번 시스템에 별도 배경 세계관으로 섞지 않는다. 이름을 듣고 바로 사용할 수 있는 간결함을 우선한다.
