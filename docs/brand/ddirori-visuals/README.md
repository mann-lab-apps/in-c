## 심벌 수정

사용자 지시에 따라 **64분 / 64분 / 점32분**으로 수정했다. 화음을 생략한 세 음표머리는 높음–낮음–높음이다. 맨 위 짧은 연결선은 첫째·둘째 줄기만 잇고, 아래 세 연결선은 세 줄기 모두를 잇는다. 오른쪽 줄기도 맨 아래 연결선까지 내려간다. 마지막 음표머리 오른쪽에 점을 둔다. 음표머리를 왼쪽으로 옮겨 기둥 위 모서리가 머리 밖으로 노출되지 않게 맞췄다. 기본형과 소형을 따로 조정했다.

[기본 구조 SVG](round-4/motif.svg) · [소형 구조 SVG](round-4/motif-small.svg). 소형에서는 간격과 점 크기를 조정하지만 음가 요소를 생략하지 않는다. 이 폴더의 SVG는 음가 구조를 확정한 연구 원본이다. 제작용 조합형·워드마크·아이콘은 [브랜드 운영 체계](../ddirori-brand-system/README.md)에서 관리한다. 실제 기기에서 점 식별성·픽셀 밀도·플랫폼 마스크를 추가 확인해야 한다.

생성 보드에는 연결선이 줄기에서 떨어지거나 개수가 달라지는 편차가 있다. 색·캐릭터 인상은 PNG, 음가 구조는 SVG를 기준으로 검토한다. 첫 두 라운드의 음형은 현재 구조 기준이 아니다.

## 선정 팔레트

| 역할 | HEX | 사용 |
| --- | --- | --- |
| 파랑 | `#0077C8` | 대표 아이콘·주요 행동 |
| 하늘색 | `#A8D4E5` | 보조 면·브랜드 그래픽 |
| 살구색 | `#F3BB9B` | 바흐와 이어지는 작은 강조 |
| 짙은 잉크 | `#203849` | 본문·윤곽·파스텔 위 글자 |
| 밝은 바탕 | `#F7FBFE` | 기본 화면 |
| 흰색 | `#FFFFFF` | 카드·악보·파랑 위 심벌 |
| 연한 파랑 | `#E8F4FC` | 선택한 항목의 면 |
| 보조 글자 | `#536B7A` | 설명·메타정보 |

파랑은 브랜드를 알아보게 하는 색, 하늘색은 넓은 면을 부드럽게 만드는 색, 살구색은 바흐의 온기를 잇는 색이다. 특정 색에 음악이라는 뜻이 본래 들어 있다고 설명하지 않는다. 도구 화면은 밝은 중립색을 넓게 쓰고 파랑으로 주요 행동을 구분한다.

흰색/파랑 대비는 **4.70:1**, 잉크/기본 바탕 **11.71:1**, 잉크/하늘색 **7.67:1**, 잉크/살구색 **7.19:1**이다. 하늘색·살구색 위에는 흰 글자를 쓰지 않는다. 이 값은 선언한 색 쌍의 계산이며 전체 접근성 검수 결과가 아니다.

성공 `#19734D`, 주의 `#8A5700`, 오류 `#C13F50`는 글자·아이콘과 함께 쓴다. 살구색을 주의 상태로 겸용하지 않는다. 옅은 구분선 `#CCDCE6`는 장식용이며 식별에 필요한 입력 윤곽에는 `#718898`를 쓴다. 버튼 반응색과 다크 파생값은 [palette.json](palette.json)에 기록했다.

다크 검토안은 바탕 `#12232E`, 표면 `#1B3343`, 글자 `#EAF4FB`, 행동 `#72B8EE`다. 앱 아이콘 대표색은 그대로 유지한다. 공통 컴포넌트와 두 앱의 다크 모드 자동·시각 검증은 후속 디자인 시스템/브랜드 작업에 기록했다. 전체 제품·실기기 검증으로 확대 해석하지 않는다. 악보 지면은 흰색·검정이 기본이다.

[이전 대표색 비교](round3.html)의 청록·귤색은 탐색 기록이다.

## 바흐와 앱 아이콘

사용자는 흰 가발·둥근 얼굴·작은 눈과 입만 남긴 바흐 얼굴형을 승인했다. 놀란 O자 입 얼굴은 음형과 함께 앱 아이콘 후보로 비교한다. 몸통·옷 주름·목 장식을 추가하지 않는다. [승인된 얼굴형 참고](round-2/palette-sky.png).

두 아이콘을 같은 대표색·비슷한 여백으로 비교한다. 이 비교안은 탐색 기록이다. 현재 배정안은 모브랜드 음형·제품별 기능 실루엣·보조 바흐이며 [배치 규칙](../ddirori-brand-system/visual-identity.md)을 따른다. 음형은 소리의 특징, 얼굴은 띠로리라는 감탄의 표정을 담는 방향으로 검토한다. 단순한 가발 얼굴만으로 누구나 바흐를 알아본다고 가정하지 않는다.

초기 플레이·노트·스튜디오는 제품명 결합 예시였다. 현재 전체 권고안과 플레이·스코어 로컬 적용 상태는 [네이밍 표](../ddirori-brand-system/naming.md)를 따른다. 공개 스토어는 변경하지 않았다. 공통 컴포넌트·음형 로딩·실행 예제는 [띠로리 디자인 시스템](../ddirori-design-system/README.md)에 정리했으며, 제품 화면의 도입은 해당 계획을 따른다.

## 제작 기록

색·캐릭터 보드는 기본 제공 image_gen으로 편집했다. SVG는 연결선과 점을 정확히 제어하기 위한 별도의 벡터 구조 연구다. 생성 원본은 보존하고 프로젝트용 PNG를 이 폴더에 복사한다. 생성 이미지의 픽셀색·문자는 편차가 있어 정확한 HEX는 palette.json을 따른다. 코드·경로는 ddirori로 통일한다. palette.json의 previousRound는 당시 미정 상태를 보존한 탐색 기록이다.

비교 화면은 Pretendard Variable을 사용한다. [공식 v1.3.9](https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard/dist/web/variable/woff2) · [동봉 OFL](fonts/LICENSE.txt).
