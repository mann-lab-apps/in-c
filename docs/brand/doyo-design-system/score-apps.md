# 악보 열람과 사보 적용 명세

현재 기능은 각 앱 README와 소스 기준이다. 이 문서의 도요 Note / Studio는 역할을 보여 주는 이름이며 실제 앱 표시명·패키지·스토어 변경이 아니다.

## Clef & Staff: 읽던 위치로 돌아오기

대상은 [SheetLibraryScreen](../../../apps/in_c_sheet/lib/main.dart), SheetViewerScreen, _AnnotationToolbar와 연습 도구다. 현재 PDF/이미지 가져오기, 악보함·검색·세트리스트, 주석·공유·백업, 메트로놈·기준음·튜너 등의 범위는 [앱 README](../../../apps/in_c_sheet/README.md)를 따른다. 기기 기능의 검증 경계도 유지한다.

| 영역 | 적용 규칙 |
| --- | --- |
| 악보함 | 제목을 읽는 목록 기본. 검색·정렬·가져오기와 빈 상태를 명확히 구별 |
| 문서 헤더 | 제목·돌아가기·북마크/옵션. 도요가 문서 제목을 압도하지 않음 |
| 보기·주석 | 선택 모드와 입력 해석을 함께 표시. 주석 종료와 페이지 넘김 충돌 방지 |
| 연습 | 악보 밖 패널에 BPM·박자·기준음. 열고 닫아도 문서 anchor 유지 |
| 페이지 | 현재/전체 쪽수와 이전/다음. 숨긴 페이지가 있으면 원본과 표시 쪽수 구분 |
| 로딩 | 가져오기·PDF 로딩 작업에 도요+구체 문구. 같은 문서를 불필요하게 지우지 않음 |
| 다크 | UI만 전환. 문서 반전·대비 효과는 사용자가 선택하는 독립 설정 |
| 공연 | 장식·비필수 반복 모션 억제, 실수로 주석에 들어가지 않는 정책 |

폰과 태블릿은 comfortable 48 이상을 기본으로 한다. 태블릿의 220 폭 탐색 열은 제안값이며 가로 두 페이지·반 페이지·fit width 같은 기존 보기 방식을 막아서는 안 된다. 미리보기에서는 예제 악보 한 장을 3쪽처럼 반복 표시하므로 PDF 페이지 품질의 증거가 아니다.

검증할 것: 실제 파일 가져오기 성공/실패/취소, 선택했던 문서의 마지막 위치, 회전·글자 확대, 주석 저장·공유, 원본과 내보낸 사본, 기존 하드웨어 키/페달 동선. 튜너 정확도·오디오 지연·S Pen·파일 제공자는 실기기에서 별도 확인한다.

## Chromatics: 선택과 입력을 혼동하지 않기

대상은 [App.tsx](../../../src/renderer/src/App.tsx), [styles.css](../../../src/renderer/src/styles.css), [SpanProperties.tsx](../../../src/renderer/src/SpanProperties.tsx), NotationPreview와 기존 명령 상태다.

권장 구조는 문서 헤더 → 명령 그룹 → 구성/캔버스/속성 → 상태줄이다. 데스크톱 compact 32를 쓰되 터치에는 comfortable을 적용한다. 좁은 창에서는 속성을 아래로 내려 캔버스를 우선하고, 모든 기능을 모바일 앱처럼 축소해서 늘어놓지 않는다.

| 상태 | 기보 위 표시 | 주변 UI |
| --- | --- | --- |
| 선택 | 명확한 테두리·선택 범위 | 대상 이름과 해당 속성 |
| 음표 입력 | 점선 입력 caret | 입력 모드·음가·성부 |
| 재생 | 세로 재생 cursor | 재생 상태·위치·정지 명령 |
| 저장/교환 대기 | 원본 악보를 유지하고 해당 작업 영역에 도요 | 작업 이름·실패·복구 |

도구 아이콘은 기보 의미를 유지한다. 귀여운 새의 부리나 다리를 모든 음악 기호로 대신하지 않는다. 루프 로딩·장식 효과가 악보 선택과 입력 위치 위를 오가게 하지 않는다.

현재 단축키·실행 취소 명령·성부·조판 계약을 보존한다. 저장한 프로젝트, MusicXML 교환, PDF 출력은 서로 다르며 내보내기를 프로젝트 저장 완료로 간주하지 않는다. 문서에 적용되지 않는 뷰 상태·선택·로딩은 출력에 포함하지 않는다.

## 다른 제품군으로 확장

| 현재 제품 역할 | 공유하는 것 | 제품 고유 위계 |
| --- | --- | --- |
| 로컬 음악 라이브러리 | 검색·목록·피드백·도요 로딩 | 작곡가 → 작품 → 녹음 → 악장 |
| 커뮤니티 | 카드·입력·상태·읽기 타입 | 작품 대화·감상 글·광고 표기 |
| 공연 발견·홍보 | 버튼·색·타입·빈/오류 상태 | 공연 정보와 실제 신청·문의 방식 |
| Click·Chime 실험 | 숫자·단위·제어·로딩 | 실제 연습·기준음 동작, 자동 소리 없음 |

루트 README는 Click/Chime을 Clef & Staff 연습 기능 범주로 다루는 공개 방향이고, 개별 디렉터리에는 독립 앱 실험이 남아 있다. 이 시스템으로 출시 경계를 임의로 재확정하지 않는다. 다른 제품의 이름과 각 앱 아이콘 파생 규칙은 별도 결정을 남긴다.
