# C19 List / Item

설계: 현행 + 명시한 후속 목표. 구현: React 공개 구현, Flutter 공개 구현. 검증: 소스 대조; 과거 테스트 기록과 이번 문서 검증은 별개. 계층 B/C.

## 목적·구조

자료 행, 열기·선택·보조 행동.

List label/children, Item leading→title/subtitle→trailing/actions. 웹 List는 ul/li·flat, Item 단독 기본 card이며 flat opt-in도 제공한다. Flutter flat opt-in; List 안 행에 flat을 명시.

외형 프로파일: [display](../component-rules.md). 토큰 값·단위는 [F-REF](../token-reference.md). 별도 size prop이 없는 항목은 조상 density로 결정한다.

## 상태·전이·접근성

title 열기와 선택 checkbox 및 actions 독립. selected는 host. React disabled는 open/checkbox 차단+actions inert. Flutter enabled=false는 IgnorePointer/ExcludeFocus/opacity.

trailing은 제목 옆 독립 보조 행동/상태, actions는 아래의 다중 행동이다. Web은 공간 부족 시 trailing을 다음 줄로 보내며 DOM 읽기 순서를 유지한다. disabled는 leading/trailing/actions를 모두 inert로 만든다. Row 안에 전체 button과 자식 button을 중첩하지 않음. Flutter semantics 차이 실기기 확인.

Web flat disabled 행은 Flutter와 같은 0.56 opacity로 구분한다. 사용 불가 이유는 host가 subtitle 등에 함께 표시한다. 기본 카드 외형은 변경하지 않는다.

공통 입력·상태 행렬의 적용 여부는 [C-BASE](../component-rules.md)를 따른다. 지원 API 밖의 success/error/readOnly 등을 새 prop처럼 사용하지 않는다. 정적 표시의 입력·busy 상태는 N/A, 동적 자식은 각 자식 계약 적용. 긴 한국어·영문은 가변 높이를 쓰며 진단·파일 경로를 기본 접근성 이름에 넣지 않는다.

## 실제 API·기본값

React: [List](../api-react.md#List) · [Item](../api-react.md#Item)
Flutter: [DdiroriList](../api-flutter.md#DdiroriList) · [DdiroriItem](../api-flutter.md#DdiroriItem)

위 API 부록은 소스 서명·필수 인자·기본값·callback 타입을 제공한다. 값/키는 host가 소유하며 비동기 지원 여부는 각 서명을 따른다. 부록과 실제 export가 달라지면 재추출 후 계약 변경을 검토한다.

## 최소 사용·서비스 연결

React (`UI`는 `@ddirori/ui`; 아래 콜백은 배선 자리이며 앱 상태 저장을 구현하지 않는다):

```tsx
<UI.List label="악보"><UI.Item title="연습곡" subtitle="작곡가" onOpen={() => {}} /></UI.List>
```

Flutter (`material.dart`와 `ddirori_ui.dart`, context는 해당 화면 BuildContext):

```dart
DdiroriList(label: '악보', children: [DdiroriItem(title: '연습곡', subtitle: '작곡가', flat: true, onTap: () {})])
```

좋은 사용: 서비스 adapter가 표시값/가용 동작을 계산해 이 API로 전달한다. 나쁜 사용: 공통 위젯이 앱 repository/엔진을 import하거나 예제의 no-op 콜백을 실제 저장 성공으로 취급한다. [서비스 명세](../README.md)의 해당 화면 조합에 연결한다.

## 수용 조건·근거

Given 선택 모드, When 보조 메뉴 선택, Then 열기/checkbox 이벤트 발생 안 함. disabled 자식은 focus·callback 차단.

시각 검사: light/dark, 임시 강조색 교체, narrow/200% 긴 label, compact 포인터·touch 최소 영역. 수동 검사: 실제 플랫폼 입력·스크린리더. 후속 작업은 [검증](../verification.md)과 [작업 패키지](../work-packages.md)를 따른다.
