# C08 Select

설계: 현행 + 명시한 후속 목표. 구현: React 공개 구현, Flutter 네이티브 합성. 검증: 소스 대조; 과거 테스트 기록과 이번 문서 검증은 별개. 계층 B/C.

## 목적·구조

유한 목록의 단일 값. 명령 메뉴/자동완성/다중선택 아님.

Field → combobox button → top-layer listbox/options + check. 현재 popup 폭=trigger, gap4/margin8/maxHeight320, radius.control10/padding4, row density.control, label wrap. 위·아래 공간에 따라 위치 선택.

외형 프로파일: [field](../component-rules.md). 토큰 값·단위는 [F-REF](../token-reference.md). 별도 size prop이 없는 항목은 조상 density로 결정한다.

## 상태·전이·접근성

값은 host, open/active/typeahead는 내부. ↑↓/Home/End/PageUp/Down/문자 탐색은 값 미변경. Enter/Space/Tab/click 확정, Escape/trigger 재클릭/외부 click 취소. Tab은 다음 요소로 이동. disabled 옵션 건너뜀, active scrollIntoView. required hidden select가 native 검증하고 오류를 보이는 control로 연결.

공통 Select의 name/FormData/readOnly API 없음. 빈/all-disabled는 열리지 않음. 사라진 값은 — 표시하며 host가 정정. Flutter는 InputDecorator+DropdownButton native 합성이고 active/commit 정책은 동일하지 않음. unsupported Popover API fallback 없음.

공통 입력·상태 행렬의 적용 여부는 [C-BASE](../component-rules.md)를 따른다. 지원 API 밖의 success/error/readOnly 등을 새 prop처럼 사용하지 않는다. 정적 표시의 입력·busy 상태는 N/A, 동적 자식은 각 자식 계약 적용. 긴 한국어·영문은 가변 높이를 쓰며 진단·파일 경로를 기본 접근성 이름에 넣지 않는다.

## 실제 API·기본값

React: [Select](../api-react.md#Select)
Flutter: [네이티브 합성](../native-recipes.md)

위 API 부록은 소스 서명·필수 인자·기본값·callback 타입을 제공한다. 값/키는 host가 소유하며 비동기 지원 여부는 각 서명을 따른다. 부록과 실제 export가 달라지면 재추출 후 계약 변경을 검토한다.

## 최소 사용·서비스 연결

React (`UI`는 `@ddirori/ui`; 아래 콜백은 배선 자리이며 앱 상태 저장을 구현하지 않는다):

```tsx
<UI.Select label="정렬" value="recent" options={[{value:"recent",label:"최근순"}]} onChange={() => {}} />
```

Flutter (`material.dart`와 `ddirori_ui.dart`, context는 해당 화면 BuildContext):

```dart
InputDecorator(decoration: const InputDecoration(labelText: '정렬'), child: DropdownButtonHideUnderline(child: DropdownButton<String>(isExpanded: true, value: 'recent', items: const [DropdownMenuItem(value: 'recent', child: Text('최근순'))], onChanged: (_) {})))
```

좋은 사용: 서비스 adapter가 표시값/가용 동작을 계산해 이 API로 전달한다. 나쁜 사용: 공통 위젯이 앱 repository/엔진을 import하거나 예제의 no-op 콜백을 실제 저장 성공으로 취급한다. [서비스 명세](../README.md)의 해당 화면 조합에 연결한다.

## 수용 조건·근거

Given 라임 선택, When 다른 항목 탐색 후 Escape, Then 라임 유지. Tab은 active 확정 후 focus 이탈. 외부 검색창 click은 새 focus 보존. 390px/200%에서 활성 행 노출.

시각 검사: light/dark, 임시 강조색 교체, narrow/200% 긴 label, compact 포인터·touch 최소 영역. 수동 검사: 실제 플랫폼 입력·스크린리더. 후속 작업은 [검증](../verification.md)과 [작업 패키지](../work-packages.md)를 따른다.

실제 소스: [basic.tsx](../../../../../packages/ddirori_web/src/basic.tsx).
카탈로그: [React](../../../../../packages/ddirori_web/catalog/basic-set.tsx) · [Flutter](../../../../../packages/ddirori_ui/example/lib/basic_set.dart). 음악 표시 세부 예제는 각 catalog/main과 example/main도 참고한다.
