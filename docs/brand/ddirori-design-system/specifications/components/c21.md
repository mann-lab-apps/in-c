# C21 Accordion

설계: 현행 + 명시한 후속 목표. 구현: React 공개 구현, Flutter 공개 구현. 검증: 소스 대조; 과거 테스트 기록과 이번 문서 검증은 별개. 계층 B/C.

## 목적·구조

보조 정보 펼치기. 필수 오류/주 행동을 숨기지 않음.

title trigger + expanded indicator + body. border-bottom1, padding12, control min.

외형 프로파일: [display](../component-rules.md). 토큰 값·단위는 [F-REF](../token-reference.md). 별도 size prop이 없는 항목은 조상 density로 결정한다.

## 상태·전이·접근성

controlled open, React onOpenChange(!open), Flutter onChanged. native button Enter/Space. React hidden 유지, Flutter child 삽입/제거 방식 차이.

숨긴 자식 focus 불가. 외부에서 강제로 닫을 때 내부 focus 처리 검증 필요.

공통 입력·상태 행렬의 적용 여부는 [C-BASE](../component-rules.md)를 따른다. 지원 API 밖의 success/error/readOnly 등을 새 prop처럼 사용하지 않는다. 정적 표시의 입력·busy 상태는 N/A, 동적 자식은 각 자식 계약 적용. 긴 한국어·영문은 가변 높이를 쓰며 진단·파일 경로를 기본 접근성 이름에 넣지 않는다.

## 실제 API·기본값

React: [Accordion](../api-react.md#Accordion)
Flutter: [DdiroriAccordion](../api-flutter.md#DdiroriAccordion)

위 API 부록은 소스 서명·필수 인자·기본값·callback 타입을 제공한다. 값/키는 host가 소유하며 비동기 지원 여부는 각 서명을 따른다. 부록과 실제 export가 달라지면 재추출 후 계약 변경을 검토한다.

## 최소 사용·서비스 연결

React (`UI`는 `@ddirori/ui`; 아래 콜백은 배선 자리이며 앱 상태 저장을 구현하지 않는다):

```tsx
<UI.Accordion title="상세" open={false} onOpenChange={() => {}}>설명</UI.Accordion>
```

Flutter (`material.dart`와 `ddirori_ui.dart`, context는 해당 화면 BuildContext):

```dart
DdiroriAccordion(title: '상세', open: false, onChanged: (_) {}, child: const Text('설명'))
```

좋은 사용: 서비스 adapter가 표시값/가용 동작을 계산해 이 API로 전달한다. 나쁜 사용: 공통 위젯이 앱 repository/엔진을 import하거나 예제의 no-op 콜백을 실제 저장 성공으로 취급한다. [서비스 명세](../README.md)의 해당 화면 조합에 연결한다.

## 수용 조건·근거

Given closed, Then body 조작 focus 없음. Enter 후 open 요청과 expanded가 연결.

시각 검사: light/dark, 임시 강조색 교체, narrow/200% 긴 label, compact 포인터·touch 최소 영역. 수동 검사: 실제 플랫폼 입력·스크린리더. 후속 작업은 [검증](../verification.md)과 [작업 패키지](../work-packages.md)를 따른다.

실제 소스: [basic.tsx](../../../../../packages/ddirori_web/src/basic.tsx), [basic.dart](../../../../../packages/ddirori_ui/lib/src/basic.dart).
카탈로그: [React](../../../../../packages/ddirori_web/catalog/basic-set.tsx) · [Flutter](../../../../../packages/ddirori_ui/example/lib/basic_set.dart). 음악 표시 세부 예제는 각 catalog/main과 example/main도 참고한다.
