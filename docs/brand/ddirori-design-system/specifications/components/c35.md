# C35 Brand / Product / ServiceLink

설계: 현행 + 명시한 후속 목표. 구현: React 공개 구현, Flutter 공개 구현. 검증: 소스 대조; 과거 테스트 기록과 이번 문서 검증은 별개. 계층 B/C.

## 목적·구조

브랜드 식별·보조 캐릭터·제품 진입.

Mark size48/pulse false; 소형<=32 별도 좌표. Bach64/surprised 기본. Glyph32/product id. Signature glyph+name/subtitle. ServiceLink signature+명시적 action.

외형 프로파일: [display](../component-rules.md). 토큰 값·단위는 [F-REF](../token-reference.md). 별도 size prop이 없는 항목은 조상 density로 결정한다.

## 상태·전이·접근성

Mark/Glyph 장식 hidden, 이름은 Signature/host. Service availability available/external/install/unavailable에 따라 행동명; unavailable 또는 callback 없음은 차단. Flutter BachVector 표정3, 기존 Bach raster는 단일 자산.

네이밍 권고와 출시 승인을 분리. 플랫폼 아이콘 자산을 UI glyph로 임의 치환하지 않음. 로그인·동기화·딥링크 구현 없음.

공통 입력·상태 행렬의 적용 여부는 [C-BASE](../component-rules.md)를 따른다. 지원 API 밖의 success/error/readOnly 등을 새 prop처럼 사용하지 않는다. 정적 표시의 입력·busy 상태는 N/A, 동적 자식은 각 자식 계약 적용. 긴 한국어·영문은 가변 높이를 쓰며 진단·파일 경로를 기본 접근성 이름에 넣지 않는다.

## 실제 API·기본값

React: [Mark](../api-react.md#Mark) · [Bach](../api-react.md#Bach) · [ProductGlyph](../api-react.md#ProductGlyph) · [ProductSignature](../api-react.md#ProductSignature) · [ServiceLink](../api-react.md#ServiceLink)
Flutter: [DdiroriMark](../api-flutter.md#DdiroriMark) · [DdiroriBach](../api-flutter.md#DdiroriBach) · [DdiroriBachVector](../api-flutter.md#DdiroriBachVector) · [DdiroriProductGlyph](../api-flutter.md#DdiroriProductGlyph) · [DdiroriProductSignature](../api-flutter.md#DdiroriProductSignature) · [DdiroriServiceLink](../api-flutter.md#DdiroriServiceLink)

위 API 부록은 소스 서명·필수 인자·기본값·callback 타입을 제공한다. 값/키는 host가 소유하며 비동기 지원 여부는 각 서명을 따른다. 부록과 실제 export가 달라지면 재추출 후 계약 변경을 검토한다.

## 최소 사용·서비스 연결

React (`UI`는 `@ddirori/ui`; 아래 콜백은 배선 자리이며 앱 상태 저장을 구현하지 않는다):

```tsx
<UI.ServiceLink product="score" name="띠로리 스코어" description="악보와 연습" availability="unavailable" />
```

Flutter (`material.dart`와 `ddirori_ui.dart`, context는 해당 화면 BuildContext):

```dart
const DdiroriProductSignature(product: DdiroriProduct.score, name: '띠로리 스코어', subtitle: '악보와 연습')
```

좋은 사용: 서비스 adapter가 표시값/가용 동작을 계산해 이 API로 전달한다. 나쁜 사용: 공통 위젯이 앱 repository/엔진을 import하거나 예제의 no-op 콜백을 실제 저장 성공으로 취급한다. [서비스 명세](../README.md)의 해당 화면 조합에 연결한다.

## 수용 조건·근거

Given unavailable, Then 연결 준비 중과 disabled. reduced motion에서 Mark pulse 정지. 제품명 없이 심벌만으로 서비스 구분하지 않음.

시각 검사: light/dark, 임시 강조색 교체, narrow/200% 긴 label, compact 포인터·touch 최소 영역. 수동 검사: 실제 플랫폼 입력·스크린리더. 후속 작업은 [검증](../verification.md)과 [작업 패키지](../work-packages.md)를 따른다.
