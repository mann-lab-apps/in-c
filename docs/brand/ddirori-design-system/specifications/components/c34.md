# C34 Settings / Metrics

설계: 현행 + 명시한 후속 목표. 구현: React 공개 구현, Flutter 공개 구현. 검증: 소스 대조; 과거 테스트 기록과 이번 문서 검증은 별개. 계층 B/C.

## 목적·구조

설정 label과 조작/읽기 수치 요약.

Settings label+description→children; 웹2열/좁은1열/gap20/padding12. Metrics label/value/icon, group minItemWidth 기본132.

외형 프로파일: [layout](../component-rules.md). 토큰 값·단위는 [F-REF](../token-reference.md). 별도 size prop이 없는 항목은 조상 density로 결정한다.

## 상태·전이·접근성

단위·집계·저장은 host, 정적 metric에 live region 기본 없음. child input은 독립 accessible label 필요.

SettingsRow label만으로 자식 input association 자동 아님. React Metric 전용 API 없음, Text/Stack 합성.

공통 입력·상태 행렬의 적용 여부는 [C-BASE](../component-rules.md)를 따른다. 지원 API 밖의 success/error/readOnly 등을 새 prop처럼 사용하지 않는다. 정적 표시의 입력·busy 상태는 N/A, 동적 자식은 각 자식 계약 적용. 긴 한국어·영문은 가변 높이를 쓰며 진단·파일 경로를 기본 접근성 이름에 넣지 않는다.

## 실제 API·기본값

React: [SettingsRow](../api-react.md#SettingsRow)
Flutter: [DdiroriSettingsRow](../api-flutter.md#DdiroriSettingsRow) · [DdiroriMetric](../api-flutter.md#DdiroriMetric) · [DdiroriMetricGroup](../api-flutter.md#DdiroriMetricGroup) · [DdiroriMetricData](../api-flutter.md#DdiroriMetricData)

위 API 부록은 소스 서명·필수 인자·기본값·callback 타입을 제공한다. 값/키는 host가 소유하며 비동기 지원 여부는 각 서명을 따른다. 부록과 실제 export가 달라지면 재추출 후 계약 변경을 검토한다.

## 최소 사용·서비스 연결

React (`UI`는 `@ddirori/ui`; 아래 콜백은 배선 자리이며 앱 상태 저장을 구현하지 않는다):

```tsx
<UI.SettingsRow label="음량"><UI.Slider label="음량" value={50} onChange={() => {}} /></UI.SettingsRow>
```

Flutter (`material.dart`와 `ddirori_ui.dart`, context는 해당 화면 BuildContext):

```dart
const DdiroriMetricGroup(metrics: [DdiroriMetricData(label: '악보', value: '12개')])
```

좋은 사용: 서비스 adapter가 표시값/가용 동작을 계산해 이 API로 전달한다. 나쁜 사용: 공통 위젯이 앱 repository/엔진을 import하거나 예제의 no-op 콜백을 실제 저장 성공으로 취급한다. [서비스 명세](../README.md)의 해당 화면 조합에 연결한다.

## 수용 조건·근거

Given 200%/좁은 폭, Then 수치·단위·label이 모두 읽힘.

시각 검사: light/dark, 임시 강조색 교체, narrow/200% 긴 label, compact 포인터·touch 최소 영역. 수동 검사: 실제 플랫폼 입력·스크린리더. 후속 작업은 [검증](../verification.md)과 [작업 패키지](../work-packages.md)를 따른다.

실제 소스: [index.tsx](../../../../../packages/ddirori_web/src/index.tsx), [components.dart](../../../../../packages/ddirori_ui/lib/src/components.dart).
카탈로그: [React](../../../../../packages/ddirori_web/catalog/basic-set.tsx) · [Flutter](../../../../../packages/ddirori_ui/example/lib/basic_set.dart). 음악 표시 세부 예제는 각 catalog/main과 example/main도 참고한다.
