# C37 AnnotationTools

설계: 현행 + 명시한 후속 목표. 구현: React 합성 recipe (전용 API 없음), Flutter 공개 구현. 검증: 소스 대조; 과거 테스트 기록과 이번 문서 검증은 별개. 계층 B/C.

## 목적·구조

기존 공통 주석 도구 표시 조합. 좌표/저장 모델 없음.

tool pen/highlight/erase, score색4개, width2/4/7, undo/redo nullable. Toolbar+Choices+IconButton. React는 같은 primitives 조합 recipe.

외형 프로파일: [music](../component-rules.md). 토큰 값·단위는 [F-REF](../token-reference.md). 별도 size prop이 없는 항목은 조상 density로 결정한다.

## 상태·전이·접근성

값과 callback은 host 소유. empty choice는 무시해 현재 tool/width 유지. 저장된 색은 UI theme와 독립.

실제 Score의 text annotation·추가 도구 전부를 이 API가 지원하지 않음. 기능을 줄여 이 위젯에 맞추지 않음.

공통 입력·상태 행렬의 적용 여부는 [C-BASE](../component-rules.md)를 따른다. 지원 API 밖의 success/error/readOnly 등을 새 prop처럼 사용하지 않는다. 정적 표시의 입력·busy 상태는 N/A, 동적 자식은 각 자식 계약 적용. 긴 한국어·영문은 가변 높이를 쓰며 진단·파일 경로를 기본 접근성 이름에 넣지 않는다.

## 실제 API·기본값

React: 이 항목 전용 공개 API 없음; 아래 합성 예제.
Flutter: [DdiroriAnnotationTools](../api-flutter.md#DdiroriAnnotationTools)

위 API 부록은 소스 서명·필수 인자·기본값·callback 타입을 제공한다. 값/키는 host가 소유하며 비동기 지원 여부는 각 서명을 따른다. 부록과 실제 export가 달라지면 재추출 후 계약 변경을 검토한다.

## 최소 사용·서비스 연결

React (`UI`는 `@ddirori/ui`; 아래 콜백은 배선 자리이며 앱 상태 저장을 구현하지 않는다):

```tsx
<UI.Toolbar label="주석"><UI.Choices label="도구" options={[{value:"pen",label:"펜"}]} selected={["pen"]} onChange={() => {}} /></UI.Toolbar>
```

Flutter (`material.dart`와 `ddirori_ui.dart`, context는 해당 화면 BuildContext):

```dart
DdiroriAnnotationTools(tool: 'pen', onToolChanged: (_) {}, color: const Color(0xFF111111), onColorChanged: (_) {}, width: 4, onWidthChanged: (_) {})
```

좋은 사용: 서비스 adapter가 표시값/가용 동작을 계산해 이 API로 전달한다. 나쁜 사용: 공통 위젯이 앱 repository/엔진을 import하거나 예제의 no-op 콜백을 실제 저장 성공으로 취급한다. [서비스 명세](../README.md)의 해당 화면 조합에 연결한다.

## 수용 조건·근거

Given theme 변경, Then 기존 stroke 색/굵기 불변. undo 불가이면 command 없음.

시각 검사: light/dark, 임시 강조색 교체, narrow/200% 긴 label, compact 포인터·touch 최소 영역. 수동 검사: 실제 플랫폼 입력·스크린리더. 후속 작업은 [검증](../verification.md)과 [작업 패키지](../work-packages.md)를 따른다.

실제 소스: [music.dart](../../../../../packages/ddirori_ui/lib/src/music.dart).
카탈로그: [React](../../../../../packages/ddirori_web/catalog/basic-set.tsx) · [Flutter](../../../../../packages/ddirori_ui/example/lib/basic_set.dart). 음악 표시 세부 예제는 각 catalog/main과 example/main도 참고한다.

## 기존 테스트 연결

이 계약의 심벌을 직접 참조하는 패키지 테스트를 찾지 못했다. 네이티브 합성·간접 테스트는 카탈로그와 앱 검증에서 별도 확인한다.

이 링크는 심벌 참조 기준이다. 개별 테스트의 assertion 범위와 위 수용 조건을 비교하고 빠진 조건을 후속 작업에 추가한다. 이번 작업에서 기존 제품 테스트를 재실행한 결과가 아니다.
