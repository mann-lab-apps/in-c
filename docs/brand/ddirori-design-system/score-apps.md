# 악보와 사보에 적용하는 패턴

## 악보함

Search → 정렬/필터 Toolbar → 최근 항목 → 목록/그리드 → 빈 상태 순으로 정리한다. 라이브러리 controller의 query와 필터를 adapter에서 연결한다. 다중 선택, 즐겨찾기, 열기는 각각 독립된 행동이다.

작품명·작곡가·컬렉션·페이지 등 실제 metadata는 앱에서 제공한다. 카탈로그 샘플은 제품 데이터를 읽지 않는다. 긴 한국어 제목과 글자 확대에서 카드 높이가 늘어날 수 있게 한다.

## 악보 보기와 공연 모드

문서 지면은 UI 테마와 분리한다. 주석 Toolbar와 PageControls는 문서 주변 영역에 배치한다. 공연 모드는 주석·메타정보를 숨기고 큰 페이지 조작만 남긴다. 페달·하드웨어 입력 매핑과 자동 스크롤 시간은 기존 controller에 남긴다.

카탈로그의 오선·음표는 직접 그린 자리 영역이다. PDF 렌더링·좌표·내보내기 정확성을 증명하는 자료가 아니다. 실제 제품 이행에서는 주석 좌표·확대·회전·링크 정책과 저장 결과를 별도로 회귀 확인한다.

## 연습 도구

BPM·박자·시작/정지는 숫자 조절과 BeatIndicator를 조합한다. Tap 추정·실제 오디오 시계는 기존 엔진의 입력이다. UI의 tick을 소리의 시간 원본으로 사용하지 않는다.

튜너는 낮음·정확·높음·신호 없음·낮은 신뢰도를 별도로 받는다. cents는 위치와 숫자로 표시하고 상태는 글자·기호로도 전달한다. 입력 파워·줄 목표·프로필 선택은 같은 설정 행과 선택 그룹으로 합성한다. 측정 preset·A4 보정·noise floor는 앱의 책임이다.

현재 Flutter와 웹 예제는 실제 마이크·오디오를 사용하지 않는다. 메트로놈의 다음 박은 수동 데모이며 실제 정확도·지연 검증과 구분한다.

## 사보 작업 공간

Chromatics의 도구 분류, 선택 속성, 팔레트/속성 dock 구조를 참고한다. 공통 토큰은 도구·패널·입력·포커스에 적용하고, NotationPreview의 음악 렌더링은 유지한다.

compact는 조작 그룹 사이 간격과 포인터 컨트롤을 줄인다. 성부 선택·편집 컨텍스트·실행 불가를 명확히 보여준다. 좁은 화면에서는 속성 패널을 아래로 보내고 도구 그룹은 줄바꿈한다. 현재 예제는 자유 dock 이동이나 사보 명령을 구현하지 않는다.

기존 단축키, 선택 범위, span endpoint, undo/redo, native 저장과 MusicXML 계약은 디자인 이행과 별개로 보존한다. 음표·성부·재생 위치의 의미색은 별도 score 토큰과 앱 규칙을 따른다.

## 다른 제품

플레이는 같은 Item에 작품/녹음 metadata를 넣고 Transport를 합성한다. 커뮤니티·공연은 제목·보조 정보·보조 행동의 구성만 바꾼다. 광고 표기와 개인 정보 상태를 친근한 브랜드 장식으로 흐리지 않는다.

어느 제품이 음형 또는 바흐 아이콘을 쓸지는 앱별 식별성 검토 뒤 정한다.


현재 토큰·상태·제품 적용 경계는 [시스템 감사](system-review.md)와 [구축 계약](component-contracts.md)을 따른다. [초기 라임 반복](refresh-2026-10-23.md)은 과거 이력이다.
