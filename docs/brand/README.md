# 음악 제품군 브랜드 작업

> 2026-10-23 후속 적용: 라임 `#D5ED70` 대표색·올리브 `#52651A` 행동색을 로컬 시범 권고안으로 적용했다. 최종 브랜드 승인은 대기 중이다. [현재 팔레트·적용 범위·재생성 기준](ddirori-design-system/refresh-2026-10-23.md)을 우선한다. 기존 파랑 설명은 이전 선택 이력이다.

모브랜드 표기는 **띠로리 / Ddirori**이며, 코드·경로에는 `ddirori`를 사용한다 (2026-10-22 사용자 확정).

현재 시범 적용색은 **파랑 `#0077C8`**, 보조색은 하늘색 `#A8D4E5`다. 2026-10-23 사용자 요청으로 대표색과 전체 팔레트를 다시 열어두었다. 다음 디자인은 **카카오·네이버의 서비스 연계 / 당근의 심플한 귀여움 / 별도 서비스의 색상 전략**을 분리해 참고한다. 색상은 Wise를 주 레퍼런스로 권고하며 최종 색조는 미정이다.

단순한 바흐 얼굴형은 승인되었고, 음형은 64분·64분·점32분이다. 맨 위만 짧은 연결선과 끝까지 내린 기둥이 현재 음형 구조다. 도요새는 현재 브랜드에서 제외한다. 플레이와 스코어(이전 Clef & Staff)는 로컬 시범 적용했으며 공개 스토어는 변경하지 않았다.

- [다음 디자인의 레퍼런스와 팔레트 검토](ddirori-brand-system/reference-direction.md): 세 축의 선정, Wise·Monzo·Mailchimp 비교, 기존 파랑과 후속 후보의 상태 구분.
- [현재 브랜드 운영 체계](ddirori-brand-system/README.md) · [전체 검토 화면](ddirori-brand-system/index.html): 제품명, 제작용 원본, 아이콘 배치·문체·모션과 실제 두 앱의 적용 결과.
- [현재 띠로리 시각 기준](ddirori-visuals/README.md): 승인 이력과 머리·기둥 접점을 맞춘 음형, 놀란 바흐, 파랑·하늘색·살구색 기준 팔레트와 밝은 화면 토큰. 다크 파생값은 검토안이다.

- [띠로리 공통 디자인 시스템](ddirori-design-system/README.md): Flutter 패키지, React 참조 구현, 토큰과 실행 카탈로그. 제품 앱 전체 이행은 별도다.

기존 [도요 디자인 시스템](doyo-design-system/README.md), [도요 시각화](doyo-visuals/README.md), [기러기 디자인 시스템](gireogi-design-system/README.md)은 탐색 기록이다. 이전 동물 로고·로딩을 띠로리의 현재 적용 기준으로 가져오지 않는다. 새 공통 기반은 띠로리 디자인 시스템을 따르고, 실제 제품 화면은 도입 계획에 따라 단계적으로 이행한다.

그 밖의 기존 in C 문서는 현재 제품의 구현·언어 기록이다. 브랜드 탐색 시안만으로 출시 이름·패키지·배포 메타데이터를 변경했다고 간주하지 않는다.
