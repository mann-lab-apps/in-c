기기에 보관하는 데이터

음원 관리 사본, 파일 정보와 경로, 메타데이터 교정과 출처, 작곡가·작품 연결, 재생목록·즐겨찾기, 재생 위치·감상 이력을 기기에 저장합니다. 원본 음원과 태그를 수정하지 않습니다. 앱에 회원가입·광고·분석 SDK·자체 클라우드 업로드 기능은 없습니다.

사용자가 선택하는 외부 연결

MusicBrainz와 IMSLP 검색은 사용자가 실행합니다. 검색어와 확인한 식별자 등이 해당 서비스로 전달되며 원본 음원과 전체 로컬 경로는 검색 요청에 포함하지 않습니다. 외부 서비스는 요청 처리 과정에서 IP 주소 등 통신 정보를 처리할 수 있습니다. 공식 사이트를 열면 해당 사이트의 개인정보·이용 조건이 적용됩니다. 검색 결과를 사용자 확인 없이 교정값이나 파일 다운로드로 확정하지 않습니다. AcoustID 지문 서비스는 현재 비활성 상태입니다.

백업과 공유

논리 백업에는 카탈로그·교정·출처·파일 ID·재생목록·감상 기록 등이 포함됩니다. 음원 내용과 원래 파일·폴더 경로는 포함하지 않으므로 다른 설치에서 복원한 뒤 음원을 다시 연결해야 합니다. 백업의 곡 정보나 감상 기록은 개인 정보일 수 있으므로 공유 대상을 확인해 주세요.

음원 내보내기와 진단 공유는 사용자가 선택합니다. 자동으로 개인 음원·파일명·경로·고유 기기 식별자를 수집해 전송하지 않습니다. 파일 앱·메일·다른 공유 대상의 보관과 처리는 사용자가 선택한 서비스의 조건을 따릅니다.

보관과 삭제

기기 내 자료는 사용자가 삭제하거나 앱의 전체 로컬 데이터 초기화를 실행할 때까지 보관됩니다. 초기화는 앱 관리 사본과 내부 데이터를 삭제하고 외부 원본은 유지합니다. 이미 내보내거나 공유한 백업·파일은 삭제하지 않으므로 해당 위치에서 별도로 관리해 주세요. OS와 파일 제공자의 백업·보관 정책은 별개입니다.

문의 정보와 삭제 요청

이메일 문의를 보내면 이메일 주소와 사용자가 적은 내용은 답변과 문제 해결에 사용됩니다. 개인 음원·경로·비밀번호를 보낼 필요가 없습니다. 문의 정보는 답변과 문제 해결에 필요한 동안 보관하며, 삭제 요청은 아래 연락처로 접수합니다. 기기에만 있는 자료는 만랩이 원격으로 열람하거나 삭제할 수 없으므로 앱에서 직접 관리해 주세요.

웹사이트 안내와 방침 변경

앱의 데이터 처리와 소개 웹사이트의 방문 분석은 별개입니다. 웹사이트의 분석·쿠키 안내는 웹사이트 개인정보 안내에서 확인할 수 있습니다. 앱의 데이터 처리나 이 방침이 바뀌면 이 페이지에 변경 내용과 시행일을 안내합니다.
