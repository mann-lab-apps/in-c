MusicXML 악보 열기와 PDF 저장

띠로리 Studio에서 MusicXML이나 MXL 악보를 열고, 편집한 총보를 PDF로 저장할 수 있습니다. 아래의 플루트·첼로 4마디 예제로 가져오기와 출력 결과를 비교해 보세요.

확인한 환경은 macOS용 띠로리 Studio 0.1.0-alpha.43입니다.

띠로리 Studio 다운로드 예제 MusicXML 받기

MusicXML 악보를 여는 방법

  1. 예제 파일 walking-duet.musicxml을 내려받습니다.
  2. Studio 시작 화면에서 MusicXML 가져오기를 누릅니다. 이미 악보를 열어 둔 경우에는 파일 → MusicXML 가져오기를 사용합니다.
  3. 파일을 고른 뒤 제목 나란히 걷는 선율과 플루트·첼로 두 파트가 표시되는지 확인합니다.

총보를 PDF로 저장하는 방법

  1. 보기 → 총보·파트보 보기에서 총보를 선택합니다.
  2. 파일 → 내보내기 설정 → PDF 변환을 누르고 새 파일 이름으로 저장합니다.
  3. 저장한 PDF를 열어 플루트와 첼로가 모두 보이는지 확인합니다. 아래 예제 결과는 A4 한 장입니다.

가져온 악보가 원본과 다르게 보일 때

MusicXML은 악보를 교환하는 형식입니다. 마디 폭과 줄바꿈은 Studio에서 다시 배치될 수 있습니다. 가져오기 경고가 있으면 표시된 파트와 마디를 원본과 비교하세요. 이어서 편집할 작업은 Studio 프로젝트로 따로 보관할 수 있습니다.

연주자에게 한 파트만 보낼 때는 총보에서 파트보 PDF 만들기를 따라가세요.
