Analytics

Google Analytics 사용

in C는 공개 사이트의 페이지 조회, 다운로드 클릭, Columns 읽기 완료, Chromatics 열기와 같은 제품 개선용 이벤트를 Google Analytics 4로 확인합니다. 이벤트 payload에는 공개 콘텐츠 제목, slug, 난이도, 파일명, 클릭 위치처럼 사이트 화면에 이미 드러나는 정보만 보냅니다.

이메일, 이름, 전화번호, 주소, 계정 ID, 앱 내부 악보 편집 내용은 사이트 analytics 이벤트로 보내지 않습니다. analytics가 비활성화되거나 로드에 실패해도 페이지 탐색과 다운로드 링크는 그대로 동작해야 합니다.

Feedback

피드백과 문의

Columns 피드백 UI는 자유 텍스트가 아니라 미리 정한 선택지 값만 전송합니다. 공개 문의와 버그 제보 채널은 계정·결제·커뮤니티 기능을 열기 전에 별도로 고지합니다.

클래식 연주회 홍보 관심 등록 폼은 신청자 이름, 전화, 이메일, 인스타 ID, 역할, 현재 상황, 선택 항목, 비고를 저장합니다. 이 정보는 공개 사이트에서 조회할 수 없고, 관심 확인과 후속 연락 목적으로만 사용합니다. Google Analytics에는 역할, 연주회 준비 상태, 선택 항목 개수처럼 개인을 직접 식별하지 않는 값만 보냅니다.

무료 음악 도구 제안 폼은 제안자 이름, 전화, 이메일, 인스타 ID, 역할, 활동 맥락, 문제 빈도, 반복 문제 설명, 현재 해결 방식, 희망 도구 형태, 함께 쓸 사람 범위를 저장합니다. 이 정보는 공개 웹도구 선정 검토와 후속 연락 목적으로만 사용하며, 공개 도구로 제작되는 경우에도 개인 연락처는 공개하지 않습니다.

in C - Click 모바일 앱은 계정, 결제, 광고, 마이크, 파일, 위치, 알림 권한을 사용하지 않으며 앱 내부에서 개인정보를 수집하지 않습니다. BPM, 박자, 첫 박 강조 같은 설정은 기기 안에만 저장합니다. 앱 상단의 기능 제안 링크를 통해 웹 폼을 제출하는 경우에는 이 문서의 무료 음악 도구 제안 폼 고지가 적용됩니다.

제보에는 재현 순서, 사용한 운영체제, 앱 버전, 화면 캡처처럼 문제를 확인하는 데 필요한 정보만 남겨 주세요. 개인 연락처, 민감한 악보, 비공개 파일은 공개 채널에 올리지 않는 것을 권장합니다.
