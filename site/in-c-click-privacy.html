in C - Click 개인정보 처리방침

이 문서는 mann-lab-apps가 제공하는 모바일 메트로놈 앱 in C - Click에 적용됩니다. 시행일은 2026년 8월 17일입니다.

App Data

앱 내부 개인정보 수집 여부

in C - Click 앱은 회원가입, 로그인, 결제, 광고, 마이크, 파일, 위치, 연락처, 사진, 알림 권한을 사용하지 않습니다. 앱 내부에서 이름, 이메일, 전화번호, 위치정보, 기기 식별자, 연습 내용과 같은 개인정보를 수집하거나 외부 서버로 전송하지 않습니다.

앱은 메트로놈 사용 편의를 위해 BPM, 박자, 첫 박 강조 여부 같은 설정을 사용자의 기기 안에만 저장합니다. 이 설정은 앱을 삭제하거나 기기 설정을 초기화하면 함께 삭제됩니다.

Feature Request

기능 제안 웹 폼

앱 상단의 기능 제안 배너를 누르면 외부 브라우저에서 in C 웹사이트의 기능 제안 폼이 열릴 수 있습니다. 사용자가 이 웹 폼을 직접 제출하는 경우에만 다음 정보가 저장됩니다.

수집 항목은 이름, 전화, 이메일, 인스타 ID, 역할, 활동 맥락, 문제 빈도, 반복 문제 설명, 현재 해결 방식, 희망 도구 형태, 함께 쓸 사람 범위, 동의 체크 여부, 유입 경로입니다. 전화, 이메일, 인스타 ID 중 하나 이상은 후속 연락을 위해 필요합니다.

이 정보는 기능 제안 검토, 공개 도구 후보 선정, 후속 연락 목적으로만 사용합니다. 공개 도구로 제작되는 경우에도 개인 연락처와 원문 제안 내용은 공개하지 않습니다.

Retention

보관 기간과 삭제 요청

앱 내부 설정은 사용자의 기기에만 보관됩니다. 기능 제안 웹 폼으로 접수된 정보는 제안 검토와 후속 연락 목적이 달성된 뒤 삭제하거나, 사용자의 삭제 요청이 있을 때 확인 후 삭제합니다.

삭제 또는 문의가 필요한 경우 아래 문의처로 연락해 주세요. 본인 확인과 접수 내역 확인에 필요한 최소 정보만 요청할 수 있습니다.

Third Parties

외부 서비스 이용

앱 자체에는 광고 SDK나 analytics SDK를 넣지 않습니다. 다만 기능 제안 웹 폼은 in C 웹사이트에서 동작하며, 폼 저장과 운영 확인을 위해 Supabase를 사용할 수 있습니다. 웹사이트의 페이지 조회와 링크 클릭 같은 제품 개선용 이벤트는 Google Analytics 4로 확인할 수 있습니다.

웹 analytics 이벤트에는 자유 입력 원문, 연락처, 이름을 보내지 않도록 설계합니다. 웹사이트 전체 운영 고지는 개인정보·문의·운영 고지에서 확인할 수 있습니다.

변경 고지
